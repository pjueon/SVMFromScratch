6장 · 화면 1

커널 트릭

5장의 소프트 마진은 이상치 몇 개가 끼어도 직선을 지켜 냈습니다. 그런데 직선이라는 틀 자체가 맞지 않는 데이터가 있습니다. 5장 화면 3 의 한계 상자에서 “점이 원형으로 안팎을 둘러싼 데이터는 C 를 어떻게 정해도 고쳐지지 않는다”고 미뤄 둔 것, 1장 화면 4 에서 처음 던진 질문이 이 장의 출발점입니다. 이 화면에서는 그런 데이터를 하나 만들고, 직선이 왜 안 되는지 5장에서 쓴 방법 그대로 확인합니다.

이 장의 데이터

점 12개입니다. 안쪽에 파란 점(+1) 6개가 모여 있고, 그 둘레를 빨간 점(−1) 6개가 고리처럼 둘러쌉니다. 5장까지는 좌표가 0 에서 6 까지였지만 이 장에서는 원점 (0, 0) 이 데이터의 한가운데이고 좌표는 −3 에서 3 까지입니다.

직선으로는 왜 안 갈리나

그림의 직선 두 개는 틀리는 점이 있습니다. 직선 가는 x₁ < 1.1 쪽을 +1 로 보면 바깥 점 x⁽⁸⁾, x⁽¹⁰⁾, x⁽¹¹⁾ 세 개를 틀리게 두고, 직선 나는 x₂ < 0.5 쪽을 +1 로 보면 다섯 개(x⁽⁶⁾, x⁽⁷⁾, x⁽⁸⁾, x⁽¹¹⁾, x⁽¹²⁾)를 틀립니다. 다른 직선을 찾아도 같을까요? 5장 화면 1 (가) 에서 쓴 “섞기” 논법으로 확인합니다. x⁽⁷⁾ 과 x⁽⁸⁾ 는 원점을 가운데 두고 정반대에 놓여 있고, 그 가운데가 안쪽 점 x⁽¹⁾ 입니다.

줄식왜 이렇게 되는지
1x⁽¹⁾ = ½ x⁽⁷⁾ + ½ x⁽⁸⁾½(2.2, 0.4) + ½(−2.2, −0.4) = (0, 0) 입니다.
2f(x⁽¹⁾) = ½ f(x⁽⁷⁾) + ½ f(x⁽⁸⁾)f(x) = w·x + b 이고 ½ + ½ = 1 이라 b 도 같은 비율로 섞입니다. 어떤 (w, b) 에서도 성립합니다.
3f(x⁽⁷⁾) < 0, f(x⁽⁸⁾) < 0 이므로 오른쪽 < 0직선이 두 점을 모두 맞게 가르려면, −1 점이니 f 가 음수여야 합니다.
4그런데 x⁽¹⁾ 은 +1 점이라 f(x⁽¹⁾) > 02 줄에 의해 왼쪽은 양수, 오른쪽은 음수여야 하니 동시에 만족할 수 없습니다.

소프트 마진도 같은 식에서 막힙니다. 점마다 ξ⁽ⁱ⁾ ≥ 1 − y⁽ⁱ⁾f(x⁽ⁱ⁾) 이니 ξ⁽¹⁾ ≥ 1 − f(x⁽¹⁾), ξ⁽⁷⁾ ≥ 1 + f(x⁽⁷⁾), ξ⁽⁸⁾ ≥ 1 + f(x⁽⁸⁾) 입니다. 1 : ½ : ½ 의 비율로 더하면 ξ⁽¹⁾ + ½ξ⁽⁷⁾ + ½ξ⁽⁸⁾ ≥ 2 + (½f(x⁽⁷⁾) + ½f(x⁽⁸⁾) − f(x⁽¹⁾)) = 2 이고, 계수가 모두 1 이하이니 Σξ ≥ 2 입니다. 어떤 직선을 골라도, C 를 얼마로 키워도 침범의 합은 2 아래로 내려가지 않습니다. 5장에서 하드 마진으로 “돌아갈 곳”이 있었던 것과 달리 여기는 돌아갈 곳이 없습니다. 12 점의 가능한 갈림을 전부 따져 보면(컴퓨터로 확인) 틀리는 점이 3 개보다 적은 직선은 하나도 없습니다. 위의 직선 가가 그 최선입니다.

이상치가 아니라 모양의 문제입니다

5장의 이상치는 “점 몇 개만 규칙에서 벗어난” 경우였고, 그래서 그 점의 침범을 싸게 만들면(작은 C) 직선이 살아났습니다. 이 데이터는 점 하나도 잡음이 아닙니다. 12 점 모두 규칙을 지키고 있는데 규칙의 모양이 원이라서, 직선이라는 도구가 맞지 않습니다. C 로 조절할 수 있는 것은 “어느 점을 포기할까” 뿐입니다.

그렇다면 요구사항은 이렇게 바뀝니다. 직선이 아니라 원 같은 곡선으로 가를 수 있어야 하고, 그러면서 지금까지 만든 쌍대문제의 틀(마진, 서포트 벡터, C)은 그대로 쓰고 싶다. 다음 화면에서 그 방법의 아이디어를 봅니다.

이 장의 진행

  1. 직선으로는 안 갈리는 원형 데이터를 확인한다 (이 화면).
  2. 점에 좌표 하나를 더 붙여 “차원을 올리면” 갈린다는 것을 본다 (화면 2, 위젯).
  3. 올리는 일을 직접 하면 얼마나 비싼지 센다 (화면 3).
  4. 쌍대문제에 데이터가 내적으로만 들어 있다는 사실로 그 비용을 없앤다 (화면 4~5).
  5. 대표적인 선택지와 그 조절 장치를 위젯으로 확인한다 (화면 6).
  6. 아무 함수나 되는 것은 아니라는 조건과 한계를 본다 (화면 7).

6장 · 화면 2

아이디어 — 차원을 하나 올리면 갈린다

화면 1 의 데이터를 다시 보면 레이블을 정하는 것은 원점에서 얼마나 먼가입니다. 안쪽 점은 원점 가까이, 바깥 점은 멀리 있습니다. 원점까지의 거리는 좌표 둘로 계산되는 값이니, 그 값을 새 좌표 하나로 만들어 점에 붙여 봅시다. 피타고라스 정리에 따라 점 (x₁, x₂) 의 원점까지 거리의 제곱은 x₁² + x₂² 이고, 이것을 z 라 부릅니다(제곱근을 안 씌우는 이유는 뒤에서 나옵니다).

(x₁, x₂)  →  (x₁, x₂, z),    z = x₁² + x₂²

평면 위의 점이 높이 z 를 얻어 3차원 공간의 점이 됩니다. 12 점의 z 를 계산하면 이렇습니다(예: x⁽⁵⁾ = (−1, 0.4) 는 1 + 0.16 = 1.16).

레이블z = x₁² + x₂² (점 번호 순서)범위
+1 (안쪽, x⁽¹⁾~x⁽⁶⁾)0, 0.9, 0.89, 0.72, 1.16, 1.09모두 1.16 이하
−1 (바깥, x⁽⁷⁾~x⁽¹²⁾)5, 5, 6.28, 6.29, 5.48, 5.8모두 5 이상

안쪽 점은 모두 낮고 바깥 점은 모두 높습니다. 1.16 과 5 사이에 아무 높이나 하나 고르면(예: z = 3) 수평한 평면 하나가 두 무리를 가릅니다. 1장 화면 2 에서 초평면은 3차원에서는 평면이라고 했습니다. SVM 이 하는 일, 곧 초평면으로 가르는 일은 3차원에서도 똑같습니다. 새 공간의 점 p = (x₁, x₂, z) 에서 이 평면은 w = (0, 0, −1), b = c, 곧 f(p) = w·p + b = c − z 이고 안쪽(+1)이 f > 0 입니다(c 는 평면의 높이).

3차원의 평면은 2차원에서는 원입니다

c − z = 0 인 점들은 x₁² + x₂² = c 를 만족합니다. 원점 중심, 반지름 √c 인 원입니다. 곧 3차원에서 평면으로 가른 것을 원래의 평면으로 되돌리면 원으로 가른 것이 됩니다. 직선으로는 안 되던 일을, 직선 하나(3차원에서는 평면 하나)로 해결했습니다.

원의 중심이 원점이 아니어도 될까요

중심이 (a, b), 반지름이 r 인 원은 (x₁ − a)² + (x₂ − b)² = r², 전개해서 정리하면 x₁² + x₂² = 2a·x₁ + 2b·x₂ + (r² − a² − b²) 입니다. 왼쪽이 z 이니 z = 2a·x₁ + 2b·x₂ + (상수), 곧 (x₁, x₂, z) 세 좌표에 대한 평면입니다. 그래서 새 좌표로 z 만 남기지 않고 x₁, x₂ 도 함께 두는 것이 안전합니다(화면 3).

한계 — 수평 평면이 곧 SVM 의 답은 아닙니다

위젯은 수평한 평면만 보여 줍니다. 1.16 과 5 사이의 어느 높이든 갈리지만, SVM 은 그중에서도 마진이 가장 넓은 평면을 고릅니다. 그 평면이 수평이라는 보장은 없습니다. 이 화면에서 확인한 것은 “3차원에서는 평면으로 가를 수 있다”는 사실까지입니다. 그리고 z = x₁² + x₂² 는 이 데이터가 원형이라는 것을 알고 있기에 고른 것입니다. 모양을 모르는 데이터에서는 어떤 좌표를 더해야 할지부터가 문제입니다. 화면 3 에서 그 이야기를 이어 갑니다.

6장 · 화면 3

특징 맵 φ — 올리는 일에 이름을 붙이고, 값을 센다

화면 2 에서 한 일은 점 하나를 받아 새 좌표 묶음으로 바꾸는 규칙이었습니다. 이 규칙에 이름과 기호를 붙입니다.

정의 — 특징 맵 φ

φ(x₁, x₂) = (x₁, x₂, x₁² + x₂²)

  • φ (파이) — 점 x 를 받아 새 좌표 묶음 φ(x) 를 내놓는 함수. 이 이름이 특징 맵(feature map)입니다. 위의 예는 2차원 점을 3차원 점으로 바꿉니다.
  • 특징 공간 — φ(x) 들이 놓이는 공간. 원래 점이 사는 공간(입력 공간)과 구분하려는 이름입니다.
  • 1장에서 특성은 점 하나를 설명하는 숫자 하나하나(x₁, x₂)였습니다. φ(x) 의 각 좌표도 같은 뜻의 숫자이고, 새로 만든 특성들의 묶음을 가리킬 때 영어의 feature 를 ‘특징’으로 옮겨 이렇게 부르는 것뿐입니다. 같은 개념의 두 번역입니다.

4·5장의 SVM 은 점이 무엇인지 모릅니다. 숫자 묶음(벡터)이면 됩니다. 그러니 x⁽ⁱ⁾ 자리에 φ(x⁽ⁱ⁾) 를 넣어도 마진 최대화·쌍대문제·C 의 유도는 한 줄도 바뀌지 않습니다. 직선으로 가르던 도구가 특징 공간에서는 평면으로 가르고, 입력 공간으로 되돌리면 곡선 경계가 됩니다.

좌표를 더 넣고 싶어지면

비용은 저장만이 아닙니다

쌍대문제(4장)가 필요로 하는 것은 점 쌍마다의 내적 φ(x⁽ⁱ⁾)·φ(x⁽ʲ⁾) 입니다. m 차원 벡터의 내적은 곱셈 m 번이고, 점이 n 개이면 쌍은 약 n² 개입니다. p = 784, d = 2(m = 308,505)에서 점 n = 1,000 개이면 10⁶ × 308,505 ≈ 3.1 × 10¹¹ 번의 곱셈입니다(대칭성으로 반을 아껴도 같은 규모). 작은 m 에서는(화면 2 의 m = 3) 직접 해도 되지만 규모가 커지면 불가능합니다. 게다가 화면 6 에서 볼 것처럼 φ 의 좌표 수가 무한인 경우도 있습니다.

정리하면 “차원을 올리면 갈린다”는 아이디어는 맞지만 φ(x) 를 정말 만들어 계산하는 길은 비쌉니다. 그런데 4장 화면 5 에서 남겨 둔 사실이 이 문제를 풀 열쇠입니다. 다음 화면에서 그 약속을 갚습니다.

6장 · 화면 4

쌍대문제에 내적만 남았다 — 그래서 K(x, z) 한 줄로

4장 화면 5 에서 쌍대 목적함수를 보며, 점의 좌표가 오직 두 점의 내적 x⁽ⁱ⁾·x⁽ʲ⁾ 의 형태로만 들어 있다고 적고 ‘6장에서 다룸’이라고 미뤄 두었습니다. 그 약속을 갚는 화면입니다. 먼저 x 자리에 φ(x) 를 넣은 모습입니다(소프트 마진이므로 0 ≤ α ≤ C).

두 식을 보면 φ(x) 의 좌표가 어디에도 따로 나오지 않습니다. 등장하는 것은 항상 두 점의 φ 내적 값 하나뿐입니다. 그렇다면 좌표를 만들지 않고 그 값만 바로 돌려주는 함수가 있으면 됩니다. 이 함수에 이름을 붙입니다.

정의 — 커널 함수 K

K(x, z) = φ(x)·φ(z)

  • 커널 함수 K(x, z) — 두 점 x, z 를 받아 특징 공간에서의 내적 값(숫자 하나)을 돌려주는 함수입니다.
  • 핵심은 K 를 φ 를 거치지 않고 x, z 로 바로 계산할 수 있으면 된다는 것입니다. 그런 K 가 실제로 있는지는 다음 화면에서 손으로 확인합니다.
  • 4·5장의 SVM 은 φ(x) = x, 곧 K(x, z) = x·z 인 특수한 경우입니다(선형 커널).

손으로 확인 — φ(x)·φ(z) 가 (x·z)² 와 같다

2차원 점에서 2차항 세 개만 모은 특징 맵을 하나 잡습니다. 가운데 항에 √2 가 붙은 이유는 아래 전개에서 드러납니다.

φ(x₁, x₂) = ( x₁²,  √2·x₁x₂,  x₂² )

x = (x₁, x₂), z = (z₁, z₂) 에 대해 φ(x)·φ(z) 를 한 줄씩 전개합니다.

줄식왜 이렇게 되는지
1φ(x)·φ(z) = x₁²z₁² + (√2 x₁x₂)(√2 z₁z₂) + x₂²z₂²내적은 같은 자리끼리 곱해 더한 값입니다.
2= x₁²z₁² + 2 x₁x₂z₁z₂ + x₂²z₂²√2 · √2 = 2 입니다.
3= (x₁z₁)² + 2 (x₁z₁)(x₂z₂) + (x₂z₂)²같은 숫자를 x₁z₁ 과 x₂z₂ 로 묶어 다시 썼습니다.
4= (x₁z₁ + x₂z₂)²a² + 2ab + b² = (a + b)² 에서 a = x₁z₁, b = x₂z₂.
5= (x·z)²x₁z₁ + x₂z₂ 가 x·z 입니다.

2 줄의 2 가 4 줄의 (a + b)² 의 가운데 항 2ab 와 맞아떨어지도록 √2 를 붙인 것입니다.

이름 — 커널 트릭

이처럼 φ(x)·φ(z) 를 φ 를 만들지 않고 K(x, z) 공식으로 바로 구하는 방법을 커널 트릭(kernel trick)이라 부릅니다. 쌍대문제와 판정식에 데이터가 내적으로만 들어 있었기에(4장 화면 5) 가능한 일입니다. 고차원으로 ‘가는 일’은 하지 않으면서 ‘간 것과 같은 답’을 얻는다는 점에서 trick 입니다.

화면 3 의 6 이 돌아옵니다

상수 1 을 더한 K(x, z) = (x·z + 1)² 도 같은 방식으로 전개되고, 그 φ 는 화면 3 의 6 개 항 전부입니다.

φ(x) = ( 1,  √2 x₁,  √2 x₂,  x₁²,  √2 x₁x₂,  x₂² )

같은 x = (1, 2), z = (3, 1) 로 확인하면 φ(x) = (1, √2, 2√2, 1, 2√2, 4), φ(z) = (1, 3√2, √2, 9, 3√2, 1) 이고 내적은 1 + 6 + 4 + 9 + 12 + 4 = 36 입니다. (x·z + 1)² = (5 + 1)² = 36 으로 같습니다. 일반 d 의 (x·z + 1)^d 는 차수 d 이하 모든 항(화면 3 의 C(p+d, d) 개)에 대응합니다(증명 생략). 화면 3 의 표에서 “2.5 조”였던 p = 784, d = 5 도 (x·z + 1)⁵ 로는 내적 한 번과 거듭제곱 한 번입니다.

원형 데이터는 이 커널로 갈립니다

이 장의 z = x₁² + x₂² 는 위의 φ 의 첫째와 셋째 좌표의 합, φ₁ + φ₃ 입니다. 그래서 화면 2 의 수평 평면 z = c 는 이 특징 공간에서 w = (−1, 0, −1), b = c 인 평면(f = c − φ₁ − φ₃)입니다. 곧 K(x, z) = (x·z)² 로 만든 SVM 에서 이 12 점은 갈립니다. 화면 2 에서 z 에 제곱근을 씌우지 않은 이유도 여기 있습니다. x₁² + x₂² 는 다항식 항의 합이라 이런 커널로 다룰 수 있습니다. SVM 이 실제로 고르는 평면은 마진이 가장 큰 것이라 이 평면과 다를 수 있습니다. 갈린다는 것까지가 이 화면에서 확인한 사실입니다.

한계 — φ 는 하나로 정해지지 않습니다

φ′(x) = (x₁², x₁x₂, x₂x₁, x₂²) 처럼 4 개 좌표로 만들어도 φ′(x)·φ′(z) = x₁²z₁² + 2x₁x₂z₁z₂ + x₂²z₂² = (x·z)² 로 같은 K 가 나옵니다. 쌍대문제와 판정식은 K 만 보므로, 본체는 φ 가 아니라 K 입니다. 어떤 φ 를 쓰든 답은 같습니다.

RBF 커널 읽기

RBF 커널(Radial Basis Function, 가우시안 커널이라고도 합니다)은 K(x, z) = exp(−γ‖x − z‖²) 입니다. 기호를 하나씩 봅니다.

  • ‖x − z‖² — 두 점 사이 거리의 제곱입니다. 2차원이면 (x₁ − z₁)² + (x₂ − z₂)² 로, 화면 2 에서 원점까지 거리의 제곱을 쓴 것과 같은 계산입니다(‖·‖ 는 1장 화면 3 의 노름, 곧 길이).
  • exp(u) — eu 입니다(e ≈ 2.718). u = 0 이면 1 이고, u 가 음수로 클수록 0 에 가깝습니다.
  • γ (감마) — 0 보다 큰 상수입니다. C 처럼 학습 전에 사람이 정하는 하이퍼파라미터입니다.

직접 움직여 보기 — RBF 의 γ 와 C

결론은 위에 적었습니다(γ 가 작으면 완만, 크면 뾰족). 위젯은 이를 확인하는 도구입니다. 슬라이더를 움직일 때마다 화면 4 의 커널 소프트 마진 쌍대문제(K 는 RBF)를 풀어 α 와 b 를 구하고, 격자의 모든 점에서 f(x) = Σα⁽ⁱ⁾y⁽ⁱ⁾K(x⁽ⁱ⁾, x) + b 를 계산해 영역을 칠합니다. 풀이 코드는 5장 위젯의 solveSoft 에서 내적 x·x 를 K 로 바꾼 것입니다.

5장 위젯과 다른 점이 하나 있습니다. 5장에서는 풀이가 w 를 돌려줘서 직선을 바로 그렸습니다. RBF 에서는 w 가 무한 차원 벡터라 적을 수가 없고, 판정도 b 를 구하는 것도 전부 커널 합으로 합니다(b = y⁽ᵏ⁾ − Σα⁽ⁱ⁾y⁽ⁱ⁾K(x⁽ⁱ⁾, x⁽ᵏ⁾), 0 < α⁽ᵏ⁾ < C 인 점 k 들의 평균). 그래서 결정경계(f = 0)는 선이 아니라 f 값의 등고선으로 그립니다.

  1. 원형 데이터, γ = 1, C = 10. 서포트 벡터 11개이고 12 점을 모두 맞힙니다. 안쪽을 감싸는 닫힌 곡선이 결정경계입니다. 새 점 시험은 100% 입니다. 화면 1 에서 직선이 최선 3 점을 틀리던 데이터를 곡선이 가릅니다.
  2. γ = 0.01, C = 1. 영향 범위가 1/√γ = 10 으로 데이터 전체보다 넓어서, 경계가 반지름이 아주 큰 완만한 호 하나로 나옵니다(그림에서 안쪽 점 일부가 경계 밖에 놓입니다). 12 점 중 3 점을 틀리고(직선이 할 수 있는 최선과 같은 수), 새 점 시험은 64% 로 떨어집니다. 이 설정에서는 b 도 구간으로만 정해지고 서포트 벡터 12개가 전부 α = C 라 과소적합입니다.

  4. 잡음 한 점, γ = 1, C = 1. 레이블이 뒤집힌 x⁽¹⁾ 은 틀리게 두고 나머지 11 점을 맞힙니다(틀린 점 1개). 새 점 시험은 100% 입니다. 잡음을 포기해서 모양이 깨끗하게 남았습니다.
  5. 같은 데이터에서 C = 10. 틀린 점이 0 이 되었지만 새 점 시험은 92% 로 내려갑니다. 경계가 잡음 한 점을 맞히려고 중앙에 작은 섬을 만들어, 그 섬 안으로 들어오는 새 점을 틀리게 만듭니다. 5장의 과적합과 같은 일입니다.

아무 함수나 커널이 되는 것은 아닙니다 — 조건, 예측식, 한계

커널이 되려면

화면 4 에서 K 는 φ(x)·φ(z) 였습니다. 거꾸로 임의의 함수 K(x, z) 를 가져와 쌍대문제의 내적 자리에 끼우면 정말 그런 φ 가 있다는 보장이 있을까요? 없습니다. K 가 진짜 커널이면 어떤 점 n 개를 골라 그램 행렬을 만들어도 만족해야 하는 성질이 하나 있습니다.

조건 — 그램 행렬이 양의 준정부호

ΣΣ ci cj Kij ≥ 0   (어떤 수 c₁, …, cₙ 을 잡아도)

  • c₁, …, cₙ — 우리가 마음대로 고르는 실수들(음수 가능)입니다. 점마다 하나씩 붙이는 가중치라고 보면 됩니다.
  • 이 성질을 양의 준정부호라 부릅니다. 그램 행렬이 대칭이라는 것(Kij = Kji)과 함께 요구됩니다.

진짜 커널은 이 조건을 항상 만족합니다. Kij = φ(x⁽ⁱ⁾)·φ(x⁽ʲ⁾) 이므로 내적의 분배법칙(4장 화면 3~4 에서 쓴 것)에 의해

ΣΣ ci cj Kij = ( Σ ciφ(x⁽ⁱ⁾) ) · ( Σ cjφ(x⁽ʲ⁾) ) = ‖ Σ ciφ(x⁽ⁱ⁾) ‖² ≥ 0

이기 때문입니다(벡터를 자기 자신과 내적하면 길이의 제곱). 반대 방향도 알려져 있습니다. K 가 대칭이고 어떤 점들을 골라도 이 조건을 만족하면(이를 Mercer 조건이라 부릅니다) K = φ·φ 인 φ 가 존재합니다. 이 방향의 증명과 엄밀한 서술(Mercer 정리)은 이 교재에서 생략합니다. 선형, 다항((x·z + 1)^d), RBF 는 모두 이 조건을 만족하는 커널입니다.

반례 — 두 점 사이 거리의 제곱은 커널이 아닙니다

1차원에서 K(x, z) = (x − z)² 라 하고 두 점 x⁽¹⁾ = 0, x⁽²⁾ = 1 을 잡습니다. 그램 행렬은 K₁₁ = K₂₂ = 0, K₁₂ = K₂₁ = 1 입니다. c = (1, −1) 로 조건을 계산하면

ΣΣ cicjKij = 2·(1)(−1)·1 = −2 < 0

조건을 어깁니다. 제곱의 합인 ‖·‖² 가 음수일 수는 없으니 이런 K 는 어떤 φ 로도 φ(x)·φ(z) 가 될 수 없습니다. 이런 K 를 쌍대문제에 끼우면 문제가 생길 수 있습니다. 위의 두 점에 레이블을 +1, −1 로 주면 Σαy = 0 에서 α⁽¹⁾ = α⁽²⁾ = a 이고 D = 2a + a² 입니다. 상한 C 가 없다면 a 를 키울수록 끝없이 커져 최댓값이 없습니다.

재미있는 점은 (x − z)² 는 안 되는데 그것을 지수 안에 넣은 exp(−γ(x − z)²) (RBF)는 된다는 것입니다. 커널이 되는지는 식의 모양만 보고는 직관으로 알기 어려워서, 새 커널을 만들 때는 이 조건으로 확인합니다.

커널 SVM 의 예측식

화면 4 에서 이미 적은 판정식이 최종 형태입니다. 한 번 더 정리합니다.

커널 SVM 의 예측식과 b

f(x) = Σi α⁽ⁱ⁾ y⁽ⁱ⁾ K(x⁽ⁱ⁾, x) + b,   새 점의 분류는 sign f(x)

b = y⁽ᵏ⁾ − Σi α⁽ⁱ⁾ y⁽ⁱ⁾ K(x⁽ⁱ⁾, x⁽ᵏ⁾)   (0 < α⁽ᵏ⁾ < C 인 점 k)

  • 합에 기여하는 것은 서포트 벡터뿐입니다. α⁽ⁱ⁾ = 0 인 점의 항은 0 이라, 학습이 끝난 뒤에는 서포트 벡터와 그 α, y, b 만 보관하면 됩니다. 위젯의 decision 함수가 정확히 이 식입니다.
  • b 도 커널로 구합니다. 5장 화면 4 의 b = y − w·x 에서 w·x 가 Σα y K 로 바뀐 것입니다. 0 < α < C 인 점이 하나도 없으면 5장처럼 b 가 구간으로만 정해집니다(위젯에서 γ = 0.01, C = 1 로 확인).
  • 선형 커널이면 Σα y (x⁽ⁱ⁾·x) = w·x 로 한 번 합쳐 둘 수 있어서 판정에 w 하나면 됩니다. RBF 에서는 합칠 w 가 없어 서포트 벡터마다 K 를 계산해야 합니다.

한계 — 공짜가 아닙니다

커널 SVM 을 쓸 때의 한계

  • 점이 많을수록 급격히 느려집니다. 그램 행렬이 n × n 이라 n = 10,000 이면 값 10⁸ 개(8 바이트씩이면 800 MB), n = 100,000 이면 10¹⁰ 개(80 GB)입니다. 구현에 따라 행렬 전체를 두지 않는 요령도 쓰지만, 학습 시간이 점의 수보다 훨씬 빠르게 늘어난다는 점은 남습니다(경험적으로 점 수의 제곱 이상으로 늘어나 수만 개를 넘으면 힘들어진다고 알려져 있습니다).
  • 예측 비용은 서포트 벡터 수에 비례합니다. 새 점 하나마다 서포트 벡터 개수만큼 K 를 계산합니다.
  • γ 와 C 가 과적합·과소적합을 정합니다. 위젯에서 본 것처럼 γ 가 너무 작으면 곡선이 휘지 못하고, 너무 크면 점마다 섬이 생깁니다. 정답은 데이터마다 달라 실전에서는 시험해서 고릅니다.
  • 커널 선택에 정답이 없습니다. 선형, 다항, RBF 중 무엇이 맞는지는 데이터의 모양에 달려 있고, 미리 알 방법이 마땅치 않아 비교해 봐야 합니다.
  • RBF 는 거리를 재므로 특성의 크기에 민감합니다. 한 특성이 다른 특성보다 값이 수백 배 크면 ‖x − z‖² 가 그 특성 하나로 거의 결정됩니다.
  • f(x) 는 점수일 뿐 확률이 아닙니다. 마진 기준의 부호 있는 값이라 “+1 일 확률 0.9” 같은 해석을 바로 붙일 수 없습니다.

커널 트릭은 “직선밖에 못 긋는 도구”를 “곡선도 긋는 도구”로 바꾸는 대신, 점이 많아지면 비싼 값을 치르게 합니다. 이 장에서 얻은 것은 쌍대문제의 x·x 자리에 K 를 끼우는 한 줄의 변화로 모양의 한계를 넘는다는 사실입니다.

6장 마무리

핵심 요약

  1. 원형으로 둘러싼 데이터는 직선으로 못 가르고(12 점 중 3 점은 틀림), C 로도 고쳐지지 않습니다. 모양의 문제이기 때문입니다. 점에 z = x₁² + x₂² 를 새 좌표로 붙이면 3차원에서 평면으로 갈리고, 평면을 되돌리면 원이 됩니다.
  2. 점을 새 좌표로 바꾸는 규칙이 특징 맵 φ 입니다. 직접 계산하면 특징 수가 C(p+d, d)(p 는 점의 차원)로 폭발하고, p = 784, d = 5 면 한 점이 2.5 조 개의 숫자입니다.
  3. 쌍대문제와 판정식에는 점이 내적으로만 들어 있어서 φ(x)·φ(z) 만 구하면 됩니다. 이 값을 돌려주는 함수가 커널 K(x, z) 이고, x⁽ⁱ⁾·x⁽ʲ⁾ 를 K(x⁽ⁱ⁾, x⁽ʲ⁾) 로 바꿔 쓰면 끝입니다. 예: φ = (x₁², √2x₁x₂, x₂²) 이면 φ(x)·φ(z) = (x·z)². 이것이 커널 트릭입니다.
  4. 대표 커널은 선형, 다항 (x·z+1)^d, RBF exp(−γ‖x−z‖²) 입니다. RBF 는 무한 차원 특징 공간에 해당하고, γ 는 서포트 벡터 하나의 영향 범위(대략 1/√γ)를 정합니다. 너무 작으면 곡선이 안 휘고 너무 크면 점마다 섬이 생기며, C 와 함께 조절합니다.
  5. 커널이 되려면 그램 행렬이 대칭이고 양의 준정부호여야 합니다(Mercer 조건). 예측식은 f(x) = Σα⁽ⁱ⁾y⁽ⁱ⁾K(x⁽ⁱ⁾, x) + b 로 서포트 벡터만 기여합니다. 점이 많아지면 n × n 표 때문에 느려지고, f 는 확률이 아닙니다.

커널 트릭이 아껴 주는 것은 무엇일까요?

  1. 쌍대문제의 변수 α 의 개수
  2. 고차원 좌표 φ(x) 를 만들어 내적하는 계산
  3. 필요한 학습 점의 수

한 가지 더. 커널 트릭은 SVM 만의 것이 아니라 데이터가 내적으로만 들어 있는 모든 알고리즘에 쓸 수 있는 요령입니다. SVM 에서는 4장의 쌍대문제가 데이터를 내적으로만 쓰게 만들었기 때문에 가능했습니다. 원문제 w·x 꼴에서는 w 라는 좌표 묶음이 필요해서 쓸 수 없었습니다. 쌍대로 푸는 이유가 여기서 하나 더 드러난 셈입니다.

화면 6 의 위젯에서 잡음 한 점이 있는 데이터를 γ = 100, C = 10 으로 학습했습니다. 어떤 모습일까요?

  1. 학습 점은 모두 맞히지만 점마다 작은 섬이 생겨 새 점은 잘 못 맞힌다
  2. 경계가 거의 직선에 가까워지고 틀리는 점이 늘어난다
  3. 서포트 벡터가 거의 없어지고 경계가 매끄러워진다

학습 점을 모두 맞히는 것은 RBF 에서 어렵지 않습니다. γ 가 크면 점 하나하나를 외우기 쉽기 때문입니다(화면 6). 그래서 학습 점의 정확도만으로는 γ 를 고를 수 없고, 학습에 쓰지 않은 점으로 시험해야 합니다. 위젯의 ‘새 점 시험’ 줄이 그 역할을 흉내 낸 것입니다.

K(x, z) = (x − z)² 를 1차원에서 커널로 쓸 수 있을까요?

  1. 쓸 수 있다. 두 점 사이의 거리를 재는 자연스러운 함수이기 때문이다
  2. 쓸 수 있다. K(x, z) = K(z, x) 로 대칭이기 때문이다
  3. 쓸 수 없다. 그램 행렬이 양의 준정부호 조건을 어기는 점 선택이 있다

같은 거리 제곱을 부호를 바꿔 지수 안에 넣은 exp(−γ(x − z)²) 가 RBF 이고 이것은 커널입니다. 그래서 “거리를 재는 함수라서”도 “대칭이라서”도 커널의 이유가 되지 못하고, 조건은 그램 행렬로 확인합니다. 아무 거리 함수나 SVM 에 끼우면 쌍대문제가 최댓값 없이 발산할 수 있습니다(화면 7 의 D = 2a + a²).

  2. 그램 행렬 Kij (4 × 4)를 구하세요. 예: K₁₁ = (x⁽¹⁾·x⁽¹⁾ + 1)² = 9.
  3. 대칭성으로 α⁽¹⁾ = α⁽²⁾ = α⁽³⁾ = α⁽⁴⁾ = a 라고 가정합니다. Σαy = 0 이 성립하는지 확인하고 D(a) 를 a 의 식으로 쓴 뒤 최대가 되는 a 를 구하세요.
  4. b = 0 으로 놓고 f(x) = Σα⁽ⁱ⁾y⁽ⁱ⁾K(x⁽ⁱ⁾, x) + b 를 네 점에서 계산해 y⁽ⁱ⁾f(x⁽ⁱ⁾) 가 얼마인지 확인하고, 이것이 정말 답인지(3 번의 가정이 맞는지) 어떤 조건으로 검증할 수 있는지 말하세요.
모범답안 — 그리고 흔한 실수가 왜 부족한지

1. 두 +1 점의 한가운데 ½x⁽¹⁾ + ½x⁽²⁾ = (0, 0) 과 두 −1 점의 한가운데 ½x⁽³⁾ + ½x⁽⁴⁾ = (0, 0) 이 같은 점입니다. f(0) = ½f(x⁽¹⁾) + ½f(x⁽²⁾) > 0 (둘 다 +1 쪽이니), 동시에 f(0) = ½f(x⁽³⁾) + ½f(x⁽⁴⁾) < 0 이라 모순입니다.

2. Kii = (2 + 1)² = 9. 서로 다른 점의 내적은 x⁽¹⁾·x⁽²⁾ = −2, x⁽¹⁾·x⁽³⁾ = 0, x⁽¹⁾·x⁽⁴⁾ = 0, x⁽²⁾·x⁽³⁾ = 0, x⁽²⁾·x⁽⁴⁾ = 0, x⁽³⁾·x⁽⁴⁾ = −2 입니다. 그래서 x⁽¹⁾x⁽²⁾ 쌍과 x⁽³⁾x⁽⁴⁾ 쌍은 (−2 + 1)² = 1, 나머지 쌍은 (0 + 1)² = 1 이라 대각선은 9, 나머지 칸은 모두 1 입니다.

3. Σαy = a(+1 + 1 − 1 − 1) = 0 ✓. y⁽ⁱ⁾y⁽ʲ⁾Kij 를 모두 더하면, 대각 4 칸은 4 × 9 = 36, 같은 레이블 쌍((1,2), (2,1), (3,4), (4,3))은 y y = +1 이고 K = 1 이라 4, 다른 레이블 쌍 8 칸은 y y = −1 이라 −8 이어서 합이 36 + 4 − 8 = 32 입니다. 따라서 D(a) = 4a − ½·32·a² = 4a − 16a², 미분이 0 인 4 − 32a = 0 에서 a = 1/8, D = ½ − ¼ = ¼.

4. f(x) = ⅛[K(x⁽¹⁾, x) + K(x⁽²⁾, x) − K(x⁽³⁾, x) − K(x⁽⁴⁾, x)]. x = x⁽¹⁾ 이면 ⅛(9 + 1 − 1 − 1) = 1, 나머지 세 점도 y f = 1 입니다(y⁽ⁱ⁾f(x⁽ⁱ⁾) = 1 네 개 모두). 정리하면 f(x) = x₁x₂ 입니다(예: f(0.5, 0.5) = 0.25, f(1, 2) = 2). 검증은 KKT 로 합니다. 쌍대 가능성(0 ≤ α ≤ C, Σαy = 0) ✓, 원문제 가능성(y f ≥ 1) ✓, 상보 여유성(α > 0 인 모든 점에서 y f = 1) ✓ 이므로 이 α 가 쌍대문제의 최적해입니다(3장·4장의 KKT 충분조건). 0 < α < C 인 점이 있으니 b 도 b = y⁽ᵏ⁾ − Σα y K = 1 − 1 = 0 으로 확인됩니다.

덧붙임. 이 f 는 화면 5 의 6 차원 φ 에서 √2 x₁x₂ 좌표 하나만 쓰는 평면입니다(w = (0, 0, 0, 0, 1/√2, 0), ½‖w‖² = ¼ 로 D 와 일치).

흔한 실수 1 — 3 번의 “α 가 모두 같다”를 사실로 두고 끝내기. 대칭성은 그럴듯한 가정일 뿐이고 4 번의 KKT 검증으로 최적임을 확인해야 합니다. 가정으로 얻은 값은 후보입니다.

흔한 실수 2 — K 를 φ(x)·φ(z) 가 아니라 “φ(x·z)” 로 읽기. K(x, z) = (x·z + 1)² 는 x·z 를 먼저 구한 값을 제곱한 것이고, 그 값이 두 점 각각의 φ 를 내적한 것과 같다는 것이 화면 5 의 내용입니다.

흔한 실수 3 — 선형 커널로는 못 가르니 점이 부족하다고 결론 내리기. 점을 늘려도 이 배치의 한가운데 일치는 사라지지 않습니다. 모양의 문제이지 점의 수의 문제가 아닙니다.

이 교재가 가는 길 — 이 장에서 쌍대문제의 내적 자리에 K 를 끼운 커널 쌍대문제까지 왔습니다. 이 문제를 컴퓨터가 어떻게 푸는지가 7장입니다.
