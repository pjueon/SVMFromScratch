6장 · 페이지 1

커널 트릭

5장의 소프트 마진은 이상치 몇 개가 끼어도 직선을 지켜 냈습니다. 그런데 직선이라는 틀 자체가 맞지 않는 데이터가 있습니다. 5장 페이지 3 의 한계 상자에서 “점이 원형으로 안팎을 둘러싼 데이터는 \(C\) 를 어떻게 정해도 고쳐지지 않는다”고 미뤄 둔 문제입니다. 1장 페이지 4 에서 처음 던진 질문이기도 하며, 이 장은 여기서 출발합니다. 이 페이지에서는 그런 데이터를 하나 만들고, 직선이 왜 안 되는지 5장에서 쓴 방법 그대로 확인합니다.

이 장의 데이터

점 12개입니다. 안쪽에 파란 점(+1) 6개가 모여 있고, 그 둘레를 빨간 점(−1) 6개가 고리처럼 둘러쌉니다. 5장까지는 좌표가 0 에서 6 까지였지만 이 장에서는 원점 \((0, 0)\) 이 데이터의 한가운데이고 좌표는 −3 에서 3 까지입니다.

직선으로 분류할 수 없는 이유

그림의 직선 두 개는 틀리는 점이 있습니다. ‘가’ 직선은 \(x_{1} < 1.1\) 쪽을 +1 로 보면 바깥 점 \(x^{(8)}, x^{(10)}, x^{(11)}\) 세 개를 잘못 분류하고, ‘나’ 직선은 \(x_{2} < 0.5\) 쪽을 +1 로 보면 다섯 개(\(x^{(6)}, x^{(7)}, x^{(8)}, x^{(11)}, x^{(12)}\))를 잘못 분류합니다. 다른 직선을 찾아도 같을까요? 5장 페이지 1 (가) 에서 쓴 “섞기” 논법으로 확인합니다. \(x^{(7)}\) 과 \(x^{(8)}\) 은 원점을 가운데 두고 정반대에 놓여 있고, 그 가운데가 안쪽 점 \(x^{(1)}\) 입니다.

줄식왜 이렇게 되는지
1\(x^{(1)} = \tfrac12 x^{(7)} + \tfrac12 x^{(8)}\)\(\tfrac12 (2.2, 0.4) + \tfrac12 (-2.2, -0.4) = (0, 0)\) 입니다.
2\(f(x^{(1)}) = \tfrac12 f(x^{(7)}) + \tfrac12 f(x^{(8)})\)\(f(x) = w\cdot x + b\) 이고 \(\tfrac12 + \tfrac12 = 1\) 이라 \(b\) 도 같은 비율로 섞입니다. 어떤 \((w, b)\) 에서도 성립합니다.
3\(f(x^{(7)}) < 0\), \(f(x^{(8)}) < 0\) 이므로 오른쪽 \(< 0\)직선이 두 점을 모두 올바르게 분류하려면, −1 점이니 \(f\) 가 음수여야 합니다.
4그런데 \(x^{(1)}\) 은 +1 점이라 \(f(x^{(1)}) > 0\)2 줄에 의해 왼쪽은 양수, 오른쪽은 음수여야 하니 동시에 만족할 수 없습니다.

소프트 마진도 같은 식에서 막힙니다. 점마다 \(\xi ^{(i)} \ge 1 - y^{(i)}f(x^{(i)})\) 이니 \(\xi ^{(1)} \ge 1 - f(x^{(1)})\), \(\xi ^{(7)} \ge 1 + f(x^{(7)})\), \(\xi ^{(8)} \ge 1 + f(x^{(8)})\) 입니다. 1 : ½ : ½ 의 비율로 더하면 \(\xi ^{(1)} + \tfrac12 \xi ^{(7)} + \tfrac12 \xi ^{(8)} \ge 2 + (\tfrac12 f(x^{(7)}) + \tfrac12 f(x^{(8)}) - f(x^{(1)})) = 2\) 이고, 계수가 모두 1 이하이니 \(\sum \xi \ge 2\) 입니다. 어떤 직선을 골라도, \(C\) 를 얼마로 키워도 침범의 합은 2 아래로 내려가지 않습니다. 5장에서 하드 마진으로 “돌아갈 곳”이 있었던 것과 달리 여기는 돌아갈 곳이 없습니다. 12 점을 나누는 방법을 전부 따져 보면(컴퓨터로 확인) 틀리는 점이 3 개보다 적은 직선은 하나도 없습니다. 위의 ‘가’ 직선이 그 최선입니다.

이상치가 아니라 모양의 문제입니다

5장의 이상치는 “점 몇 개만 규칙에서 벗어난” 경우였고, 그래서 그 점의 침범을 싸게 만들면(작은 \(C\)) 직선이 살아났습니다. 이 데이터는 점 하나도 잡음이 아닙니다. 12 점 모두 규칙을 지키고 있는데 규칙의 모양이 원이라서, 직선이라는 도구가 맞지 않습니다. \(C\) 로 조절할 수 있는 것은 “어느 점을 포기할까” 뿐입니다.

그렇다면 요구사항은 이렇게 바뀝니다. 직선이 아니라 원 같은 곡선으로 분류할 수 있어야 하고, 그러면서 지금까지 만든 쌍대문제의 틀(마진, 서포트 벡터, \(C\))은 그대로 쓰고 싶다. 다음 페이지에서 그 방법의 아이디어를 봅니다.

이 장의 진행

  1. 직선으로 분류되지 않는 원형 데이터를 확인한다 (이 페이지).
  2. 점에 좌표 하나를 더 붙여 “차원을 올리면” 분류할 수 있다는 것을 본다 (페이지 2, 위젯).
  3. 올리는 일을 직접 하면 얼마나 비싼지 센다 (페이지 3).
  4. 쌍대문제에 데이터가 내적으로만 들어 있다는 사실로 그 비용을 없앤다 (페이지 4~5).
  5. 대표 커널과 그 파라미터를 위젯으로 확인한다 (페이지 6).
  6. 아무 함수나 되는 것은 아니라는 조건과 한계를 본다 (페이지 7).

이 장에서 다루는 것

  • 원형 데이터는 \(C\) 로 안 고쳐진다 → 이 페이지에서 이유를 확인하고, 페이지 2~6 에서 해결 (1장 페이지 4, 5장 페이지 3)
  • 쌍대문제에 내적 \(x^{(i)}\cdot x^{(j)}\) 만 남았다 → 페이지 4~5 (4장 페이지 5)

6장 · 페이지 2

아이디어 — 차원을 하나 올리면 분류할 수 있다

페이지 1 의 데이터를 다시 보면 레이블을 정하는 것은 원점에서 얼마나 먼가입니다. 안쪽 점은 원점 가까이, 바깥 점은 멀리 있습니다. 원점까지의 거리는 좌표 둘로 계산되는 값이니, 그 값을 새 좌표 하나로 만들어 점에 붙여 봅시다. 피타고라스 정리에 따라 점 \((x_{1}, x_{2})\) 의 원점까지 거리의 제곱은 \(x_{1}^{2} + x_{2}^{2}\) 이고, 이것을 \(z\) 라 부릅니다(제곱근을 안 씌우는 이유는 뒤에서 나옵니다).

\((x_{1}, x_{2}) \; \to \; (x_{1}, x_{2}, z)\),    \(z = x_{1}^{2} + x_{2}^{2}\)

평면 위의 점에 높이 \(z\) 가 더해져 3차원 공간의 점이 됩니다. 12 점의 \(z\) 를 계산하면 이렇습니다(예: \(x^{(5)} = (-1, 0.4)\) 는 \(1 + 0.16 = 1.16\)).

레이블\(z = x_{1}^{2} + x_{2}^{2}\) (점 번호 순서)범위
+1 (안쪽, \(x^{(1)}\sim x^{(6)}\))0, 0.9, 0.89, 0.72, 1.16, 1.09모두 1.16 이하
−1 (바깥, \(x^{(7)}\sim x^{(12)}\))5, 5, 6.28, 6.29, 5.48, 5.8모두 5 이상

안쪽 점은 모두 낮고 바깥 점은 모두 높습니다. 1.16 과 5 사이에 아무 높이나 하나 고르면(예: \(z = 3\)) 수평한 평면 하나가 두 무리를 구분합니다. 1장 페이지 2 에서 초평면은 3차원에서는 평면이라고 했습니다. SVM 이 하는 일, 곧 초평면으로 분류하는 일은 3차원에서도 똑같습니다. 새 공간의 점 \(p = (x_{1}, x_{2}, z)\) 에서 이 평면은 \(w = (0, 0, -1)\), \(b = c\), 곧 \(f(p) = w\cdot p + b = c - z\) 이고 안쪽(+1)이 \(f > 0\) 입니다(\(c\) 는 평면의 높이).

3차원의 평면은 2차원에서는 원입니다

\(c - z = 0\) 인 점들은 \(x_{1}^{2} + x_{2}^{2} = c\) 를 만족합니다. 원점 중심, 반지름 \(\sqrt{c}\) 인 원입니다. 곧 3차원에서 평면으로 분류한 것을 원래의 평면으로 되돌리면 원으로 분류한 것이 됩니다. 원래 평면에서는 직선으로 안 되던 분류를, 3차원에서는 평면 하나로 해결했습니다.

원의 중심이 원점이 아니어도 될까요

중심이 \((a, b)\), 반지름이 \(r\) 인 원은 \((x_{1} - a)^{2} + (x_{2} - b)^{2} = r^{2}\), 전개해서 정리하면 \(x_{1}^{2} + x_{2}^{2} = 2ax_{1} + 2bx_{2} + (r^{2} - a^{2} - b^{2})\) 입니다. 왼쪽이 \(z\) 이니 \(z = 2ax_{1} + 2bx_{2} + (\text{상수})\), 곧 \((x_{1}, x_{2}, z)\) 세 좌표에 대한 평면입니다. 그래서 새 좌표로 \(z\) 만 남기지 않고 \(x_{1}, x_{2}\) 도 함께 두는 것이 안전합니다(페이지 3).

직접 움직여 보기

위에서 얻은 결론을 위젯으로 확인합니다. 올리기 슬라이더가 0 이면 모든 점이 바닥(원래의 평면)에 놓여 있고, 1 이면 각 점이 \(z = x_{1}^{2} + x_{2}^{2}\) 높이까지 올라갑니다(그림의 높이는 \(z\) 의 절반으로 줄여 그렸습니다). 회전으로 보는 방향을, 평면 높이로 두 무리를 나누는 평면의 \(c\) 를 바꿉니다. 점선은 점에서 바닥으로 내린 수선, 바닥의 점선 원과 평면 위의 실선 원은 \(x_{1}^{2} + x_{2}^{2} = c\) 입니다.

한계 — 수평 평면이 곧 SVM 의 답은 아닙니다

위젯은 수평한 평면만 보여 줍니다. 1.16 과 5 사이의 어느 높이든 분류할 수 있지만, SVM 은 그중에서도 마진이 가장 넓은 평면을 고릅니다. 그 평면이 수평이라는 보장은 없습니다. 이 페이지에서 확인한 것은 “3차원에서는 평면으로 분류할 수 있다”는 사실까지입니다. 그리고 \(z = x_{1}^{2} + x_{2}^{2}\) 는 이 데이터가 원형이라는 것을 알고 있기에 고른 것입니다. 모양을 모르는 데이터에서는 어떤 좌표를 더해야 할지부터가 문제입니다. 페이지 3 에서 그 이야기를 이어 갑니다.

6장 · 페이지 3

특징 맵 \(\varphi \) — 올리는 일에 이름을 붙이고 필요한 좌표 수를 센다

페이지 2 에서 한 일은 점 하나를 받아 새 좌표 묶음으로 바꾸는 규칙이었습니다. 이 규칙에 이름과 기호를 붙입니다.

정의 — 특징 맵 \(\varphi \)

\[\varphi (x_{1}, x_{2}) = (x_{1}, x_{2}, x_{1}^{2} + x_{2}^{2})\]

  • φ (파이) — 점 \(x\) 를 받아 새 좌표 묶음 \(\varphi (x)\) 를 내놓는 함수. 이 이름이 특징 맵(feature map)입니다. 위의 예는 2차원 점을 3차원 점으로 바꿉니다.
  • 특징 공간 — \(\varphi (x)\) 들이 놓이는 공간. 원래 점이 사는 공간(입력 공간)과 구분하려는 이름입니다.
  • 1장에서 특성은 점 하나를 설명하는 숫자 하나하나(\(x_{1}, x_{2}\))였습니다. \(\varphi (x)\) 의 각 좌표도 같은 뜻의 숫자이고, 새로 만든 특성들의 묶음을 가리킬 때 영어의 feature 를 ‘특징’으로 옮겨 이렇게 부르는 것뿐입니다. 같은 개념의 두 번역입니다.

4·5장의 SVM 은 점이 무엇인지 모릅니다. 숫자 묶음(벡터)이면 됩니다. 그러니 \(x^{(i)}\) 자리에 \(\varphi (x^{(i)})\) 를 넣어도 마진 최대화·쌍대문제·\(C\) 의 유도는 한 줄도 바뀌지 않습니다. 직선으로 분류하던 도구가 특징 공간에서는 평면으로 분류하고, 입력 공간으로 되돌리면 곡선 경계가 됩니다.

다항식 항으로 좌표 늘리기

페이지 2 의 \(z\) 하나는 “원형”이라는 것을 미리 알고 고른 좌표였습니다. 모양을 모를 때는 후보를 넉넉히 넣고 SVM 이 필요한 것을 쓰게 하고 싶습니다. 가장 흔한 후보는 다항식 항입니다. 2차원에서 차수가 2 이하인 모든 항은 6개입니다.

\[\varphi (x_{1}, x_{2}) = (1, \; x_{1}, \; x_{2}, \; x_{1}^{2}, \; x_{1}x_{2}, \; x_{2}^{2})\]

(\(x_{1}x_{2}\) 는 두 좌표의 곱으로, 타원이 기울어져 있거나 두 좌표가 얽힌 모양을 만드는 데 필요합니다.) 점이 \(p\) 차원(좌표가 \(p\) 개, 점의 개수 \(n\) 과 구분하려고 \(p\) 라 씁니다)이면 몇 개일까요. 차수 2 이하만 세면 이렇습니다.

비용은 저장만이 아닙니다

쌍대문제(4장)가 필요로 하는 것은 점 쌍마다의 내적 \(\varphi (x^{(i)})\cdot \varphi (x^{(j)})\) 입니다. \(m\) 차원 벡터의 내적은 곱셈 \(m\) 번이고, 점이 \(n\) 개이면 쌍은 약 \(n^{2}\) 개입니다. \(p = 784\), \(d = 2\)(\(m = 308,505\))에서 점 \(n = 1,000\) 개이면 \(10^{6} \times 308,505 \approx 3.1 \times 10^{11}\) 번의 곱셈입니다(대칭성으로 반을 아껴도 같은 규모). 작은 \(m\) 에서는(페이지 2 의 \(m = 3\)) 직접 해도 되지만 규모가 커지면 불가능합니다. 게다가 페이지 6 에서 볼 것처럼 \(\varphi \) 의 좌표 수가 무한인 경우도 있습니다.

정리하면 “차원을 올리면 분류할 수 있다”는 아이디어는 맞지만 \(\varphi (x)\) 를 정말 만들어 계산하는 방법은 비쌉니다. 그런데 4장 페이지 5 에서 남겨 둔 사실이 이 문제를 푸는 실마리입니다. 다음 페이지에서 그 약속을 지킵니다.

6장 · 페이지 4

쌍대문제에는 내적만 남으므로 \(K(x, z)\) 하나로 바꿔 쓸 수 있다

4장 페이지 5 에서 쌍대 목적함수를 보며, 점의 좌표가 오직 두 점의 내적 \(x^{(i)}\cdot x^{(j)}\) 의 형태로만 들어 있다고 적고 ‘6장에서 다룸’이라고 미뤄 두었습니다. 그 약속을 지키는 페이지입니다. 먼저 \(x\) 자리에 \(\varphi (x)\) 를 넣은 모습입니다(소프트 마진이므로 \(0 \le \alpha \le C\)).

입력 공간에서 (4·5장)특징 공간에서 (\(x \to \varphi (x)\))
쌍대 목적 \(D(\alpha )\)\(\sum \alpha ^{(i)} - \tfrac12 \sum \sum \alpha ^{(i)}\alpha ^{(j)}y^{(i)}y^{(j)} (x^{(i)}\cdot x^{(j)})\)\(\sum \alpha ^{(i)} - \tfrac12 \sum \sum \alpha ^{(i)}\alpha ^{(j)}y^{(i)}y^{(j)} (\varphi (x^{(i)})\cdot \varphi (x^{(j)}))\)
제약\(0 \le \alpha ^{(i)} \le C\),  \(\sum \alpha ^{(i)}y^{(i)} = 0\) (같음)
새 점 \(x\) 의 판정\(f(x) = \sum \alpha ^{(i)}y^{(i)} (x^{(i)}\cdot x) + b\)\(f(x) = \sum \alpha ^{(i)}y^{(i)} (\varphi (x^{(i)})\cdot \varphi (x)) + b\)

아래쪽 판정식은 4장 페이지 6 끝에서 본 \(w\cdot q + b = \sum \alpha ^{(i)}y^{(i)}(x^{(i)}\cdot q) + b\) 에 \(\varphi \) 를 씌운 것입니다. \(w = \sum \alpha ^{(i)}y^{(i)}\varphi (x^{(i)})\) 는 특징 공간의 벡터라서 좌표가 수백만 개일 수도 있지만, 판정에는 \(w\) 가 따로 필요 없습니다. 합 안의 내적만 알면 됩니다.

두 식을 보면 \(\varphi (x)\) 의 좌표가 어디에도 따로 나오지 않습니다. 등장하는 것은 항상 두 점의 \(\varphi \) 내적 값 하나뿐입니다. 그렇다면 좌표를 만들지 않고 그 값만 바로 돌려주는 함수가 있으면 됩니다. 이 함수에 이름을 붙입니다.

정의 — 커널 함수 \(K\)

\[K(x, z) = \varphi (x)\cdot \varphi (z)\]

  • 커널 함수 \(K(x, z)\) — 두 점 \(x, z\) 를 받아 특징 공간에서의 내적 값(숫자 하나)을 돌려주는 함수입니다.
  • 핵심은 \(K\) 를 \(\varphi \) 없이 \(x, z\) 만으로 바로 계산할 수 있으면 충분하다는 점입니다. 그런 \(K\) 가 실제로 있는지는 다음 페이지에서 손으로 확인합니다.
  • 4·5장의 SVM 은 \(\varphi (x) = x\), 곧 \(K(x, z) = x\cdot z\) 인 특수한 경우입니다(선형 커널).

쌍대문제를 \(K\) 로 다시 쓰기

\(\varphi (x^{(i)})\cdot \varphi (x^{(j)})\) 를 \(K(x^{(i)}, x^{(j)})\) 로 바꿔 쓰기만 하면 됩니다.

커널을 쓴 소프트 마진 쌍대문제

\[\max _{\alpha } \; D(\alpha ) = \sum \alpha ^{(i)} - \tfrac12 \sum _{i}\sum _{j} \alpha ^{(i)}\alpha ^{(j)} y^{(i)}y^{(j)} K(x^{(i)}, x^{(j)})\]

\[\text{s.t.} \; 0 \le \alpha ^{(i)} \le C \; (\text{모든} i), \; \; \sum \alpha ^{(i)}y^{(i)} = 0\]

판정:  \(f(x) = \sum \alpha ^{(i)}y^{(i)} K(x^{(i)}, x) + b\),  \(\operatorname{sign} f(x)\) 가 분류

달라진 것은 내적 자리의 \(K\) 하나뿐입니다. 4장과 5장에서 한 일(서포트 벡터 = \(\alpha > 0\), \(0 < \alpha < C\) 인 점으로 \(b\) 구하기 등)이 그대로 성립합니다. 이 문제를 컴퓨터가 어떻게 푸는지는 7장에서 구현합니다. 7장에서 구현

손으로 확인 — \(\varphi (x)\cdot \varphi (z)\) 가 \((x\cdot z)^{2}\) 와 같다

2차원 점에서 2차항 세 개만 모은 특징 맵을 하나 잡습니다. 가운데 항에 \(\sqrt{2}\) 가 붙은 이유는 아래 전개에서 드러납니다.

\[\varphi (x_{1}, x_{2}) = ( x_{1}^{2}, \; \sqrt{2}x_{1}x_{2}, \; x_{2}^{2} )\]

\(x = (x_{1}, x_{2})\), \(z = (z_{1}, z_{2})\) 에 대해 \(\varphi (x)\cdot \varphi (z)\) 를 한 줄씩 전개합니다.

줄식왜 이렇게 되는지
1\(\varphi (x)\cdot \varphi (z) = x_{1}^{2}z_{1}^{2} + (\sqrt{2} x_{1}x_{2})(\sqrt{2} z_{1}z_{2}) + x_{2}^{2}z_{2}^{2}\)내적은 같은 자리끼리 곱해 더한 값입니다.
2\(= x_{1}^{2}z_{1}^{2} + 2 x_{1}x_{2}z_{1}z_{2} + x_{2}^{2}z_{2}^{2}\)\(\sqrt{2} \times \sqrt{2} = 2\) 입니다.
3\(= (x_{1}z_{1})^{2} + 2 (x_{1}z_{1})(x_{2}z_{2}) + (x_{2}z_{2})^{2}\)같은 숫자를 \(x_{1}z_{1}\) 과 \(x_{2}z_{2}\) 로 묶어 다시 썼습니다.
4\(= (x_{1}z_{1} + x_{2}z_{2})^{2}\)\(a^{2} + 2ab + b^{2} = (a + b)^{2}\) 에서 \(a = x_{1}z_{1}\), \(b = x_{2}z_{2}\).
5\(= (x\cdot z)^{2}\)\(x_{1}z_{1} + x_{2}z_{2}\) 가 \(x\cdot z\) 입니다.

2 줄의 \(2\) 가 4 줄의 \((a + b)^{2}\) 의 가운데 항 \(2ab\) 와 맞아떨어지도록 \(\sqrt{2}\) 를 붙인 것입니다.

이름 — 커널 트릭

이처럼 \(\varphi (x)\cdot \varphi (z)\) 를 \(\varphi \) 를 만들지 않고 \(K(x, z)\) 공식으로 바로 구하는 방법을 커널 트릭(kernel trick)이라 부릅니다. 쌍대문제와 판정식에 데이터가 내적으로만 들어 있었기에(4장 페이지 5) 가능한 일입니다. 고차원으로 실제로 올라가지 않고도 올라간 것과 같은 결과를 얻기 때문에 ‘트릭(꾀)’이라 부릅니다.

페이지 3 의 6개 항 다시 보기

상수 1 을 더한 \(K(x, z) = (x\cdot z + 1)^{2}\) 도 같은 방식으로 전개되고, 그 \(\varphi \) 는 페이지 3 의 6 개 항 전부입니다.

\[\varphi (x) = ( 1, \; \sqrt{2} x_{1}, \; \sqrt{2} x_{2}, \; x_{1}^{2}, \; \sqrt{2} x_{1}x_{2}, \; x_{2}^{2} )\]

같은 \(x = (1, 2)\), \(z = (3, 1)\) 로 확인하면 \(\varphi (x) = (1, \sqrt{2}, 2\sqrt{2}, 1, 2\sqrt{2}, 4)\), \(\varphi (z) = (1, 3\sqrt{2}, \sqrt{2}, 9, 3\sqrt{2}, 1)\) 이고 내적은 \(1 + 6 + 4 + 9 + 12 + 4 = 36\) 입니다. \((x\cdot z + 1)^{2} = (5 + 1)^{2} = 36\) 으로 같습니다. 일반 \(d\) 의 \((x\cdot z + 1)^d\) 는 차수 \(d\) 이하 모든 항(페이지 3 의 \(\binom{p+d}{d}\) 개)에 대응합니다(증명 생략). 페이지 3 의 표에서 “2.5 조”였던 \(p = 784\), \(d = 5\) 도 \((x\cdot z + 1)^{5}\) 로는 내적 한 번과 거듭제곱 한 번입니다.

원형 데이터는 이 커널로 분류됩니다

페이지 2 의 높이(그 페이지에서는 \(z\) 로 썼지만 \(K(x, z)\) 의 \(z\) 와 구분하려고 여기서는 \(h\) 라 씁니다) \(h = x_{1}^{2} + x_{2}^{2}\) 는 이 페이지 처음의 \(\varphi (x_{1}, x_{2}) = (x_{1}^{2}, \sqrt{2}x_{1}x_{2}, x_{2}^{2})\) 에서 첫째와 셋째 좌표의 합, \(\varphi _{1} + \varphi _{3}\) 입니다. 그래서 페이지 2 의 수평 평면 \(h = c\) 는 이 특징 공간에서 \(w = (-1, 0, -1)\), \(b = c\) 인 평면(\(f = c - \varphi _{1} - \varphi _{3}\))입니다. 곧 \(K(x, z) = (x\cdot z)^{2}\) 로 만든 SVM 에서 이 12 점은 분류됩니다. 페이지 2 에서 높이에 제곱근을 씌우지 않은 이유도 여기 있습니다. \(x_{1}^{2} + x_{2}^{2}\) 는 다항식 항의 합이라 이런 커널로 다룰 수 있습니다. SVM 이 실제로 고르는 평면은 마진이 가장 큰 것이라 이 평면과 다를 수 있습니다. 분류된다는 것까지가 이 페이지에서 확인한 사실입니다.

한계 — \(\varphi \) 는 하나로 정해지지 않습니다

\(\varphi '(x) = (x_{1}^{2}, x_{1}x_{2}, x_{2}x_{1}, x_{2}^{2})\) 처럼 4 개 좌표로 만들어도 \(\varphi '(x)\cdot \varphi '(z) = x_{1}^{2}z_{1}^{2} + 2x_{1}x_{2}z_{1}z_{2} + x_{2}^{2}z_{2}^{2} = (x\cdot z)^{2}\) 로 같은 \(K\) 가 나옵니다. 쌍대문제와 판정식은 \(K\) 만 보므로, 결과는 \(\varphi \) 가 아니라 \(K\) 하나로 정해집니다. 어떤 \(\varphi \) 를 쓰든 답은 같습니다.

RBF 커널의 수식 풀이

RBF 커널(Radial Basis Function, 가우시안 커널이라고도 합니다)은 \(K(x, z) = \exp (-\gamma \lVert x - z\rVert ^{2})\) 입니다. 기호를 하나씩 봅니다.

  • \(\lVert x - z\rVert ^{2}\) — 두 점 사이 거리의 제곱입니다. 2차원이면 \((x_{1} - z_{1})^{2} + (x_{2} - z_{2})^{2}\) 로, 페이지 2 에서 원점까지 거리의 제곱을 쓴 것과 같은 계산입니다(\(\lVert \cdot \rVert \) 는 1장 페이지 3 의 노름, 곧 길이).
  • \(\exp (u)\) — \(e^{u}\) 입니다(\(e \approx 2.718\)). \(u = 0\) 이면 1 이고, \(u\) 가 음수로 클수록 0 에 가깝습니다.
  • γ (감마) — 0 보다 큰 상수입니다. \(C\) 처럼 학습 전에 사람이 정하는 하이퍼파라미터입니다.

따라서 \(K\) 는 두 점이 같으면 \(\exp (0) = 1\) 이고, 멀어질수록 0 에 가까워지는 “닮은 정도” 점수입니다. \(\gamma \) 가 점수가 떨어지는 속도를 정합니다.

“무한 차원”이라는 말의 뜻

RBF 의 \(\varphi \) 는 좌표가 무한히 많다고 합니다. 점이 1차원(\(x, z\) 가 숫자)인 경우로 그 이유를 직관으로 따라가 봅니다.

줄식왜 이렇게 되는지
1\(\exp (-\gamma (x - z)^{2}) = e^{-\gamma x^{2}}e^{-\gamma z^{2}}e^{2\gamma xz}\)\((x - z)^{2} = x^{2} - 2xz + z^{2}\) 이고 \(e^{a+b+c} = e^{a}e^{b}e^{c}\).
2\(e^{2\gamma xz} = \sum _{k=0}^{\infty } (2\gamma )^{k} x^{k} z^{k} / k!\)테일러 전개 \(e^{u} = 1 + u + u^{2}/2! + u^{3}/3! + \ldots \) 에 \(u = 2\gamma xz\) 를 넣었습니다. 이 식은 증명 없이 씁니다.
3\(K(x, z) = \sum _{k} \varphi _{k}(x) \varphi _{k}(z)\),   \(\varphi _{k}(x) = e^{-\gamma x^{2}} \sqrt{(2\gamma )^{k}/k!}x^{k}\)2 줄의 각 항을 \(x\) 몫과 \(z\) 몫으로 나눴습니다. \(x^{k}z^{k}\) 는 \(x\) 쪽 \(x^{k}\) 와 \(z\) 쪽 \(z^{k}\) 로 나뉘고, 계수는 제곱근을 씌워 \(x\) 쪽과 \(z\) 쪽에 똑같이 나눕니다.

3 줄은 \(K(x, z) = \varphi (x)\cdot \varphi (z)\) 이고, \(\varphi (x) = (\varphi _{0}(x), \varphi _{1}(x), \varphi _{2}(x), \ldots )\) 에는 \(k = 0, 1, 2, \ldots \) 에 해당하는 좌표가 끝없이 이어집니다. 각 \(\varphi _{k}\) 는 가우시안 인자 \(e^{-\gamma x^{2}}\) 에 \(x\) 의 \(k\) 차 항을 곱한 꼴이라, \(\varphi _{0}\) 는 \(e^{-\gamma x^{2}}\), \(\varphi _{1}\) 은 여기에 \(x\) 의 1차 항, \(\varphi _{2}\) 는 2차 항을 곱한 식…으로 가우시안 인자가 붙은 모든 차수의 항이 들어 있는 셈입니다. 2차원 이상에서는 \(x^{k}z^{k}\) 자리에 \((x\cdot z)^{k}\) 가 들어가 모든 차수의 항이 들어갑니다. 이것이 “무한 차원”입니다.

무한 차원의 의미와 오해

  • 서로 다른 점들에 대해 RBF 그램 행렬은 가역(역행렬이 있음)임이 알려져 있어서(증명 생략), 점이 서로 다르기만 하면 레이블을 어떻게 붙여도 분류할 수 있는 특징 공간입니다. 표현력이 큰 만큼 \(\gamma \) 가 크면 점 하나하나를 외우는 과적합이 쉽게 일어납니다. 아래 위젯에서 볼 수 있습니다.
  • 분류할 수 있다는 것과 새 점을 잘 분류한다는 것은 다릅니다. 새 점에서의 성능은 \(\gamma \) 와 \(C\) 로 조절합니다.

직접 움직여 보기 — RBF 의 \(\gamma \) 와 \(C\)

\(\gamma \) 가 작으면 완만하고 크면 뾰족하다는 위의 설명을 위젯으로 확인합니다. 슬라이더를 움직일 때마다 페이지 4 의 커널 소프트 마진 쌍대문제(\(K\) 는 RBF)를 풀어 \(\alpha \) 와 \(b\) 를 구하고, 격자의 모든 점에서 \(f(x) = \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x) + b\) 를 계산해 영역을 칠합니다. 풀이 코드는 5장 위젯의 \(solveSoft\) 에서 내적 \(x\cdot x\) 를 \(K\) 로 바꾼 것입니다.

5장 위젯과 다른 점이 하나 있습니다. 5장에서는 풀이가 \(w\) 를 돌려줘서 직선을 바로 그렸습니다. RBF 에서는 \(w\) 가 무한 차원 벡터라 적을 수가 없고, 판정도 \(b\) 계산도 모두 커널의 합으로 처리합니다(\(b = y^{(k)} - \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x^{(k)})\), \(0 < \alpha ^{(k)} < C\) 인 점 \(k\) 들의 평균). 그래서 결정경계(\(f = 0\))는 선이 아니라 \(f\) 값의 등고선으로 그립니다.

커널의 조건

페이지 4 에서 \(K\) 는 \(\varphi (x)\cdot \varphi (z)\) 였습니다. 거꾸로 임의의 함수 \(K(x, z)\) 를 가져와 쌍대문제의 내적 자리에 끼우면 정말 그런 \(\varphi \) 가 있다는 보장이 있을까요? 없습니다. \(K\) 가 진짜 커널이면 어떤 점 \(n\) 개를 골라 그램 행렬을 만들어도 만족해야 하는 성질이 하나 있습니다.

조건 — 그램 행렬이 양의 준정부호

\(\sum \sum c_{i} c_{j} K_{ij} \ge 0\)   (어떤 수 \(c_{1}, \ldots , c_{n}\) 을 잡아도)

  • \(c_{1}, \ldots , c_{n}\) — 우리가 마음대로 고르는 실수들(음수 가능)입니다. 점마다 하나씩 붙이는 가중치라고 보면 됩니다.
  • 이 성질을 양의 준정부호라 부릅니다. 그램 행렬이 대칭이라는 것(\(K_{ij} = K_{ji}\))과 함께 요구됩니다.

진짜 커널은 이 조건을 항상 만족합니다. \(K_{ij} = \varphi (x^{(i)})\cdot \varphi (x^{(j)})\) 이므로 내적의 분배법칙(4장 페이지 3~4 에서 쓴 것)에 의해

\[\sum \sum c_{i} c_{j} K_{ij} = ( \sum c_{i}\varphi (x^{(i)}) ) \cdot ( \sum c_{j}\varphi (x^{(j)}) ) = \lVert \sum c_{i}\varphi (x^{(i)}) \rVert ^{2} \ge 0\]

위 식이 0 이상이 되는 이유는, 벡터를 자기 자신과 내적하면 길이의 제곱이 되기 때문입니다. 반대 방향도 알려져 있습니다. \(K\) 가 대칭이고 어떤 점들을 골라도 이 조건을 만족하면(이를 Mercer 조건이라 부릅니다) \(K = \varphi \cdot \varphi \) 인 \(\varphi \) 가 존재합니다. 이 방향의 증명과 엄밀한 서술(Mercer 정리)은 이 교재에서 생략합니다. 선형, 다항(\((x\cdot z + 1)^d\)), RBF 는 모두 이 조건을 만족하는 커널입니다.

반례 — 두 점 사이 거리의 제곱은 커널이 아닙니다

1차원에서 \(K(x, z) = (x - z)^{2}\) 라 하고 두 점 \(x^{(1)} = 0\), \(x^{(2)} = 1\) 을 잡습니다. 그램 행렬은 \(K_{11} = K_{22} = 0\), \(K_{12} = K_{21} = 1\) 입니다. \(c = (1, -1)\) 로 조건을 계산하면

\[\sum \sum c_{i}c_{j}K_{ij} = 2\times (1)(-1)\times 1 = -2 < 0\]

이 \(K\) 는 조건을 만족하지 않습니다. 제곱의 합인 \(\lVert \cdot \rVert ^{2}\) 가 음수일 수는 없으니 이런 \(K\) 는 어떤 \(\varphi \) 로도 \(\varphi (x)\cdot \varphi (z)\) 가 될 수 없습니다. 이런 \(K\) 를 쌍대문제에 끼우면 쌍대문제의 최댓값이 존재하지 않을 수 있습니다. 위의 두 점에 레이블을 \(+1, -1\) 로 주면 \(\sum \alpha y = 0\) 에서 \(\alpha ^{(1)} = \alpha ^{(2)} = a\) 이고 \(D = 2a + a^{2}\) 입니다. 상한 \(C\) 가 없다면 \(a\) 를 키울수록 끝없이 커져 최댓값이 없습니다.

재미있는 점은 \((x - z)^{2}\) 는 안 되는데 음의 부호를 붙여 지수 안에 넣은 \(\exp (-\gamma (x - z)^{2})\) (RBF)는 된다는 것입니다. 커널이 되는지는 식의 모양만 보고는 직관으로 알기 어려워서, 새 커널을 만들 때는 이 조건으로 확인합니다.

커널 SVM 의 예측식

페이지 4 에서 이미 적은 판정식이 최종 형태입니다. 한 번 더 정리합니다.

커널 SVM 의 예측식과 \(b\)

\(f(x) = \sum _{i} \alpha ^{(i)} y^{(i)} K(x^{(i)}, x) + b\),   새 점의 분류는 \(\operatorname{sign} f(x)\)

\(b = y^{(k)} - \sum _{i} \alpha ^{(i)} y^{(i)} K(x^{(i)}, x^{(k)})\)   (\(0 < \alpha ^{(k)} < C\) 인 점 \(k\))

  • 합에 기여하는 것은 서포트 벡터뿐입니다. \(\alpha ^{(i)} = 0\) 인 점의 항은 0 이라, 학습이 끝난 뒤에는 서포트 벡터와 그 \(\alpha \), \(y\), \(b\) 만 보관하면 됩니다. 위젯의 \(decision\) 함수가 정확히 이 식입니다.
  • \(b\) 도 커널로 구합니다. 5장 페이지 4 의 \(b = y - w\cdot x\) 에서 \(w\cdot x\) 가 \(\sum \alpha y K\) 로 바뀐 것입니다. \(0 < \alpha < C\) 인 점이 하나도 없으면 5장처럼 \(b\) 가 구간으로만 정해집니다(위젯에서 \(\gamma = 0.01\), \(C = 1\) 로 확인).
  • 선형 커널이면 \(\sum \alpha y (x^{(i)}\cdot x) = w\cdot x\) 로 한 번 합쳐 둘 수 있어서 판정에 \(w\) 하나면 됩니다. RBF 에서는 합칠 \(w\) 가 없어 서포트 벡터마다 \(K\) 를 계산해야 합니다.

커널 SVM 의 한계

커널 SVM 을 쓸 때의 한계

  • 점이 많을수록 급격히 느려집니다. 그램 행렬이 \(n \times n\) 이라 \(n = 10,000\) 이면 값 \(10^{8}\) 개(8 바이트씩이면 800 MB), \(n = 100,000\) 이면 \(10^{10}\) 개(80 GB)입니다. 구현에 따라 행렬 전체를 두지 않는 요령도 쓰지만, 학습 시간이 점의 수보다 훨씬 빠르게 늘어난다는 점은 남습니다(경험적으로 점 수의 제곱 이상으로 늘어나 수만 개를 넘으면 힘들어진다고 알려져 있습니다).
  • 예측 비용은 서포트 벡터 수에 비례합니다. 새 점 하나마다 서포트 벡터 개수만큼 \(K\) 를 계산합니다.
  • \(\gamma \) 와 \(C\) 가 과적합·과소적합을 정합니다. 위젯에서 본 것처럼 \(\gamma \) 가 너무 작으면 곡선이 휘지 못하고, 너무 크면 점마다 섬이 생깁니다. 정답은 데이터마다 달라 실전에서는 시험해서 고릅니다.
  • 커널 선택에 정답이 없습니다. 선형, 다항, RBF 중 무엇이 맞는지는 데이터의 모양에 달려 있고, 미리 알 방법이 마땅치 않아 비교해 봐야 합니다.
  • RBF 는 거리를 재므로 특성의 크기에 민감합니다. 한 특성이 다른 특성보다 값이 수백 배 크면 \(\lVert x - z\rVert ^{2}\) 가 그 특성 하나로 거의 결정됩니다.
  • \(f(x)\) 는 점수일 뿐 확률이 아닙니다. 마진 기준의 부호 있는 값이라 “+1 일 확률 0.9” 같은 해석을 바로 붙일 수 없습니다.

커널 트릭은 “직선밖에 못 긋는 도구”를 “곡선도 긋는 도구”로 바꾸는 대신, 점이 많아지면 계산 비용이 크게 늘어납니다. 이 장에서 얻은 것은 쌍대문제의 \(x\cdot x\) 자리에 \(K\) 를 끼우는 한 줄의 변화로 모양의 한계를 넘는다는 사실입니다.

핵심 요약

  1. 원형으로 둘러싼 데이터는 직선으로 분류하지 못하고(12 점 중 3 점은 틀림), \(C\) 로도 고쳐지지 않습니다. 모양의 문제이기 때문입니다. 점에 \(z = x_{1}^{2} + x_{2}^{2}\) 를 새 좌표로 붙이면 3차원에서 평면으로 분류되고, 평면을 되돌리면 원이 됩니다.
  2. 점을 새 좌표로 바꾸는 규칙이 특징 맵 \(\varphi \) 입니다. 직접 계산하면 특징 수가 \(\binom{p+d}{d}\)(\(p\) 는 점의 차원)로 급격히 늘어나고, \(p = 784\), \(d = 5\) 면 한 점이 2.5 조 개의 숫자입니다.
  3. 쌍대문제와 판정식에는 점이 내적으로만 들어 있어서 \(\varphi (x)\cdot \varphi (z)\) 만 구하면 됩니다. 이 값을 돌려주는 함수가 커널 \(K(x, z)\) 이고, \(x^{(i)}\cdot x^{(j)}\) 를 \(K(x^{(i)}, x^{(j)})\) 로 바꿔 쓰면 끝입니다. 예: \(\varphi = (x_{1}^{2}, \sqrt{2}x_{1}x_{2}, x_{2}^{2})\) 이면 \(\varphi (x)\cdot \varphi (z) = (x\cdot z)^{2}\). 이것이 커널 트릭입니다.
  4. 대표 커널은 선형, 다항 \((x\cdot z+1)^d\), RBF \(\exp (-\gamma \lVert x-z\rVert ^{2})\) 입니다. RBF 는 무한 차원 특징 공간에 해당하고, \(\gamma \) 는 서포트 벡터 하나의 영향 범위(대략 \(1/\sqrt{\gamma }\))를 정합니다. 너무 작으면 곡선이 안 휘고 너무 크면 점마다 섬이 생기며, \(C\) 와 함께 조절합니다.
  5. 커널이 되려면 그램 행렬이 대칭이고 양의 준정부호여야 합니다(Mercer 조건). 예측식은 \(f(x) = \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x) + b\) 로 서포트 벡터만 기여합니다. 점이 많아지면 \(n \times n\) 표 때문에 느려지고, \(f\) 는 확률이 아닙니다.

커널 트릭이 줄여 주는 것은 무엇일까요?

  1. 쌍대문제의 변수 α 의 개수
  2. 고차원 좌표 φ(x) 를 만들어 내적하는 계산
  3. 필요한 학습 점의 수

한 가지 더. 커널 트릭은 SVM 만의 것이 아니라 데이터가 내적으로만 들어 있는 모든 알고리즘에 쓸 수 있는 요령입니다. SVM 에서는 4장의 쌍대문제가 데이터를 내적으로만 쓰게 만들었기 때문에 가능했습니다. 원문제 \(w\cdot x\) 꼴에서는 \(w\) 라는 좌표 묶음이 필요해서 쓸 수 없었습니다. 쌍대로 푸는 이유가 여기서 하나 더 드러난 셈입니다.

페이지 6 의 위젯에서 잡음 한 점이 있는 데이터를 \(\gamma = 100\), \(C = 10\) 으로 학습했습니다. 어떤 모습일까요?

  1. 학습 점은 모두 정확히 분류하지만 점마다 작은 섬이 생겨 새 점은 잘 분류하지 못한다
  2. 경계가 거의 직선에 가까워지고 틀리는 점이 늘어난다
  3. 서포트 벡터가 거의 없어지고 경계가 매끄러워진다

학습 점을 모두 정확히 분류하는 것은 RBF 에서 어렵지 않습니다. \(\gamma \) 가 크면 점 하나하나를 외우기 쉽기 때문입니다(페이지 6). 그래서 학습 점의 정확도만으로는 \(\gamma \) 를 고를 수 없고, 학습에 쓰지 않은 점으로 시험해야 합니다. 위젯의 ‘새 점 시험’ 줄이 그 역할을 흉내 낸 것입니다.

\(K(x, z) = (x - z)^{2}\) 를 1차원에서 커널로 쓸 수 있을까요?

  1. 쓸 수 있다. 두 점 사이의 거리를 재는 자연스러운 함수이기 때문이다
  2. 쓸 수 있다. K(x, z) = K(z, x) 로 대칭이기 때문이다
  3. 쓸 수 없다. 그램 행렬이 양의 준정부호 조건을 어기는 점 선택이 있다

같은 거리 제곱을 부호를 바꿔 지수 안에 넣은 \(\exp (-\gamma (x - z)^{2})\) 가 RBF 이고 이것은 커널입니다. 그래서 “거리를 재는 함수라서”도 “대칭이라서”도 커널이 되는 이유가 아니고, 조건은 그램 행렬로 확인합니다. 아무 거리 함수나 SVM 에 끼우면 쌍대문제가 최댓값 없이 발산할 수 있습니다(페이지 7 의 \(D = 2a + a^{2}\)).

XOR 모양의 네 점입니다. \(x^{(1)} = (1, 1)\)(+1), \(x^{(2)} = (-1, -1)\)(+1), \(x^{(3)} = (1, -1)\)(−1), \(x^{(4)} = (-1, 1)\)(−1). 커널은 \(K(x, z) = (x\cdot z + 1)^{2}\) 입니다(\(C\) 는 충분히 크다고 합니다).

  1. 직선(선형 커널)으로 이 네 점을 분류할 수 없는 이유를 이 장 페이지 1 의 방법으로 설명하세요.
  2. 그램 행렬 \(K_{ij}\) (4 × 4)를 구하세요. 예: \(K_{11} = (x^{(1)}\cdot x^{(1)} + 1)^{2} = 9\).
  3. 대칭성으로 \(\alpha ^{(1)} = \alpha ^{(2)} = \alpha ^{(3)} = \alpha ^{(4)} = a\) 라고 가정합니다. \(\sum \alpha y = 0\) 이 성립하는지 확인하고 \(D(a)\) 를 \(a\) 의 식으로 쓴 뒤 최대가 되는 \(a\) 를 구하세요.
  4. \(b = 0\) 으로 놓고 \(f(x) = \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x) + b\) 를 네 점에서 계산해 \(y^{(i)}f(x^{(i)})\) 가 얼마인지 확인하고, 이것이 정말 답인지(3 번의 가정이 맞는지) 어떤 조건으로 검증할 수 있는지 말하세요.
모범답안과 흔한 실수

1. 두 +1 점의 한가운데 \(\tfrac12 x^{(1)} + \tfrac12 x^{(2)} = (0, 0)\) 과 두 −1 점의 한가운데 \(\tfrac12 x^{(3)} + \tfrac12 x^{(4)} = (0, 0)\) 이 같은 점입니다. \(f(0) = \tfrac12 f(x^{(1)}) + \tfrac12 f(x^{(2)}) > 0\) (둘 다 +1 쪽이니), 동시에 \(f(0) = \tfrac12 f(x^{(3)}) + \tfrac12 f(x^{(4)}) < 0\) 이라 모순입니다.

2. \(K_{ii} = (2 + 1)^{2} = 9\). 서로 다른 점의 내적은 \(x^{(1)}\cdot x^{(2)} = -2\), \(x^{(1)}\cdot x^{(3)} = 0\), \(x^{(1)}\cdot x^{(4)} = 0\), \(x^{(2)}\cdot x^{(3)} = 0\), \(x^{(2)}\cdot x^{(4)} = 0\), \(x^{(3)}\cdot x^{(4)} = -2\) 입니다. 그래서 \(x^{(1)}x^{(2)}\) 쌍과 \(x^{(3)}x^{(4)}\) 쌍은 \((-2 + 1)^{2} = 1\), 나머지 쌍은 \((0 + 1)^{2} = 1\) 이라 대각선은 9, 나머지 칸은 모두 1 입니다.

3. \(\sum \alpha y = a(+1 + 1 - 1 - 1) = 0\) ✓. \(y^{(i)}y^{(j)}K_{ij}\) 를 모두 더하면, 대각 4 칸은 \(4 \times 9 = 36\), 같은 레이블 쌍(\((1,2), (2,1), (3,4), (4,3)\))은 \(y y = +1\) 이고 \(K = 1\) 이라 4, 다른 레이블 쌍 8 칸은 \(y y = -1\) 이라 \(-8\) 이어서 합이 \(36 + 4 - 8 = 32\) 입니다. 따라서 \(D(a) = 4a - \tfrac12 \times 32a^{2} = 4a - 16a^{2}\), 미분이 0 인 \(4 - 32a = 0\) 에서 \(a = 1/8\), \(D = \tfrac12 - \tfrac14 = \tfrac14 \).

4. \(f(x) = \tfrac18\left[K(x^{(1)}, x) + K(x^{(2)}, x) - K(x^{(3)}, x) - K(x^{(4)}, x)\right]\). \(x = x^{(1)}\) 이면 \(\tfrac18 (9 + 1 - 1 - 1) = 1\), 나머지 세 점도 \(y f = 1\) 입니다(\(y^{(i)}f(x^{(i)}) = 1\) 네 개 모두). 정리하면 \(f(x) = x_{1}x_{2}\) 입니다(예: \(f(0.5, 0.5) = 0.25\), \(f(1, 2) = 2\)). 검증은 KKT 로 합니다. 쌍대 가능성(\(0 \le \alpha \le C\), \(\sum \alpha y = 0\)) ✓, 원문제 가능성(\(y f \ge 1\)) ✓, 상보 여유성(\(\alpha > 0\) 인 모든 점에서 \(y f = 1\)) ✓ 이므로 이 \(\alpha \) 가 쌍대문제의 최적해입니다(3장·4장의 KKT 충분조건). \(0 < \alpha < C\) 인 점이 있으니 \(b\) 도 \(b = y^{(k)} - \sum \alpha y K = 1 - 1 = 0\) 으로 확인됩니다.

덧붙임. 이 \(f\) 는 페이지 5 의 6 차원 \(\varphi \) 에서 \(\sqrt{2} x_{1}x_{2}\) 좌표 하나만 쓰는 평면입니다(\(w = (0, 0, 0, 0, 1/\sqrt{2}, 0)\), \(\tfrac12 \lVert w\rVert ^{2} = \tfrac14 \) 로 \(D\) 와 일치).

흔한 실수 1 — 3 번의 “\(\alpha \) 가 모두 같다”를 사실로 두고 끝내기. 대칭성은 그럴듯한 가정일 뿐이고 4 번의 KKT 검증으로 최적임을 확인해야 합니다. 가정으로 얻은 값은 후보입니다.

흔한 실수 2 — \(K\) 를 \(\varphi (x)\cdot \varphi (z)\) 가 아니라 “\(\varphi (x\cdot z)\)” 로 읽기. \(K(x, z) = (x\cdot z + 1)^{2}\) 는 \(x\cdot z\) 를 먼저 구한 값을 제곱한 것이고, 그 값이 두 점 각각의 \(\varphi \) 를 내적한 것과 같다는 것이 페이지 5 의 내용입니다.

흔한 실수 3 — 선형 커널로는 분류할 수 없으니 점이 부족하다고 결론 내리기. 점을 늘려도 두 쌍의 한가운데가 같은 점이라는 사실은 사라지지 않습니다. 모양의 문제이지 점의 수의 문제가 아닙니다.
