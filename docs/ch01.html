1장 · 페이지 1

점들을 분류하는 직선

파란 점과 빨간 점이 흩어져 있고, 그 사이에 새 점이 하나 나타났습니다. 이 점은 어느 쪽일까요? 서포트 벡터 머신(SVM)은 이런 점들을 직선(점이 3차원 이상이면 초평면)으로 나누어 분류하는 방법입니다. 이 교재는 8장에 걸쳐, 직선을 어떻게 그어야 가장 안전한지(그 안전한 정도가 마진입니다)를 밑바닥부터 차근차근 살펴봅니다. 초평면은 곧 페이지 2에서, 마진은 2장에서 뜻을 풀어 드리니 지금은 낯설어도 괜찮습니다. 1장에서는 먼저 직선으로 점을 분류하는 일을 ‘눈대중’이 아니라 ‘숫자’로 처리하는 기본 방법을 익힙니다.

문제 상황

스팸 메일 걸러내기를 떠올려 보세요. 메일 한 통을 숫자 두 개(예를 들어 링크의 개수와 느낌표의 개수)로 요약하면 평면 위의 점 하나가 됩니다. 이미 사람이 ‘스팸/정상’을 가려 둔 메일들은 파란 점과 빨간 점으로 찍혀 있고, 새로 도착한 메일은 점 하나(?)로 나타납니다. 이렇게 새 입력이 미리 정해진 범주 중 어디에 속하는지 맞히는 문제를 분류라고 합니다.

말을 정확히 해 두겠습니다. 점 하나를 설명하는 숫자 하나하나(가로 좌표, 세로 좌표)를 특성이라 하고, 점 하나를 \(x = (x_{1}, x_{2})\) 로 씁니다. 여기서 \(x_{1}\) 은 가로 좌표, \(x_{2}\) 는 세로 좌표입니다. 점마다 붙어 있는 정답 표시를 레이블 \(y\) 라고 하며, 파랑이면 \(+1\), 빨강이면 \(-1\) 로 쓰기로 합니다. 정답을 이미 아는 점들을 학습 데이터라고 부릅니다.

이 교재 전체에서 계속 사용할 관통 예제는 바로 이 세 점입니다.

점좌표 \(x = (x_{1}, x_{2})\)레이블 \(y\)색
x(1)(3, 3)+1파랑
x(2)(4, 3)+1파랑
x(3)(1, 1)−1빨강

기호 약속 — 이 교재 내내 씁니다

아래첨자 \(x_{1}, x_{2}\) 는 한 점의 가로·세로 좌표이고, 위에 괄호를 씌운 \(x^{(1)}, x^{(2)}, x^{(3)}\) 은 몇 번째 점인지를 나타냅니다. 위 표의 점 이름은 모두 후자입니다. 이 세 점은 2장에서 마진(가장 안전한 직선의 여유)을 구하고, 4장에서 손으로 SVM 의 답을 구하고, 7장에서 코드로 다시 확인할 때까지 계속 나옵니다. 지금 외울 필요는 없고, 나올 때마다 다시 적어 드립니다.

새 점 ? 는 파랑 점 \(x^{(1)}\) 에서 거리 1 만큼 떨어져 있고, 빨강 점에서는 훨씬 멉니다(√5≈2.2). 눈으로는 파랑 쪽 같습니다. 하지만 점이 수천 개이고 특성이 수백 개가 되면 눈으로는 판단할 수 없습니다. 그래서 이 장에서 답할 질문은 이것입니다. 직선을 식으로 어떻게 나타내고, 새 점이 그 직선의 어느 쪽에 있는지를 숫자로 어떻게 판단할 수 있을까?

1장 · 페이지 2

직선의 방정식을 \(w\cdot x+b=0\) 로 다시 쓰기

점들을 두 무리로 나누는 가장 단순한 도구는 직선입니다. 직선의 방정식은 학교에서 이미 배우셨습니다. 다만 이 교재에서는 \(y\) 를 레이블로 쓰므로, 가로를 \(x_{1}\), 세로를 \(x_{2}\) 로 쓰겠습니다.

익숙한 꼴. 점 (0, 4) 와 (4, 0) 을 지나는 직선은 \(x_{2} = -x_{1} + 4\) 입니다 (기울기 −1, 세로 절편 4). 검산해 보면 (2, 2) 를 넣었을 때 오른쪽은 −2+4 = 2 로 왼쪽의 \(x_{2}\) = 2 와 같습니다. 이제 모든 항을 왼쪽으로 옮깁니다.

\[x_{1} + x_{2} - 4 = 0\]

이 직선은 왼쪽 식의 값이 정확히 0 이 되는 점들의 모임입니다. (4, 0) 을 넣으면 4+0−4 = 0, (2, 2) 는 2+2−4 = 0, (0, 4) 는 0+4−4 = 0 입니다. 직선 위가 아닌 점, 예를 들어 (3, 3) 은 3+3−4 = 2 로 0 이 아닙니다. 이 “0 이냐 아니냐”를 기억해 두세요. 다음 페이지에서 중요하게 쓰입니다.

왜 다시 쓰는가

첫째, \(x_{2} = (\text{기울기})x_{1} + (\text{절편})\) 꼴은 세로선을 쓸 수 없습니다. 세로선은 기울기가 무한대이기 때문입니다. 그러나 \(x_{1} - 2.5 = 0\) 은 세로선을 문제없이 나타냅니다. 둘째, 특성이 둘이 아니라 셋, 열, 수백 개가 되어도 같은 꼴로 이어 쓸 수 있습니다. 그래서 이 교재에서는 모든 항을 왼쪽으로 모은 다음 꼴을 기본으로 씁니다.

\[w_{1}x_{1} + w_{2}x_{2} + b = 0\]

기호뜻\(x_{1}+x_{2}-4=0\) 이라면
\(x_{1}, x_{2}\)직선 위(또는 밖)에 있는 점 하나의 가로·세로 좌표값이 정해져 있지 않은 변수
\(w_{1}, w_{2}\)각 좌표에 곱해 주는 수 (가중치, weight). 직선의 기울어진 정도를 정합니다\(w_{1} = 1\), \(w_{2} = 1\)
\(b\)좌표와 상관없이 더해지는 상수 (편향, bias). 직선을 평행하게 옮깁니다\(b = -4\)

좌표를 \(x = (x_{1}, x_{2})\), 가중치를 \(w = (w_{1}, w_{2})\) 라는 벡터로 묶으면 \(w_{1}x_{1} + w_{2}x_{2}\) 는 두 벡터를 “같은 자리끼리 곱해서 더한 값”, 즉 내적 \(w\cdot x\) 입니다. 그러면 위의 식은 한 줄로 줄어듭니다.

\[w\cdot x + b = 0\]

다른 책의 표기

다른 책에서는 같은 값을 \(w^{T}x\) 로 쓰기도 합니다. 벡터를 세로로 세워 둔 행렬로 보고 곱하는 표기인데, 결과는 \(w\cdot x\) 와 같은 숫자 하나입니다. 이 교재는 계속 \(w\cdot x\) 로 씁니다.

곱셈 기호 약속

이 교재에서 가운뎃점 \(\cdot\) 은 벡터끼리의 내적에만 씁니다. 수나 문자 사이의 곱은 \(tw\), \(\alpha y\) 처럼 기호를 생략하고, 숫자끼리는 \(3 \times 4\) 처럼 \(\times\) 로 씁니다 (생략하면 12 가 아니라 34 처럼 읽히기 때문입니다). 같은 자리끼리 곱해서 결과가 벡터로 남는 원소별 곱은 \(\odot\) 로 씁니다. 예: \((1, 2)\odot (3, 4) = (3, 8)\) 이고, 이 값을 더해 숫자 하나로 만든 것이 내적 \((1, 2)\cdot (3, 4) = 11\) 입니다.

직선 \(x_{1}+x_{2}-4=0\) 은 \(w = (1, 1)\), \(b = -4\) 인 경우입니다.

같은 직선을 나타내는 (w, b) 는 하나가 아닙니다

식 전체에 0 이 아닌 수를 곱해도 직선은 그대로입니다. \(x_{1}+x_{2}-4=0\) 의 양변에 ½ 을 곱한 \(\tfrac12 x_{1} + \tfrac12 x_{2} - 2 = 0\) 도 같은 직선입니다. 검산: (4, 0) → 2+0−2 = 0, (2, 2) → 1+1−2 = 0 입니다. 이 사실은 페이지 4 에서 다시 만납니다.

이렇게 \(w\cdot x+b=0\) 으로 쓴 점들의 집합에 이름이 있습니다. 2차원에서는 직선이지만 3차원에서는 평면, 그보다 높은 차원에서는 “평평한 판”이 되지만 식은 그대로입니다. 이 일반적인 대상을 초평면이라 부릅니다. 점들을 두 범주로 나누는 경계라는 역할에 초점을 맞출 때는 결정경계라고도 합니다. 이 교재에서 “초평면”이라고 하면 지금은 “\(w\cdot x+b=0\) 인 직선”이라고 읽으시면 됩니다.

1장 · 페이지 3

내적 복습과 부호의 의미

직선 위 점들은 \(w\cdot x+b\) 가 0 이었습니다. 그렇다면 직선 밖의 점은 이 값이 어떻게 될까요? 결론부터 말씀드리면 직선 한쪽은 양수, 반대쪽은 음수가 됩니다. 이유를 내적으로 풀어 보겠습니다.

내적의 의미

두 벡터 \(a = (a_{1}, a_{2})\), \(c = (c_{1}, c_{2})\) 의 내적은 \(a\cdot c = a_{1}c_{1} + a_{2}c_{2}\) 입니다. 예를 들어 \(w = (1, 1)\) 과 \(x^{(1)} = (3, 3)\) 이면 \(w\cdot x^{(1)} = 1\times 3 + 1\times 3 = 6\) 입니다. 이 값에는 기하학적 뜻이 있습니다.

\[a\cdot c = \lVert a\rVert\,\lVert c\rVert \cos \theta \]

\(\lVert a\rVert \) 는 벡터 \(a\) 의 길이(노름)로 \(\sqrt{a_{1}^{2}+a_{2}^{2}}\) 이고, \(\theta \) 는 두 벡터 사이의 각입니다. 길이를 따로 떼어 놓고 보면 내적은 두 벡터가 얼마나 같은 방향을 향하는지를 나타내는 값입니다. 같은 방향(θ=0°)이면 가장 크고, 수직(θ=90°)이면 cos 90° = 0 이라 0, 반대 방향이면 음수입니다. 검산: \((1, 1)\cdot (1, 0) = 1\) 이고, \(\lVert (1,1)\rVert = \sqrt{2}\), \(\lVert (1,0)\rVert = 1\), θ = 45° 이므로 \(\sqrt{2} \times 1 \times \cos 45^\circ = \sqrt{2} \times (\sqrt{2}/2) = 1\) 로 같습니다. 또 \((1, 1)\cdot (1, -1) = 1 - 1 = 0\) 이니 두 벡터는 수직입니다.

왜 w 는 직선에 수직인가

직선 위의 두 점 \(a\), \(c\) 를 잡으면 둘 다 식을 0 으로 만듭니다.

\(w\cdot a + b = 0\),   \(w\cdot c + b = 0\)

위 식에서 아래 식을 빼면 \(b\) 가 사라지고 \(w\cdot a - w\cdot c = w\cdot (a - c) = 0\) 이 남습니다. \(a - c\) 는 직선을 따라가는 방향의 벡터이고, 내적이 0 이라는 것은 수직이라는 뜻입니다. 즉 \(w\) 는 직선과 수직이고, 이런 벡터를 법선 벡터라고 합니다. 숫자로 확인하면, \(x_{1}+x_{2}-4=0\) 위의 두 점 \(a = (4, 0)\), \(c = (0, 4)\) 에서 \(a - c = (4, -4)\), \(w\cdot (a - c) = 1\times 4 + 1\times (-4) = 0\) 입니다.

부호와 분류 규칙

이제 \(f(x) = w\cdot x + b\) 라고 이름 붙이겠습니다. 직선 위의 한 점 \(p\) (그래서 \(f(p) = 0\)) 에서 \(w\) 방향으로 \(t\) 만큼 이동하면,

\[f(p + tw) = w\cdot p + t(w\cdot w) + b = (w\cdot p + b) + t\lVert w\rVert ^{2} = t\lVert w\rVert ^{2}\]

여기서 \(w\cdot w = \lVert w\rVert ^{2}\) 이므로 값은 \(t\lVert w\rVert ^{2}\) 입니다. \(t > 0\) 이면 양수, \(t < 0\) 이면 음수입니다. 직선 방향 \(d\) (\(w\cdot d = 0\)) 로 \(s\) 만큼 움직여도 \(f(p + sd) = w\cdot p + s(w\cdot d) + b = 0\) 이라 여전히 직선 위입니다. 그러므로 평면의 모든 점은 \(p + sd + tw\) 꼴로 쓸 수 있고, 그 점의 값은 \(t\lVert w\rVert ^{2}\) 입니다. 따라서 \(f(x) > 0\) 이면 \(w\) 가 가리키는 쪽, \(f(x) < 0\) 이면 그 반대쪽, \(f(x) = 0\) 이면 직선 위입니다. 검산: \(p = (2, 2)\), \(t = 1\) 이면 \(p + tw = (3, 3)\) 이고 \(f = 2 = 1\times \lVert w\rVert ^{2} = 1\times 2\) 입니다. \(t = -1\) 이면 (1, 1) 이고 \(f = -2\) 입니다.

따라서 분류 규칙은 한 줄입니다. 예측 레이블을 \(\hat{y} \) 이라 하면,

\[\hat{y} = \operatorname{sign}( w\cdot x + b )\]

sign 은 양수면 +1, 음수면 −1 을 돌려주는 함수입니다(0 이면 어느 쪽도 아니라는 뜻으로, 직선 위의 점입니다). 직선 \(w = (1, 1)\), \(b = -4\) 로 관통 예제를 계산해 보겠습니다. 새 점 ? 는 \(q = (2, 3)\) 이라 부르겠습니다.

점계산 \(w\cdot x+b\)값부호실제 레이블
x(1) = (3, 3)1×3 + 1×3 − 42+ → +1+1 (맞음)
x(2) = (4, 3)1×4 + 1×3 − 43+ → +1+1 (맞음)
x(3) = (1, 1)1×1 + 1×1 − 4−2− → −1−1 (맞음)
새 점 q = (2, 3)1×2 + 1×3 − 41+ → +1(모름) 파랑으로 예측

레이블을 +1, −1 로 정한 이유를 여기서 알 수 있습니다.

“맞게 분류했다” = \(y\) 와 \(f(x)\) 의 부호가 같다

\(y\) 는 +1 또는 −1 이므로, 부호가 같으면 곱 \(y\,f(x)\) 가 양수이고 다르면 음수입니다. 그래서 맞게 분류했는지는 \(y(w\cdot x + b) > 0\) 한 줄로 확인합니다.

예: \(x^{(1)}\) 은 (+1)×2 = 2 > 0, \(x^{(3)}\) 은 (−1)×(−2) = 2 > 0 입니다. 이 한 줄은 2장에서 제약 조건의 바탕이 됩니다. 한 가지 주의할 점은, 값 2, 3 이 곧 “직선까지의 거리”는 아니라는 것입니다. 거리와의 정확한 관계는 2장에서 구합니다.

아무 직선이나 그어도 될까?

세 점을 올바르게 분류하는 직선을 찾았으니 일이 끝난 것 같습니다. 그런데 정말 그럴까요? 다음 네 직선을 보세요.

직선식\(x^{(1)}\)\(x^{(2)}\)\(x^{(3)}\)새 점 ?판정
가\(x_{1}+x_{2}-2.5=0\)3.54.5−0.52.5파랑
나\(x_{1}+x_{2}-4=0\)23−21파랑
다\(x_{1}+x_{2}-5.5=0\)0.51.5−3.5−0.5빨강
라\(x_{1}-2.5=0\)0.51.5−1.5−0.5빨강

표의 값은 각 직선의 \(w\cdot x+b\) 입니다. 예를 들어 ‘가’ 는 \(w = (1, 1)\), \(b = -2.5\) 이므로 \(x^{(3)}\) 에서 1+1−2.5 = −0.5, 새 점에서 2+3−2.5 = 2.5 입니다. ‘라’ 는 \(w = (1, 0)\), \(b = -2.5\) 인 세로선입니다. 세 학습 점의 부호는 (+, +, −) 로 네 직선이 똑같으니 학습 데이터만 보면 네 직선 모두 100% 정답입니다. 그런데 새 점 ? 의 판정은 가·나 직선은 파랑, 다·라 직선은 빨강으로 엇갈립니다.

문제 — 답이 하나로 정해지지 않습니다

세 점을 올바르게 분류하는 직선은 네 개가 아니라 무수히 많습니다. 직선 \(x_{1}+x_{2}=c\) 를 보면 \(x^{(3)}\) 이 반대쪽에 있으려면 \(2 - c < 0\), 즉 \(c > 2\), \(x^{(1)}\) 이 파랑 쪽에 있으려면 \(6 - c > 0\), 즉 \(c < 6\) 이어야 합니다 (\(x^{(2)}\) 는 \(7 - c > 0\) 이라 자동으로 통과). 2 와 6 사이의 모든 실수 c 가 정답이니 직선은 셀 수도 없이 많습니다. 게다가 분류만 맞으면 멈추는 학습법(퍼셉트론이 대표적입니다)은 시작값과 점을 읽는 순서에 따라 이 중 아무 직선이나 내놓습니다. 학습 데이터에서는 어느 직선도 모두 맞게 분류하므로, 학습 데이터만으로는 어느 직선이 더 나은지 구별할 수 없습니다.

어느 직선이 더 나을까

힌트는 “새 점은 기존 점들 근처에 조금씩 흩어져 나타난다”는 것입니다. 측정에는 늘 오차가 있기 때문입니다. 이 관점에서 직선을 다시 살펴보겠습니다.

  • 가 직선은 빨강 점 \(x^{(3)}\) 에 바싹 붙어 있습니다. \(x^{(3)}\) 이 (1, 1) 에서 (1.5, 1.5) 로 살짝만 움직여도 값이 1.5+1.5−2.5 = 0.5 > 0 이 되어 파랑으로 오분류됩니다. 같은 움직임이 나 직선에서는 어떨까요? 값이 1.5+1.5−4 = −1 < 0 이라 여전히 맞습니다.
  • 다 직선은 반대로 파랑 점 \(x^{(1)}\) 에 붙어 있습니다. \(x^{(1)}\) 이 (2.7, 2.7) 로 조금 밀리면 2.7+2.7−5.5 = −0.1 < 0 으로 틀립니다. 나 직선은 2.7+2.7−4 = 1.4 > 0 으로 안전합니다.

점에 바싹 붙은 직선은 작은 흔들림에도 틀리고, 양쪽 점들에게서 최대한 멀리 떨어진 직선이 가장 안전합니다. ‘나’ 직선이 바로 그렇습니다. 이유는 계산으로 확인할 수 있습니다. ‘나’ 직선은 점 (2, 2) 를 지나고, \(x^{(1)}\) 과 \(x^{(3)}\) 의 한가운데가 바로 (2, 2) 입니다. \(x^{(1)}\) 에서 (2, 2) 로 가는 벡터는 (−1, −1) 이고 \(w = (1, 1)\) 과 평행(방향만 반대)이라 직선과 수직입니다. 즉 ‘나’ 직선은 \(x^{(1)}\) 과 \(x^{(3)}\) 을 잇는 선분을 정확히 수직으로 이등분하며, 두 점에서 똑같이 √2 만큼 떨어져 있습니다 (\((3,3) - (2,2) = (1,1)\) 의 길이가 √2). 한 가지 더 짚어 둘 점이 있습니다. ‘나’ 직선을 이렇게 정하는 데 \(x^{(2)}\) 는 필요하지 않았습니다. 이것이 우연이 아니라는 사실을 4장에서 보게 됩니다.

이 직관에 이름을 붙이고 식으로 나타내는 것이 2장의 내용입니다. 지금은 이름 없이 “양쪽에서 가장 멀리 떨어진 직선”이라고만 기억해 주세요.

나중에 다룰 것 — 정답 직선

이 관통 예제의 정답 직선은 \(x_{1} + x_{2} - 4 = 0\), 곧 \(\tfrac12 x_{1} + \tfrac12 x_{2} - 2 = 0\) 입니다. 방금은 ‘두 점의 한가운데를 지나니 그럴듯하다’ 수준으로 짚어 보았을 뿐입니다. 이 직선이 정말 가장 멀리 떨어진 직선인지를 식으로 보이는 일, 그리고 왜 하필 ½ 꼴로 적는지(그 꼴이면 \(x^{(1)}\) 에서 ½×3+½×3−2 = +1, \(x^{(3)}\) 에서 ½+½−2 = −1 이 되어 값이 정확히 ±1 로 떨어지기 때문입니다)는 2장에서 다룹니다. 2장에서 다룸

한계 — 직선으로는 구분할 수 없는 데이터도 있습니다

지금까지는 직선 하나로 깔끔하게 구분되는 경우만 봤습니다. 빨강 점들 한가운데 파랑 점이 하나 끼어 있거나(이상치), 파랑 점들이 빨강 점들을 동그랗게 에워싸고 있다면, 어떤 직선을 그어도 틀리는 점이 생깁니다. 그 경우를 위한 장치가 각각 5장(소프트 마진)과 6장(커널 트릭)에 있습니다. 이 장과 다음 몇 장은 일단 ‘직선으로 구분할 수 있다’는 가정 아래에서 진행합니다.

1장 · 페이지 5

1장 마무리

핵심 요약

  1. 분류는 점에 파랑(+1)/빨강(−1) 레이블을 붙이는 문제이고, 직선은 \(w\cdot x+b=0\) 으로 씁니다.
  2. \(w\) 는 직선에 수직인 법선 벡터이고, \(b\) 는 직선을 밀어 옮깁니다. 같은 직선을 나타내는 \((w, b)\) 는 무수히 많습니다.
  3. \(w\cdot x+b\) 가 양수면 \(w\) 가 가리키는 쪽, 음수면 반대쪽이라, \(\hat{y} = \operatorname{sign}(w\cdot x+b)\) 로 분류하고 맞았는지는 \(y(w\cdot x+b) > 0\) 으로 확인합니다.
  4. 세 점을 올바르게 분류하는 직선은 무수히 많고 새 점의 판정이 직선마다 엇갈립니다. 양쪽에서 가장 멀리 떨어진 직선이 안전해 보인다는 것이 2장의 출발점입니다.

직선 \(w = (2, -1)\), \(b = -1\) 로 점 (1, 1.5) 를 분류하면 어떻게 될까요?

  1. +1 (파랑), 왜냐하면 w·x = 0.5 > 0 이므로
  2. −1 (빨강), 왜냐하면 w·x + b = −0.5 < 0 이므로
  3. 직선 위에 있다 (w·x+b = 0)

여기서 \(b\) 를 빼먹는 실수는 구현에서도 흔합니다. 그래서 코드에서는 점에 상수 1 을 하나 덧붙여 \((x_{1}, x_{2}, 1)\), 가중치에 \(b\) 를 덧붙여 \((w_{1}, w_{2}, b)\) 로 만들고 내적 한 번으로 \(w\cdot x+b\) 를 계산하는 요령을 자주 씁니다. 두 벡터의 내적은 \(w_{1}x_{1} + w_{2}x_{2} + b\times 1\) 이라 값이 정확히 같습니다. 이렇게 하면 \(b\) 도 다른 가중치처럼 한꺼번에 다룰 수 있습니다.

\((w, b) = (1, 1, -4)\) 와 \((3, 3, -12)\) 는 같은 직선일까요? 두 경우의 분류 결과는 어떨까요?

  1. 다른 직선이다. w 가 다르기 때문이다
  2. 같은 직선이고, 값이 3배가 될 뿐 분류 결과도 같다
  3. 같은 직선이지만 분류 결과는 반대가 된다

분류기가 쓰는 것은 부호뿐이라 양수배를 해도 결과가 달라지지 않습니다. 하지만 값의 크기가 “직선에서 얼마나 떨어졌나”를 말해 주는 척도로 쓰이려면 크기를 정해 둘 규칙이 필요합니다. 마음대로 3배, 100배를 할 수 있으면 값 자체에 아무 뜻이 없기 때문입니다. SVM 은 2장에서 그 규칙을 하나 세웁니다.

직접 해 보기

직선 \(w = (1, 2)\), \(b = -5\) (식으로는 \(x_{1} + 2x_{2} - 5 = 0\)) 가 주어졌습니다.

  1. 관통 예제 세 점 \(x^{(1)}, x^{(2)}, x^{(3)}\) 에서 \(w\cdot x+b\) 를 계산하고 분류가 맞는지 확인하세요.
  2. 새 점 \(q = (2, 3)\) 은 어느 쪽으로 분류될까요?
  3. \(w\) 와 \(b\) 를 모두 2배한 \((2, 4, -10)\) 에서 세 점의 값은 어떻게 변할까요?
  4. 세 점을 올바르게 분류하면서 새 점 \(q\) 를 이 직선과 다르게 분류하는 직선을 하나 직접 만들어 보세요(\(w\cdot x+b\) 값 네 개로 증명).
모범답안과 흔한 실수

1. \(x^{(1)}\): 1×3 + 2×3 − 5 = 4 > 0 → +1 (맞음). \(x^{(2)}\): 1×4 + 2×3 − 5 = 5 > 0 → +1 (맞음). \(x^{(3)}\): 1×1 + 2×1 − 5 = −2 < 0 → −1 (맞음). 세 점 모두 맞습니다.

2. \(q\): 1×2 + 2×3 − 5 = 3 > 0 이므로 +1, 파랑입니다.

3. 값은 8, 10, −4 로 정확히 2배가 되고 부호는 그대로입니다. 같은 직선이라는 증거입니다.

4. 정답은 여럿입니다. 한 예로 \(w = (1, 1)\), \(b = -5.5\): \(x^{(1)}\) 은 0.5, \(x^{(2)}\) 는 1.5, \(x^{(3)}\) 은 −3.5 이므로 (+, +, −) 로 세 점을 맞게 분류하고, \(q\) 는 2+3−5.5 = −0.5 < 0 이라 빨강입니다. 1번의 직선과 새 점의 판정이 달라졌습니다.

흔한 실수 1 — \(b\) 를 빼먹기. \(w\cdot x\) 만 보면 \(x^{(3)}\) 이 1+2 = 3 > 0 이라 파랑으로 오판합니다. 직선이 원점을 지날 때만 \(b\) 를 빼도 됩니다.

흔한 실수 2 — “값이 큰 쪽이 파랑”이라고 기억하기. 기준은 값의 크기가 아니라 부호입니다. 그리고 \(w\) 의 방향이 바뀌면(예: 모든 값에 −1 을 곱하면) 파랑이 음수 쪽이 됩니다.

이 교재가 가는 길 — 4번의 답이 여러 개라는 것이 이 장에서 제기하는 문제입니다. 정답을 하나로 좁히는 기준(양쪽에서 가장 멀리)을 2장에서 식으로 만듭니다.
