풀어야 할 문제

6장에서 받은 문제를 그대로 적습니다. 이 장의 코드가 하는 일은 이것 하나입니다.

커널 소프트 마진 쌍대문제 (6장에서 받은 것)

\[\max _{\alpha } \; D(\alpha ) = \sum \alpha ^{(i)} - \tfrac12 \sum _{i}\sum _{j} \alpha ^{(i)}\alpha ^{(j)} y^{(i)}y^{(j)} K_{ij}\]

\[\text{s.t.} \; 0 \le \alpha ^{(i)} \le C \; (\text{모든} i), \; \; \sum \alpha ^{(i)}y^{(i)} = 0\]

구할 것은 점마다 하나씩, \(n\) 개의 \(\alpha ^{(i)}\) 입니다. \(y^{(i)}\) 는 레이블(±1), Kij = K(x⁽ⁱ⁾, x⁽ʲ⁾) 는 6장의 그램 행렬 칸, \(C\) 는 5장의 침범 단가입니다. 풀고 나면 \(f(x) = \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x) + b\) 로 새 점을 분류합니다.

어디가 까다로운가

제약이 두 종류입니다. \(0 \le \alpha ^{(i)} \le C\) 는 변수마다 따로 지키면 되니 쉽습니다. 까다로운 것은 \(\sum \alpha ^{(i)}y^{(i)} = 0\) 하나입니다. 이 식이 모든 \(\alpha \) 를 한 줄로 묶어서, 변수 하나를 움직이면 다른 변수가 따라 움직여야 합니다. 왜 그런지는 화면 2 에서 숫자로 봅니다.

SMO 의 아이디어 — 두 개씩 골라 푼다

SMO(Sequential Minimal Optimization, Platt 1998)는 문제를 통째로 풀지 않습니다. \(\alpha \) 중 두 개만 골라 나머지를 고정하고, 그 두 개에 대해서만 \(D\) 를 가장 크게 만드는 값으로 바꿉니다. 두 개만 남으면 문제가 한 변수의 2차함수로 줄어서 손으로 풀립니다(화면 2). 그 뒤 또 다른 두 개를 골라 같은 일을 하고, 더 개선할 쌍이 없을 때까지 되풀이합니다. 5장과 6장의 위젯이 학습할 때 안에서 돌린 방법도 이것입니다.

왜 \(\alpha \) 를 한 개가 아니라 두 개씩 움직일까

가장 쉬운 방법은 \(\alpha \) 를 하나씩 돌아가며 \(D\) 가 커지게 바꾸는 것입니다(변수 하나만 보면 2차함수의 꼭짓점 찾기라서 쉽습니다). 이 문제에서는 그 방법이 통하지 않습니다. 이유부터 숫자로 확인합니다.

하나만 움직이면 제약이 깨진다

4장의 점 3개(\(y = (+1, +1, -1)\))에서 제약은 \(\alpha ^{(1)} + \alpha ^{(2)} - \alpha ^{(3)} = 0\) 입니다. 이 제약을 지키는 점 \(\alpha = (\tfrac14 , 0, \tfrac14 )\) 에서 \(\alpha ^{(1)}\) 만 0.3 으로 올려 봅니다. 0.3 + 0 − 0.25 = 0.05 ≠ 0. 제약이 깨집니다. 제약을 지키는 점에서 변수 하나만 움직이면 언제나 이렇게 됩니다. 합이 0 이었는데 한 항만 바뀌었으니 0 이 아닐 수밖에 없기 때문입니다.

둘을 움직이면 길이 생긴다

고르는 두 점을 \(i\), \(j\) 라 하고 나머지 \(\alpha \) 는 고정합니다. 제약이 지켜지려면 두 항의 합 \(\alpha ^{(i)}y^{(i)} + \alpha ^{(j)}y^{(j)}\) 이 움직이기 전과 같아야 합니다. 그러면 \(\alpha ^{(j)}\) 를 새 값 \(t\) 로 정했을 때 \(\alpha ^{(i)}\) 는 저절로 정해집니다.

\[\alpha ^{(i)} \text{의 새 값} = \alpha ^{(i)} + y^{(i)}y^{(j)} (\alpha ^{(j)} - t)\]

(\(\alpha ^{(i)}\), \(\alpha ^{(j)}\) 는 움직이기 전 값입니다. 검산: 새 \(\alpha ^{(i)}y^{(i)} = \alpha ^{(i)}y^{(i)} + y^{(j)}(\alpha ^{(j)} - t)\) 이고 \(y^{(i)2} = 1\) 이므로, 새 \(\alpha ^{(i)}y^{(i)} + t\cdot y^{(j)} = \alpha ^{(i)}y^{(i)} + \alpha ^{(j)}y^{(j)}\) 로 합이 그대로입니다.) 자유로운 변수가 \(t\) 하나로 줄었습니다.

남은 제약은 상자 \(0 \le \alpha \le C\) 뿐입니다. 두 \(\alpha \) 의 평면에서 상자는 정사각형이고, 합이 일정하다는 조건은 그 위의 선 하나입니다. 선이 상자 안에 있는 부분이 \(t\) 가 움직일 수 있는 구간 [L, H] 입니다.

구간은 두 경우로 나뉩니다(\(\alpha ^{(i)}\), \(\alpha ^{(j)}\) 는 움직이기 전 값). \(y^{(i)} = y^{(j)}\) 이면 \(\alpha ^{(i)} + \alpha ^{(j)}\) 가 일정하고 \(t \ge 0\), \(\alpha ^{(i)} \text{의 새 값} \ge 0\), 양쪽 \(\le C\) 를 모두 지켜야 하니 \(L = \max (0, \alpha ^{(i)} + \alpha ^{(j)} - C)\), \(H = \min (C, \alpha ^{(i)} + \alpha ^{(j)})\) 입니다. \(y^{(i)} \ne y^{(j)}\) 이면 \(\alpha ^{(i)} - \alpha ^{(j)}\) 가 일정하고 \(L = \max (0, \alpha ^{(j)} - \alpha ^{(i)})\), \(H = \min (C, C + \alpha ^{(j)} - \alpha ^{(i)})\) 입니다.

한 변수의 2차함수로 줄이기 — 손으로 한 단계

이제 \(t\) 하나에 대한 \(D\) 의 모양을 구합니다. 한 줄씩 갑니다.

① 오차 E 를 정한다. 점 \(k\) 에서 예측값(\(b\) 를 뺀 판정식)에서 정답을 뺀 값을 오차 \(E^{(k)}\) 라 부릅니다.

\[E^{(k)} = \sum _{m} \alpha ^{(m)}y^{(m)}K(x^{(m)}, x^{(k)}) - y^{(k)}\]

② D 를 α⁽ᵏ⁾ 로 편미분한다. 이중합에서 \(\alpha ^{(k)}\) 가 들어 있는 항은 바깥 합이 \(k\) 인 줄과 안쪽 합이 \(k\) 인 줄, 두 곳입니다. \(K\) 가 대칭이라 둘이 같아서 앞의 \(\tfrac12 \) 과 약분됩니다.

\[\partial D/\partial \alpha ^{(k)} = 1 - y^{(k)} \sum _{m} \alpha ^{(m)}y^{(m)}K_{km} = 1 - y^{(k)}(E^{(k)} + y^{(k)}) = -y^{(k)}E^{(k)}\]

(합이 \(E^{(k)} + y^{(k)}\) 인 것은 ①의 정의이고, \(y^{(k)2} = 1\) 을 썼습니다.)

③ 사슬 법칙으로 t 에 대한 기울기를 구한다. 위의 선 위에서는 \(\alpha ^{(i)}\) 가 \(t\) 에 따라 dα⁽ⁱ⁾/dt = −y⁽ⁱ⁾y⁽ʲ⁾ 로 움직입니다. 따라서 움직이기 전 위치(\(t = \alpha ^{(j)}\))에서

\[dD/dt = \partial D/\partial \alpha ^{(j)} + (\partial D/\partial \alpha ^{(i)})\cdot (-y^{(i)}y^{(j)}) = -y^{(j)}E^{(j)} + y^{(j)}E^{(i)} = y^{(j)}(E^{(i)} - E^{(j)})\]

(가운데 항은 \((-y^{(i)}E^{(i)})(-y^{(i)}y^{(j)}) = y^{(j)}E^{(i)}\), \(y^{(i)2} = 1\) 입니다.)

④ 곡률을 구한다. 같은 사슬 법칙을 한 번 더 쓰면, 2차 편미분 ∂²D/∂α⁽ᵏ⁾∂α⁽ᵐ⁾ = −y⁽ᵏ⁾y⁽ᵐ⁾Kkm 에서

\[d^{2}D/dt^{2} = -K_{jj} + 2(-y^{(i)}y^{(j)})(-y^{(i)}y^{(j)}K_{ij}) - K_{ii} = -(K_{ii} + K_{jj} - 2K_{ij}) = -\eta \]

여기서 η = Kii + Kjj − 2Kij 입니다. \(K\) 를 \(\varphi \) 의 내적으로 풀면 \(\eta = \varphi (x^{(i)})\cdot \varphi (x^{(i)}) + \varphi (x^{(j)})\cdot \varphi (x^{(j)}) - 2\varphi (x^{(i)})\cdot \varphi (x^{(j)}) = \lVert \varphi (x^{(i)}) - \varphi (x^{(j)})\rVert ^{2} \ge 0\) 이라 늘 0 이상입니다. \(D\) 는 \(\alpha \) 의 2차식이고 \(\alpha ^{(i)}\) 가 \(t\) 의 1차식이므로 D(t) 는 정확히 2차함수이고, 기울기와 곡률을 알았으니 모양이 다 정해집니다.

\[D(t) = D(\alpha ^{(j)}) + y^{(j)}(E^{(i)} - E^{(j)})(t - \alpha ^{(j)}) - \tfrac12 \eta (t - \alpha ^{(j)})^{2}\]

⑤ 꼭짓점을 구한다. 위로 볼록한 2차함수이니 꼭짓점이 최댓값입니다. 미분이 0 이 되는 \(t\) 는

두 α 갱신식 (Platt 1998 의 식과 같다)

\[t* = \alpha ^{(j)} + y^{(j)}(E^{(i)} - E^{(j)}) / \eta \]

⑥ 상자에 맞춰 클리핑한다. 꼭짓점이 구간 [L, H] 밖이면 안 됩니다. 위로 볼록한 2차함수는 꼭짓점에서 멀어질수록 값이 줄어드니, 구간 안에서 가장 큰 곳은 꼭짓점에 가장 가까운 끝입니다. 그래서 α⁽ʲ⁾ 의 새 값 = min(H, max(L, t*)) 로 자르고, \(\alpha ^{(i)}\) 는 위의 식 \(\alpha ^{(i)} + y^{(i)}y^{(j)}(\alpha ^{(j)} - \text{새} \alpha ^{(j)})\) 로 따라옵니다. 이 갱신은 \(D\) 를 줄이지 않습니다(꼭짓점이나 그에 가장 가까운 끝으로 가므로).

⑦ b 는 어디 갔나. ① 에서 \(b\) 를 뺀 판정식을 썼습니다. \(E^{(i)} - E^{(j)}\) 에서는 \(b\) 가 양쪽에 똑같이 들어 있어 사라지므로, \(\alpha \) 를 갱신하는 데 \(b\) 는 필요 없습니다. Platt 원전은 갱신마다 \(b\) 도 고쳐 쓰지만, 이 교재의 코드는 \(\alpha \) 만 갱신하고 \(b\) 는 끝에서 5장·6장의 규칙(\(0 < \alpha < C\) 인 점에서 \(b = y - \sum \alpha y K\))으로 한 번 구합니다. 두 방법은 같은 \(\alpha \) 를 향합니다.

커널 행렬과 헬퍼 함수

화면 2 의 계산에 필요한 재료는 세 가지입니다. 그램 행렬 \(K\), 이번에 움직일 쌍 (i, j), 그 쌍이 움직일 수 있는 구간 [L, H]. 마지막으로 반복이 끝난 뒤 \(b\) 도 구해야 합니다. 이것을 작은 함수 넷으로 만듭니다. 먼저 NumPy 에서 처음 쓰는 기능을 점 3개로 맛봅니다.

  1. 1~3행 np.array 는 리스트를 배열로 바꿉니다. 여기서는 3 × 2 표로, 한 행이 점 하나입니다. import numpy as np 는 NumPy 를 np 라는 짧은 이름으로 쓰겠다는 관용 표기입니다.
  2. 4행 X.T 는 행과 열을 뒤집은 전치(2 × 3)이고, @ 는 행렬곱입니다. X @ X.T 의 (i, j) 칸은 X 의 i 행과 j 행의 내적이라 3 × 3 내적 표가 나옵니다. 4장 화면 7 의 값 18, 21, 6, 25, 7, 2 와 같습니다.
  3. 5행 X**2 는 모든 칸을 제곱하고, .sum(1) 은 열 방향(1 번 축)으로 더해 행마다 하나씩, 곧 점마다 \(x\cdot x\) 를 구합니다(9 + 9 = 18, 16 + 9 = 25, 1 + 1 = 2).
  4. 7행 이 줄이 이 장에서 가장 낯선 줄입니다. s[:, None] 은 길이 3 의 \(s\) 를 3 × 1 열로, s[None, :] 은 1 × 3 행으로 세웁니다. 열과 행을 더하면 NumPy 가 부족한 방향을 복사해 늘려서 3 × 3 표가 되고, (i, j) 칸이 s[i] + s[j] 입니다. 이 규칙을 브로드캐스팅이라 부릅니다. 여기서 2 * X @ X.T 를 빼면 칸마다 \(x\cdot x + z\cdot z - 2x\cdot z = \lVert x - z\rVert ^{2}\), 두 점 사이 거리의 제곱이 됩니다(반복문 없이 모든 쌍을 한 번에). 예: 1번과 2번은 \((3-4)^{2} + 0 = 1\), 2번과 3번은 9 + 4 = 13.

커널 행렬 — linear_kernel, rbf_kernel

위의 두 식이 그대로 커널 함수가 됩니다. 앞의 X @ X.T 가 선형 커널의 그램 행렬이고, 거리 제곱 표에 6장의 RBF 식 \(\exp (-\gamma \lVert x - z\rVert ^{2})\) 를 씌운 것이 RBF 커널입니다. 인자를 (X, Z) 로 받는 것은 학습 점끼리(X, X)뿐 아니라 새 점과 학습 점 사이(새 점, X)의 값도 같은 함수로 구하려는 것입니다.

# svm.pyimport numpy as np

def linear_kernel(X, Z):
    return X @ Z.T                      # K[i, j] = X[i]·Z[j]

def rbf_kernel(X, Z, gamma=1.0):
    sq = (X**2).sum(1)[:, None] + (Z**2).sum(1)[None, :] - 2 * X @ Z.T
    return np.exp(-gamma * sq)          # sq[i, j] = ‖X[i] − Z[j]‖²
  1. 3~4행 선형 커널. X 가 n × p, \(Z\) 가 m × p 이면 결과는 n × m 표입니다. 점 묶음을 한꺼번에 받는 이유는 파이썬 반복문(for i, for j)보다 NumPy 의 행렬곱이 훨씬 빠르기 때문입니다.
  2. 6~8행 RBF 커널. 7행은 앞의 맛보기와 같은 계산인데 X 와 \(Z\) 가 서로 다른 점 묶음이라 \(s\) 가 둘(점 묶음마다 하나)입니다. 8행의 np.exp 는 배열의 모든 칸에 e^ 를 씌우고, -gamma * sq 가 6장의 \(-\gamma \lVert x - z\rVert ^{2}\) 입니다. 같은 점끼리(대각선)는 거리 0 이라 K = 1 이 됩니다. gamma 의 기본값 1.0 은 6장 위젯과 맞춘 값입니다.

쌍 고르기와 구간 — violating_pair, clip_range

화면 2 의 식은 쌍 (i, j) 가 주어졌다고 보고 계산했습니다. 이제 그 쌍을 정합니다. 쌍을 “D 가 가장 크게 오르는 쌍”으로 고르는 것이 목표입니다. 두 \(\alpha ^{(i)}y^{(i)}\) 와 \(\alpha ^{(j)}y^{(j)}\) 를 같은 양 δ 만큼 하나는 올리고 하나는 내리면 합이 유지되어 제약이 지켜집니다. 이때 화면 2 의 ② 를 쓰면 \(D\) 의 변화는 처음에

\[(-E^{(i)})\cdot \delta + (+E^{(j)})\cdot \delta = (E^{(j)} - E^{(i)})\cdot \delta \]

(\(\alpha ^{(i)}\) 는 \(y^{(i)}\delta \) 만큼 변하고 \(\partial D/\partial \alpha ^{(i)} = -y^{(i)}E^{(i)}\) 이므로 \(-E^{(i)}\delta \), \(\alpha ^{(j)}\) 는 \(-y^{(j)}\delta \) 만큼 변하므로 \(+E^{(j)}\delta \))이라, \(E\) 가 작은 점의 \(\alpha y\) 를 올리고 \(E\) 가 큰 점의 \(\alpha y\) 를 내릴수록 이득이 큽니다. 이득의 크기 \(E^{(j)} - E^{(i)}\) 가 그 쌍의 ‘위반 정도’이고, 위반이 가장 큰 쌍을 고르는 규칙이 최대 위반 쌍 규칙입니다. 5장과 6장의 위젯이 쓴 방법과 같습니다. 가장 큰 위반 정도도 tol 보다 작으면 올라갈 방향이 없다고 보고 끝냅니다(화면 4).

단, \(\alpha \) 가 상자 끝에 붙어 있어서 그 방향으로 못 움직이는 점은 후보에서 뺍니다. \(\alpha y\) 를 올릴 수 있는 점과 내릴 수 있는 점은 다음과 같습니다.

레이블\(\alpha y\) 를 올릴 수 있다 (up)\(\alpha y\) 를 내릴 수 있다 (down)
y = +1\(\alpha y = \alpha \) 가 커져야 하니 \(\alpha < C\)\(\alpha \) 가 줄어야 하니 \(\alpha > 0\)
\(y = -1\)\(\alpha y = -\alpha \) 가 커지려면 \(\alpha \) 가 줄어야 하니 \(\alpha > 0\)\(\alpha \) 가 커져야 하니 \(\alpha < C\)
# svm.py (이어서)def violating_pair(E, y, a, C):
    up   = ((y > 0) & (a < C)) | ((y < 0) & (a > 0))
    down = ((y > 0) & (a > 0)) | ((y < 0) & (a < C))
    i = np.flatnonzero(up)[np.argmin(E[up])]        # E 가 가장 작은 쪽
    j = np.flatnonzero(down)[np.argmax(E[down])]    # E 가 가장 큰 쪽
    return i, j

def clip_range(ai, aj, yi, yj, C):
    if yi != yj:
        return max(0, aj - ai), min(C, C + aj - ai)
    return max(0, ai + aj - C), min(C, ai + aj)
  1. 2~3행 위 표를 그대로 옮겼습니다. y > 0 처럼 배열과 수를 비교하면 점마다 참 · 거짓이 담긴 불리언 배열이 나오고, &(그리고), |(또는)로 점마다 따로 합칩니다(파이썬의 and · or 는 배열에 쓸 수 없고, 괄호는 꼭 필요합니다). 결과 up 과 down 은 길이 n 의 참 · 거짓 배열입니다.
  2. 4행 E[up] 은 불리언 배열을 인덱스로 써서 참인 점의 \(E\) 만 뽑아냅니다(불리언 마스크). np.argmin 은 그중 가장 작은 값의 순서를 알려 주는데 이것은 뽑은 배열 안의 순서입니다. np.flatnonzero(up) 이 참인 점의 원래 번호 목록이라 [...] 로 한 번 더 이어 원래 번호 \(i\) 를 얻습니다. 동점이면 번호가 빠른 쪽이 뽑힙니다.
  3. 5행 같은 방식으로 down 중 \(E\) 가 가장 큰 점 \(j\). 한 점이 up 과 down 에 모두 들 수 있는데(예: \(0 < \alpha < C\) 인 점), 그래서 i == j 도 나올 수 있고 그때는 위반 정도가 0 이라 끝나게 됩니다.
  4. 6행 return i, j 는 값을 둘 돌려줍니다(튜플). 부르는 쪽에서 i, j = violating_pair(...) 로 한 번에 받습니다.
  5. 8~11행 화면 2 의 [L, H] 공식 그대로입니다. 9~10행이 \(y^{(i)} \ne y^{(j)}\)(차가 일정), 11행이 \(y^{(i)} = y^{(j)}\)(합이 일정)일 때입니다. if 안에서 return 하면 그 아래는 읽지 않으므로 else 를 따로 쓰지 않았습니다.

끝난 뒤 b — bias

5장과 6장의 규칙을 코드로 옮깁니다. \(0 < \alpha < C\) 인 점(경계 위에 정확히 있는 점)이 있으면 y = f 이므로 \(b = y - \sum \alpha y K\), 이것은 화면 2 ① 의 \(E\) 로 \(-E^{(k)}\) 입니다. 그런 점이 여럿이면 평균을 냅니다. 하나도 없으면 \(b\) 는 한 값이 아니라 구간이고, 구간의 가운데를 고릅니다. 구간은 \(-E^{(i)}\)(올릴 수 있는 점 중 최소 \(E\))에서 \(-E^{(j)}\)(내릴 수 있는 점 중 최대 \(E\))까지입니다. 반복이 끝났다면 앞의 것이 뒤의 것 이하입니다.

# svm.py (이어서)def bias(E, y, a, C, eps=1e-8):
    free = (a > eps) & (a < C - eps)
    if free.any():
        return -E[free].mean()
    i, j = violating_pair(E, y, a, C)
    return -(E[i] + E[j]) / 2
  1. 2행 \(0 < \alpha < C\) 인 점(자유 서포트 벡터)의 불리언 배열. 컴퓨터의 소수는 정확히 0 이나 \(C\) 가 되지 않을 수 있어서 eps(1e-8)만큼의 여유를 둡니다.
  2. 3~4행 .any() 는 하나라도 참이면 참입니다. 그런 점이 있으면 E[free] 로 그 점들의 \(E\) 만 뽑아 .mean() 으로 평균을 내고 부호를 바꿉니다(\(b = -E\)). 이런 점들은 올릴 수도 내릴 수도 있어 \(E\) 가 모두 같으므로 평균은 하나의 값입니다.
  3. 5~6행 자유 서포트 벡터가 없으면 위 구간의 가운데. 해가 하나가 아닐 때 어느 값을 고르는지는 구현의 선택일 뿐이고, 어느 쪽을 골라도 KKT 를 만족하는 \(b\) 입니다. 화면 5 에서 숫자로 봅니다.

SMO 본체

준비한 부품을 화면 2 의 순서대로 이어 붙이면 반복문 하나입니다. 이 함수가 이 장의 심장입니다. 전체 흐름은 이렇습니다.

  1. 모든 \(\alpha \) 를 0 으로 시작한다(\(\sum \alpha y = 0\) 과 상자 제약을 지키는 가능한 점).
  2. 오차 \(E\) 를 구하고 최대 위반 쌍 (i, j) 를 고른다.
  3. 위반 정도 \(E^{(j)} - E^{(i)}\) 가 tol 보다 작으면 끝낸다.
  4. 꼭짓점 t* 를 구하고 [L, H] 로 자른 뒤 \(\alpha ^{(j)}\), \(\alpha ^{(i)}\) 를 갱신하고 2 로 돌아간다.
# svm.py (이어서)def smo(K, y, C, tol=1e-10, max_iter=100000):
    a = np.zeros(len(y))
    for it in range(max_iter):
        E = K @ (a * y) - y
        i, j = violating_pair(E, y, a, C)
        if E[j] - E[i] < tol:
            return a, it
        eta = max(K[i, i] + K[j, j] - 2 * K[i, j], 1e-12)
        L, H = clip_range(a[i], a[j], y[i], y[j], C)
        aj_new = np.clip(a[j] + y[j] * (E[i] - E[j]) / eta, L, H)
        a[i] += y[i] * y[j] * (a[j] - aj_new)
        a[j] = aj_new
    return a, max_iter
  1. 1행 입력은 그램 행렬 \(K\)(n × n), 레이블 \(y\)(±1 배열), 침범 단가 \(C\) 입니다. 점의 좌표는 필요 없고 데이터는 \(K\) 로만 들어옵니다(6장). 돌려주는 값은 끝난 \(\alpha \) 와 갱신한 횟수 it 입니다. tol 은 멈춤 허용 오차, max_iter 는 무한 반복을 막는 안전장치입니다.
  2. 2행 np.zeros(n) 은 0 이 n 개인 배열. 시작점 \(\alpha = 0\) 은 제약을 모두 지킵니다.
  3. 4행 a * y 는 같은 자리끼리 곱한 배열 \(\alpha ^{(m)}y^{(m)}\) 이고, K @ (...) 는 표와 벡터의 곱이라 \(k\) 번째 값이 Σm K[k, m]·α⁽ᵐ⁾y⁽ᵐ⁾ 입니다. 여기서 \(y\) 를 빼면 화면 2 ① 의 \(E^{(k)}\) 가 모든 점에 대해 한 번에 나옵니다. 매번 처음부터 다시 구하는 단순한 방식입니다(비용은 화면 5 의 한계).
  4. 5행 화면 3 의 함수로 이번에 움직일 쌍을 고릅니다.
  5. 6~7행 끝내는 조건. 가장 큰 위반 정도가 tol 보다 작으면 더 올라갈 방향이 없으니 지금 \(\alpha \) 를 돌려줍니다. 함수 안에서 return 하면 반복문을 한꺼번에 빠져나옵니다. 이 규칙이 KKT 를 만족한다는 것과 정확히 같은 말이라는 점은 증명하지 않습니다(LIBSVM 도 같은 꼴의 멈춤 규칙을 씁니다).
  6. 8행 화면 2 ④ 의 \(\eta \). max(…, 1e-12) 는 0 으로 나누는 오류를 피합니다. \(\eta = 0\) 이면 \(D\) 가 직선이라 기울기 방향의 끝으로 가는 것이 답인데, 아주 작은 수로 나누면 t* 가 매우 커져 10행의 클리핑이 같은 끝으로 보내 줍니다.
  7. 9행 화면 2 의 구간 [L, H]. 쌍의 현재 값과 레이블을 넘깁니다.
  8. 10행 화면 2 ⑤ 의 t* 를 구하고 np.clip(값, L, H) 로 [L, H] 밖이면 가까운 끝으로 잘라 화면 2 ⑥ 의 클리핑을 합니다.
  9. 11~12행 먼저 \(\alpha ^{(i)}\)(11행) 를 구하고 나서 \(\alpha ^{(j)}\)(12행) 를 덮어씁니다. 순서가 중요합니다. 11행이 a[j] 의 움직이기 전 값을 써야 하기 때문입니다. += 는 “더해서 다시 넣기”입니다.
  10. 13행 반복 횟수를 다 채우고도 끝나지 않으면 max_iter 를 돌려줍니다. it == max_iter 는 수렴하지 못했다는 신호입니다.

이 함수가 12점에서 하는 일 — 한 단계씩

6장의 원형 12 점에 RBF(\(\gamma = 1\), C = 1)로 smo 를 돌리는 과정을 단계별로 봅니다(화면 5 의 파이썬 실행과 같은 알고리즘을 같은 식으로 계산하는 JavaScript 입니다). 점의 위치는 6장과 같고, 점 둘레의 테두리 반지름이 \(\alpha \) 의 크기입니다. 이번 단계에서 움직인 두 점에는 i (올림), j (내림) 표시가 붙습니다.

단계 수를 늘려 보면 처음에는 \(D\) 가 크게 오르고 점점 조금씩 오르다가 끝에는 위반 정도가 tol 아래로 내려옵니다. 1·6·7 번째 갱신에서는 꼭짓점이 구간 밖이라 클리핑이 일어나 \(\alpha \) 가 C = 1 에 붙습니다. 그렇게 붙었던 점(예: \(x^{(1)}\))이 뒤 단계에서 다시 내려와 끝에는 0 이 되는 것도 눈여겨보세요. 마지막에는 D = 4.53924, b = −0.36583 로, 6장 화면 6 위젯에서 원형 데이터, \(\gamma = 1\), C = 1 로 맞출 때 나오는 값과 같습니다(\(C\) 슬라이더는 처음에 10 이라 1 로 내려야 하고, 위젯은 \(D\) 와 \(b\) 를 소수 셋째~넷째 자리까지 보여 줍니다).

7장 · 화면 5

클래스로 묶어 돌려 보기

지금까지의 함수를 SVM 클래스 하나로 묶습니다. fit 은 K 를 만들고 smo 로 \(\alpha \) 를 구하고 bias 로 \(b\) 를 구해 기억합니다. decision_function 은 6장의 \(f(x) = \sum \alpha y K(x^{(i)}, x) + b\) 입니다. 이름은 scikit-learn 의 SVC 와 같게 지었습니다(비교가 쉽도록).

# svm.py (이어서)class SVM:
    def __init__(self, C=1.0, kernel="rbf", gamma=1.0, tol=1e-10, max_iter=100000):
        self.C, self.kernel, self.gamma = C, kernel, gamma
        self.tol, self.max_iter = tol, max_iter

    def _kernel(self, X, Z):
        if self.kernel == "linear":
            return linear_kernel(X, Z)
        return rbf_kernel(X, Z, self.gamma)

    def fit(self, X, y):
        X, y = np.asarray(X, float), np.asarray(y, float)
        K = self._kernel(X, X)
        a, self.n_iter_ = smo(K, y, self.C, self.tol, self.max_iter)
        E = K @ (a * y) - y
        self.b_ = bias(E, y, a, self.C)
        self.X_, self.y_, self.alpha_ = X, y, a
        self.support_ = np.flatnonzero(a > 1e-8)
        self.dual_ = a.sum() - 0.5 * (a * y) @ K @ (a * y)
        return self

    def decision_function(self, X):
        K = self._kernel(np.asarray(X, float), self.X_)
        return K @ (self.alpha_ * self.y_) + self.b_

    def predict(self, X):
        return np.where(self.decision_function(X) >= 0, 1, -1)
  1. 1~4행 class 는 데이터(\(C\), gamma …)와 함수(fit …)를 한 묶음으로 만드는 틀이고, __init__ 은 SVM(C=1, ...) 으로 만들 때 한 번 불립니다. 첫 인자 self 는 만들어진 객체 자신이라, self.C = C 는 “이 객체에 \(C\) 를 기억해 둔다”는 뜻입니다. 3행의 쉼표 대입 a, b, c = x, y, z 는 세 줄을 한 줄로 쓴 것입니다.
  2. 6~9행 문자열 kernel 에 따라 화면 3 의 두 함수 중 하나를 고르는 도우미입니다. 이름 앞의 _ 는 “클래스 안에서만 쓰는 함수”라는 파이썬 관례입니다. 이 간이 버전에는 선형과 RBF 두 가지만 있습니다.
  3. 12~13행 np.asarray(X, float) 는 리스트든 배열이든 실수 배열로 맞춥니다(리스트·정수 배열이 들어와도 항상 실수 배열로 맞춰, 이후 계산과 @ 에서 자료형을 신경 쓰지 않게). X, y = ..., ... 로 둘을 한 줄에 맞춥니다. 13행이 n × n 그램 행렬 \(K\) 입니다.
  4. 14행 화면 4 의 smo 가 돌려주는 두 값 \((\alpha , \text{횟수})\) 를 한 번에 받습니다. self.n_iter_ 처럼 끝에 _ 가 붙은 이름은 scikit-learn 에서 “학습한 결과”를 나타내는 관례입니다.
  5. 15~16행 끝난 \(\alpha \) 로 \(E\) 를 다시 구해 bias 에 넘깁니다. (\(E\) 는 smo 안의 지역 변수라 돌려받지 못하므로, 끝난 \(\alpha \) 로 다시 구합니다.)
  6. 17~19행 예측에 필요한 것(학습 점 X_, 레이블 y_, \(\alpha \)), 서포트 벡터의 번호 support_(\(\alpha > 1e-8\) 인 점, 0 부터 센 번호), 쌍대 목적값 dual_((a * y) @ K @ (a * y) 가 ΣΣ α⁽ⁱ⁾α⁽ʲ⁾y⁽ⁱ⁾y⁽ʲ⁾Kij 입니다)을 기억합니다. 20행의 return self 는 SVM(...).fit(X, y) 처럼 이어 쓰게 해 줍니다.
  7. 22~24행 \(K\) 는 새 점 X 와 학습 점 X_ 사이의 표(m × n)이고, K @ (α y) 가 점마다 \(\sum \alpha y K\) 이므로 b_ 를 더하면 f(x) 입니다.
  8. 26~27행 np.where(조건, 1, −1) 은 조건이 참인 곳은 1, 거짓인 곳은 −1 로 채운 배열입니다. f(x) = 0(경계 위)은 +1 로 칩니다.

이 구현의 한계 — 어디가 ‘간이’인가

  • 메모리 O(n²) — 그램 행렬이 \(n \times n\) 칸이고 칸마다 8 바이트입니다. n = 10,000 이면 \(10^{8}\) 칸으로 약 0.8 GB, n = 100,000 이면 약 80 GB 라 메모리에 올라가지 않습니다. LIBSVM 은 필요한 행만 계산해서 캐시에 두는 방식으로 이 문제를 줄입니다.
  • 반복마다 O(n²) — 4행의 K @ (a * y) 로 \(E\) 를 매번 처음부터 구합니다. 두 \(\alpha \) 만 바뀌었으니 \(E\) 의 변화분(O(n))만 더해 주는 것이 Platt 원전과 LIBSVM 의 방식인데, 이 교재의 코드는 읽기 쉽게 단순화했습니다.
  • 쌍 고르기가 단순함 — 최대 위반 쌍(Keerthi 외 2001 에서 온 규칙)이라 계산은 간단해도 수렴이 느릴 수 있고, LIBSVM 은 2차 정보를 쓰는 더 정교한 규칙(Fan · Chen · Lin 2005)을 씁니다.
  • tol 과 수치 안정성 — 위 비교처럼 tol 에 따라 \(\alpha \) 의 자릿수가 달라집니다. tol 을 부동소수의 반올림 오차(1e-16 근처)보다 작게 잡으면 끝나지 않을 수 있고(이 구현은 max_iter 로 막으며 n_iter_ == max_iter 면 수렴 실패), 너무 크게 잡으면 답이 거칩니다. \(\eta \approx 0\) 처리와 eps 도 간이입니다.
  • 입력 가정 — 두 레이블(+1, −1)이 모두 있다고 가정합니다. 한쪽만 있으면 violating_pair 가 빈 배열에서 값을 뽑다가 오류를 냅니다. 같은 점이 중복되거나 \(y\) 가 ±1 이 아닌 경우도 처리하지 않습니다.
  • 정당성 증명 생략 — 화면 2 는 한 번의 갱신이 \(D\) 를 줄이지 않는다는 것까지만 보였고, 수렴 증명은 문헌(Platt 1998, Keerthi 외 2001 이후의 수렴 논문들, Fan · Chen · Lin 2005)에 맡겼습니다.

7장 마무리

핵심 요약

  1. 풀 문제는 6장의 커널 소프트 마진 쌍대문제입니다. 까다로운 것은 \(\sum \alpha y = 0\) 이라서, 하나만 움직이면 제약이 깨지므로 두 개씩 움직입니다(SMO). 두 개의 합 \(\alpha ^{(i)}y^{(i)} + \alpha ^{(j)}y^{(j)}\) 을 일정하게 두면 \(D\) 가 \(\alpha ^{(j)}\) 하나의 2차함수가 됩니다.
  2. 갱신식은 \(\alpha ^{(j)} \leftarrow \alpha ^{(j)} + y^{(j)}(E^{(i)} - E^{(j)})/\eta \), η = Kii + Kjj − 2Kij 이고 구간 [L, H] 로 클리핑합니다. \(\alpha ^{(i)}\) 는 합을 유지하며 따라오고, \(b\) 는 \(E\) 의 차에서 사라지므로 끝에 한 번 구합니다.
  3. 쌍은 \(E\) 가 가장 작은 up 점 \(i\) 와 가장 큰 down 점 \(j\)(최대 위반 쌍)로 고르고, 위반 정도 E⁽ʲ⁾ − E⁽ⁱ⁾ < tol 이면 끝냅니다. 코드는 linear_kernel / rbf_kernel, violating_pair, clip_range, bias, smo, SVM 으로 약 70 줄입니다.
  4. 점 3개에서 \(\alpha = (\tfrac14 , 0, \tfrac14 )\), \(b = -2\), 원형 12 점(RBF \(\gamma = 1\), C = 1)에서 D = 4.53924, b = −0.36583 이 나왔고 scikit-learn 과 서포트 벡터가 같았습니다. tol 을 같게 하면 \(\alpha \) 가 1e-8 이하로 일치합니다.
  5. 한계: \(n \times n\) 행렬의 메모리, 매번 O(n²) 인 \(E\) 계산, 단순한 쌍 선택, tol 에 민감한 수치, 생략한 증명. \(b\) 가 구간이면 구현마다 값이 다를 수 있습니다.

SMO 가 \(\alpha \) 를 한 개가 아니라 두 개씩 움직이는 가장 직접적인 이유는 무엇일까요?

  1. 변수가 하나이면 D 가 2차함수가 되지 않아 최댓값을 구할 수 없어서
  2. 두 개씩 움직이면 한 개씩 움직일 때보다 더 빨리 수렴하는 것이 증명되어서
  3. Σα⁽ⁱ⁾y⁽ⁱ⁾ = 0 때문에, 하나만 바꾸면 제약이 깨지므로

한 가지 더. 이 등식 제약은 모델에 절편 \(b\) 를 넣었기 때문에 생깁니다(4장 화면 3 의 \(\partial L/\partial b = 0\)). \(b\) 가 없는 모델이라면 쌍대문제에 이 제약이 없어서 \(\alpha \) 를 하나씩 올리는 좌표상승이 가능해집니다. 대신 경계가 원점을 지나야 하는 형태가 되어 표현할 수 있는 경계가 달라지므로, 이 교재는 \(b\) 를 둡니다.

smo 의 10행에서 꼭짓점 t* 가 [L, H] 의 오른쪽 밖(t* > H)으로 나왔습니다. 코드는 \(\alpha ^{(j)}\) 를 어떻게 하고, 왜 그것이 맞을까요?

  1. t* 를 그대로 쓴다. 꼭짓점이 D 가 가장 큰 곳이기 때문에
  2. H 로 자른다. 위로 볼록한 2차함수는 꼭짓점에서 멀수록 작으므로 구간 안에서는 H 가 가장 크다
  3. 이 쌍은 건너뛰고 다음으로 위반이 큰 쌍을 고른다

클리핑은 ‘구간에 맞추는 편의’를 넘어 5장에서 본 \(\alpha = C\) 인 점(마진 안쪽이나 오분류 점)이 생기는 경로입니다. 12 점 예제에서 \(x^{(2)}\) 의 \(\alpha = 1 = C\) 가 나온 것도 위젯의 어느 단계에서 클리핑이 일어났기 때문이고, 한번 \(C\) 에 붙은 점도 뒤의 단계에서 다시 내려올 수 있습니다.

scikit-learn 의 SVC 를 기본 설정으로 돌렸더니 이 장의 \(\alpha \) 가 넷째 자리에서 달랐습니다. 가장 알맞은 해석은 무엇일까요?

  1. 멈춤 기준 tol 이 달라 같은 답에서 다른 지점에 멈춘 것이다
  2. 우리 구현에 오류가 있다는 증거이다
  3. 쌍대문제의 해가 여러 개여서 구현마다 다른 해를 고른 것이다

서로 다른 점에 RBF 커널을 쓰면 그램 행렬이 양의 정부호(c≠0 이면 ΣΣcᵢcⱼK_ij > 0 인 성질)로 알려져 있어 \(D\) 가 엄밀하게 볼록(오목)이고 \(\alpha \) 가 유일합니다. 반대로 선형 커널은 점이 차원보다 많으면 그램 행렬에 여유가 생겨 \(\alpha \) 마저 유일하지 않을 수 있습니다. 구현끼리 비교할 때 \(b\) 구간 외에도 ‘\(\alpha \) 의 비교 가능성’을 따져야 하는 이유입니다.
