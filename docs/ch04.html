4장 · 화면 1

쌍대문제 유도

2장은 문제를 하나 세웠고(\(\tfrac12 \lVert w\rVert ^{2}\) 를 줄이되 점마다 제약 하나), 3장은 그런 문제를 푸는 도구(라그랑지안과 KKT 조건)를 만들었습니다. 이 장은 그 도구를 SVM 에 직접 대 보는 장입니다. 계산을 따라가면 변수가 \(w, b\) 에서 점마다 하나씩의 \(\alpha \) 로 바뀐 새 문제, 곧 쌍대문제가 나옵니다. 이 문제 하나에서 두 가지 질문이 풀립니다. 답을 정하는 점은 왜 몇 개뿐일까, 그리고 6장에서 왜 새로운 일이 가능해질까.

유도는 줄이 많습니다. 그래서 세부보다 지도를 먼저 보겠습니다. 이 화면에서는 어디로 가는지만 보고, 각 걸음은 화면 2~5 에서 한 줄씩 걷습니다.

4장 · 화면 2

SVM 의 라그랑지안 세우기

지도의 ② 입니다. 3장 화면 3 에서 정한 규약은 이랬습니다. 최소화할 식 \(J\), 제약은 \(g \ge 0\) 꼴, 라그랑지안은 \(L = J - \lambda g\), 그리고 \(\lambda \ge 0\). SVM 의 각 부분을 이 규약에 하나씩 맞춰 봅시다.

3장의 말SVM 에서는덧붙임
변수 \(w_{1}, w_{2}\)변수 \(w\) (= \((w_{1}, w_{2})\))와 \(b\)3장의 장난감 문제에는 \(b\) 가 없었지만 SVM 에서는 직선의 위치를 정하는 \(b\) 도 변수입니다
최소화할 식 \(J\)\(\tfrac12 \lVert w\rVert ^{2}\)2장 화면 4. \(\lVert w\rVert ^{2} = w_{1}^{2} + w_{2}^{2}\) 이므로 \(\tfrac12 (w_{1}^{2} + w_{2}^{2})\)
제약 \(g \ge 0\)\(g^{(i)} = y^{(i)}(w\cdot x^{(i)} + b) - 1 \ge 0\)2장의 \(y(w\cdot x+b) \ge 1\) 에서 1 을 왼쪽으로 넘긴 것. 점마다 하나, 점이 \(n\) 개면 \(n\) 개
승수 \(\lambda \)\(\alpha ^{(i)}\)제약이 점마다 하나이므로 승수도 점마다 하나

먼저 Σ 읽는 법

제약이 \(n\) 개이면 \(L\) 에서 뺄 덩어리도 \(n\) 개입니다. 이것을 한 줄로 쓰려고 Σ(시그마)를 씁니다. 이 교재에서 처음 쓰는 기호이니 뜻을 정확히 해 둡시다.

정의 — Σ (더하기 기호)

\[\sum _{i=1}^{n} a^{(i)} = a^{(1)} + a^{(2)} + \ldots + a^{(n)}\]

Σ 아래의 \(i=1\) 은 “\(i\) 를 1 에서 시작해”, 위의 \(n\) 은 “\(n\) 까지 1 씩 올리며”, 오른쪽의 식은 “매번 이 식에 \(i\) 를 넣어 만든 항을 전부 더하라”는 뜻입니다. 범위가 분명할 때는 \(\sum _{i}\) 로 줄여 씁니다.

우리 예제는 \(n = 3\) 이고 \(y^{(1)} = +1, y^{(2)} = +1, y^{(3)} = -1\) 입니다. 직접 펼쳐 봅시다.

Σ 로 쓴 것\(n = 3\) 으로 펼친 것예제 숫자를 넣으면
\(\sum _{i} \alpha ^{(i)}\)\(\alpha ^{(1)} + \alpha ^{(2)} + \alpha ^{(3)}\)그대로 (아직 값을 모릅니다)
\(\sum _{i} \alpha ^{(i)}y^{(i)}\)\(\alpha ^{(1)}y^{(1)} + \alpha ^{(2)}y^{(2)} + \alpha ^{(3)}y^{(3)}\)\(\alpha ^{(1)} + \alpha ^{(2)} - \alpha ^{(3)}\)
\(\sum _{i} \alpha ^{(i)}y^{(i)}x^{(i)}\)\(\alpha ^{(1)}y^{(1)}x^{(1)} + \alpha ^{(2)}y^{(2)}x^{(2)} + \alpha ^{(3)}y^{(3)}x^{(3)}\)\(\alpha ^{(1)}(3, 3) + \alpha ^{(2)}(4, 3) - \alpha ^{(3)}(1, 1)\) (벡터의 합)

라그랑지안

정의 — SVM 의 라그랑지안

\(L(w, b, \alpha ) = \tfrac12 \lVert w\rVert ^{2} - \sum _{i=1}^{n} \alpha ^{(i)} [ y^{(i)}(w\cdot x^{(i)} + b) - 1 ]\)  ,   \(\alpha ^{(i)} \ge 0\)

  • \(\tfrac12 \lVert w\rVert ^{2}\) — 3장의 \(J\). 줄이고 싶은 값.
  • \(\alpha ^{(i)}\) — \(i\) 번째 점의 제약에 곱하는 승수. 아직 값을 모르는 미지수이며 \(w, b\) 와 똑같이 \(L\) 의 변수입니다.
  • \(y^{(i)}(w\cdot x^{(i)} + b) - 1\) — 대괄호 안 전체가 \(g^{(i)}\). 점 \(i\) 가 띠 바깥에 얼마나 여유 있게 있는지(2장의 함수 마진에서 1 을 뺀 값)이고, 제약은 이것이 0 이상이라는 것입니다.
  • \(\sum \) — 모든 점 \(i = 1, \ldots , n\) 에 대해 \(\alpha ^{(i)}g^{(i)}\) 를 더합니다. 3장의 \(L = J - \lambda _{1}g_{1} - \ldots - \lambda _{m}g_{m}\) 를 Σ 로 쓴 것일 뿐입니다.
  • \(\alpha ^{(i)} \ge 0\) — 3장의 쌍대 가능성. 부등식 제약의 승수는 음수가 될 수 없습니다.

3점 예제에 쓰면 \(L\) 은 미지수 여섯 개(\(w_{1}, w_{2}, b\) 와 \(\alpha ^{(1)}, \alpha ^{(2)}, \alpha ^{(3)}\))의 함수입니다. 각 점의 대괄호는 2장 화면 5 에서 쓴 제약 세 개 그대로입니다 (\(x^{(3)}\) 는 \(y = -1\) 이라 \(-(w_{1} + w_{2} + b) - 1\)).

\[L = \tfrac12 (w_{1}^{2} + w_{2}^{2}) - \alpha ^{(1)}(3w_{1} + 3w_{2} + b - 1) - \alpha ^{(2)}(4w_{1} + 3w_{2} + b - 1) - \alpha ^{(3)}(-w_{1} - w_{2} - b - 1)\]

숫자로 감 잡기 — 2장의 답에서 대괄호 값

2장의 답 \((w, b) = ((\tfrac12 , \tfrac12 ), -2)\) 에서 세 대괄호의 값은 \(3\times \tfrac12 + 3\times \tfrac12 - 2 - 1 = 0\), \(4\times \tfrac12 + 3\times \tfrac12 - 2 - 1 = \tfrac12 \), \(-\tfrac12 - \tfrac12 + 2 - 1 = 0\) 입니다 (2장 화면 5 의 함수 마진 1, 1.5, 1 에서 1 을 뺀 값). 제약이 딱 맞는 점은 대괄호가 0 이고, 여유 있는 점은 양수입니다. 이 차이가 화면 6 에서 중요해집니다.

이 \(L\) 을 어떻게 쓰는지는 3장에서 배웠습니다. 변수로 편미분해서 0 으로 놓는다. 다음 화면에서 \(w\) 와 \(b\) 로 그렇게 합니다. 그 전에 한 가지만 짚어 둡니다. 지금 \(\alpha \) 는 값이 정해지지 않은 채입니다. 그래서 편미분 결과는 숫자가 아니라 \(\alpha \) 를 포함한 식으로 나옵니다.

4장 · 화면 3

\(w\) 와 \(b\) 로 편미분해 0 으로

지도의 ③ 입니다. 3장의 정상성(\(\nabla _{w}L = 0\))을 실제로 해 봅니다. 먼저 \(L\) 을 편미분하기 좋게 괄호를 풀어 정리하고, 그 다음 미분합니다.

1단계 — 괄호 풀어 정리하기

줄식왜 이렇게 되는지
a\(\alpha ^{(i)}[ y^{(i)}(w\cdot x^{(i)} + b) - 1 ] = \alpha ^{(i)}y^{(i)}(w\cdot x^{(i)}) + \alpha ^{(i)}y^{(i)}b - \alpha ^{(i)}\)분배법칙입니다. 대괄호 안의 세 덩어리(\(yw\cdot x\), \(yb\), \(-1\))에 \(\alpha ^{(i)}\) 를 각각 곱했습니다.
b\(\sum _{i} [ A^{(i)} + B^{(i)} + C^{(i)} ] = \sum _{i} A^{(i)} + \sum _{i} B^{(i)} + \sum _{i} C^{(i)}\)Σ 는 항을 전부 더하라는 뜻이라 더하는 순서를 바꿔도 됩니다. 점이 3개면 \((A^{(1)}+B^{(1)}+C^{(1)}) + (A^{(2)}+B^{(2)}+C^{(2)}) + (A^{(3)}+B^{(3)}+C^{(3)})\) 을 같은 종류끼리 묶은 것입니다.
c\(\sum _{i} \alpha ^{(i)}y^{(i)}b = b\sum _{i} \alpha ^{(i)}y^{(i)}\)\(b\) 는 점 번호 \(i\) 와 상관없는 한 개의 수라서 Σ 밖으로 꺼냅니다 (\(\alpha ^{1}y^{1}b + \alpha ^{2}y^{2}b + \alpha ^{3}y^{3}b = b(\alpha ^{1}y^{1} + \alpha ^{2}y^{2} + \alpha ^{3}y^{3})\)).
d\(\sum _{i} \alpha ^{(i)}y^{(i)}(w\cdot x^{(i)}) = w \cdot ( \sum _{i} \alpha ^{(i)}y^{(i)}x^{(i)} )\)\(w\) 도 \(i\) 와 상관없습니다. 내적의 분배법칙 \(w\cdot u + wv = w\cdot (u + v)\) 를 점 3개에 적용한 것입니다.

세 덩어리를 모으면 \(L\) 은 이렇게 정리됩니다. 이 식에 (★) 표시를 해 두고 화면 4 에서 다시 씁니다.

\[(\star ) \; L = \tfrac12 \lVert w\rVert ^{2} - w \cdot ( \sum _{i} \alpha ^{(i)}y^{(i)}x^{(i)} ) - b\sum _{i} \alpha ^{(i)}y^{(i)} + \sum _{i} \alpha ^{(i)}\]

2단계 — \(w\) 로 편미분

\(w = (w_{1}, w_{2})\) 이므로 편미분이 둘입니다. (★) 에서 \(w_{1}\) 이 들어 있는 항은 둘뿐입니다. \(\tfrac12 \lVert w\rVert ^{2} = \tfrac12 (w_{1}^{2} + w_{2}^{2})\) 와 \(w\cdot (\sum \alpha yx) = w_{1}(\sum \alpha yx \text{의 첫째 성분}) + w_{2}(\text{둘째 성분})\) 입니다. 점 \(i\) 의 첫째·둘째 좌표를 \(x_{1}^{(i)}, x_{2}^{(i)}\) 로 쓰면 첫째 성분은 \(\sum _{i} \alpha ^{(i)}y^{(i)}x_{1}^{(i)}\) 입니다.

편미분 = 0계산왜 이렇게 되는지
\(\partial L/\partial w_{1} = 0\)\(w_{1} - \sum _{i} \alpha ^{(i)}y^{(i)}x_{1}^{(i)} = 0\)\(\tfrac12 w_{1}^{2}\) 은 \(w_{1}\). \(w_{1}\) 에 곱해진 계수가 그대로 남는다는 3장 화면 1 의 요령 3 입니다(\(5w_{1} + 2w_{2}\) 를 \(w_{1}\) 로 미분하면 5). 나머지 항은 \(w_{1}\) 이 없어 0 입니다.
\(\partial L/\partial w_{2} = 0\)\(w_{2} - \sum _{i} \alpha ^{(i)}y^{(i)}x_{2}^{(i)} = 0\)같은 방식입니다. \(w_{2}\) 에 곱해진 계수가 남습니다.

두 식을 한 줄로 묶습니다(첫째 성분끼리, 둘째 성분끼리 같다는 것이 벡터로 같다는 뜻입니다).

결과 ① — \(w\) 를 \(\alpha \) 로 쓴 식

\[w = \sum _{i=1}^{n} \alpha ^{(i)} y^{(i)} x^{(i)}\]

예제에서 펼치면 \(w = \alpha ^{(1)}(3, 3) + \alpha ^{(2)}(4, 3) - \alpha ^{(3)}(1, 1)\), 곧 \(w_{1} = 3\alpha ^{(1)} + 4\alpha ^{(2)} - \alpha ^{(3)}\), \(w_{2} = 3\alpha ^{(1)} + 3\alpha ^{(2)} - \alpha ^{(3)}\) 입니다. 직선의 방향 \(w\) 는 점들을 \(\alpha \) 의 비중으로 섞은 것이고, \(y\) 가 −1 인 점은 음의 부호로 들어갑니다.

이 식에서 \(x^{(i)}\) 앞의 \(\alpha ^{(i)}\) 가 0 이면 그 점은 \(w\) 를 만드는 데 한 몫도 하지 못합니다. 이 관찰을 화면 6 에서 다시 꺼냅니다.

3단계 — \(b\) 로 편미분

(★) 에서 \(b\) 가 들어 있는 항은 \(-b\sum \alpha ^{(i)}y^{(i)}\) 하나뿐입니다. 이 항은 \(b\) 에 대한 일차식이라 기울기는 \(b\) 앞의 계수 \(-\sum \alpha ^{(i)}y^{(i)}\) 입니다.

결과 ② — \(\alpha \) 들 사이의 식

\[\partial L/\partial b = -\sum _{i} \alpha ^{(i)}y^{(i)} = 0 \; \; \Longrightarrow \; \; \sum _{i=1}^{n} \alpha ^{(i)} y^{(i)} = 0\]

예제에서는 \(\alpha ^{(1)} + \alpha ^{(2)} - \alpha ^{(3)} = 0\), 곧 +1 인 점들의 \(\alpha \) 합과 −1 인 점들의 \(\alpha \) 합이 같다는 식입니다.

그런데 \(b\) 는 어디 갔나 — 그리고 왜 “= 0”이 조건이 되나

결과 ② 에는 \(b\) 가 없습니다. \(b\) 의 값을 알려 주는 식이 아니라 \(\alpha \) 들이 지켜야 할 식이 나온 것입니다. \(b\) 는 화면 7 에서 따로 구합니다. 이유는 이렇습니다. \(L\) 은 \(b\) 에 대해 일차식(직선)이라서, \(\sum \alpha y \ne 0\) 이면 \(b\) 를 한없이 키우거나 줄여서 \(L\) 을 한없이 작게 만들 수 있고 바닥이 없습니다. 기울기가 0 인 곳이 있으려면 \(\sum \alpha y = 0\) 이어야 합니다. 다시 말해 이 식은 “\(b\) 를 풀어 주는 식”이 아니라 “\(L\) 에 바닥이 있으려면 \(\alpha \) 가 지켜야 하는 조건”이고, 쌍대문제의 제약 하나로 남습니다.

왜 “기울기 0”이 곧 “바닥”인가

\(\alpha \) 를 하나 정해 놓고 \(w\) 만 움직이면 \(L\) 은 \(\tfrac12 \lVert w\rVert ^{2}\) 에 \(w\) 의 일차식을 더한 것이라 그릇 모양입니다(3장 화면 1 의 한계 상자: 그릇 모양이면 기울기 0 이 바닥). 그러므로 결과 ① 은 “\(\alpha \) 가 이 값일 때 \(L\) 을 가장 작게 만드는 \(w\)”입니다. 다음 화면에서 이 \(w\) 를 \(L\) 에 넣는 일은 곧 \(L\) 의 최솟값을 구하는 일이 됩니다.

4장 · 화면 4

대입해서 \(w\) 와 \(b\) 지우기 — 유도의 핵심

지도의 ④ 입니다. 화면 3 의 (★) 에 결과 ① \(w = \sum \alpha yx\) 와 결과 ② \(\sum \alpha y = 0\) 을 넣습니다. 한 줄씩 가겠습니다. 먼저 이 화면에서 처음 만나는 이중합을 준비합니다.

준비 — 이중합 \(\sum \sum \) 읽는 법

마지막 줄에서 \(w\cdot w\) 를 \(\alpha \) 로 풀어 쓰면 Σ 가 두 겹이 됩니다. 먼저 \(w = \sum _{i} \alpha ^{(i)}y^{(i)}x^{(i)}\) 를 점 3개로 펼쳐 이름을 붙입니다. \(u^{(i)} = \alpha ^{(i)}y^{(i)}x^{(i)}\) 라 두면 \(w = u^{(1)} + u^{(2)} + u^{(3)}\) 이고,

\[w\cdot w = (u^{(1)} + u^{(2)} + u^{(3)}) \cdot (u^{(1)} + u^{(2)} + u^{(3)})\]

쌍대문제 완성

지도의 ⑤ 입니다. 화면 4 의 식에, 유도 중에 나온 조건 두 개를 붙이면 문제가 완성됩니다.

SVM 의 쌍대문제

\[\max _{\alpha } \; D(\alpha ) = \sum _{i=1}^{n} \alpha ^{(i)} - \tfrac12 \sum _{i=1}^{n} \sum _{j=1}^{n} \alpha ^{(i)}\alpha ^{(j)} y^{(i)}y^{(j)} (x^{(i)}\cdot x^{(j)})\]

\[\text{s.t.} \; \alpha ^{(i)} \ge 0 \; (\text{모든} i), \; \; \sum _{i=1}^{n} \alpha ^{(i)}y^{(i)} = 0\]

  • \(\alpha ^{(i)} \ge 0\) — 화면 2 에서 부등식 제약의 승수에 붙은 부호 조건(쌍대 가능성)입니다.
  • \(\sum \alpha y = 0\) — 화면 3 의 결과 ② 입니다. 이 조건이 깨지면 \(L\) 에 바닥이 없었습니다.
  • 변수는 \(\alpha ^{(1)}, \ldots , \alpha ^{(n)}\) 뿐입니다. \(w\) 와 \(b\) 는 문제 안에 없습니다.

그런데 \(\min \) 이었던 문제가 왜 \(\max \) 가 되었나

이것이 처음 보는 사람에게 가장 낯선 부분입니다. 이유는 \(D(\alpha )\) 가 원문제 답의 아래쪽 한계(하한)이기 때문입니다.

  1. 원문제의 가능한 \((w, b)\) 에서는 모든 대괄호 \(g^{(i)} \ge 0\) 이고 \(\alpha ^{(i)} \ge 0\) 이므로, \(L\) 에서 빼는 \(\sum \alpha ^{(i)}g^{(i)}\) 는 0 이상입니다. 그래서 \(L(w, b, \alpha ) \le \tfrac12 \lVert w\rVert ^{2}\).
  2. \(D(\alpha )\) 는 \(L\) 을 \(w, b\) 에 대해 가장 작게 만든 값이므로 \(D(\alpha ) \le L(w, b, \alpha )\) 입니다.
  3. 합치면 \(D(\alpha ) \le \tfrac12 \lVert w\rVert ^{2}\). 아무 \(\alpha \ge 0\) 를 넣어도 \(D(\alpha )\) 는 원문제의 어떤 가능한 값보다도 크지 않습니다.

그러면 가장 쓸모 있는 하한은 가장 높은 하한이니, \(D(\alpha )\) 를 최대로 만드는 것이 맞습니다. 이 사실을 약쌍대성이라 합니다. 예제의 숫자로 직접 확인합니다. 원문제의 값은 2장에서 본 \(\tfrac12 \lVert w\rVert ^{2} = \tfrac14 \) 입니다. \(D(\alpha )\) 값은 화면 4 의 5 줄 식에서 나옵니다(화면 7 에서 같은 식을 직접 전개합니다).

‘쌍대’라는 이름

쌍대(dual)는 “짝”이라는 뜻입니다. 같은 \(L\) 을 두 방향에서 본 두 문제가 짝을 이룹니다.

  • 원문제: \(w, b\) 를 정해 \(L\) 이 가장 작은 곳을 찾는다. 이때 \(\alpha \) 는 제약을 지키게 하는 역할이다. 제약을 어긴 점이 있으면(\(g < 0\)) 그 점의 \(\alpha \) 를 키워 \(L\) 이 얼마든지 커지게 만들 수 있으니, 어긴 \((w, b)\) 는 최소화에서 걸러진다. 지킨 점뿐이면 \(\alpha = 0\) 이 가장 큰 값을 주어 \(L = \tfrac12 \lVert w\rVert ^{2}\) 이 된다. 따라서 원문제는 “\(\alpha \ge 0\) 로 \(L\) 을 가장 크게 만든 뒤, \(w, b\) 로 가장 작게” 하는 것과 같다 (min-max).
  • 쌍대문제: 순서를 뒤집는다. \(w, b\) 로 \(L\) 을 먼저 가장 작게(화면 3·4) 만든 뒤, \(\alpha \ge 0\) 로 가장 크게 (max-min).

변수도 바뀝니다. 원문제는 \(w, b\) (이 예제에서 세 개)가 변수이고 제약이 \(n\) 개였는데, 쌍대문제는 \(\alpha \) (\(n\) 개)가 변수이고 제약이 단순합니다(\(\alpha \ge 0\) 과 등식 하나). 두 문제의 역할이 맞바뀐 짝입니다. 3장 화면 5 의 ‘쌍대 가능성(\(\lambda \ge 0\))’이라는 이름은 이제 설명이 됩니다. \(\alpha \ge 0\) 은 쌍대문제의 가능해가 되기 위한 조건이라서 그 이름이 붙었습니다.

한계 — 하한이 답과 같다는 것은 증명하지 않았습니다

약쌍대성은 \(D(\alpha ) \le (\text{원문제 값})\) 만 보장합니다. 하한의 최댓값이 원문제 최솟값과 정확히 같은지(강쌍대성)는 별개의 사실입니다. 이 교재의 문제(그릇 모양 목적함수 + 직선 제약, 곧 볼록 이차계획)에서는 성립하고, 예제에서도 화면 7 에서 \(\tfrac14 = \tfrac14 \) 로 확인합니다. 증명은 하지 않습니다. 원전은 Boyd & Vandenberghe, 『Convex Optimization』 5장(쌍대성)입니다. 일반 문제에서는 둘 사이에 간격이 있을 수 있습니다.

그리고 — 데이터가 어디에 들어 있나

\(D(\alpha )\) 를 다시 보세요. 점의 좌표 \(x^{(i)}\) 는 오직 \((x^{(i)}\cdot x^{(j)})\), 두 점의 내적의 형태로만 들어 있고 다른 곳에는 없습니다. 레이블 \(y\) 는 ±1 의 부호로만 들어옵니다. 원문제에서는 \(w\cdot x^{(i)}\) 가 곳곳에 있었습니다. 이 변화는 지금 보기에는 사소해 보이지만, 점이 2차원이든 백만 차원이든 쌍대문제의 모양은 같다는 뜻입니다. 이것이 6장에서 커널 트릭이 가능해지는 이유입니다. 6장에서 다룸

승수가 0 이 아닌 점 — 서포트 벡터

3장 화면 5 의 상보 여유성을 SVM 에 적용합니다. 모든 점 \(i\) 에서 이것이 성립해야 합니다.

\(g^{(i)} = 0\) 은 함수 마진이 정확히 1, 곧 2장 화면 3 의 띠의 가장자리에 점이 닿은 상태이고, \(g^{(i)} > 0\) 은 가장자리에서 떨어져 띠 바깥쪽에 여유 있게 있는 상태입니다. 곱이 0 이니 둘 중 하나는 0 이어야 합니다.

정의 — 서포트 벡터

쌍대문제의 답 \(\alpha \) 를 하나 골랐을 때 \(\alpha ^{(i)} > 0\) 인 점 \(x^{(i)}\) 를 서포트 벡터(support vector)라 합니다. 위에서 보았듯 서포트 벡터는 모두 마진 경계 위에 있습니다. 띠를 양쪽에서 받쳐서(support) 그 자리에 세워 두는 점들이라는 뜻입니다.

예제에서 — 1장에서 미룬 것 다루기

2장 화면 5 에서 세 점의 \(g\) 값은 \(0, \tfrac12 , 0\) 이었습니다. 이를 표에 적용하면 이렇습니다.

  • \(x^{(2)}\) 는 \(g = \tfrac12 > 0\), 띠 바깥에 여유가 있습니다. 그러므로 \(\alpha ^{(2)} = 0\) 입니다.
  • \(x^{(1)}, x^{(3)}\) 는 \(g = 0\) 이라 \(\alpha \) 가 0 일 수도 있습니다. 그런데 \(\alpha ^{(2)} = 0\) 이면 화면 3 의 결과 ② 가 \(\alpha ^{(1)} = \alpha ^{(3)}\) 이 되고, 결과 ① 은 \(w = \alpha ^{(1)}(3, 3) - \alpha ^{(3)}(1, 1) = \alpha ^{(1)}(2, 2)\) 입니다. 둘이 모두 0 이면 \(w = (0, 0)\) 인데 이것은 제약을 어깁니다(2장 화면 4). 그러므로 둘 다 양수이고, 서포트 벡터는 \(x^{(1)}, x^{(3)}\) 입니다. 값은 화면 7 에서 직접 구합니다.

1장 화면 4 에서 남겨 둔 질문, “\(x^{(2)}\) 는 직선을 정하는 데 왜 필요 없는가”의 답이 이것입니다.

  • \(w\) 에서: 결과 ① \(w = \sum \alpha yx\) 에서 \(x^{(2)}\) 앞의 \(\alpha ^{(2)}\) 가 0 이라 그 항이 통째로 사라집니다.
  • \(b\) 에서: \(b\) 는 서포트 벡터 하나의 등식 \(y(w\cdot x+b) = 1\) 에서 구하는데(화면 7), \(x^{(2)}\) 에서는 부등식(\(\ge 1\))만 나옵니다.

한계 — 이 말들이 어디까지 맞는가

  • 방향: 서포트 벡터는 \(\alpha > 0\) 인 점이고, 그러면 경계 위에 있습니다. 경계 위에 있어도 \(\alpha = 0\) 일 수 있습니다(위젯 4번).
  • \(\alpha \) 가 하나로 정해지지 않을 수 있습니다: 경계 위에 점이 여럿 놓인 퇴화 배치에서는 같은 \((w, b)\) 를 주는 \(\alpha \) 가 여러 개일 수 있고, 그러면 “\(\alpha > 0\) 인 점”도 고른 \(\alpha \) 에 따라 달라집니다. 예를 들어 \((2,1)\)+, \((2,-1)\)+, \((0,1)\)−, \((0,-1)\)− 는 네 점이 모두 경계 위이고 답은 \(w = (1, 0)\), \(b = -1\) 입니다. \(\alpha = (\tfrac12 , 0, \tfrac12 , 0)\) 이면 \(x^{(1)}\) 이 서포트 벡터지만 \(x^{(1)}\) 을 지워도 답은 같습니다. 화면 7 의 세 점 예제는 \(\alpha \) 가 하나로 정해지는 경우입니다.

  • 쌍대가 늘 빠르지는 않습니다: 쌍대문제의 변수는 점의 수 \(n\) 개입니다. 점이 아주 많고 특성이 적은 선형 SVM 에서는 원문제 형태가 더 싼 경우도 있습니다. 쌍대로 푸는 두 이유(내적만 남는다, \(\alpha \) 가 대부분 0 이다)가 힘을 쓰는 곳은 커널을 쓸 때입니다.

세 점 예제에 새 점 \(x^{(4)} = (5, 5)\)(레이블 +1)를 추가했습니다. 쌍대문제의 답은 어떻게 될까요? (기존 답: \(w = (\tfrac12 , \tfrac12 )\), \(b = -2\))

  1. 답 (w, b) 는 그대로이고, α⁽⁴⁾ > 0 이라 서포트 벡터가 하나 늘어난다
  2. 새 점 때문에 마진이 줄고 w 가 달라진다
  3. 답은 그대로이고 α⁽⁴⁾ = 0 이다

반대로 같은 파란 점을 \((2, 2)\) 에 두면 기존 직선에서 \(w\cdot x + b = \tfrac12 \times 2 + \tfrac12 \times 2 - 2 = 0\) 으로 직선 위에 놓이게 되어 제약 \(y(w\cdot x+b) \ge 1\) 을 지키지 못하므로 답이 달라집니다. 서포트 벡터가 아닌 점이 해를 바꾸려면 띠 안으로 들어와 제약을 어겨야 합니다. 학습 데이터를 모을 때도 “경계 가까운 점이 정보를 갖고 있다”는 감각의 근거가 이것입니다.

“마진 경계 위에 있는데 \(\alpha = 0\) 인 점”은 존재할 수 있을까요?

  1. 존재할 수 있다. 서포트 벡터는 α > 0 인 점이고, 경계 위라는 것만으로는 α > 0 이 보장되지 않는다
  2. 존재할 수 없다. 경계 위의 점은 모두 α > 0 이다
  3. 존재할 수 없다. α = 0 이면 반드시 g > 0 이다

\(\alpha \) 와 \(g\) 중 정확히 하나만 0 이어야 한다는 더 강한 조건을 문헌에서는 엄격 상보성(strict complementarity)이라 부르는데, 이것은 늘 성립하지 않습니다. 그래서 이 교재는 서포트 벡터를 “경계 위의 점”이 아니라 \(\alpha > 0\) 인 점으로 정의했습니다. 경계 위이면서 \(\alpha = 0\) 인 점은 지워도 해가 안 바뀌고, 서포트 벡터는 지우면 대개 해가 바뀝니다. 경계 위에 점이 많은 퇴화 배치에서는 \(\alpha \) 가 하나로 정해지지 않아 예외가 있습니다(화면 6 의 한계).

직접 해보기

점 두 개 \(x^{(1)} = (2, 0)\)(+1), \(x^{(2)} = (0, 0)\)(−1) 입니다. 이 장의 방법으로 SVM 의 답을 구합니다.

  1. 세 가지 내적 \(x^{(1)}\cdot x^{(1)}, x^{(1)}\cdot x^{(2)}, x^{(2)}\cdot x^{(2)}\) 와 레이블을 곱한 값을 구하고, 쌍대 목적식 \(D(\alpha ^{(1)}, \alpha ^{(2)})\) 를 쓰세요.
  2. 제약 \(\sum \alpha y = 0\) 으로 \(\alpha ^{(2)}\) 를 \(\alpha ^{(1)}\) 로 쓰고, \(D\) 를 한 변수 \(a\) 의 식으로 만들어 최대가 되는 \(a\) 를 구하세요.
  3. \(w = \sum \alpha yx\) 와 서포트 벡터의 등식으로 \(w, b\) 를 구하세요.
  4. 쌍대 최댓값과 원문제 값 \(\tfrac12 \lVert w\rVert ^{2}\) 이 같은지 확인하세요.
  5. 세 번째 점 \(x^{(3)} = (3, 0)\)(+1)을 더하면 서포트 벡터가 되나요? \(g^{(3)}\) 를 계산해 답하세요.
모범답안 — 그리고 흔한 실수가 왜 부족한지

1. 내적은 \(x^{(1)}\cdot x^{(1)} = 4\), \(x^{(1)}\cdot x^{(2)} = 0\), \(x^{(2)}\cdot x^{(2)} = 0\). 레이블 곱을 하면 \(y^{(1)}y^{(1)}\times 4 = 4\), \(y^{(1)}y^{(2)}\times 0 = 0\), \(y^{(2)}y^{(2)}\times 0 = 0\) 입니다. 따라서 \(D = \alpha ^{(1)} + \alpha ^{(2)} - \tfrac12 \times 4(\alpha ^{(1)})^{2} = \alpha ^{(1)} + \alpha ^{(2)} - 2(\alpha ^{(1)})^{2}\) 입니다.

2. \(\sum \alpha y = \alpha ^{(1)} - \alpha ^{(2)} = 0\) 에서 \(\alpha ^{(2)} = \alpha ^{(1)} = a\). \(D = 2a - 2a^{2}\), \(dD/da = 2 - 4a = 0\) 에서 \(a = \tfrac12 \) 이고 \(D = 1 - \tfrac12 = \tfrac12 \) 입니다 (\(a \ge 0\) 의 경계 \(a = 0\) 은 \(D = 0\) 이고 키우면 늘어나므로 최대가 아닙니다). \(\alpha = (\tfrac12 , \tfrac12 )\).

3. \(w = \tfrac12 \times (+1)(2, 0) + \tfrac12 \times (-1)(0, 0) = (1, 0)\). \(\alpha ^{(1)} > 0\) 이므로 \(y^{(1)}(w\cdot x^{(1)} + b) = 1\), 곧 \(2 + b = 1\), \(b = -1\). 검산: \(x^{(2)}\) 에서 \(-(0 + b) = 1\), \(b = -1\) ✓. 직선은 \(x_{1} = 1\) 로 두 점의 한가운데이고 마진은 \(2/\lVert w\rVert = 2\) 입니다.

4. \(\tfrac12 \lVert w\rVert ^{2} = \tfrac12 \times 1 = \tfrac12 \), \(D = \tfrac12 \) 로 같습니다.

5. \(g^{(3)} = y(w\cdot x + b) - 1 = (1\times 3 - 1) - 1 = 1 > 0\) 이므로 띠 바깥이고 \(\alpha ^{(3)} = 0\), 서포트 벡터가 아닙니다. 답은 그대로 \(w = (1, 0)\), \(b = -1\) 입니다.

흔한 실수 1 — 2번에서 \(a_{1}, a_{2}\) 를 따로 최대화하기. \(D = \alpha ^{(1)} + \alpha ^{(2)} - 2(\alpha ^{(1)})^{2}\) 에서 \(\alpha ^{(2)}\) 를 한없이 키우면 \(D\) 도 한없이 커지는 것처럼 보이지만, \(\sum \alpha y = 0\) 이라는 조건이 둘을 묶습니다. 쌍대문제는 목적식만이 아니라 제약까지 합쳐 하나의 문제입니다.

흔한 실수 2 — \(b\) 를 \(\sum \alpha y = 0\) 에서 구하려 하기. 그 식에는 \(b\) 가 없습니다. \(b\) 는 \(\alpha > 0\) 인 점의 등식 \(y(w\cdot x+b) = 1\) 에서 구합니다. \(\alpha = 0\) 인 점에서는 부등식만 나와서 \(b\) 를 정할 수 없습니다.

흔한 실수 3 — 답 \(\alpha \) 가 양수인지 확인하지 않기. 편미분 = 0 으로 구한 점이 \(\alpha < 0\) 이면 가능해가 아닙니다(화면 7 의 \((3/2, -1)\)).

이 교재가 가는 길 — 5장은 지금의 쌍대문제에서 딱 한 줄(\(0 \le \alpha \le C\))만 바꾸어 이상치를 견디는 SVM 을 만들고, 6장은 \(D(\alpha )\) 에 남은 내적 \(x^{(i)}\cdot x^{(j)}\) 를 다른 함수로 바꿔 끼웁니다.
