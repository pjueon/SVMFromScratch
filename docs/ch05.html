5장 · 화면 1

소프트 마진

지금까지 다룬 데이터는 직선 하나로 깔끔하게 갈리는 운 좋은 경우였습니다. 현실의 데이터는 그렇지 않습니다. 측정이 잘못되었거나, 레이블이 잘못 붙었거나, 정말로 드문 사례이거나 해서 다른 점들의 규칙에서 벗어난 점 하나가 끼어 있기 마련입니다. 이 장은 그런 점이 하나 끼었을 때 지금까지 만든 SVM(하드 마진)이 어떻게 무너지는지 눈으로 보고, 어떻게 고치는지를 다룹니다.

이렇게 홀로 떨어진 점을 이상치(outlier)라 부릅니다. 이 화면에서는 우리의 세 점 x⁽¹⁾ = (3, 3)(+1), x⁽²⁾ = (4, 3)(+1), x⁽³⁾ = (1, 1)(−1)에 파란 점(+1) 하나 x⁽⁴⁾ 를 더 놓습니다. 놓는 자리에 따라 하드 마진이 무너지는 방식이 두 가지로 갈립니다.

두 가지 무너짐

(가) x⁽⁴⁾ = (0.5, 0.5) — 해가 없습니다

빨간 점 x⁽³⁾ = (1, 1) 이 파란 두 점 x⁽⁴⁾ 와 x⁽¹⁾ 를 잇는 선분 위에 정확히 놓입니다. 0.8·(0.5, 0.5) + 0.2·(3, 3) = (0.4 + 0.6, 0.4 + 0.6) = (1, 1) 이기 때문입니다. 이것이 왜 막다른 길인지 식으로 보입니다. f(x) = w·x + b 라 두면(1장 화면 3) 0.8 + 0.2 = 1 이라 b 도 같은 비율로 섞여서

f(x⁽³⁾) = 0.8·f(x⁽⁴⁾) + 0.2·f(x⁽¹⁾)

가 어떤 (w, b) 에서도 성립합니다(0.8(w·p + b) + 0.2(w·q + b) = w·(0.8p + 0.2q) + b).

줄식왜 이렇게 되는지
1f(x⁽⁴⁾) ≥ 1,   f(x⁽¹⁾) ≥ 1하드 마진 제약(2장 화면 4): 파란 점(y = +1) 두 개이니 y·f ≥ 1 은 f ≥ 1 입니다.
2f(x⁽³⁾) = 0.8 f(x⁽⁴⁾) + 0.2 f(x⁽¹⁾) ≥ 0.8 + 0.2 = 1위의 섞기 식에 1 줄을 넣었습니다.
3y⁽³⁾ f(x⁽³⁾) = −f(x⁽³⁾) ≤ −1x⁽³⁾ 은 빨간 점(y = −1)이라 부호가 뒤집힙니다.
4그런데 제약은 y⁽³⁾ f(x⁽³⁾) ≥ 13 줄은 ≤ −1, 제약은 ≥ 1 이라 동시에 만족할 수 없습니다. 어떤 (w, b) 도 가능해가 아닙니다.

2장 화면 4 의 한계 상자에서 “가를 수 없으면 답이 없다”고 한 것이 이것이고, 4장 화면 6 위젯의 ‘못 가르는 배치’ 버튼이 안내만 하고 넘어간 것도 이것입니다. 이 장이 그 약속을 갚습니다. (그 위젯의 배치는 x⁽³⁾ 를 옮겨 만든 다른 모양이지만, 파란 두 점의 선분 위에 빨간 점이 놓이는 같은 현상입니다.)

(나) x⁽⁴⁾ = (1.5, 1.5) — 해는 있지만 마진이 4분의 1 로

이번에는 가를 수 있습니다. 빨간 x⁽³⁾ = (1, 1) 이 선분의 바깥쪽에 있기 때문입니다. 그런데 두 점 x⁽³⁾ 과 x⁽⁴⁾ 의 거리는 ‖(0.5, 0.5)‖ = √0.5 ≈ 0.71 로 아주 가깝고, 하드 마진 직선은 이 가까운 한 쌍 때문에 크게 제약받습니다. 얼마나 좁아지는지 한계부터 잡아 봅시다.

줄식왜 이렇게 되는지
1w·x⁽⁴⁾ + b ≥ 1 ,   −(w·x⁽³⁾ + b) ≥ 1두 점의 하드 마진 제약입니다.
2w·(x⁽⁴⁾ − x⁽³⁾) ≥ 2두 식을 더하면 b 가 지워집니다.
3w·(x⁽⁴⁾ − x⁽³⁾) ≤ ‖w‖ · ‖x⁽⁴⁾ − x⁽³⁾‖ = 0.71 ‖w‖1장 화면 3 의 a·c = ‖a‖‖c‖cos θ 에서 cos θ ≤ 1 입니다. 내적은 두 길이의 곱을 넘지 못합니다.
40.71 ‖w‖ ≥ 2 → ‖w‖ ≥ 2.83 → 마진 2/‖w‖ ≤ 0.712 줄과 3 줄을 이었습니다. 마진은 두 점 사이 거리를 넘을 수 없다는 뜻입니다.

이 한계에 실제로 닿는 직선이 있습니다. 두 점의 한가운데를 수직으로 가르는 직선, w = (2, 2), b = −5 입니다(x₁ + x₂ = 2.5). 네 점 모두 제약을 지키는지 확인합니다.

점y(w·x + b) = y(2x₁ + 2x₂ − 5)≥ 1 ?
x⁽¹⁾ = (3, 3), +16 + 6 − 5 = 7예 (여유 있음)
x⁽²⁾ = (4, 3), +18 + 6 − 5 = 9예 (여유 있음)
x⁽³⁾ = (1, 1), −1−(2 + 2 − 5) = 1예 (딱 닿음)
x⁽⁴⁾ = (1.5, 1.5), +13 + 3 − 5 = 1예 (딱 닿음)

마진은 2/‖w‖ = 2/(2√2) = √2/2 ≈ 0.71, 한계와 같으니 이것이 하드 마진의 답입니다. 이상치가 없을 때의 마진 2√2 ≈ 2.83 의 정확히 4분의 1 입니다. 이상치가 없을 때의 직선(회색 점선, w = (½, ½), b = −2)은 이 점을 어떻게 보는지 계산해 보면 ½·1.5 + ½·1.5 − 2 = −½, 곧 x⁽⁴⁾ 를 빨간 쪽으로 분류합니다. 하드 마진은 이 한 점을 맞히려고 직선을 빨간 점 쪽으로 바싹 끌어당긴 것입니다.

한 점이 해 전체를 좌우합니다

(가) 에서는 점 하나가 해를 없앴고, (나) 에서는 해를 남겨 두는 대신 마진을 4분의 1 로 만들었습니다. 이 위치에서는 직선이 기울지 않고 평행하게 옮겨 가지만, 위치가 다르면 직선이 크게 기울기도 합니다(2장 화면 4 의 한계 상자). 원인은 같습니다. 하드 마진의 요구는 “모든 점이 예외 없이” 입니다. 그러니 점 하나의 요구가 전체 답을 결정합니다. 이 점이 잡음이었다면 우리는 큰 손해를 본 셈입니다.

그렇다면 요구사항을 이렇게 바꾸고 싶어집니다. “점 하나쯤은 띠를 침범해도, 심지어 틀려도 봐주자. 단 침범한 만큼 대가를 치르게 하자.” 다음 화면에서 이 문장을 식으로 쓰고, 이름을 붙입니다.

이 장의 진행

  1. 이상치가 하드 마진을 무너뜨리는 두 방식을 본다 (이 화면).
  2. “봐주는 양”을 변수 ξ 로 쓰고 목적함수에 벌점을 단다 (화면 2).
  3. 벌점의 비싼 정도 C 를 움직이며 직선이 어떻게 변하는지 본다 (화면 3, 위젯).
  4. 쌍대문제가 어떻게 달라지는지 확인하고, 같은 문제를 힌지 손실로 다시 본다 (화면 4).

이 장에서 갚는 빚

  • 이상치가 끼면 어떻게 하나 → 화면 2~4 (1장 화면 4)
  • 하드 마진은 가를 수 없는 데이터에서 가능해가 없다 → 이 화면 (가) 에서 확인하고, 화면 2~3 에서 해결 (2장 화면 4, 4장 화면 6)

5장 · 화면 2

슬랙 변수 ξ — 조금은 침범해도 봐주자

하드 마진의 제약은 점마다 하나씩 y⁽ⁱ⁾(w·x⁽ⁱ⁾ + b) ≥ 1 이었습니다. 이 제약을 점마다 조금씩 풀어 주는 방법은 간단합니다. 오른쪽의 1 에서 점마다 따로 정한 양을 빼 주는 것입니다. 그 양을 ξ⁽ⁱ⁾ 라 쓰고, 문제가 알아서 정하는 변수로 둡니다. 다만 아무 때나 풀어 주면 안 되니 풀어 준 양만큼 목적함수에 벌점을 답니다.

정의 — 소프트 마진 SVM (원문제)

minw, b, ξ   ½‖w‖² + C Σi=1n ξ⁽ⁱ⁾

s.t.   y⁽ⁱ⁾(w·x⁽ⁱ⁾ + b) ≥ 1 − ξ⁽ⁱ⁾  ,   ξ⁽ⁱ⁾ ≥ 0   (모든 i)

  • ξ⁽ⁱ⁾ (크사이, 슬랙 변수) — 점 i 가 요구된 여유(함수 마진 1)에 모자란 양. 점마다 하나씩이라 n 개이고, w, b 와 똑같이 문제가 정하는 변수입니다. 점이 n 개면 변수는 w₁, w₂, b 에 ξ 가 n 개 더해집니다.
  • y⁽ⁱ⁾(w·x⁽ⁱ⁾ + b) ≥ 1 − ξ⁽ⁱ⁾ — 하드 마진 제약에서 1 을 1 − ξ⁽ⁱ⁾ 로 낮춘 것. ξ⁽ⁱ⁾ = 0 이면 원래 제약 그대로입니다.
  • ξ⁽ⁱ⁾ ≥ 0 — 봐주는 양은 음수가 될 수 없다는 조건. 음수를 허용하면 “어긴 만큼 벌점”이 아니라 “여유가 클수록 상”이 되어 문제의 뜻이 바뀝니다.
  • Σ ξ⁽ⁱ⁾ — 모든 점의 침범량을 더한 총량(Σ 읽는 법은 4장 화면 2). 이것이 벌점입니다.
  • C — 벌점의 단가. 0 보다 큰 상수이고 우리가 미리 정해 줍니다. 값의 의미는 다음 화면의 주제입니다.
  • ½‖w‖² — 2장의 목적함수 그대로. 마진을 넓히려는 항입니다.

이 문제를 소프트 마진 SVM 이라 부릅니다. 어김을 허용한다는 뜻에서 ‘soft’ 이고, 지금까지의 것은 허용하지 않는다는 뜻에서 하드 마진이었습니다.

ξ 의 값은 점의 위치를 말해 줍니다

함수 마진 y⁽ⁱ⁾(w·x⁽ⁱ⁾ + b) 를 z 라 부르겠습니다(2장 화면 3). 제약은 z ≥ 1 − ξ 이고, 벌점을 줄이려면 ξ 는 작을수록 좋으니 제약이 허락하는 가장 작은 값, 곧 1 − z 와 0 중 큰 쪽이 됩니다. 곧 ξ > 0 인 점에서는 z = 1 − ξ 로 읽을 수 있습니다.

ξ⁽ⁱ⁾z = y(w·x+b)점의 위치
0z ≥ 1제약을 그대로 지킴: 마진 경계 위이거나 띠 바깥
0 < ξ < 10 < z < 1띠 안쪽으로 들어왔지만 올바른 쪽
1z = 0직선 위
ξ > 1z < 0틀린 쪽. 분류가 틀렸다

그래서 ξ 는 오차 그 자체가 아니라 마진 규칙에서 얼마나 벗어났는가의 크기입니다. 1 을 넘어야 틀린 것입니다.

후보 둘만 비교했을 뿐입니다

소프트 마진은 이런 후보를 모든 (w, b) 에 대해 비교해서 가장 작은 것을 고르는 문제입니다. 두 후보 사이에 더 나은 직선이 있을 수 있습니다. 예를 들어 C = 2 에서 w = (1, 1), b = −2.5 를 계산하면 x⁽³⁾ 의 z = 0.5, x⁽⁴⁾ 의 z = 0.5 라 ξ = 0.5, 0.5, 값은 ½·2 + 2·1 = 3 입니다. 후보 1(3.25), 후보 2(4) 보다 작습니다. 이 직선은 두 점을 모두 맞히면서 둘 다 띠 안쪽에 두었습니다.

한계 — 소프트 마진은 이상치를 알아보지 못합니다

소프트 마진은 어떤 점이 이상치인지 판별하지 않습니다. 그저 어기는 비용이 싼 점을 어깁니다. 이 예의 x⁽⁴⁾ 가 잡음이 아니라 정말로 파란 영역이 거기까지 내려와 있다는 신호였다면, 후보 1(그리고 C 가 작을 때의 답)은 새로 오는 파란 점을 틀리게 분류할 수 있습니다. 잡음인지 신호인지는 데이터가 알려 주지 않고 우리가 C 로 정합니다.

5장 · 화면 3

C 의 의미 — 엄격할 것인가, 관대할 것인가

목적함수 ½‖w‖² + C Σξ⁽ⁱ⁾ 에는 서로 반대로 당기는 두 힘이 있습니다.

  • ½‖w‖² 는 w 를 작게, 곧 마진 2/‖w‖ 을 넓게 만들려 합니다. 이 힘만 있으면 점들을 아무리 많이 침범해도 상관하지 않습니다(w 를 0 에 가깝게).
  • CΣξ 는 침범을 줄이려 합니다. 이 힘만 있으면 마진이 아무리 좁아져도 점을 전부 띠 밖에 두려 합니다.

이 두 힘의 세기를 정하는 단가표가 C 입니다. 침범량 ξ 1 마다 목적함수에 C 가 얹힙니다.

위젯에 쓰는 점 — 세 점을 더했습니다

아래 위젯은 점을 일곱 개로 늘려 씁니다. 세 점 x⁽¹⁾, x⁽²⁾, x⁽³⁾ 과 이상치 x⁽⁴⁾ 에 x⁽⁵⁾ = (3, 4.5)(+1), x⁽⁶⁾ = (0, 1.5)(−1), x⁽⁷⁾ = (1.5, 0)(−1) 를 더한 것입니다. 이유는 두 가지입니다.

  1. 점이 너무 적으면 소프트 마진이 직선을 포기합니다. 세 점 + x⁽⁴⁾ = (0.5, 0.5) 에서는 C 가 얼마든 답이 w = (0, 0)(전부 +1 로 분류)입니다. 이유는 화면 1 의 섞기 식 x⁽³⁾ = 0.8x⁽⁴⁾ + 0.2x⁽¹⁾ 에서 나옵니다. f(x⁽³⁾) = 0.8f(x⁽⁴⁾) + 0.2f(x⁽¹⁾) 이므로 어떤 직선에서도 ξ⁽³⁾ + 0.8ξ⁽⁴⁾ + 0.2ξ⁽¹⁾ ≥ (1 + f(x⁽³⁾)) + 0.8(1 − f(x⁽⁴⁾)) + 0.2(1 − f(x⁽¹⁾)) = 2 이고, 따라서 Σξ ≥ 2 입니다. w = 0, b = 1 은 ξ⁽³⁾ = 2, 나머지 0 으로 이 하한에 정확히 닿으면서 ½‖w‖² = 0 이라, 어떤 C 에서도 이 “전부 +1” 이 가장 쌉니다. 파란 점이 셋이고 빨간 점이 하나뿐인 데이터에서는 빨간 점 하나를 포기하는 것이 가장 싸다는, 자연스럽지만 직선 그림에는 쓸모없는 결과입니다.
  2. 세 점의 답을 그대로 두면서 점 구름의 모양을 낼 수 있습니다. 새 세 점은 모두 4장 화면 6 의 ‘띠 바깥’에 놓입니다(w = (½, ½), b = −2 에서 z = 1.75, 1.25, 1.25, 모두 1 보다 큼). 그래서 이상치가 없을 때의 답은 4장과 똑같이 w = (½, ½), b = −2 입니다.

한계 — C → ∞ 이면 하드 마진이라는 말의 조건

C 를 키우면 ξ 는 점점 비싸져서 결국 모두 0 이 되고 하드 마진으로 돌아간다고 볼 수 있습니다. 이것은 하드 마진의 가능해가 있을 때만 맞습니다. 가를 수 없는 배치(화면 1 (가))에서는 돌아갈 하드 마진 자체가 없어서, C 를 키워도 답은 “침범의 총량이 가장 작은 직선” 쪽에서 더 변하지 않습니다(위젯의 강한 이상치). 또한 점이 원형으로 안팎을 둘러싼 데이터는 이상치 몇 개가 아니라 모양 자체가 직선이 아니라서 C 를 어떻게 정해도 고쳐지지 않습니다. 6장에서 다룸

5장 · 화면 4

쌍대문제는 어떻게 바뀌나 — 한 줄 차이

4장의 방법을 그대로 써 봅니다. 라그랑지안을 세우고 변수로 편미분해 0 으로 놓고 대입합니다. 새로 생긴 것은 제약이 하나 더 늘어난 것(ξ ≥ 0)과 변수가 하나 더 늘어난 것(ξ)뿐입니다.

라그랑지안

3장의 규약(g ≥ 0 꼴, L = J − Σλg)에 맞춥니다. 제약이 두 종류입니다.

점의 세 부류

3장의 상보 여유성(승수 × 제약 = 0)이 이번에는 두 줄입니다. 승수 α, μ 와 제약 g⁽ⁱ⁾, ξ⁽ⁱ⁾ 에 각각 적용되고, μ = C − α 를 쓰면 다음과 같습니다.

α⁽ⁱ⁾ [ y⁽ⁱ⁾(w·x⁽ⁱ⁾ + b) − 1 + ξ⁽ⁱ⁾ ] = 0  ,   (C − α⁽ⁱ⁾) ξ⁽ⁱ⁾ = 0

α⁽ⁱ⁾두 줄에서 따라 나오는 것점의 위치 (z = y(w·x+b))
α = 0C − α = C > 0 이라 둘째 줄에서 ξ = 0, 곧 제약 z ≥ 1마진 경계 밖이거나 경계 위. w 에 기여하지 않음
0 < α < CC − α > 0 이라 ξ = 0. α > 0 이라 첫째 줄에서 대괄호가 0, 곧 z = 1마진 경계 위 (4장의 서포트 벡터)
α = CC − α = 0 이라 ξ 는 0 이상 아무 값. α > 0 이라 대괄호가 0, 곧 z = 1 − ξ ≤ 1경계 안쪽·틀린 쪽 (ξ > 0)이거나 경계 위 (ξ = 0)

화면 3 위젯의 α 열에서 ‘= C’ 로 표시된 점이 셋째 부류입니다. 거꾸로 읽으면 이렇습니다.

  • 점이 띠 바깥(z > 1)이면 α = 0. (α > 0 이면 z = 1 − ξ ≤ 1 이라 모순)
  • 점이 띠 안쪽이거나 틀린 쪽(z < 1)이면 ξ > 0 이고, 그러면 C − α = 0 이라 α = C. 곧 ξ > 0 인 점은 모두 서포트 벡터(α > 0)입니다.
  • 마진 경계 위(z = 1)에 있는 점은 세 부류 모두 가능합니다. 4장에서 경계 위인데 α = 0 인 점이 있었던 것처럼, 이제는 경계 위인데 α = C 인 점도 있습니다.

검증 — 화면 3 의 4점 예제 C = 1

화면 3 의 표에서 C = 1 이면 α = (0, 0, 1, 1), w = (½, ½) 라고 했습니다. 직접 확인합니다. (점 번호: x⁽¹⁾ = (3, 3), x⁽²⁾ = (4, 3), x⁽³⁾ = (1, 1), x⁽⁴⁾ = (1.5, 1.5))

  • 쌍대 가능성. 0 ≤ α ≤ C = 1 ✓. Σαy = 0·1 + 0·1 + 1·(−1) + 1·(+1) = 0 ✓.
  • w 복원. w = 1·(−1)·(1, 1) + 1·(+1)·(1.5, 1.5) = (0.5, 0.5) ✓.
  • 쌍대 값. D = Σα − ½‖w‖² = 2 − ½·½ = 1.75 (ΣΣ 가 w·w 와 같다는 4장 화면 4 의 4 줄을 썼습니다).
  • 원문제 값. b = −2 로 놓으면 화면 2 의 후보 1 이라 ½‖w‖² + CΣξ = ¼ + 1.5 = 1.75.
  • 쌍대 값은 어떤 가능한 원문제 값보다도 크지 않고(약쌍대성, 4장 화면 5), 위의 원문제 값이 쌍대 값과 같으므로 둘 다 최적입니다. C = 1 에서 후보 1 이 정말 답입니다.

점의 부류는 x⁽¹⁾, x⁽²⁾ 가 α = 0(z = 1, 1.5 ≥ 1), x⁽³⁾, x⁽⁴⁾ 가 α = C(x⁽⁴⁾ 는 z = −½ < 1 로 틀린 쪽, x⁽³⁾ 는 z = 1 이라 ξ = 0 이지만 α = C)입니다. 세 부류 중 둘만 나왔고, 가운데 부류(0 < α < C)는 4장의 세 점 예제(C > ¼ 이면 α = (¼, 0, ¼) 의 두 양수가 모두 0 < α < C)에서 만납니다.

b 는 어떤 점으로 구하나

4장에서는 α > 0 인 점에서 등식 y(w·x+b) = 1 이 나온다고 했습니다. 소프트 마진에서는 α > 0 인 점이 두 종류라 조심해야 합니다.

  • 0 < α < C 인 점은 ξ = 0 임이 확실해서 등식 y(w·x+b) = 1 이 성립합니다. b = y − w·x 로 구합니다.
  • α = C 인 점은 z = 1 − ξ 인데 ξ 를 모르니 b 를 정해 주지 못합니다.
  • α = 0 인 점은 부등식 z ≥ 1 만 줍니다.

한계 — 0 < α < C 인 점이 하나도 없으면 b 는 구간입니다

위 4점 예제(C = 1)가 그런 경우입니다. w = (½, ½) 는 하나로 정해지지만 b 는 −2 ≤ b ≤ −½ 의 어느 값이든 됩니다. 조건은 이렇습니다. α = 0 인 x⁽¹⁾ 은 3 + b ≥ 1, α = C 인 x⁽³⁾ 은 z = −(1 + b) ≤ 1, x⁽⁴⁾ 은 z = 1.5 + b ≤ 1 에서 b ≥ −2 와 b ≤ −½ 가 나옵니다. 그 구간 안에서는 ξ⁽³⁾ = 2 + b, ξ⁽⁴⁾ = −½ − b 라 합이 늘 1.5 이고 목적값이 같아서 어느 b 도 똑같이 최적입니다. 위젯도 이럴 때는 구간을 알려 주고 가운데 값을 그립니다. 0 < α < C 인 점이 하나라도 있으면 b 가 정해집니다. 여기서 w 는 언제나 하나이고 b 만 구간일 수 있습니다.

힌지 손실로 다시 보기

이번에는 같은 문제를 ξ 없이 다시 씁니다. (w, b) 를 하나 정했다고 합시다. 그러면 점 i 의 ξ⁽ⁱ⁾ 는 제약 ξ⁽ⁱ⁾ ≥ 1 − z⁽ⁱ⁾, ξ⁽ⁱ⁾ ≥ 0 을 지키는 가장 작은 값이면 되고 (C > 0 이라 작을수록 이득입니다), 그것은 둘 중 큰 쪽입니다.

ξ⁽ⁱ⁾ = max( 0, 1 − y⁽ⁱ⁾ f(x⁽ⁱ⁾) )    (f(x) = w·x + b)

이 식은 목적함수가 두 항의 합임을 선명하게 보여 줍니다. ½‖w‖² 은 w 를 작게, 곧 마진을 넓게 유지하는 항이고, CΣ(힌지 손실) 은 학습 데이터에서 얼마나 어겼는지를 재는 손실 항입니다. C 는 손실 항의 비중입니다. 하드 마진은 그 손실을 한 점도 허용하지 않는 극단입니다.

왜 0-1 손실이 아니고 힌지인가 — 그리고 한계 두 가지

  • 힌지 손실은 늘 0-1 손실 이상입니다(z < 0 이면 힌지는 1 이상). 그래서 Σξ 는 틀린 점의 수 이상의 값입니다. 0-1 손실은 계단이라 최소화하기 어렵고, 힌지 손실은 꺾이는 한 곳을 빼면 직선이라 이 문제가 푸는 쉬운 문제(4장의 이차 문제)가 됩니다.
  • 힌지 손실은 틀린 정도에 비례해 벌점이 계속 올라가서, 멀리 떨어진 이상치일수록 ξ 가 크고 큰 C 에서 직선을 더 세게 끌어당깁니다. 마지막 줄의 z = −2 가 그것입니다.
  • ξ = max(0, 1 − z) 가 정확히 성립하는 것은 최적해에서입니다. 제약식만 보면 ξ 는 그 값 이상이면 아무 값이나 가능합니다(C > 0 이 아래로 눌러 줍니다).

5장 · 화면 5

5장 마무리

핵심 요약

  1. 하드 마진은 “모든 점이 예외 없이” 라서 이상치 하나에 약합니다. 빨간 점이 파란 두 점의 선분 위에 놓이면 가능해가 없고, 가를 수 있어도 마진이 크게 줄어듭니다(예제에서 2.83 → 0.71).
  2. 점마다 슬랙 변수 ξ⁽ⁱ⁾ ≥ 0 을 두어 제약을 y⁽ⁱ⁾(w·x⁽ⁱ⁾+b) ≥ 1 − ξ⁽ⁱ⁾ 로 풀고, 목적함수에 벌점을 더한 것이 소프트 마진입니다: min ½‖w‖² + CΣξ⁽ⁱ⁾. ξ = 0 은 제약 그대로, 0 < ξ < 1 은 띠 안, ξ > 1 은 틀린 쪽이고, ξ = max(0, 1 − y f(x)) 는 힌지 손실입니다.
  3. C 는 침범의 단가입니다. 크면 엄격해서 하드 마진에 가까워지고(이상치에 끌려 과적합할 수 있음), 작으면 관대해서 마진이 넓어집니다(점을 거의 안 봐 과소적합할 수 있음). 정답 C 는 사람이 정하는 하이퍼파라미터이고, 하드 마진의 가능해가 있을 때만 C 를 키우면 하드 마진이 됩니다.
  4. 쌍대문제는 α ≥ 0 이 0 ≤ α ≤ C 로 바뀌는 한 줄 차이입니다. α = 0 은 띠 바깥, 0 < α < C 는 마진 경계 위, α = C 는 경계 안쪽·틀린 쪽(또는 경계 위)이고, b 는 0 < α < C 인 점의 y(w·x+b) = 1 에서 구합니다.

어떤 점의 슬랙 변수가 ξ⁽ⁱ⁾ = 0.4 입니다. 이 점은 어디에 있을까요?

  1. 마진 띠 안쪽이지만 올바른 쪽이다
  2. 직선을 넘어 틀린 쪽에 있다
  3. 마진 경계 위에 있다

화면 4 의 부류표로 한 걸음 더 갑니다. ξ = 0.4 > 0 이면 상보 여유성 (C − α)ξ = 0 에서 α = C 여야 합니다. 띠를 침범한 점은 예외 없이 α = C 의 서포트 벡터이고, 거꾸로 α = C 라고 침범한 것은 아닙니다(경계 위에 정확히 놓인 점도 있습니다). 직선을 정하는 데 점이 얼마나 힘을 쓰는지(α)의 상한이 C 이므로, 이상치 한 점의 영향력도 C 로 막혀 있습니다.

화면 3 의 위젯에서 약한 이상치를 놓고 C = 0.01 로 아주 작게 했습니다. 어떤 모습이 나올까요?

  1. 모든 점이 띠 바깥에 놓이고 마진이 좁아져 이상치도 맞힌다
  2. 마진이 0.71 로 좁아지고 직선이 이상치 쪽에 붙는다
  3. 침범이 싸서 마진이 매우 넓어지고, 많은 점이 띠 안쪽에 들어가며 일부는 틀리게 분류된다

이것이 과소적합입니다. 재미있는 점은 이상치가 없는 데이터에서도 같은 일이 생긴다는 것입니다. 이상치 없음에서 C = 0.01 로 놓으면 여섯 점이 모두 α = C 이고 모든 점이 띠 안쪽에 있습니다(가운데 값의 b 에서 ξ ≈ 0.8). 소프트 마진의 C 는 이상치를 위한 다이얼이기 전에 “데이터를 얼마나 믿느냐”의 다이얼입니다. 너무 작으면 직선을 데이터에 맞추는 일 자체를 포기합니다.

소프트 마진의 쌍대문제를 풀어 α 를 얻었습니다. b 를 구하려면 어떤 점의 식 y(w·x + b) = 1 을 써야 할까요?

  1. α = C 인 점 (서포트 벡터이므로)
  2. 0 < α < C 인 점
  3. α = 0 인 점 (w 에 기여하지 않으므로)

여러 점이 0 < α < C 이면 각 점으로 구한 b 가 모두 같아야 합니다. 실제 구현에서는 수치 오차 때문에 조금씩 달라서 그 평균을 쓰는 것이 흔합니다. 위젯의 계산도 그렇게 합니다. 반대로 이런 점이 없는 경우에는 화면 4 처럼 b 의 가능한 구간을 구하고 그 가운데를 고르는 것이 한 방법인데, 이것은 약속일 뿐 유일한 답은 아닙니다.

직접 해보기

수직선 위(x₂ = 0)의 네 점입니다. x⁽¹⁾ = (2, 0)(+1), x⁽²⁾ = (3, 0)(+1), x⁽³⁾ = (0, 0)(−1), 그리고 이상치 x⁽⁴⁾ = (0.5, 0)(+1) 입니다. 후보 직선 세 개를 비교합니다.

  • 후보 A: w = (1, 0), b = −1 (4장 과제의 답)
  • 후보 H: w = (4, 0), b = −1
  • 후보 Z: w = (0, 0), b = 1
  1. 세 후보 각각에서 네 점의 z = y(w·x+b) 와 ξ = max(0, 1 − z) 를 구하세요.
  2. 각 후보의 목적값 ½‖w‖² + CΣξ 를 C 의 식으로 쓰세요.
  3. C 가 어느 범위일 때 세 후보 중 A 가 가장 작습니까?
  4. 후보 Z 와 후보 H 가 각각 이기는 범위에서 직선이 어떤 상태인지 이 장의 말(과소적합, 과적합, 엄격, 관대)로 한 줄씩 설명하세요.
모범답안 — 그리고 흔한 실수가 왜 부족한지

1. 후보 A 는 f = x₁ − 1. x⁽¹⁾: z = 1, ξ = 0. x⁽²⁾: z = 2, ξ = 0. x⁽³⁾: f = −1, y = −1 이라 z = 1, ξ = 0. x⁽⁴⁾: f = −0.5 라 z = −0.5, ξ = 1.5.
후보 H 는 f = 4x₁ − 1. x⁽¹⁾: 7, x⁽²⁾: 11, x⁽³⁾: f = −1 이라 z = 1, x⁽⁴⁾: f = 1 이라 z = 1. 네 점 모두 z ≥ 1 이라 ξ = 0.
후보 Z 는 f = 1. x⁽¹⁾, x⁽²⁾, x⁽⁴⁾: z = 1, ξ = 0. x⁽³⁾: z = −1, ξ = 2.

2. A: ½·1 + 1.5C = ½ + 1.5C. H: ½·16 + 0 = 8. Z: 0 + 2C = 2C.

3. A < Z 는 ½ + 1.5C < 2C, 곧 C > 1. A < H 는 ½ + 1.5C < 8, 곧 C < 5. 따라서 1 < C < 5 일 때 A 가 가장 작습니다(경계 C = 1, C = 5 에서는 동점).

4. C < 1 에서는 Z 가 이깁니다. 침범이 싸서 w = 0 으로 두고 빨간 점 하나를 틀리게 두는 직선으로, 관대함이 지나쳐 데이터를 보지 않는 과소적합입니다. C > 5 에서는 H 가 이깁니다. 침범이 비싸서 이상치까지 z = 1 에 맞추려고 마진을 2/‖w‖ = 0.5 로 좁힌 엄격한 직선으로, 이상치 하나에 휘둘리는 과적합 쪽입니다. 둘 사이(1 < C < 5)에서는 A 가 이상치 하나를 틀리게 두는 대신 마진을 지킵니다.

흔한 실수 1 — ξ⁽⁴⁾ = 1.5 를 “오차 1.5 개”로 읽기. ξ 는 1 − z 라는 마진 규칙에서의 이탈 크기이지 틀린 개수가 아닙니다. 1 을 넘으면 틀린 것이라는 사실만 개수와 연결되고, 그래서 Σξ 는 틀린 개수의 상한입니다.

흔한 실수 2 — C 와 마진의 방향을 거꾸로 알기. C 가 클수록 침범이 비싸 마진이 좁아지고, 작을수록 마진이 넓어집니다(H 와 Z 로 확인).

흔한 실수 3 — 세 후보 중 A 가 이겼다고 A 가 진짜 최적이라고 단정하기. 비교한 것은 후보 셋뿐입니다. 이 문제의 실제 최적해는 세 후보 사이의 직선일 수 있습니다(화면 2 의 C = 2 예와 같습니다).

이 교재가 가는 길 — 5장의 소프트 마진은 이상치 몇 개를 견디게 했지만 직선이라는 틀은 그대로입니다. 6장은 직선으로 가를 수 없는 데이터(원형으로 둘러싼 점)를 다룹니다.
