5장 · 페이지 1

소프트 마진

지금까지 다룬 데이터는 직선 하나로 깔끔하게 분리되는 운 좋은 경우였습니다. 현실의 데이터는 그렇지 않습니다. 측정이 잘못되었거나, 레이블이 잘못 붙었거나, 정말로 드문 사례이거나 해서 다른 점들의 규칙에서 벗어난 점 하나가 끼어 있기 마련입니다. 이 장은 그런 점이 하나 끼였을 때 지금까지 만든 SVM(하드 마진)이 어떻게 무너지는지 눈으로 보고, 어떻게 고치는지를 다룹니다.

이렇게 홀로 떨어진 점을 이상치(outlier)라 부릅니다. 이 페이지에서는 우리의 세 점 \(x^{(1)} = (3, 3)\)(+1), \(x^{(2)} = (4, 3)\)(+1), \(x^{(3)} = (1, 1)\)(−1)에 파란 점(+1) 하나 \(x^{(4)}\) 를 더 놓습니다. 놓는 자리에 따라 하드 마진이 무너지는 방식이 두 가지로 나뉩니다.

하드 마진이 무너지는 두 가지 경우

(가) \(x^{(4)} = (0.5, 0.5)\) — 해가 없습니다

빨간 점 \(x^{(3)} = (1, 1)\) 이 파란 두 점 \(x^{(4)}\) 와 \(x^{(1)}\) 를 잇는 선분 위에 정확히 놓입니다. \(0.8(0.5, 0.5) + 0.2(3, 3) = (0.4 + 0.6, 0.4 + 0.6) = (1, 1)\) 이기 때문입니다. 이것이 왜 해가 없는 경우인지 식으로 확인합니다. \(f(x) = w\cdot x + b\) 라 두면(1장 페이지 3) \(0.8 + 0.2 = 1\) 이므로 \(b\) 도 같은 비율로 섞여서, 어떤 \((w, b)\) 에서도 다음 식이 성립합니다.

\[f(x^{(3)}) = 0.8f(x^{(4)}) + 0.2f(x^{(1)})\]

이 식은 \(0.8(w\cdot p + b) + 0.2(w\cdot q + b) = w\cdot (0.8p + 0.2q) + b\) 에서 나옵니다.

줄식왜 이렇게 되는지
1\(f(x^{(4)}) \ge 1\),   \(f(x^{(1)}) \ge 1\)하드 마진 제약(2장 페이지 4): 파란 점(\(y = +1\)) 두 개이니 \(yf \ge 1\) 은 \(f \ge 1\) 입니다.
2\(f(x^{(3)}) = 0.8 f(x^{(4)}) + 0.2 f(x^{(1)}) \ge 0.8 + 0.2 = 1\)위 식에 1 줄을 대입했습니다.
3\(y^{(3)} f(x^{(3)}) = -f(x^{(3)}) \le -1\)\(x^{(3)}\) 은 빨간 점(\(y = -1\))이라 부호가 뒤집힙니다.
4그런데 제약은 \(y^{(3)} f(x^{(3)}) \ge 1\)3 줄은 \(\le -1\), 제약은 \(\ge 1\) 이라 동시에 만족할 수 없습니다. 어떤 \((w, b)\) 도 가능해가 아닙니다.

2장 페이지 4 의 한계 상자에서 “직선으로 분류할 수 없으면 답이 없다”고 한 것이 이 경우이고, 4장 페이지 6 위젯의 ‘분리할 수 없는 배치’ 버튼이 안내만 하고 넘어간 것도 이 경우입니다. 이 장에서 그 부분을 설명합니다. (그 위젯의 배치는 \(x^{(3)}\) 을 옮겨 만든 다른 모양이지만, 파란 두 점의 선분 위에 빨간 점이 놓이는 같은 현상입니다.)

(나) \(x^{(4)} = (1.5, 1.5)\) — 해는 있지만 마진이 4분의 1로 줄어듭니다

이번에는 분리할 수 있습니다. 빨간 \(x^{(3)} = (1, 1)\) 이 선분의 바깥쪽에 있기 때문입니다. 그런데 두 점 \(x^{(3)}\) 과 \(x^{(4)}\) 의 거리는 \(\lVert (0.5, 0.5)\rVert = \sqrt{0.5} \approx 0.71\) 로 아주 가깝고, 하드 마진 직선은 이 가까운 한 쌍 때문에 크게 제약받습니다. 마진이 최대 얼마까지 가능한지 상한부터 구해 봅시다.

줄식왜 이렇게 되는지
1\(w\cdot x^{(4)} + b \ge 1\) ,   \(-(w\cdot x^{(3)} + b) \ge 1\)두 점의 하드 마진 제약입니다.
2\(w\cdot (x^{(4)} - x^{(3)}) \ge 2\)두 식을 더하면 \(b\) 가 지워집니다.
3\(w\cdot (x^{(4)} - x^{(3)}) \le \lVert w\rVert\lVert x^{(4)} - x^{(3)}\rVert = 0.71 \lVert w\rVert \)1장 페이지 3 의 \(a\cdot c = \lVert a\rVert\,\lVert c\rVert \cos \theta \) 에서 \(\cos \theta \le 1\) 입니다. 내적은 두 길이의 곱을 넘지 못합니다.
4\(0.71 \lVert w\rVert \ge 2\) → \(\lVert w\rVert \ge 2.83\) → 마진 \(2/\lVert w\rVert \le 0.71\)2 줄과 3 줄을 이었습니다. 마진은 두 점 사이 거리를 넘을 수 없다는 뜻입니다.

이 한계에 실제로 닿는 직선이 있습니다. 두 점을 잇는 선분의 수직이등분선, \(w = (2, 2)\), \(b = -5\) 입니다(\(x_{1} + x_{2} = 2.5\)). 네 점 모두 제약을 지키는지 확인합니다.

점\(y(w\cdot x + b) = y(2x_{1} + 2x_{2} - 5)\)≥ 1 ?
\(x^{(1)} = (3, 3)\), +1\(6 + 6 - 5 = 7\)예 (여유 있음)
\(x^{(2)} = (4, 3)\), +1\(8 + 6 - 5 = 9\)예 (여유 있음)
\(x^{(3)} = (1, 1)\), −1\(-(2 + 2 - 5) = 1\)예 (경계에 정확히 닿음)
\(x^{(4)} = (1.5, 1.5)\), +1\(3 + 3 - 5 = 1\)예 (경계에 정확히 닿음)

마진은 \(2/\lVert w\rVert = 2/(2\sqrt{2}) = \sqrt{2}/2 \approx 0.71\), 한계와 같으니 이것이 하드 마진의 답입니다. 이상치가 없을 때의 마진 \(2\sqrt{2} \approx 2.83\) 의 정확히 4분의 1 입니다. 이상치가 없을 때의 직선(회색 점선, \(w = (\tfrac12 , \tfrac12 )\), \(b = -2\))은 이 점을 어떻게 보는지 계산해 보면 \(\tfrac12 \times 1.5 + \tfrac12 \times 1.5 - 2 = -\tfrac12 \), 곧 \(x^{(4)}\) 를 빨간 쪽으로 분류합니다. 하드 마진은 이 한 점을 올바르게 분류하려고 직선을 빨간 점 쪽으로 바싹 끌어당긴 것입니다.

한 점이 해 전체를 좌우합니다

(가) 에서는 점 하나가 해를 없앴고, (나) 에서는 해를 남겨 두는 대신 마진을 4분의 1 로 만들었습니다. 이 위치에서는 직선이 기울지 않고 평행하게 옮겨 가지만, 위치가 다르면 직선이 크게 기울기도 합니다(2장 페이지 4 의 한계 상자). 원인은 같습니다. 하드 마진의 요구는 “모든 점이 예외 없이”입니다. 따라서 점 하나의 요구가 전체 답을 결정합니다. 이 점이 잡음이었다면 해가 크게 왜곡된 셈입니다.

그렇다면 요구사항을 이렇게 바꾸고 싶어집니다. “점 하나쯤은 띠를 침범해도, 심지어 틀려도 봐주자. 단 침범한 만큼 대가를 치르게 하자.” 다음 페이지에서 이 문장을 식으로 쓰고, 이름을 붙입니다.

이 장의 진행

  1. 이상치가 하드 마진을 무너뜨리는 두 방식을 본다 (이 페이지).
  2. “봐주는 양”을 변수 \(\xi \) 로 쓰고 목적함수에 벌점을 단다 (페이지 2).
  3. 벌점의 단가 \(C\) 를 움직이며 직선이 어떻게 변하는지 본다 (페이지 3, 위젯).
  4. 쌍대문제가 어떻게 달라지는지 확인하고, 같은 문제를 힌지 손실로 다시 본다 (페이지 4).

이 장에서 다루는 것

  • 이상치가 끼면 어떻게 하나 → 페이지 2~4 (1장 페이지 4)
  • 하드 마진은 분리할 수 없는 데이터에서 가능해가 없다 → 이 페이지 (가) 에서 확인하고, 페이지 2~3 에서 해결 (2장 페이지 4, 4장 페이지 6)

5장 · 페이지 2

슬랙 변수 \(\xi \) — 제약을 조금 느슨하게 만들기

하드 마진의 제약은 점마다 하나씩 \(y^{(i)}(w\cdot x^{(i)} + b) \ge 1\) 이었습니다. 이 제약을 점마다 조금씩 풀어 주는 방법은 간단합니다. 부등식 오른쪽의 1 에서 점마다 따로 정한 양을 빼 주는 것입니다. 그 양을 \(\xi ^{(i)}\) 라 쓰고, \(w, b\) 와 마찬가지로 최적화에서 함께 정해지는 변수로 둡니다. 다만 제약을 마음대로 풀 수는 없으므로, 푼 양만큼 목적함수에 벌점을 더합니다.

정의 — 소프트 마진 SVM (원문제)

\[\min _{w, b, \xi } \; \tfrac12 \lVert w\rVert ^{2} + C \sum _{i=1}^{n} \xi ^{(i)}\]

\[\text{s.t.} \; y^{(i)}(w\cdot x^{(i)} + b) \ge 1 - \xi ^{(i)} \; ,\; \; \xi ^{(i)} \ge 0 \; \; (\text{모든} i)\]

  • ξ⁽ⁱ⁾ (크사이, 슬랙 변수) — 점 \(i\) 가 요구된 여유(함수 마진 1)에 모자란 양. 점마다 하나씩이라 \(n\) 개이고, \(w, b\) 와 마찬가지로 최적화에서 함께 정해지는 변수입니다. 점이 \(n\) 개면 변수는 \(w_{1}, w_{2}, b\) 에 \(\xi \) 가 \(n\) 개 더해집니다.
  • \(y^{(i)}(w\cdot x^{(i)} + b) \ge 1 - \xi ^{(i)}\) — 하드 마진 제약에서 1 을 \(1 - \xi ^{(i)}\) 로 낮춘 것. \(\xi ^{(i)} = 0\) 이면 원래 제약 그대로입니다.
  • \(\xi ^{(i)} \ge 0\) — 봐주는 양은 음수가 될 수 없다는 조건. 음수를 허용하면 “어긴 만큼 벌점”이 아니라 “여유가 클수록 상”이 되어 문제의 뜻이 바뀝니다.
  • \(\sum \xi ^{(i)}\) — 모든 점의 침범량을 더한 총량(Σ 읽는 법은 4장 페이지 2). 이것이 벌점입니다.
  • \(C\) — 벌점의 단가. 0 보다 큰 상수이고 우리가 미리 정해 줍니다. 값의 의미는 다음 페이지의 주제입니다.
  • \(\tfrac12 \lVert w\rVert ^{2}\) — 2장의 목적함수 그대로. 마진을 넓히려는 항입니다.

이 문제를 소프트 마진 SVM 이라 부릅니다. 제약을 어기는 것을 허용하므로 ‘soft’ 라 부르고, 지금까지의 것은 허용하지 않아서 하드 마진이라 불렀습니다.

\(\xi \) 의 값과 점의 위치

함수 마진 \(y^{(i)}(w\cdot x^{(i)} + b)\) 를 \(z\) 라 부르겠습니다(2장 페이지 3). 제약은 \(z \ge 1 - \xi \) 이고, 벌점을 줄이려면 \(\xi \) 는 작을수록 좋으니 제약을 만족하는 가장 작은 값, 즉 \(1 - z\) 와 0 중 큰 값이 됩니다. 따라서 \(\xi > 0\) 인 점에서는 \(z = 1 - \xi \) 로 읽을 수 있습니다.

\(\xi ^{(i)}\)\(z = y(w\cdot x+b)\)점의 위치
\(0\)\(z \ge 1\)제약을 그대로 지킴: 마진 경계 위이거나 띠 바깥
\(0 < \xi < 1\)\(0 < z < 1\)띠 안쪽으로 들어왔지만 올바른 쪽
\(1\)\(z = 0\)직선 위
\(\xi > 1\)\(z < 0\)틀린 쪽. 분류가 틀림

그래서 \(\xi \) 는 오차 그 자체가 아니라 마진 규칙에서 벗어난 정도입니다. 1 을 넘어야 틀린 것입니다.

후보 둘만 비교했을 뿐입니다

소프트 마진은 이런 후보를 모든 \((w, b)\) 에 대해 비교해서 가장 작은 것을 고르는 문제입니다. 두 후보 사이에 더 나은 직선이 있을 수 있습니다. 예를 들어 \(C = 2\) 에서 \(w = (1, 1)\), \(b = -2.5\) 를 계산하면 \(x^{(3)}\) 의 \(z = 0.5\), \(x^{(4)}\) 의 \(z = 0.5\) 라 \(\xi = 0.5, 0.5\), 값은 \(\tfrac12 \times 2 + 2\times 1 = 3\) 입니다. 후보 1(3.25), 후보 2(4) 보다 작습니다. 이 직선은 두 점을 모두 올바르게 분류하면서도 둘 다 띠 안쪽에 있습니다.

한계 — 소프트 마진은 이상치를 구별하지 못합니다

소프트 마진은 어떤 점이 이상치인지 판별하지 않습니다. 제약을 어기는 비용이 낮은 점부터 어길 뿐입니다. 이 예의 \(x^{(4)}\) 가 잡음이 아니라 정말로 파란 영역이 거기까지 내려와 있다는 신호였다면, 후보 1(그리고 \(C\) 가 작을 때의 답)은 새로 오는 파란 점을 잘못 분류할 수 있습니다. 잡음인지 신호인지는 데이터가 알려 주지 않고 우리가 \(C\) 로 정합니다.

5장 · 페이지 3

\(C\) 의 의미 — 엄격한 직선과 관대한 직선

목적함수 \(\tfrac12 \lVert w\rVert ^{2} + C \sum \xi ^{(i)}\) 에는 서로 반대로 당기는 두 힘이 있습니다.

  • \(\tfrac12 \lVert w\rVert ^{2}\) 은 \(w\) 를 작게, 곧 마진 \(2/\lVert w\rVert \) 을 넓게 만들려 합니다. 이 힘만 있으면 점들을 아무리 많이 침범해도 상관하지 않습니다(\(w\) 가 0 에 가까워집니다).
  • \(C\sum \xi \) 는 침범을 줄이려 합니다. 이 힘만 있으면 마진이 아무리 좁아져도 점을 전부 띠 밖에 두려 합니다.

이 두 힘의 세기를 조절하는 값이 \(C\) 입니다. 침범량 \(\xi \) 가 1 늘어날 때마다 목적함수가 \(C\) 만큼 커집니다.

\(C\) 는 \(w, b, \alpha \) 처럼 학습으로 구하는 값이 아니라 학습을 시작하기 전에 사람이 정해 주는 값이라 하이퍼파라미터라 부릅니다. 모든 데이터에 맞는 정답 \(C\) 는 없고, 실전에서는 데이터로 시험해서 고릅니다.

4점 예제의 모든 \(C\) 에 대한 답

페이지 2 의 네 점(\(x^{(4)} = (1.5, 1.5)\))은 모든 \(C\) 에 대해 풀 수 있습니다(페이지 4 에서 \(C = 1\) 일 때 맞는지 검증합니다). \(C \le 4\) 이면 답은 \(w = (C/2, C/2)\), 마진은 \(2\sqrt{2}/C\), 목적값은 \(2C - C^{2}/4\) 입니다. \(C \ge 4\) 이면 페이지 1 의 하드 마진 답 \(w = (2, 2)\) 와 같습니다. (손으로 푼 결과입니다.)

\(C\)\(w\)마진 \(2/\lVert w\rVert \)목적값 \(2C - C^{2}/4\)

위젯에 쓰는 점 — 새 점 세 개를 추가했습니다

아래 위젯은 점을 일곱 개로 늘려 씁니다. 세 점 \(x^{(1)}, x^{(2)}, x^{(3)}\) 과 이상치 \(x^{(4)}\) 에 \(x^{(5)} = (3, 4.5)\)(+1), \(x^{(6)} = (0, 1.5)\)(−1), \(x^{(7)} = (1.5, 0)\)(−1) 를 더한 것입니다. 이유는 두 가지입니다.

  1. 점이 너무 적으면 소프트 마진의 답이 직선 없는 해(\(w = 0\))가 됩니다. 세 점 + \(x^{(4)} = (0.5, 0.5)\) 에서는 \(C\) 가 얼마든 답이 \(w = (0, 0)\)(전부 +1 로 분류)입니다. 파란 점이 셋이고 빨간 점이 하나뿐인 데이터에서는 빨간 점 하나를 포기하는 것이 가장 이득이라는 결과입니다. 자연스럽긴 하지만 직선을 그리는 데는 쓸 수 없습니다. 이유는 아래 ‘왜 \(w = 0\) 이 되는가’에서 확인합니다.
  2. 세 점의 답을 그대로 두면서 점들의 분포를 더 현실적으로 만들 수 있습니다. 새 세 점은 모두 4장 페이지 6 의 ‘띠 바깥’에 놓입니다(\(w = (\tfrac12 , \tfrac12 )\), \(b = -2\) 에서 \(z = 1.75, 1.25, 1.25\), 모두 1 보다 큼). 그래서 이상치가 없을 때의 답은 4장과 똑같이 \(w = (\tfrac12 , \tfrac12 )\), \(b = -2\) 입니다.
왜 \(w = 0\) 이 되는가

페이지 1 의 섞기 식 \(x^{(3)} = 0.8x^{(4)} + 0.2x^{(1)}\) 에서 \(f(x^{(3)}) = 0.8f(x^{(4)}) + 0.2f(x^{(1)})\) 이므로, 어떤 직선에서도 다음이 성립합니다.

\[\xi ^{(3)} + 0.8\xi ^{(4)} + 0.2\xi ^{(1)} \ge (1 + f(x^{(3)})) + 0.8(1 - f(x^{(4)})) + 0.2(1 - f(x^{(1)})) = 2\]

따라서 \(\sum \xi \ge 2\) 입니다. \(w = 0\), \(b = 1\) 은 \(\xi ^{(3)} = 2\), 나머지 0 으로 이 하한에 정확히 닿으면서 \(\tfrac12 \lVert w\rVert ^{2} = 0\) 이라, 어떤 \(C\) 에서도 이 “전부 +1” 이 가장 이득입니다.

한계 — \(C\) 를 키우면 하드 마진이 된다는 말이 성립하는 조건

\(C\) 를 키우면 침범의 값이 점점 비싸져서 \(\xi \) 가 결국 모두 0 이 되고 하드 마진으로 돌아간다고 볼 수 있습니다. 이것은 하드 마진의 가능해가 있을 때만 맞습니다. 분리할 수 없는 배치(페이지 1 (가))에서는 돌아갈 하드 마진 자체가 없어서, \(C\) 를 키워도 답은 “침범의 총량이 가장 작은 직선” 쪽에서 더 변하지 않습니다(위젯의 강한 이상치). 또한 한쪽 클래스가 다른 쪽을 원형으로 둘러싼 데이터는 이상치 몇 개의 문제가 아니라, 경계가 직선으로는 표현되지 않는 모양이라서 \(C\) 를 어떻게 정해도 고쳐지지 않습니다. 6장에서 다룸

5장 · 페이지 4

쌍대문제는 어떻게 바뀌나 — 한 줄 차이

4장의 방법을 그대로 써 봅니다. 라그랑지안을 세우고 변수로 편미분해 0 으로 놓고 대입합니다. 새로 생긴 것은 제약(\(\xi \ge 0\))과 변수(\(\xi \))뿐입니다.

라그랑지안

3장의 규약(\(g \ge 0\) 꼴, \(L = J - \sum \lambda g\))에 맞춥니다. 제약이 두 종류입니다.

제약 (\(g \ge 0\) 꼴)승수
\(g^{(i)} = y^{(i)}(w\cdot x^{(i)} + b) - 1 + \xi ^{(i)} \ge 0\)\(\alpha ^{(i)} \ge 0\) (4장의 그 α)
\(\xi ^{(i)} \ge 0\)\(\mu ^{(i)} \ge 0\) (새 승수. 이름만 \(\mu \)(뮤)로 구분)

\[L(w, b, \xi , \alpha , \mu ) = \tfrac12 \lVert w\rVert ^{2} + C \sum _{i} \xi ^{(i)} - \sum _{i} \alpha ^{(i)} [ y^{(i)}(w\cdot x^{(i)} + b) - 1 + \xi ^{(i)} ] - \sum _{i} \mu ^{(i)} \xi ^{(i)}\]

4장 페이지 2 의 라그랑지안에 \(C\sum \xi \), \(-\sum \alpha \xi \), \(-\sum \mu \xi \) 세 항이 더해진 모양입니다. 이제 \(w, b, \xi ^{(i)}\) 에 대해 편미분해 0 으로 놓습니다.

편미분 = 0결과4장과 비교
\(\partial L/\partial w = w - \sum \alpha ^{(i)}y^{(i)}x^{(i)} = 0\)\(w = \sum \alpha ^{(i)}y^{(i)}x^{(i)}\)같음. \(\xi \) 가 들어 있는 새 항들은 \(w\) 를 포함하지 않아 미분하면 사라집니다.
\(\partial L/\partial b = -\sum \alpha ^{(i)}y^{(i)} = 0\)\(\sum \alpha ^{(i)}y^{(i)} = 0\)같음. 새 항들에 \(b\) 가 없습니다.
\(\partial L/\partial \xi ^{(i)} = C - \alpha ^{(i)} - \mu ^{(i)} = 0\)\(\alpha ^{(i)} = C - \mu ^{(i)}\)새 줄. \(\xi ^{(i)}\) 가 들어 있는 항은 \(C\xi \), \(-\alpha \xi \), \(-\mu \xi \) 셋이고 모두 \(\xi \) 에 곱해진 계수가 그대로 남습니다.

새 줄에서 \(\mu ^{(i)} \ge 0\) 이니 \(\alpha ^{(i)} = C - \mu ^{(i)} \le C\) 입니다. 원래부터 \(\alpha ^{(i)} \ge 0\) 이었으니 \(0 \le \alpha ^{(i)} \le C\) 가 됩니다. 이 식들을 \(L\) 에 대입할 때, \(\xi \) 가 들어 있는 항은 \(C\sum \xi - \sum \alpha \xi - \sum \mu \xi = \sum (C - \alpha - \mu )\xi \) 로 묶이고 괄호가 방금 구한 새 줄에 의해 0 이라 \(\xi \) 가 통째로 사라집니다. 남은 것은 4장 페이지 4 의 줄과 똑같아서 쌍대 목적함수 \(D(\alpha )\) 도 같습니다.

소프트 마진의 쌍대문제

\[\max _{\alpha } \; D(\alpha ) = \sum \alpha ^{(i)} - \tfrac12 \sum _{i}\sum _{j} \alpha ^{(i)}\alpha ^{(j)} y^{(i)}y^{(j)} (x^{(i)}\cdot x^{(j)})\]

\[\text{s.t.} \; \boldsymbol{0 \le \alpha ^{(i)} \le C} \; (\text{모든} i), \; \; \sum \alpha ^{(i)}y^{(i)} = 0\]

하드 마진 (4장)소프트 마진 (5장)
목적 \(D(\alpha )\)같음 (데이터는 여전히 내적 \(x^{(i)}\cdot x^{(j)}\) 로만 들어 있음)
등식 제약\(\sum \alpha ^{(i)}y^{(i)} = 0\), 같음
부호 제약\(\alpha ^{(i)} \ge 0\)\(0 \le \alpha ^{(i)} \le C\)
\(w\) 복원\(w = \sum \alpha ^{(i)}y^{(i)}x^{(i)}\), 같음

\(\alpha \le C\) 라는 상한 하나가 두 극단을 한꺼번에 설명합니다. \(C\) 가 아주 크면 이 상한이 사실상 없는 것과 같아 4장의 문제로 돌아갑니다. 정확히는 하드 마진 쌍대문제의 답에서 모든 \(\alpha \) 성분이 \(C\) 이하이기만 하면 이 상한이 아무 영향도 주지 않아 같은 답이 나옵니다. 4장 페이지 7 의 \(\alpha = (\tfrac14 , 0, \tfrac14 )\) 가 그 경우라 \(C \ge \tfrac14 \) 이면 세 점의 답이 그대로이고, 페이지 1 (나) 의 네 점은 하드 마진 답이 \(\alpha = (0, 0, 4, 4)\) 이므로 \(C \ge 4\) 일 때 페이지 3 의 표가 하드 마진 \(w = (2, 2)\) 가 되는 것과 맞아떨어집니다.

점의 세 부류

3장의 상보 여유성(\(\text{승수} \times \text{제약} = 0\))이 이번에는 두 줄입니다. 승수 \(\alpha \), \(\mu \) 와 제약 \(g^{(i)}\), \(\xi ^{(i)}\) 에 각각 적용되고, \(\mu = C - \alpha \) 를 쓰면 다음과 같습니다.

\[\alpha ^{(i)} [ y^{(i)}(w\cdot x^{(i)} + b) - 1 + \xi ^{(i)} ] = 0 \; ,\; \; (C - \alpha ^{(i)}) \xi ^{(i)} = 0\]

\(\alpha ^{(i)}\)두 줄에서 따라 나오는 것점의 위치 (\(z = y(w\cdot x+b)\))
\(\alpha = 0\)\(C - \alpha = C > 0\) 이라 둘째 줄에서 \(\xi = 0\), 곧 제약 \(z \ge 1\)마진 경계 밖이거나 경계 위. \(w\) 에 기여하지 않음
\(0 < \alpha < C\)\(C - \alpha > 0\) 이라 \(\xi = 0\). \(\alpha > 0\) 이라 첫째 줄에서 대괄호가 0, 곧 \(z = 1\)마진 경계 위 (4장의 서포트 벡터)
\(\alpha = C\)\(C - \alpha = 0\) 이라 \(\xi \) 는 0 이상 아무 값. \(\alpha > 0\) 이라 대괄호가 0, 곧 \(z = 1 - \xi \le 1\)경계 안쪽·틀린 쪽 (\(\xi > 0\))이거나 경계 위 (\(\xi = 0\))

페이지 3 위젯의 \(\alpha \) 열에서 ‘= C’ 로 표시된 점이 셋째 부류입니다. 거꾸로 읽으면 이렇습니다.

  • 점이 띠 바깥(\(z > 1\))이면 \(\alpha = 0\). (\(\alpha > 0\) 이면 \(z = 1 - \xi \le 1\) 이라 모순)
  • 점이 띠 안쪽이거나 틀린 쪽(\(z < 1\))이면 \(\xi > 0\) 이고, 그러면 \(C - \alpha = 0\) 이라 \(\alpha = C\). 곧 \(\xi > 0\) 인 점은 모두 서포트 벡터(\(\alpha > 0\))입니다.
  • 마진 경계 위(\(z = 1\))에 있는 점은 세 부류 모두 가능합니다. 4장에서 경계 위인데 \(\alpha = 0\) 인 점이 있었던 것처럼, 이제는 경계 위인데 \(\alpha = C\) 인 점도 있습니다.

검증 — 페이지 3 의 4점 예제 \(C = 1\)

페이지 3 의 표에서 \(C = 1\) 이면 \(\alpha = (0, 0, 1, 1)\), \(w = (\tfrac12 , \tfrac12 )\) 라고 했습니다. 직접 확인합니다. (점 번호: \(x^{(1)} = (3, 3)\), \(x^{(2)} = (4, 3)\), \(x^{(3)} = (1, 1)\), \(x^{(4)} = (1.5, 1.5)\))

  • 쌍대 제약 확인. \(0 \le \alpha \le C = 1\) ✓. \(\sum \alpha y = 0\times 1 + 0\times 1 + 1\times (-1) + 1\times (+1) = 0\) ✓.
  • \(w\) 복원. \(w = 1\times (-1)(1, 1) + 1\times (+1)(1.5, 1.5) = (0.5, 0.5)\) ✓.
  • 쌍대 값. \(D = \sum \alpha - \tfrac12 \lVert w\rVert ^{2} = 2 - \tfrac12 \times \tfrac12 = 1.75\) (\(\sum \sum \) 가 \(w\cdot w\) 와 같다는 4장 페이지 4 의 4 줄을 썼습니다).
  • 원문제 값. \(b = -2\) 로 놓으면 페이지 2 의 후보 1 이라 \(\tfrac12 \lVert w\rVert ^{2} + C\sum \xi = \tfrac14 + 1.5 = 1.75\).
  • 쌍대 값은 원문제의 어떤 가능해의 값보다도 크지 않고(약쌍대성, 4장 페이지 5), 위의 원문제 값이 쌍대 값과 같으므로 둘 다 최적입니다. \(C = 1\) 에서 후보 1 이 정말 답입니다.

점의 부류는 \(x^{(1)}, x^{(2)}\) 가 \(\alpha = 0\)(\(z = 1, 1.5\) ≥ 1), \(x^{(3)}, x^{(4)}\) 가 \(\alpha = C\)(\(x^{(4)}\) 는 \(z = -\tfrac12 < 1\) 로 틀린 쪽, \(x^{(3)}\) 은 \(z = 1\) 이라 \(\xi = 0\) 이지만 \(\alpha = C\))입니다. 세 부류 중 둘만 나왔고, 가운데 부류(\(0 < \alpha < C\))는 4장의 세 점 예제에서 확인할 수 있습니다. \(C > \tfrac14 \) 이면 \(\alpha = (\tfrac14 , 0, \tfrac14 )\) 의 양수 두 개가 모두 이 범위에 듭니다.

\(b\) 는 어떤 점으로 구하나

4장에서는 \(\alpha > 0\) 인 점에서 등식 \(y(w\cdot x+b) = 1\) 이 나온다고 했습니다. 소프트 마진에서는 \(\alpha > 0\) 인 점이 두 종류라 조심해야 합니다.

  • \(0 < \alpha < C\) 인 점은 \(\xi = 0\) 임이 확실해서 등식 \(y(w\cdot x+b) = 1\) 이 성립합니다. \(b = y - w\cdot x\) 로 구합니다.
  • \(\alpha = C\) 인 점은 \(z = 1 - \xi \) 인데 \(\xi \) 를 모르니 \(b\) 를 정해 주지 못합니다.
  • \(\alpha = 0\) 인 점은 부등식 \(z \ge 1\) 만 줍니다.

한계 — \(0 < \alpha < C\) 인 점이 하나도 없으면 \(b\) 는 한 값으로 정해지지 않고 구간이 됩니다

위 4점 예제(\(C = 1\))가 그런 경우입니다. \(w = (\tfrac12 , \tfrac12 )\) 는 하나로 정해지지만 \(b\) 는 \(-2 \le b \le -\tfrac12 \) 의 어느 값이든 됩니다. 조건은 이렇습니다. \(\alpha = 0\) 인 \(x^{(1)}\) 은 \(3 + b \ge 1\), \(\alpha = C\) 인 \(x^{(3)}\) 은 \(z = -(1 + b) \le 1\), \(x^{(4)}\) 는 \(z = 1.5 + b \le 1\) 에서 \(b \ge -2\) 와 \(b \le -\tfrac12 \) 가 나옵니다. 그 구간 안에서는 \(\xi ^{(3)} = 2 + b\), \(\xi ^{(4)} = -\tfrac12 - b\) 라 합이 늘 1.5 이고 목적값이 같아서 어느 \(b\) 도 똑같이 최적입니다. 위젯도 이럴 때는 구간을 알려 주고 가운데 값을 그립니다. \(0 < \alpha < C\) 인 점이 하나라도 있으면 \(b\) 가 정해집니다. 여기서 \(w\) 는 언제나 하나이고 \(b\) 만 구간일 수 있습니다.

힌지 손실로 다시 보기

이번에는 같은 문제를 \(\xi \) 없이 다시 씁니다. \((w, b)\) 를 하나 정했다고 합시다. 그러면 점 \(i\) 의 \(\xi ^{(i)}\) 는 제약 \(\xi ^{(i)} \ge 1 - z^{(i)}\), \(\xi ^{(i)} \ge 0\) 을 지키는 가장 작은 값이면 되고 (\(C > 0\) 이므로 작을수록 이득입니다), 그 값은 둘 중 큰 값입니다.

\(\xi ^{(i)} = \max ( 0, 1 - y^{(i)} f(x^{(i)}) )\)    (\(f(x) = w\cdot x + b\))

오른쪽의 \(\max (0, 1 - z)\) 가 힌지 손실(hinge loss)입니다. 마진 밖(\(z \ge 1\))에서는 0 이고 그 안쪽에서는 1 에서 모자란 만큼 올라갑니다. 곧 \(\xi \) 는 힌지 손실입니다. 문제는 \(\xi \) 를 지우고 이렇게 쓸 수 있습니다.

\[\min _{w, b} \; \tfrac12 \lVert w\rVert ^{2} + C \sum _{i} \max ( 0, 1 - y^{(i)} f(x^{(i)}) )\]

\(z = yf(x)\)힌지 손실 \(\xi \)예

10마진 경계 위
0.50.5띠 안, 올바른 쪽 (페이지 2 의 \(C = 2\) 직선에서 \(x^{(3)}, x^{(4)}\))

−0.51.5틀린 쪽 (페이지 2 후보 1 의 \(x^{(4)}\))
−23멀리 틀린 쪽: 벌점이 거리에 비례해 계속 올라감

이 식을 보면 목적함수가 두 항의 합임이 분명해집니다. \(\tfrac12 \lVert w\rVert ^{2}\) 은 \(w\) 를 작게, 곧 마진을 넓게 유지하는 항이고, \(C\sum (\text{힌지 손실})\) 은 학습 데이터에서 얼마나 어겼는지를 재는 손실 항입니다. \(C\) 는 손실 항의 비중입니다. 하드 마진은 그 손실을 한 점도 허용하지 않는 극단입니다.

왜 0-1 손실이 아니라 힌지 손실인가 — 한계 두 가지

  • 힌지 손실은 늘 0-1 손실 이상입니다(\(z < 0\) 이면 힌지는 1 이상). 그래서 \(\sum \xi \) 는 틀린 점의 수 이상의 값입니다. 0-1 손실은 계단이라 최소화하기 어렵고, 힌지 손실은 한 곳에서만 꺾일 뿐 나머지는 직선이라, 이 문제는 4장에서 다룬 이차 계획 문제로 풀 수 있습니다.
  • 힌지 손실은 틀린 정도에 비례해 벌점이 계속 올라가서, 멀리 떨어진 이상치일수록 \(\xi \) 가 크고 큰 \(C\) 에서 직선을 더 세게 끌어당깁니다. 마지막 줄의 \(z = -2\) 가 그것입니다.
  • \(\xi = \max (0, 1 - z)\) 가 정확히 성립하는 것은 최적해에서입니다. 제약식만 보면 \(\xi \) 는 그 값 이상이면 아무 값이나 가능합니다(\(C > 0\) 이므로 \(\xi \) 는 작을수록 이득입니다).

5장 마무리

핵심 요약

  1. 하드 마진은 “모든 점이 예외 없이”라서 이상치 하나에 약합니다. 빨간 점이 파란 두 점의 선분 위에 놓이면 가능해가 없고, 분리할 수 있어도 마진이 크게 줄어듭니다(예제에서 2.83 → 0.71).
  2. 점마다 슬랙 변수 \(\xi ^{(i)} \ge 0\) 을 두어 제약을 \(y^{(i)}(w\cdot x^{(i)}+b) \ge 1 - \xi ^{(i)}\) 로 풀고, 목적함수에 벌점을 더한 것이 소프트 마진이며, 식으로는 \(\min \tfrac12 \lVert w\rVert ^{2} + C\sum \xi ^{(i)}\) 입니다. \(\xi = 0\) 은 제약 그대로, \(0 < \xi < 1\) 은 띠 안, \(\xi > 1\) 은 틀린 쪽이고, \(\xi = \max (0, 1 - y f(x))\) 는 힌지 손실입니다.
  3. \(C\) 는 침범의 단가입니다. 크면 엄격해서 하드 마진에 가까워지고(이상치에 끌려 과적합할 수 있음), 작으면 관대해서 마진이 넓어집니다(점을 거의 안 봐 과소적합할 수 있음). \(C\) 는 사람이 정하는 하이퍼파라미터입니다. 하드 마진의 가능해가 있을 때에 한해 \(C\) 를 키우면 하드 마진에 가까워집니다.
  4. 쌍대문제는 \(\alpha \ge 0\) 이 \(0 \le \alpha \le C\) 로 바뀌는 한 줄 차이입니다. \(\alpha = 0\) 은 띠 바깥, \(0 < \alpha < C\) 는 마진 경계 위, \(\alpha = C\) 는 경계 안쪽·틀린 쪽(또는 경계 위)이고, \(b\) 는 \(0 < \alpha < C\) 인 점의 \(y(w\cdot x+b) = 1\) 에서 구합니다.

어떤 점의 슬랙 변수가 \(\xi ^{(i)} = 0.4\) 입니다. 이 점은 어디에 있을까요?

  1. 마진 띠 안쪽이지만 올바른 쪽이다
  2. 직선을 넘어 틀린 쪽에 있다
  3. 마진 경계 위에 있다

페이지 4 의 부류표로 더 따져 봅시다. \(\xi = 0.4 > 0\) 이면 상보 여유성 \((C - \alpha )\xi = 0\) 에서 \(\alpha = C\) 여야 합니다. 띠를 침범한 점은 예외 없이 \(\alpha = C\) 의 서포트 벡터이고, 반대로 \(\alpha = C\) 이더라도 반드시 침범한 것은 아닙니다(경계 위에 정확히 놓인 점도 있습니다). 각 점이 직선을 정하는 데 미치는 영향(\(\alpha \))의 상한이 \(C\) 이므로, 이상치 한 점의 영향력도 \(C\) 로 막혀 있습니다.

페이지 3 의 위젯에서 약한 이상치를 놓고 \(C = 0.01\) 로 아주 작게 했습니다. 어떤 모습이 나올까요?

  1. 모든 점이 띠 바깥에 놓이고 마진이 좁아져 이상치도 올바르게 분류한다
  2. 마진이 0.71 로 좁아지고 직선이 이상치 쪽에 붙는다
  3. 침범이 싸서 마진이 매우 넓어지고, 많은 점이 띠 안쪽에 들어가며 일부는 잘못 분류된다

이것이 과소적합입니다. 눈여겨볼 점은 이상치가 없는 데이터에서도 같은 일이 생긴다는 것입니다. 이상치 없음에서 \(C = 0.01\) 로 놓으면 여섯 점이 모두 \(\alpha = C\) 이고 모든 점이 띠 안쪽에 있습니다(가운데 값의 \(b\) 에서 \(\xi \approx 0.8\)). 소프트 마진의 \(C\) 는 이상치를 다루는 값이기 전에, 데이터를 얼마나 신뢰할지 정하는 값입니다. 너무 작으면 직선을 데이터에 맞추는 일 자체를 포기합니다.

소프트 마진의 쌍대문제를 풀어 \(\alpha \) 를 얻었습니다. \(b\) 를 구하려면 어떤 점의 식 \(y(w\cdot x + b) = 1\) 을 써야 할까요?

  1. α = C 인 점 (서포트 벡터이므로)
  2. 0 < α < C 인 점
  3. α = 0 인 점 (w 에 기여하지 않으므로)

여러 점이 \(0 < \alpha < C\) 이면 각 점으로 구한 \(b\) 가 모두 같아야 합니다. 실제 구현에서는 수치 오차 때문에 조금씩 달라서 그 평균을 쓰는 것이 흔합니다. 위젯의 계산도 그렇게 합니다. 반대로 이런 점이 없는 경우에는 페이지 4 처럼 \(b\) 의 가능한 구간을 구하고 그 가운데를 고르는 것이 한 방법인데, 이것은 약속일 뿐 유일한 답은 아닙니다.

직접 해 보기

수직선 위(\(x_{2} = 0\))의 네 점입니다. \(x^{(1)} = (2, 0)\)(+1), \(x^{(2)} = (3, 0)\)(+1), \(x^{(3)} = (0, 0)\)(−1), 그리고 이상치 \(x^{(4)} = (0.5, 0)\)(+1) 입니다. 후보 직선 세 개를 비교합니다.

  • 후보 A: \(w = (1, 0)\), \(b = -1\) (4장 과제의 답)
  • 후보 H: \(w = (4, 0)\), \(b = -1\)
  • 후보 Z: \(w = (0, 0)\), \(b = 1\)
  1. 세 후보 각각에서 네 점의 \(z = y(w\cdot x+b)\) 와 \(\xi = \max (0, 1 - z)\) 를 구하세요.
  2. 각 후보의 목적값 \(\tfrac12 \lVert w\rVert ^{2} + C\sum \xi \) 를 \(C\) 의 식으로 쓰세요.
  3. \(C\) 가 어느 범위일 때 세 후보 중 A 가 가장 작습니까?
  4. 후보 Z 와 후보 H 가 각각 이기는 범위에서 직선이 어떤 상태인지 이 장의 용어(과소적합, 과적합, 엄격, 관대)로 한 줄씩 설명하세요.
모범답안과 흔한 실수

1. 후보 A 는 \(f = x_{1} - 1\). \(x^{(1)}\): \(z = 1\), \(\xi = 0\). \(x^{(2)}\): \(z = 2\), \(\xi = 0\). \(x^{(3)}\): \(f = -1\), \(y = -1\) 이라 \(z = 1\), \(\xi = 0\). \(x^{(4)}\): \(f = -0.5\) 라 \(z = -0.5\), \(\xi = 1.5\).
후보 H 는 \(f = 4x_{1} - 1\). \(x^{(1)}\): 7, \(x^{(2)}\): 11, \(x^{(3)}\): \(f = -1\) 이라 \(z = 1\), \(x^{(4)}\): \(f = 1\) 이라 \(z = 1\). 네 점 모두 \(z \ge 1\) 이라 \(\xi = 0\).
후보 Z 는 \(f = 1\). \(x^{(1)}, x^{(2)}, x^{(4)}\): \(z = 1\), \(\xi = 0\). \(x^{(3)}\): \(z = -1\), \(\xi = 2\).

2. A: \(\tfrac12 \times 1 + 1.5C = \tfrac12 + 1.5C\). H: \(\tfrac12 \times 16 + 0 = 8\). Z: \(0 + 2C = 2C\).

3. A < Z 는 \(\tfrac12 + 1.5C < 2C\), 곧 \(C > 1\). A < H 는 \(\tfrac12 + 1.5C < 8\), 곧 \(C < 5\). 따라서 \(1 < C < 5\) 일 때 A 가 가장 작습니다(경계 \(C = 1\), \(C = 5\) 에서는 동점).

4. \(C < 1\) 에서는 Z 가 이깁니다. 침범이 싸서 \(w = 0\) 으로 두고 빨간 점 하나를 오분류하는 직선으로, 관대함이 지나쳐 데이터를 보지 않는 과소적합입니다. \(C > 5\) 에서는 H 가 이깁니다. 침범이 비싸서 이상치까지 \(z = 1\) 에 맞추려고 마진을 \(2/\lVert w\rVert = 0.5\) 로 좁힌 엄격한 직선으로, 이상치 하나에 크게 흔들리는 과적합 쪽입니다. 둘 사이(\(1 < C < 5\))에서는 A 가 이상치 하나를 오분류하는 대신 마진을 지킵니다.

흔한 실수 1 — \(\xi ^{(4)} = 1.5\) 를 “오차 1.5 개”로 읽기. \(\xi \) 는 \(1 - z\) 라는 마진 규칙에서의 이탈 크기이지 틀린 개수가 아닙니다. \(\xi \) 가 1 을 넘으면 틀린 것이므로 \(\sum \xi \) 는 틀린 점 수의 상한이 됩니다.

흔한 실수 2 — \(C\) 와 마진의 방향을 거꾸로 알기. \(C\) 가 클수록 침범이 비싸 마진이 좁아지고, 작을수록 마진이 넓어집니다(H 와 Z 로 확인).

흔한 실수 3 — 세 후보 중 A 가 이겼다고 A 가 진짜 최적이라고 단정하기. 비교한 것은 후보 셋뿐입니다. 이 문제의 실제 최적해는 세 후보 사이의 직선일 수 있습니다(페이지 2 의 \(C = 2\) 예와 같습니다).

다음 장으로 — 5장의 소프트 마진은 이상치 몇 개를 견디게 해 주지만 직선이라는 틀은 그대로입니다. 6장은 직선으로 분리할 수 없는 데이터(원형으로 둘러싼 점)를 다룹니다.
