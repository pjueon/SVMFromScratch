3장 · 화면 1

제약 있는 최적화 기초 (라그랑주·KKT)

2장은 문제 하나를 남기고 끝났습니다. \(\tfrac12 \lVert w\rVert ^{2}\) 를 가장 작게 만들라면 \(w = (0, 0)\) 이 답이지만, 그 \(w\) 로는 제약을 만족할 수 없었습니다(2장 화면 4). 제약이 있는 최적화는 “기울기가 0 인 곳 찾기”로는 풀리지 않습니다. 이 장에서는 그 문제를 푸는 도구인 라그랑주 승수법과 KKT 조건을 배웁니다. 이 도구에는 편미분이 필요하므로, 이 화면에서 먼저 가볍게 복습합니다.

이 장의 진행

  1. 편미분과 기울기를 복습하고, 제약이 없을 때의 풀이를 확인한다 (이 화면).
  2. 등식 제약이 붙으면 답이 어디에 놓이는지, 등고선과 제약선이 ‘접하는 점’으로 확인한다 (화면 2).
  3. 그 접점을 식으로 찾는 라그랑주 승수법을 손으로 끝까지 푼다 (화면 3).
  4. 부등식 제약에서는 제약이 ‘활성’인지 ‘비활성’인지에 따라 풀이가 달라진다 (화면 4).
  5. 그 모든 것을 KKT 조건 네 줄로 정리한다 (화면 5).

이 장의 기호 두 가지

이 장에서 움직이는 변수는 \(w_{1}, w_{2}\) 입니다. 2장의 문제와 같은 모양으로 쓰려고 \(w\) 라고 부를 뿐, 데이터 점 \(x^{(i)}\) 와는 아직 아무 상관이 없습니다. 또 이 장에서 줄이고 싶은 값(목적함수)은 \(J\) 라 쓰겠습니다. 1·2장의 \(f(x)\) 와 글자가 겹치지 않도록 \(J\) 를 골랐습니다.

제약이 없을 때 — 기울기가 0 인 곳

변수가 하나인 \(J(w) = \tfrac12 w^{2}\) 부터 봅니다. 2장 화면 4 에서 보았듯 \(w\) 를 조금 늘렸을 때 값이 늘어나는 비율, 곧 기울기는 \(w\) 입니다(예: \(w = 2\) 에서 기울기 2). \(w\) 가 양수이면 오르막이라 줄이려면 왼쪽으로, 음수이면 내리막이라 오른쪽으로 가야 하고, \(w = 0\) 에서 기울기가 0 이 되어 바닥에 닿습니다. 그릇 모양 함수의 바닥은 기울기가 0 인 곳입니다.

변수가 둘이면 — 편미분

변수가 둘이면 “기울기”가 한 개가 아닙니다. 산비탈에 서 있다고 합시다. 동쪽으로 한 걸음 갈 때의 가파름과 북쪽으로 한 걸음 갈 때의 가파름은 다릅니다. 그래서 한 변수만 움직이고 나머지는 고정해 둔 채 기울기를 잽니다. 이것이 편미분입니다.

2장의 \(\tfrac12 \lVert w\rVert ^{2}\) 를 좌표로 풀어 쓰면 \(\lVert w\rVert ^{2} = w_{1}^{2} + w_{2}^{2}\) 이므로,

\[J(w_{1}, w_{2}) = \tfrac12 (w_{1}^{2} + w_{2}^{2})\]

점 \((w_{1}, w_{2}) = (3, 1)\) 에서 시작해 봅시다. \(w_{2}\) 를 1 로 고정하면 남는 것은 \(J = \tfrac12 w_{1}^{2} + \tfrac12 \) 입니다 (고정한 \(w_{2}\) 부분 \(\tfrac12 \times 1^{2} = \tfrac12 \) 은 그냥 숫자입니다). 이 함수를 \(w_{1}\) 로 보았을 때의 기울기는 \(w_{1} = 3\) 입니다. \(w_{1}\) 을 0.01 늘려 확인하면 \(J(3, 1) = 5\) 가 \(J(3.01, 1) = 5.03005\) 로 변합니다. 늘어난 양 0.03005 를 0.01 로 나누면 약 3.005 이므로 3 에 가깝습니다. 이 값을 \(w_{1}\) 에 대한 편미분이라 부릅니다.

편미분 요령 세 가지

  1. 미분하는 변수 말고는 전부 숫자로 봅니다.
  2. 미분하는 변수가 들어 있지 않은 항은 상수이므로 미분하면 0 입니다.
  3. 변수에 상수가 곱해진 항 \(c_{1}w_{1} + c_{2}w_{2}\) 는 \(w_{1}\) 로 미분하면 \(c_{1}\), \(w_{2}\) 로 미분하면 \(c_{2}\) 입니다. 예를 들어 \(w_{1} + w_{2}\) 의 편미분은 둘 다 1 이고, \(5w_{1} + 2w_{2}\) 는 \(w_{1}\) 에 대해 5, \(w_{2}\) 에 대해 2 입니다. (\(w\cdot x = w_{1}x_{1} + w_{2}x_{2}\) 도 같은 모양입니다. 4장에서 쓴다)

편미분을 모으면 — 기울기 벡터

두 편미분을 한 벡터로 묶은 것이 기울기 벡터 \(\nabla J\) (“나블라 J”)입니다. 영어로는 그래디언트(gradient)라고 하며, 다른 책이나 코드에서는 이 이름을 더 자주 만납니다. 이 교재에서는 ‘기울기 벡터’, ‘기울기’, ‘그래디언트’를 같은 뜻으로 씁니다.

\[\nabla J = ( \partial J/\partial w_{1} , \partial J/\partial w_{2} )\]

우리 함수에서는 \(\nabla J = (w_{1}, w_{2}) = w\) 입니다. 2장에서 ½ 를 붙인 이유가 여기서 보입니다. 제곱에서 나오는 2 를 ½ 가 지워서, \(\tfrac12 \lVert w\rVert ^{2}\) 의 기울기가 깔끔하게 \(w\) 자신이 됩니다. 점 \((3, 1)\) 에서는 \(\nabla J = (3, 1)\) 입니다.

이 벡터의 뜻은 이렇습니다. 점에서 변수를 아주 조금, 곧 작은 걸음 \(dw = (dw_{1}, dw_{2})\) 만큼 움직이면 \(J\) 의 변화량 \(dJ\) 는 각 변수 방향의 변화를 더한 것입니다(전미분).

\[dJ = \frac{\partial J}{\partial w_{1}} dw_{1} + \frac{\partial J}{\partial w_{2}} dw_{2} = \nabla J\cdot dw\]

가운데 식을 두 벡터 \(\nabla J\) 와 \(dw\) 의 내적(1장)으로 묶은 것이 오른쪽 식입니다. 점 \((3, 1)\) 에서는 \(\nabla J = (3, 1)\) 이므로 \(dJ = 3dw_{1} + 1dw_{2}\) 입니다. 확인해 봅시다. \(dw = (0.01, 0.01)\) 이면 예측은 \(3\times 0.01 + 1\times 0.01 = 0.04\) 이고, 실제로는 \(J(3.01, 1.01) - J(3, 1) = 5.0401 - 5 = 0.0401\) 입니다(걸음이 작을수록 더 잘 맞습니다). 같은 길이만큼 걸을 때 내적은 \(dw\) 가 \(\nabla J\) 와 같은 방향일 때 가장 크므로, \(\nabla J\) 는 값이 가장 빨리 오르는 방향이고 그 반대가 가장 빨리 내리는 방향입니다.

제약이 없다면 — ∇J = 0

바닥에서는 어느 방향으로 가도 값이 줄지 않으므로 \(\nabla J = 0\) 입니다. 우리 함수에서는 \((w_{1}, w_{2}) = (0, 0)\) 이고, 2장 화면 4 의 “제약 없는 최솟값”이 이것입니다.

한계 — 기울기 0 이 늘 바닥은 아닙니다

\(\nabla J = 0\) 인 점은 바닥일 수도, 언덕 꼭대기일 수도(\(J = -w_{1}^{2}-w_{2}^{2}\)), 한쪽으로는 내리막이고 다른 쪽으로는 오르막인 말안장일 수도 있습니다(\(J = w_{1}^{2} - w_{2}^{2}\)). 그릇 모양 함수여야 “기울기 0 이면 바닥”이 보장됩니다. 이 교재의 \(\tfrac12 \lVert w\rVert ^{2}\) 는 그릇 모양입니다.

이제 2장에서 남긴 질문으로 돌아갑니다. 2장의 문제에서는 \(\nabla J = 0\) 인 점은 제약을 만족하지 못합니다. 그렇다면 어디가 답일까요? 다음 화면에서 가장 단순한 제약인 등식 하나를 붙여 그림으로 봅니다.

등식 제약이 붙으면 — 접하는 점

가장 단순한 제약부터 시작합니다. 2장 화면 5 에서 제약 1 과 3 을 더해 얻은 \(w_{1} + w_{2} \ge 1\) 을 기억하시나요? 그 경계인 등식 \(w_{1} + w_{2} = 1\) 을 지키면서 \(J = \tfrac12 (w_{1}^{2} + w_{2}^{2})\) 를 가장 작게 만드는 문제를 풉니다.

이 화면의 문제

\[\min _{w_{1},w_{2}} \; \tfrac12 (w_{1}^{2} + w_{2}^{2}) \; \; \text{s.t.} \; w_{1} + w_{2} = 1\]

이제 가능해는 평면 전체가 아니라 직선 \(w_{1} + w_{2} = 1\) 위의 점들뿐입니다. 원점 \((0, 0)\) 은 이 직선 위에 없습니다.

등고선 — 같은 높이의 점들

지도의 등고선처럼, \(J\) 의 값이 같은 점들을 이은 곡선을 등고선이라 합니다. \(J = \tfrac12 (w_{1}^{2}+w_{2}^{2})\) 에서 \(J = 0.5\) 인 점은 \(w_{1}^{2}+w_{2}^{2} = 1\), 곧 원점을 중심으로 한 반지름 1 인 원입니다. \(J = \tfrac14 \) 이면 반지름 \(\sqrt{\tfrac12 } \approx 0.71\) 인 원입니다. 값이 클수록 큰 원이고, 원점이 바닥입니다.

그러면 문제는 이렇게 바뀝니다. 직선 위의 점 중에서, 가장 작은 원 위에 있는 점을 찾아라.

  • 원이 직선을 가로지르면 직선을 따라 한쪽으로 가는 동안 더 안쪽 원(더 작은 \(J\))으로 들어갈 수 있으니 아직 최소가 아닙니다.
  • 원이 직선에 정확히 접하면 직선 위 어느 쪽으로 가도 더 바깥 원으로 나가기만 합니다. 여기가 최소입니다.

접한다는 것을 식으로 — 기울기가 평행하다

그림에서 본 “두 화살표가 같은 방향”이라는 사실이 접점을 식으로 나타내는 출발점입니다. 화면 1 에서 본 대로, 점을 작은 걸음 \(dw\) 만큼 움직일 때 \(J\) 의 변화량은 내적 \(dJ = \nabla J\cdot dw\) 로 나타낼 수 있고, 제약식 \(h\) 의 변화량도 같은 모양으로 \(dh = \nabla h\cdot dw\) 입니다. 이 식을 등고선과 제약선을 따라 움직이는 두 경우에 적용해 봅시다.

  1. 등고선 위에서는 \(J\) 가 변하지 않습니다. 등고선을 따라 움직이면 \(dJ = 0\), 곧 \(\nabla J\cdot dw = 0\) 입니다. 내적이 0 이라는 것은 \(\nabla J\) 가 움직인 방향 \(dw\), 곧 등고선에 수직이라는 뜻입니다(1장의 내적과 수직). 위젯의 원에서도 화살표 \(\nabla J\) 는 원의 반지름 방향, 곧 원에 수직입니다.
  2. 제약선 \(h = 0\) 위에서는 \(h\) 가 늘 0 입니다. 그래서 제약선을 따라 움직이면 \(h\) 의 변화도 0, 곧 \(dh = \nabla h\cdot dw = 0\) 이고, \(\nabla h\) 는 제약선에 수직입니다. \(h(w) = w_{1} + w_{2} - 1\) 이라 두면 \(\nabla h = (1, 1)\) 입니다. 1장에서 직선 \(w\cdot x + b = 0\) 의 계수 벡터 \(w\) 가 직선에 수직인 법선 벡터였던 것과 같은 모양입니다.

두 곡선이 접하면 접선 방향이 같으므로, 그 수직 방향도 같습니다. 따라서 접점에서는 \(\nabla J\) 와 \(\nabla h\) 가 같은 직선 위에 놓입니다. 평행하다는 것은 한쪽이 다른 쪽의 몇 배라는 말이고, 위젯의 접점에서는 \(\nabla J = (\tfrac12 , \tfrac12 ) = \tfrac12 \times (1, 1) = \tfrac12 \times \nabla h\) 입니다. 이 “몇 배”에 다음 화면에서 이름을 붙입니다.

이 화면의 결론

등식 제약 \(h(w) = 0\) 아래에서 \(J\) 가 최소인 점에서는 \(\nabla J = (\text{어떤 수}) \times \nabla h\) 이고 \(h(w) = 0\) 입니다. 미지수는 \(w_{1}, w_{2}\) 와 그 “어떤 수”까지 세 개이고, 식도 세 개이므로 풀 수 있습니다.

3장 · 화면 3

라그랑주 승수법 — 접점을 식으로 찾기

화면 2 의 결론을 식으로 다시 적어 봅시다. 풀려는 문제는 같습니다.

\[\min \; J(w_{1}, w_{2}) = \tfrac12 (w_{1}^{2} + w_{2}^{2}) \; \; \text{s.t.} \; h(w_{1}, w_{2}) = w_{1} + w_{2} - 1 = 0\]

화면 2 에서 최솟값이 되는 점은 \(\nabla J = \lambda \nabla h\) 이고 \(h = 0\) 인 점이라고 했습니다(\(\lambda \) 가 화면 2 의 “어떤 수”입니다). \(\nabla J = \lambda \nabla h\) 는 성분이 둘이므로, 풀어 쓰면 식은 모두 셋입니다.

\[\begin{aligned}\partial J/\partial w_{1} &= \lambda \, \partial h/\partial w_{1}\\ \partial J/\partial w_{2} &= \lambda \, \partial h/\partial w_{2}\\ h(w_{1}, w_{2}) &= 0\end{aligned}\]

제약이 없을 때는 \(\nabla J = 0\) 인 점을 찾으면 됐지만(화면 1), 제약이 붙으면 그 점이 제약을 어기므로 이 방식으로는 답을 구할 수 없습니다(이 장 화면 1, 2장 화면 4). 라그랑주 승수법은 이 문제를 제약이 없는 문제로 바꿔 푸는 방법입니다. 제약식에 새 변수 \(\lambda \) 를 붙여 라그랑지안이라는 함수를 만들고, 이 함수의 편미분이 모두 0 인 점을 찾습니다. 이 조건은 위의 세 식과 똑같습니다. 순서대로 따라가 봅시다.

1단계 — 라그랑지안을 정의하기

제약식 \(h\) 에 새 변수 \(\lambda \)(람다)를 곱해 목적함수에서 뺀 함수를 다음과 같이 정의합니다. 이 함수가 라그랑지안입니다.

정의 — 라그랑지안과 라그랑주 승수

\[L(w_{1}, w_{2}, \lambda ) = J(w_{1}, w_{2}) - \lambda h(w_{1}, w_{2})\]

  • \(L\) — 라그랑지안. 목적함수와 제약을 한 함수로 묶은 것입니다.
  • \(\lambda \) — 라그랑주 승수. 제약식 \(h\) 에 곱해 주는 수이며, 이 값도 \(w_{1}, w_{2}\) 처럼 풀어서 찾아야 하는 미지수입니다.

우리 문제에서는 \(L = \tfrac12 (w_{1}^{2} + w_{2}^{2}) - \lambda (w_{1} + w_{2} - 1)\) 입니다.

왜 빼는가 — 부호는 약속입니다

\(J - \lambda h\) 로 쓰든 \(J + \lambda h\) 로 쓰든 \(\lambda \) 의 부호만 뒤집힐 뿐 답 \(w\) 는 같습니다. 이 교재는 빼는 쪽으로 통일합니다. 4장에서 SVM 의 제약 \(y(w\cdot x+b) - 1 \ge 0\) 을 같은 모양으로 쓰려고 미리 맞춘 것이고, 거기서는 \(\lambda \) 를 \(\alpha \) 라는 이름으로 부르게 됩니다.

2단계 — 편미분을 전부 0 으로 놓기

이제 라그랑지안 \(L\) 의 편미분이 전부 0 이라는 조건을 생각합니다. \(L\) 은 \(w_{1}, w_{2}, \lambda \) 세 변수의 함수이므로 편미분이 셋입니다. 화면 1 의 요령대로 미분하는 변수 말고는 전부 숫자로 봅니다.

편미분 = 0계산
\(\partial L/\partial w_{1} = 0\)\(w_{1} - \lambda \times 1 = 0\) → \(w_{1} = \lambda \)
\(\partial L/\partial w_{2} = 0\)\(w_{2} - \lambda \times 1 = 0\) → \(w_{2} = \lambda \)
\(\partial L/\partial \lambda = 0\)\(-(w_{1} + w_{2} - 1) = 0\) → \(w_{1} + w_{2} = 1\)

(\(w_{1}\) 로 미분할 때 \(\tfrac12 w_{2}^{2}\) 는 \(w_{1}\) 이 없는 항이라 0 이 되고, \(\lambda (w_{1}+w_{2}-1)\) 은 \(w_{1}\) 의 계수 \(\lambda \) 만 남습니다.) 위 두 줄을 묶으면 \((w_{1}, w_{2}) = \lambda (1, 1)\), 곧 \(\nabla J = \lambda \nabla h\) 로 화면 2 의 결론과 같습니다. 세 번째 줄은 \(\lambda \) 로 편미분하면 제약식 \(h = 0\) 이 그대로 나온다는 뜻으로, 제약을 지켜야 한다는 조건이 식 안에 자동으로 들어 있습니다.

3단계 — 연립방정식을 풀기

첫째·둘째 줄에서 \(w_{1} = w_{2} = \lambda \) 이므로 셋째 줄에 넣으면 \(\lambda + \lambda = 1\), 곧 \(\lambda = \tfrac12 \) 입니다. 따라서

\[w_{1} = w_{2} = \tfrac12 , \; \lambda = \tfrac12 , \; J = \tfrac12 (\tfrac14 + \tfrac14 ) = \tfrac14 \]

화면 2 의 표에서 찾은 값과 같습니다. 검산합니다. 제약 \(\tfrac12 + \tfrac12 = 1\) ✓, 기울기 \(\nabla J = (\tfrac12 , \tfrac12 ) = \tfrac12 \times (1, 1) = \lambda \nabla h\) ✓ 입니다.

라그랑주 승수법 — 손으로 푸는 순서

  1. \(L = J - \lambda h\) 를 쓴다.
  2. 모든 변수(\(w_{1}, w_{2}\) 와 \(\lambda \))로 편미분해 0 으로 놓는다.
  3. 얻은 연립방정식을 푼다.

\(\lambda \) 의 의미

\(\lambda \) 는 제약이 답을 밀어내는 힘의 세기입니다. 제약이 없을 때 최솟값이 되는 점의 조건은 \(\nabla J = 0\) 이었는데, 제약이 있으면 \(\nabla J = \lambda \nabla h\) 로 바뀝니다. \(J\) 는 \(-\nabla J\) 방향으로 내려가려 하고, 제약선이 이를 막으며 \(\lambda \nabla h\) 의 힘으로 반대쪽으로 밉니다. 두 힘이 같아지는 점이 답입니다. 우리 문제의 \(\lambda = \tfrac12 \) 은 \(\nabla J = (\tfrac12 , \tfrac12 )\) 가 \(\nabla h = (1, 1)\) 의 \(\tfrac12 \) 배라는 뜻입니다. \(\lambda = 0\) 이면 \(\nabla J = 0\), 곧 제약이 작용하지 않는 경우입니다(화면 4).

\(\lambda \) 의 또 다른 의미는 숫자로 확인할 수 있습니다. 제약선을 \(w_{1} + w_{2} = c\) 로 옮기고 같은 방법으로 풀면 \(w_{1} = w_{2} = \lambda \), \(2\lambda = c\) 이니 \(\lambda = c/2\), 최솟값은 \(J = \tfrac12 \times 2\times (c/2)^{2} = c^{2}/4\) 입니다. \(c = 1\) 에서 \(c\) 를 조금 올릴 때(직선이 원점에서 멀어집니다) 최솟값이 늘어나는 비율은 \(c^{2}/4\) 의 기울기 \(c/2 = \tfrac12 \) 로 \(\lambda \) 와 같습니다.

따라서 \(\lambda \) 는 제약을 한 단위 옮길 때 최솟값이 얼마나 변하는가, 곧 제약이 답에 미치는 영향의 크기이기도 합니다. \(\lambda \) 의 숫자는 \(h\) 를 쓰는 방식에 따라 달라지므로(\(h\) 를 \(2h\) 로 쓰면 \(\lambda \) 는 절반) 값 자체보다 이런 뜻으로 읽습니다.

한계 — 편미분 0 인 점이 늘 최솟값은 아닙니다

이 방법이 주는 것은 후보 점입니다. 목적함수가 그릇 모양이 아니면 후보가 최대나 말안장일 수 있습니다. 예를 들어 같은 제약 아래서 \(w_{1}w_{2}\) 를 작게 하려 하면 \(L = w_{1}w_{2} - \lambda (w_{1}+w_{2}-1)\) 의 편미분 0 에서 \(w_{2} = \lambda \), \(w_{1} = \lambda \), 곧 똑같이 \((\tfrac12 , \tfrac12 )\) 가 나옵니다. 그런데 직선 위 점 \((t, 1-t)\) 에서 \(w_{1}w_{2} = t(1-t)\) 는 \(t = \tfrac12 \) 에서 최대 ¼ 이고 \(t\) 를 크게 하면 한없이 작아져서 최솟값이 아예 없습니다. 그릇 모양 목적함수 \(\tfrac12 \lVert w\rVert ^{2}\) 와 직선 제약의 조합에서는 후보가 곧 답입니다(증명은 생략합니다). 이 교재는 이 사실을 전제로 합니다.

지금까지는 변수가 둘이고 제약이 하나인 문제를 풀었습니다. 변수가 더 많아도, 제약이 여러 개여도 방법은 같습니다. 제약이 \(m\) 개이면 제약마다 승수 \(\lambda _{i}\) 가 하나씩 생기고, 라그랑지안은 \(L = J - \lambda _{1}h_{1} - \cdots - \lambda _{m}h_{m}\) 입니다. 4장에서 쓰는 것은 이 결과뿐이므로, 왜 그렇게 되는지 궁금하지 않다면 아래 접는 상자는 건너뛰어도 됩니다.

더 깊이 — 일반적인 형태와, 이 방법이 통하는 이유

일반적인 형태. 방법 자체는 변수 개수와 상관없습니다. 제약식 \(h(w) = 0\) 이 있을 때 \(n\) 개 변수 \(w = (w_{1}, \dots , w_{n})\) 의 함수 \(J(w)\) 가 극소 또는 극대가 되는 점(극점)을 찾으려면, 라그랑지안 \(L(w, \lambda ) = J(w) - \lambda h(w)\) 를 만들고 모든 변수로 편미분한 값을 0 으로 놓습니다.

\[\nabla _{w}L = \nabla J - \lambda \nabla h = 0, \qquad \frac{\partial L}{\partial \lambda } = -h(w) = 0\]

\(\nabla _{w}L\) 은 \(L\) 을 \(w\) 의 성분으로만 편미분해 모은 기울기입니다. 풀어 쓰면 위 식은 \(\nabla J = \lambda \nabla h\) 이고 \(h(w) = 0\) 이라는 말로, 화면 2 의 결론과 같은 모양입니다. 미지수는 \(w\) 의 \(n\) 개 성분과 \(\lambda \) 를 합쳐 \(n + 1\) 개이고, 식도 \(n + 1\) 개입니다.

왜 통하는가 — 변수가 많아도 같은 논리. 화면 2 에서는 변수가 둘인 그림으로 “기울기가 평행하다”를 보았습니다. 변수가 \(n\) 개인 경우에도 제약 \(h(w) = 0\) 아래의 극점에서 \(\nabla J\) 와 \(\nabla h\) 가 평행하다는 것(\(\nabla h \ne 0\) 일 때)을 네 단계로 따라가 봅니다.

  1. 움직일 수 있는 곳. \(h(w) = 0\) 을 만족하는 점들은 \(n - 1\) 차원의 곡면입니다(\(n = 2\) 이면 곡선, \(n = 3\) 이면 곡면). 우리는 이 곡면 위에서만 움직일 수 있습니다.
  2. \(\nabla h\) 는 곡면에 수직입니다. 곡면 위의 이동 방향 \(dw\) 는 곡면의 접선 방향입니다. 곡면 위에서는 \(h\) 가 늘 0 이라 \(dh = \nabla h\cdot dw = 0\) 이므로, \(\nabla h\) 는 모든 접선 방향에 수직입니다.
  3. 극점에서는 \(\nabla J\) 도 곡면에 수직입니다. 접선 방향 \(dw\) 로 움직이면 \(J\) 는 \(dJ = \nabla J\cdot dw\) 만큼 변합니다. 이 값이 0 이 아니면 \(dw\) 와 \(-dw\) 중 한쪽은 \(J\) 를 줄이고 다른 쪽은 늘립니다(둘 다 곡면 위의 방향입니다). 그러면 극점이 아닙니다. 그러므로 극점에서는 모든 접선 방향에 대해 \(\nabla J\cdot dw = 0\), 곧 \(\nabla J\) 도 곡면에 수직입니다.
  4. 따라서 \(\nabla J\) 와 \(\nabla h\) 는 평행합니다. \(n\) 차원에서 \(n - 1\) 차원인 접선 방향들에 수직인 방향은 한 줄(1차원)뿐입니다. \(\nabla J\) 와 \(\nabla h\) 가 둘 다 이 한 줄 위에 있으므로 한쪽이 다른 쪽의 상수배, \(\nabla J = \lambda \nabla h\) 입니다. (\(\nabla h = 0\) 이면 한 줄이 정해지지 않아서 이 논리가 쓰이지 않습니다. 그래서 \(\nabla h \ne 0\) 을 조건으로 둡니다.)

이렇게 얻은 \(\nabla J = \lambda \nabla h\) 가 위에서 \(L\) 의 편미분을 0 으로 놓아 얻은 식과 같은 말입니다. 다만 이것은 극점의 후보를 찾는 조건이어서, 위 ‘한계’ 상자처럼 후보가 최댓값이나 말안장일 수도 있습니다.

제약이 여러 개일 때. 제약이 \(h_{1}(w) = 0, \; \dots , \; h_{m}(w) = 0\) 으로 \(m\) 개이면 같은 논리가 이어집니다. \(m < n\) 이고 \(\nabla h_{1}, \dots , \nabla h_{m}\) 이 서로 독립(예컨대 두 개라면 한쪽이 다른 쪽의 상수배가 아닌 경우)이라고 합니다.

  1. 모든 제약을 만족하는 점들은 \(n - m\) 차원의 곡면입니다.
  2. 곡면 위에서는 각 \(h_{i}\) 가 늘 0 이므로, 접선 방향 \(dw\) 는 \(\nabla h_{i}\cdot dw = 0\) 을 모든 \(i\) 에 대해 만족합니다. 곧 \(\nabla h_{1}, \dots , \nabla h_{m}\) 이 모두 접선 방향에 수직입니다.
  3. 극점에서는 앞과 같은 이유로 \(\nabla J\) 도 모든 접선 방향에 수직입니다.
  4. 접선 방향에 수직인 방향 전체는 \(m\) 차원입니다. \(n\) 차원 공간에서 접선 방향이 \(n - m\) 차원이므로, 거기에 수직인 방향은 나머지 \(m\) 차원입니다. 예를 들어 \(n = 3, m = 2\) 이면 두 평면이 만나는 직선이 접선 방향(1차원)이고, 이 직선에 수직인 방향 전체는 평면, 곧 2 차원입니다.
  5. \(\nabla h_{1}, \dots , \nabla h_{m}\) 은 모두 이 \(m\) 차원 안에 있고 서로 독립이므로, 이들만으로 그 안의 모든 방향을 만들 수 있습니다(예에서는 두 평면의 법선 \(\nabla h_{1}, \nabla h_{2}\) 가 그 평면의 모든 방향을 만듭니다). \(\nabla J\) 도 이 안에 있으므로 이들에 각각 수를 곱해 더한 합(일차결합)으로 쓸 수 있습니다.

\[\nabla J = \lambda _{1}\nabla h_{1} + \lambda _{2}\nabla h_{2} + \cdots + \lambda _{m}\nabla h_{m}\]

모든 변수(\(w\) 의 \(n\) 개 성분과 \(\lambda _{1}, \dots , \lambda _{m}\))로 편미분해 0 으로 놓으면 식 \(n + m\) 개로 미지수 \(n + m\) 개를 풀게 됩니다.

4장에서 SVM 은 점마다 제약이 하나씩이라 승수 \(\alpha \) 가 점마다 하나씩 생깁니다.

지금까지는 제약이 등식(\(=\))이었습니다. 하지만 2장의 제약은 \(y(w\cdot x+b) \ge 1\) 이라는 부등식입니다. 부등식에서는 무엇이 달라질까요?

3장 · 화면 4

부등식 제약 — 제약이 작용하는가, 작용하지 않는가

제약을 부등식으로 바꿉니다. 이 교재는 부등식을 항상 “식 ≥ 0” 꼴로 씁니다. 2장의 \(y(w\cdot x+b) \ge 1\) 도 1 을 좌변으로 옮겨 \(y(w\cdot x+b) - 1 \ge 0\) 으로 쓰면 이 꼴입니다. 그 왼쪽 식을 \(g\) 라 두고 라그랑지안은 같은 방식으로 \(L = J - \lambda g\) 로 씁니다.

예 A — 제약이 경계에서 작용한다

문제 A

\[\min \; \tfrac12 (w_{1}^{2} + w_{2}^{2}) \; \; \text{s.t.} \; g(w) = w_{1} + w_{2} - 1 \ge 0\]

가능해는 직선 \(w_{1} + w_{2} = 1\) 과 그 오른쪽 위 영역 전체입니다. 원점은 \(g = -1\) 이라 가능해 밖입니다.

이제 답이 경계(직선) 위에 있을지 영역 안쪽에 있을지 모릅니다. 두 경우를 나누어 각각 가정하고, 모순이 없는 쪽을 고릅니다.

가정그 가정에서 풀면결과
제약이 작용하지 않는다 (\(\lambda = 0\))\(L = J\) 가 되어 제약 없는 문제와 같음 → \(\nabla J = w = 0\), \(w = (0, 0)\)\(g = 0 + 0 - 1 = -1 < 0\), 가능해가 아님 → 탈락
제약이 경계에서 작용한다 (\(g = 0\))화면 3 과 같음 → \(w = (\tfrac12 , \tfrac12 )\), \(\lambda = \tfrac12 \)\(\lambda = \tfrac12 \ge 0\) ✓ → 통과

답은 화면 3 과 같은 \(w = (\tfrac12 , \tfrac12 )\), \(J = \tfrac14 \) 이고, 제약이 \(g = 0\) 으로 정확히 닿아 있습니다.

예 B — 제약이 있어도 무관하다

같은 목적함수에서 제약만 한 칸 옮깁니다.

문제 B

\[\min \; \tfrac12 (w_{1}^{2} + w_{2}^{2}) \; \; \text{s.t.} \; g(w) = w_{1} + w_{2} + 1 \ge 0\]

이번에는 원점이 \(g = 0 + 0 + 1 = 1 > 0\) 이라 가능해 안쪽에 들어 있습니다.

가정그 가정에서 풀면결과
제약이 작용하지 않는다 (\(\lambda = 0\))\(w = (0, 0)\)\(g = 1 \ge 0\) 가능해 ✓ → 통과
제약이 경계에서 작용한다 (\(g = 0\))\(w_{1} + w_{2} = -1\), 그리고 \(w_{1} = w_{2} = \lambda \) → \(\lambda = -\tfrac12 \), \(w = (-\tfrac12 , -\tfrac12 )\)\(\lambda = -\tfrac12 < 0\) → 탈락 (이유는 아래)

답은 제약이 없던 때와 같은 \(w = (0, 0)\) 이고 \(\lambda = 0\) 입니다. 제약이 답에 영향을 주지 않는 문제입니다. 경계 위의 \((-\tfrac12 , -\tfrac12 )\) 는 가능해이긴 해도 \(J = \tfrac14 \) 로 원점의 \(J = 0\) 보다 큽니다.

정의 — 활성과 비활성

최적해에서 \(g = 0\) 으로 경계에 닿아 있는 제약을 활성 제약, \(g > 0\) 으로 여유가 있는 제약을 비활성 제약이라 합니다. 예 A 의 제약은 활성이고 \(\lambda = \tfrac12 > 0\), 예 B 의 제약은 비활성이고 \(\lambda = 0\) 입니다. 둘 중 하나는 반드시 0 입니다. 제약의 여유 \(g\) 가 0 이거나, \(\lambda \) 가 0 입니다.

왜 부등식에서는 λ ≥ 0 이어야 하나

예 B 에서 탈락한 이유를 짚어 봅시다. 비탈에 놓인 공을 떠올립니다. 공은 \(J\) 가 줄어드는 방향(\(-\nabla J\))으로 굴러가려 하고, 벽(제약의 경계)이 그것을 막습니다. 벽은 공을 가능해 영역 쪽으로 밀 수는 있어도, 영역 바깥으로 잡아당길 수는 없습니다. 경계에 멈춘 공은 \(-\nabla J\) 방향, 곧 영역 바깥으로 굴러가려 합니다. 영역 바깥은 \(-\nabla g\) 방향이므로 \(-\nabla J\) 와 \(-\nabla g\) 는 같은 쪽을 향합니다. 그러므로 \(\nabla J = \lambda \nabla g\) 에서 \(\lambda \ge 0\) 이어야 합니다. 예 A 는 \(\nabla J = (\tfrac12 , \tfrac12 ) = \tfrac12 (1, 1)\) 로 맞고, 예 B 의 경계 점 \((-\tfrac12 , -\tfrac12 )\) 는 \(\nabla J = (-\tfrac12 , -\tfrac12 ) = -\tfrac12 (1, 1)\) 로 부호가 거꾸로입니다. 그 점에서 \(J\) 가 줄어드는 방향은 오히려 가능해 안쪽(원점 쪽)이라 벽이 막고 있는 것이 아닙니다. 등식 제약에서는 이런 제한이 없어서 \(\lambda \) 가 음수여도 됩니다(경계 양쪽 어디로도 못 나가기 때문입니다).

변수 하나로 줄여 보기

예 A·B 를 변수 하나로 줄여 같은 풀이를 반복해 봅시다. \(\min \tfrac12 w^{2} \text{s.t.} g(w) = w - 1 \ge 0\) 에서는 \(L = \tfrac12 w^{2} - \lambda (w - 1)\) 이므로 \(\partial L/\partial w = w - \lambda = 0\), 곧 \(w = \lambda \) 입니다. 비활성(\(\lambda = 0\))이면 \(w = 0\) 이 \(g = -1 < 0\) 으로 탈락하고, 활성(\(g = 0\))이면 \(w = 1\), \(\lambda = 1 \ge 0\) 으로 통과해 답은 \(w = 1\) 입니다. 제약이 \(w \ge -1\) 이면 비활성 \(w = 0\) 이 통과하고 (\(g = 1 \ge 0\)), 활성은 \(\lambda = -1 < 0\) 으로 탈락해 제약이 답과 무관합니다.

SVM 의 제약은 점마다 하나씩, 여러 개입니다. 그중 어떤 것은 활성이고 어떤 것은 비활성일 텐데, 어느 쪽인지를 어떻게 알아낼까요? 다음 화면에서 이 모든 것을 한 묶음의 조건으로 정리합니다.

KKT 조건 네 줄 읽기

화면 3~4 에서 한 일을 일반적인 모양으로 정리합니다. 목적함수 \(J(w)\) 와 부등식 제약 \(g_{1}(w) \ge 0, \ldots , g_{m}(w) \ge 0\) 이 있고, 제약마다 승수 \(\lambda _{1}, \ldots , \lambda _{m}\) 를 하나씩 둡니다. 라그랑지안은 이렇습니다.

\[L(w, \lambda ) = J(w) - \lambda _{1}g_{1}(w) - \ldots - \lambda _{m}g_{m}(w)\]

최솟값을 주는 점 \(w\) 와 그때의 승수 \(\lambda \) 는 다음 네 줄을 만족해야 합니다. 이것이 KKT 조건(Karush–Kuhn–Tucker 조건)입니다. 각 줄 옆에 화면 4 의 예 A(\(w = (\tfrac12 , \tfrac12 )\), \(\lambda = \tfrac12 \))로 확인한 결과를 적었습니다.

제약이 둘일 때 — 어느 것이 활성인지 따져 보기

④가 하는 일은 “어느 제약이 활성인가”를 경우의 수로 바꿔 주는 것입니다. 제약이 둘인 작은 문제로 확인합니다.

\[\min \; \tfrac12 (w_{1}^{2} + w_{2}^{2}) \; \; \text{s.t.} \; g_{1} = w_{1} - 1 \ge 0, \; g_{2} = w_{2} + 1 \ge 0\]

\(L = \tfrac12 (w_{1}^{2}+w_{2}^{2}) - \lambda _{1}(w_{1}-1) - \lambda _{2}(w_{2}+1)\) 이므로 ①은 \(w_{1} = \lambda _{1}\), \(w_{2} = \lambda _{2}\) 입니다. 각 제약이 활성(\(g = 0\))이거나 비활성(\(\lambda = 0\))인 경우가 2 × 2 = 4 가지입니다.

한계 — KKT 가 답을 보장하는 조건

일반적인 문제에서 KKT 는 “답이라면 반드시 만족하는” 필요조건이고(제약에 약간의 조건이 필요합니다), 만족하는 점이 곧 최솟값인지는 보장하지 않습니다(화면 3 의 \(w_{1}w_{2}\) 처럼). 다만 이 교재의 문제처럼 목적함수가 그릇 모양이고 제약이 직선(평면)이면, KKT 를 만족하는 점이 곧 최솟값입니다(증명은 생략합니다). 그래서 4장에서 KKT 로 푸는 일이 정당합니다.

핵심 요약

  1. 편미분 \(\partial J/\partial w_{1}\) 은 다른 변수들을 고정시켜 두고 한 변수만 움직일 때의 기울기이고, 모으면 기울기 벡터 \(\nabla J\) 입니다. 제약이 없으면 그릇 모양 함수의 바닥은 \(\nabla J = 0\) 입니다.

모범답안과 흔한 실수

1. \(\partial L/\partial w_{1} = w_{1} - \lambda = 0\), \(\partial L/\partial w_{2} = w_{2} - 2\lambda = 0\), \(\partial L/\partial \lambda = -(w_{1} + 2w_{2} - 5) = 0\). 앞의 둘에서 \(w_{1} = \lambda \), \(w_{2} = 2\lambda \) 이고 셋째에 넣으면 \(\lambda + 4\lambda = 5\), \(\lambda = 1\) 입니다. 따라서 \(w = (1, 2)\), \(J = \tfrac12 (1 + 4) = 2.5\) 입니다. 검산: \(1 + 2\times 2 = 5\) ✓, \(\nabla J = (1, 2) = 1(1, 2) = \lambda \nabla h\) ✓.

2. 비활성(\(\lambda = 0\))이라 가정하면 \(w = (0, 0)\) 인데 \(g = -5 < 0\) 이라 탈락합니다. 활성(\(g = 0\))이라 가정하면 1번과 같은 \(w = (1, 2)\), \(\lambda = 1 \ge 0\) 으로 통과하므로 답이 같습니다.

3. 비활성이라 가정하면 \(w = (0, 0)\), \(g = 5 \ge 0\) 으로 통과하고 \(J = 0\) 입니다. 활성이라 가정하면 \(w_{1} = \lambda \), \(w_{2} = 2\lambda \), \(5\lambda = -5\) 에서 \(\lambda = -1 < 0\) 이라 탈락합니다. 답은 \(w = (0, 0)\) 이고 이 제약은 비활성(\(\lambda = 0\))입니다.

4. \(w = (1, 2)\), \(\lambda = 1\): ① \(\nabla J = (1, 2) = 1\nabla g = 1(1, 2)\) ✓, ② \(g = 1 + 4 - 5 = 0 \ge 0\) ✓, ③ \(\lambda = 1 \ge 0\) ✓, ④ \(\lambda g = 1\times 0 = 0\) ✓.
