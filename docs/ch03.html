3장 · 화면 1

제약 있는 최적화 기초 (라그랑주·KKT)

2장은 문제 하나를 남기고 끝났습니다. ½‖w‖² 를 가장 작게 만들라면 w = (0, 0) 이 답이지만, 그 w 로는 제약을 만족할 수 없었습니다(2장 화면 4). 제약이 있는 최적화는 “기울기가 0 인 곳 찾기”로는 풀리지 않습니다. 이 장은 그 문제를 푸는 도구, 라그랑주 승수법과 KKT 조건을 만드는 장입니다. 도구의 첫 부품은 편미분이라, 이 화면에서 가볍게 복습합니다.

이 장의 진행

  1. 편미분과 기울기를 복습하고, 제약이 없을 때의 풀이를 확인한다 (이 화면).
  2. 등식 제약이 붙으면 답이 어디로 가는지, 등고선과 제약선이 ‘접하는 점’으로 본다 (화면 2).
  3. 그 접점을 식으로 찾는 라그랑주 승수법을 손으로 끝까지 푼다 (화면 3).
  4. 부등식 제약에서는 제약이 ‘활성’인지 ‘비활성’인지가 갈린다 (화면 4).
  5. 그 모든 것을 KKT 조건 네 줄로 정리한다 (화면 5).

이 장의 기호 두 가지

이 장에서 움직이는 변수는 w₁, w₂ 입니다. 2장의 문제와 모양을 같게 하려고 w 라 불렀을 뿐, 데이터 점 x(i) 와는 아직 아무 상관이 없습니다. 또 이 장에서 줄이고 싶은 값(목적함수)은 J 라 쓰겠습니다. 1·2장의 f(x) = w·x+b 와는 이름만 겹치지 않게 다른 글자를 고른 것입니다.

제약이 없을 때 — 기울기가 0 인 곳

변수가 하나인 J(w) = ½w² 부터 봅니다. 2장 화면 4 에서 보았듯 w 를 조금 늘렸을 때 값이 늘어나는 비율, 곧 기울기는 w 입니다(예: w = 2 에서 기울기 2). w 가 양수이면 오르막이라 줄이려면 왼쪽으로, 음수이면 내리막이라 오른쪽으로 가야 하고, w = 0 에서 기울기가 0 이 되어 바닥에 닿습니다. 그릇 모양 함수의 바닥은 기울기가 0 인 곳입니다.

변수가 둘이면 — 편미분

변수가 둘이면 “기울기”가 한 개가 아닙니다. 산비탈에 서 있다고 합시다. 동쪽으로 한 걸음 갈 때의 가파름과 북쪽으로 한 걸음 갈 때의 가파름은 다릅니다. 그래서 한 변수만 움직이고 나머지는 얼려 둔 채 기울기를 잽니다. 이것이 편미분입니다.

2장의 ½‖w‖² 를 좌표로 풀어 쓰면 ‖w‖² = w₁² + w₂² 이므로,

J(w₁, w₂) = ½(w₁² + w₂²)

점 (w₁, w₂) = (3, 1) 에서 시작해 봅시다. w₂ 를 1 로 얼리면 남는 것은 J = ½w₁² + ½ 입니다 (얼린 w₂ 부분 ½·1² = ½ 은 그냥 숫자입니다). 이 함수를 w₁ 로 보았을 때의 기울기는 w₁ = 3 입니다. w₁ 을 0.01 늘려 확인하면 J(3, 1) = 5 가 J(3.01, 1) = 5.03005 로 변해 늘어난 양 0.03005 를 0.01 로 나누면 약 3.005 입니다. 3 에 가깝습니다. 이 값을 w₁ 에 대한 편미분이라 부릅니다.

정의 — 편미분과 기호 ∂

∂J/∂w₁ 은 편미분이라 읽고(“라운드 J 라운드 w₁”), w₂ 를 상수로 얼린 채 w₁ 만 조금 움직일 때 J 가 변하는 비율을 뜻합니다. 변수가 하나일 때 쓰는 d 와 구분하려고 둥글린 ∂ 를 씁니다.

  • ∂J/∂w₁ — w₂ 를 숫자 취급하고 w₁ 으로 미분. ½(w₁²+w₂²) 에서는 w₁.
  • ∂J/∂w₂ — w₁ 을 숫자 취급하고 w₂ 로 미분. ½(w₁²+w₂²) 에서는 w₂.
점 (w₁, w₂)∂J/∂w₁ = w₁∂J/∂w₂ = w₂손으로 확인 (0.01 늘려 보기)

편미분 요령 세 가지

  1. 미분하는 변수 말고는 전부 숫자로 봅니다.
  2. 미분하는 변수가 들어 있지 않은 항은 상수이므로 미분하면 0 입니다.
  3. 변수에 상수가 곱해진 항 c₁w₁ + c₂w₂ 는 w₁ 로 미분하면 c₁, w₂ 로 미분하면 c₂ 입니다. 예를 들어 w₁ + w₂ 의 편미분은 둘 다 1 이고, 5w₁ + 2w₂ 는 w₁ 에 대해 5, w₂ 에 대해 2 입니다. (w·x = w₁x₁ + w₂x₂ 도 같은 모양입니다. 4장에서 쓴다)

편미분을 모으면 — 기울기 벡터

두 편미분을 한 벡터로 묶은 것이 기울기 벡터 ∇J (“나블라 J”)입니다.

∇J = ( ∂J/∂w₁ , ∂J/∂w₂ )

우리 함수에서는 ∇J = (w₁, w₂) = w 입니다. 2장에서 ½ 를 붙인 이유가 여기서 보입니다. 제곱에서 나오는 2 를 ½ 가 지워서, ½‖w‖² 의 기울기가 깔끔하게 w 자신이 됩니다. 점 (3, 1) 에서는 ∇J = (3, 1) 입니다.

이 벡터의 뜻은 이렇습니다. 점에서 작은 걸음 δ = (δ₁, δ₂) 만큼 움직이면 J 는 대략 ∇J·δ = 3δ₁ + 1δ₂ 만큼 변합니다(1장의 내적입니다). 확인해 봅시다. δ = (0.01, 0.01) 이면 예측은 3·0.01 + 1·0.01 = 0.04 이고, 실제로는 J(3.01, 1.01) − J(3, 1) = 5.0401 − 5 = 0.0401 입니다. 같은 길이만큼 걸을 때 내적은 δ 가 ∇J 와 같은 방향일 때 가장 크므로, ∇J 는 값이 가장 빨리 오르는 방향이고 그 반대가 가장 빨리 내리는 방향입니다.

제약이 없다면 — ∇J = 0

바닥에서는 어느 방향으로 가도 값이 줄지 않으므로 ∇J = 0 입니다. 우리 함수에서는 (w₁, w₂) = (0, 0) 이고, 2장 화면 4 의 “제약 없는 최솟값”이 이것입니다.

한계 — 기울기 0 이 늘 바닥은 아닙니다

∇J = 0 인 점은 바닥일 수도, 언덕 꼭대기일 수도(J = −w₁²−w₂²), 한쪽으로는 내리막이고 다른 쪽으로는 오르막인 말안장일 수도 있습니다(J = w₁² − w₂²). 그릇 모양 함수여야 “기울기 0 이면 바닥”이 보장됩니다. 이 교재의 ½‖w‖² 는 그릇 모양입니다.

이제 2장에서 남긴 질문으로 돌아갑니다. 2장의 문제에서는 ∇J = 0 인 점이 제약을 어깁니다. 그렇다면 어디가 답일까요? 다음 화면에서 가장 단순한 제약인 등식 하나를 붙여 그림으로 봅니다.

3장 · 화면 2

등식 제약이 붙으면 — 접하는 점

가장 단순한 제약부터 시작합니다. 2장 화면 5 에서 제약 1 과 3 을 더해 얻은 w₁ + w₂ ≥ 1 을 기억하시나요? 그 경계인 등식 w₁ + w₂ = 1 을 지키면서 J = ½(w₁² + w₂²) 를 가장 작게 만드는 문제를 풉니다.

이 화면의 문제

minw₁,w₂   ½(w₁² + w₂²)    s.t.   w₁ + w₂ = 1

이제 가능해는 평면 전체가 아니라 직선 w₁ + w₂ = 1 위의 점들뿐입니다. 원점 (0, 0) 은 이 직선 위에 없습니다.

직선 위를 걸어 보기

직선 위의 점은 (w₁, w₂) = (t, 1−t) 로 쓸 수 있습니다(t 는 직선 위의 위치를 정하는 수입니다). 이 점에서 J = ½(t² + (1−t)²) = t² − t + ½ 입니다. 몇 점을 직접 계산해 보면 이렇습니다.

t = ½, 곧 (½, ½) 에서 가장 작고 값은 ¼ 입니다. 2장 화면 5 에서 요령으로 보인 바로 그 답입니다. 이번에는 이 답이 왜 거기인지를 그림으로 이해해 봅시다.

등고선 — 같은 높이의 점들

지도의 등고선처럼, J 의 값이 같은 점들을 이은 곡선을 등고선이라 합니다. J = ½(w₁²+w₂²) 에서 J = 0.5 인 점은 w₁²+w₂² = 1, 곧 원점을 중심으로 한 반지름 1 인 원입니다. J = ¼ 이면 반지름 √½ ≈ 0.71 인 원입니다. 값이 클수록 큰 원이고, 원점이 바닥입니다.

그러면 문제는 이렇게 바뀝니다. 직선 위의 점 중에서, 가장 작은 원 위에 있는 점을 찾아라.

  • 원이 직선을 가로지르면 직선을 따라 한쪽으로 가는 동안 더 안쪽 원(더 작은 J)으로 들어갈 수 있으니 아직 최소가 아닙니다.
  • 원이 직선에 딱 접하면 직선 위 어느 쪽으로 가도 더 바깥 원으로 나가기만 합니다. 여기가 최소입니다.

접한다는 것을 식으로 — 기울기가 평행하다

그림에서 본 “두 화살표가 같은 방향”이 접점을 식으로 쓰는 열쇠입니다. 이유는 두 가지 사실입니다.

  1. 등고선 위에서는 J 가 변하지 않습니다. 등고선을 따라 작은 걸음 δ 를 가면 J 의 변화 ∇J·δ 가 0 이므로, 내적이 0 이라는 것은 ∇J 가 등고선에 수직이라는 뜻입니다(1장의 내적과 수직). 위젯의 원에서도 화살표 ∇J 는 원의 반지름 방향, 곧 원에 수직입니다.
  2. 제약선 h = 0 에도 같은 말이 통합니다. h(w) = w₁ + w₂ − 1 이라 두면 ∇h = (1, 1) 이고, 이것은 1장에서 본 직선의 법선 벡터 w 자리와 같아서 직선에 수직입니다.

두 곡선이 접하면 접선 방향이 같으므로, 그 수직 방향도 같습니다. 따라서 접점에서는 ∇J 와 ∇h 가 같은 직선 위에 놓입니다. 평행하다는 것은 한쪽이 다른 쪽의 몇 배라는 말이고, 위젯의 접점에서는 ∇J = (½, ½) = ½ × (1, 1) = ½ × ∇h 입니다. 이 “몇 배”에 다음 화면에서 이름을 붙입니다.

이 화면의 결론

등식 제약 h(w) = 0 아래에서 J 가 최소인 점에서는 ∇J = (어떤 수) × ∇h 이고 h(w) = 0 입니다. 미지수 w₁, w₂ 와 그 “어떤 수”, 합쳐 셋을 식 셋으로 풀 수 있다는 뜻입니다.

3장 · 화면 3

라그랑주 승수법 — 접점을 식으로 찾기

화면 2 의 결론을 식 셋으로 쓰고 손으로 끝까지 풉니다. 같은 문제입니다.

min   J(w₁, w₂) = ½(w₁² + w₂²)    s.t.   h(w₁, w₂) = w₁ + w₂ − 1 = 0

1단계 — 라그랑지안을 만든다

식 셋을 따로 쓰는 대신, 하나의 함수로 묶어 “편미분이 전부 0”으로 말하는 요령이 있습니다. 제약식 h 에 새 변수 λ(람다)를 곱해 목적함수에서 빼서 만든 함수입니다.

정의 — 라그랑지안과 라그랑주 승수

L(w₁, w₂, λ) = J(w₁, w₂) − λ · h(w₁, w₂)

  • L — 라그랑지안. 목적함수와 제약을 한 함수로 묶은 것입니다.
  • λ — 라그랑주 승수. 제약식 h 에 곱해 주는 수이며, 이 값도 w₁, w₂ 처럼 풀어서 찾아야 하는 미지수입니다.

우리 문제에서는 L = ½(w₁² + w₂²) − λ(w₁ + w₂ − 1) 입니다.

왜 빼는가 — 부호는 약속입니다

J − λh 로 쓰든 J + λh 로 쓰든 λ 의 부호만 뒤집힐 뿐 답 w 는 같습니다. 이 교재는 빼는 쪽으로 통일합니다. 4장에서 SVM 의 제약 y(w·x+b) − 1 ≥ 0 을 같은 모양으로 쓰려고 미리 맞춘 것이고, 거기서는 λ 를 α 라는 이름으로 부르게 됩니다.

2단계 — 편미분을 전부 0 으로

L 은 w₁, w₂, λ 세 변수의 함수이므로 편미분이 셋입니다. 화면 1 의 요령대로 미분하는 변수 말고는 전부 숫자로 봅니다.

편미분 = 0계산뜻
∂L/∂w₁ = 0w₁ − λ·1 = 0 → w₁ = λ∇J 의 첫째 성분 = λ × (∇h 의 첫째 성분)
∂L/∂w₂ = 0w₂ − λ·1 = 0 → w₂ = λ∇J 의 둘째 성분 = λ × (∇h 의 둘째 성분)
∂L/∂λ = 0−(w₁ + w₂ − 1) = 0 → w₁ + w₂ = 1제약 h = 0 이 그대로 되살아남

(w₁ 로 미분할 때 ½w₂² 는 w₁ 이 없는 항이라 0 이 되고, λ(w₁+w₂−1) 은 w₁ 의 계수 λ 만 남습니다.) 위 두 줄을 묶으면 (w₁, w₂) = λ(1, 1), 곧 ∇J = λ∇h 로 화면 2 의 결론과 정확히 같습니다. 세 번째 줄은 λ 로 편미분하면 제약식이 되살아난다는 것으로, 제약을 지켜야 한다는 조건이 식 안에 자동으로 들어 있습니다.

3단계 — 연립해서 푼다

첫째·둘째 줄에서 w₁ = w₂ = λ 이므로 셋째 줄에 넣으면 λ + λ = 1, 곧 λ = ½ 입니다. 따라서

w₁ = w₂ = ½,   λ = ½,   J = ½(¼ + ¼) = ¼

화면 2 의 표에서 찾은 값과 같습니다. 검산합니다. 제약 ½ + ½ = 1 ✓, 기울기 ∇J = (½, ½) = ½ × (1, 1) = λ∇h ✓ 입니다. 2장의 마지막에서 말했던 “작게 하고 싶은 욕심”(∇J)과 “제약이 미는 힘”(λ∇h)이 팽팽히 맞서는 곳이 바로 이 점입니다.

라그랑주 승수법 — 손으로 푸는 순서

  1. L = J − λh 를 쓴다.
  2. 모든 변수(w₁, w₂ 와 λ)로 편미분해 0 으로 놓는다.
  3. 얻은 연립방정식을 푼다.

λ 는 무엇인가

λ = ½ 은 계산 도중의 부산물처럼 보이지만 뜻이 있습니다. 제약을 w₁ + w₂ = c 로 바꾸고 같은 방법으로 풀면 w₁ = w₂ = λ, 2λ = c 이니 λ = c/2, 최솟값은 J = ½·2·(c/2)² = c²/4 입니다. c = 1 에서 c 를 조금 올렸을 때 최솟값이 늘어나는 비율은 c²/4 의 기울기 c/2 = ½ 로 λ 와 같습니다. λ 는 “제약을 한 단위 조일 때 목적함수가 얼마나 손해를 보는가”, 곧 제약이 얼마나 세게 답을 밀고 있는가의 크기입니다.

한계 — 편미분 0 인 점이 늘 최솟값은 아닙니다

이 방법이 주는 것은 후보 점입니다. 목적함수가 그릇 모양이 아니면 후보가 최대나 말안장일 수 있습니다. 예를 들어 같은 제약 아래서 w₁w₂ 를 작게 하려 하면 L = w₁w₂ − λ(w₁+w₂−1) 의 편미분 0 에서 w₂ = λ, w₁ = λ, 곧 똑같이 (½, ½) 가 나옵니다. 그런데 직선 위 점 (t, 1−t) 에서 w₁w₂ = t(1−t) 는 t = ½ 에서 최대 ¼ 이고 t 를 크게 하면 한없이 작아져서 최솟값이 아예 없습니다. 그릇 모양 목적함수 ½‖w‖² 와 직선 제약의 조합에서는 후보가 곧 답이라는 것(증명은 생략)이 이 교재가 기대는 사실입니다.

지금까지는 제약이 등식(=)이었습니다. 하지만 2장의 제약은 y(w·x+b) ≥ 1 이라는 부등식입니다. 부등식에서는 무엇이 달라질까요?

3장 · 화면 4

부등식 제약 — 제약이 힘을 쓰는가, 안 쓰는가

제약을 부등식으로 바꿉니다. 이 교재는 부등식을 항상 “식 ≥ 0” 꼴로 씁니다. 2장의 y(w·x+b) ≥ 1 도 1 을 넘겨 y(w·x+b) − 1 ≥ 0 으로 쓰면 이 꼴입니다. 그 왼쪽 식을 g 라 두고 라그랑지안은 같은 방식으로 L = J − λ·g 로 씁니다.

예 A — 제약이 경계에서 힘을 쓴다

문제 A

min   ½(w₁² + w₂²)    s.t.   g(w) = w₁ + w₂ − 1 ≥ 0

가능해는 직선 w₁ + w₂ = 1 과 그 오른쪽 위 영역 전체입니다. 원점은 g = −1 이라 가능해 밖입니다.

이제 답이 경계(직선) 위에 있을지 영역 안쪽에 있을지 모릅니다. 두 경우를 나누어 각각 가정하고, 모순이 없는 쪽을 고릅니다.

가정그 가정에서 풀면결과
제약이 힘을 안 쓴다 (λ = 0)L = J 가 되어 제약 없는 문제와 같음 → ∇J = w = 0, w = (0, 0)g = 0 + 0 − 1 = −1 < 0, 가능해가 아님 → 탈락
제약이 경계에서 힘을 쓴다 (g = 0)화면 3 과 같음 → w = (½, ½), λ = ½λ = ½ ≥ 0 ✓ → 통과

답은 화면 3 과 같은 w = (½, ½), J = ¼ 이고, 제약이 g = 0 으로 딱 닿아 있습니다.

예 B — 제약이 있어도 무관하다

같은 목적함수에서 제약만 한 칸 옮깁니다.

문제 B

min   ½(w₁² + w₂²)    s.t.   g(w) = w₁ + w₂ + 1 ≥ 0

이번에는 원점이 g = 0 + 0 + 1 = 1 > 0 이라 가능해 안쪽에 들어 있습니다.

가정그 가정에서 풀면결과
제약이 힘을 안 쓴다 (λ = 0)w = (0, 0)g = 1 ≥ 0 가능해 ✓ → 통과
제약이 경계에서 힘을 쓴다 (g = 0)w₁ + w₂ = −1, 그리고 w₁ = w₂ = λ → λ = −½, w = (−½, −½)λ = −½ < 0 → 탈락 (이유는 아래)

답은 제약이 없던 때와 같은 w = (0, 0) 이고 λ = 0 입니다. 제약이 있으나 마나 한 문제입니다. 경계 위의 (−½, −½) 는 가능해이긴 해도 J = ¼ 로 원점의 J = 0 보다 큽니다.

정의 — 활성과 비활성

최적해에서 g = 0 으로 경계에 닿아 있는 제약을 활성 제약, g > 0 으로 여유가 있는 제약을 비활성 제약이라 합니다. 예 A 의 제약은 활성이고 λ = ½ > 0, 예 B 의 제약은 비활성이고 λ = 0 입니다. 둘 중 하나는 반드시 0 입니다. 제약의 여유 g 가 0 이거나, λ 가 0 입니다.

왜 부등식에서는 λ ≥ 0 이어야 하나

예 B 에서 탈락한 이유를 짚어 봅시다. 비탈에 놓인 공을 떠올립니다. 공은 J 가 줄어드는 방향(−∇J)으로 굴러가려 하고, 벽(제약의 경계)이 그것을 막습니다. 벽은 가능해 영역 쪽으로 밀 수는 있어도, 영역 바깥으로 잡아당길 수는 없습니다. 경계에 닿아 멈춘 공에서는 굴러가려는 방향 −∇J 가 금지 구역을 향하고, 금지 구역 쪽은 −∇g 방향이므로 ∇J = λ∇g 에서 λ ≥ 0 이어야 합니다. 예 A 는 ∇J = (½, ½) = ½(1, 1) 로 맞고, 예 B 의 경계 점 (−½, −½) 는 ∇J = (−½, −½) = −½ (1, 1) 로 부호가 거꾸로입니다. 그 점에서 J 가 줄어드는 방향은 오히려 가능해 안쪽(원점 쪽)이라 벽이 막고 있는 것이 아닙니다. 등식 제약에서는 이런 제한이 없어서 λ 가 음수여도 됩니다(경계 양쪽 어디로도 못 나가기 때문입니다).

2장의 모양으로 — 변수 하나

2장의 min ½‖w‖² 구조를 변수 하나로 줄여 같은 일을 해 봅시다. min ½w² s.t. g(w) = w − 1 ≥ 0, 곧 w ≥ 1 입니다. L = ½w² − λ(w − 1) 이고 ∂L/∂w = w − λ = 0 이므로 w = λ 입니다.

제약가정풀면결과
w ≥ 1
(g = w − 1)		λ = 0 (비활성)w = λ = 0g = −1 < 0 → 탈락
g = 0 (활성)w = 1, λ = w = 1λ = 1 ≥ 0 ✓ → 답 w = 1, J = ½
w ≥ −1
(g = w + 1)		λ = 0 (비활성)w = 0g = 1 ≥ 0 ✓ → 답 w = 0, J = 0
g = 0 (활성)w = −1, λ = w = −1λ < 0 → 탈락

w ≥ 1 에서는 가장 작은 w 가 1 이니 당연한 답이고, 이것이 “제약이 w 를 0 에서 밀어내는 힘 λ = 1”과 “작게 하고 싶은 욕심 ∇J = w = 1”이 맞서는 점입니다. w ≥ −1 에서는 제약이 아예 상관이 없습니다. SVM 의 제약은 점마다 하나씩, 여러 개입니다. 그중 어떤 것은 활성이고 어떤 것은 비활성일 텐데, 어느 쪽인지를 어떻게 알아낼까요? 다음 화면에서 이 모든 것을 한 묶음의 조건으로 정리합니다.

3장 · 화면 5

KKT 조건 네 줄 읽기

화면 3~4 에서 한 일을 일반적인 모양으로 정리합니다. 목적함수 J(w) 와 부등식 제약 g₁(w) ≥ 0, …, gm(w) ≥ 0 이 있고, 제약마다 승수 λ₁, …, λm 를 하나씩 둡니다. 라그랑지안은 이렇습니다.

L(w, λ) = J(w) − λ₁g₁(w) − … − λmgm(w)

최솟값을 주는 점 w 와 그때의 승수 λ 는 다음 네 줄을 만족해야 합니다. 이것이 KKT 조건(Karush–Kuhn–Tucker 조건)입니다. 각 줄 옆에 화면 4 의 예 A(w = (½, ½), λ = ½)로 확인한 결과를 적었습니다.

KKT 조건 네 줄

이름식읽는 법예 A 로 확인
① 정상성∇wL = 0, 곧 ∇J = λ₁∇g₁ + … + λm∇gmw 로 편미분한 것이 0 (λ 는 숫자로 봄). 욕심 ∇J 와 제약이 미는 힘이 맞섬(½, ½) = ½·(1, 1) ✓
② 원문제 가능성gi(w) ≥ 0답은 모든 제약을 지켜야 한다g = ½+½−1 = 0 ≥ 0 ✓
③ 쌍대 가능성λi ≥ 0승수는 음수가 될 수 없다 (벽은 당길 수 없다)½ ≥ 0 ✓
④ 상보 여유성λi · gi(w) = 0각 제약마다 λ 와 g 둘 중 하나는 반드시 0½ · 0 = 0 ✓

줄 읽는 요령. ①은 “편미분 = 0”으로 화면 3 에서 해 본 것입니다. ②는 제약 그 자체이고, ③은 화면 4 의 “벽은 당길 수 없다”입니다. ④가 새로운 줄입니다. 활성이면 g = 0 이라 성립하고, 비활성이면 g > 0 이므로 λ = 0 이어야 한다는, 화면 4 에서 본 “둘 중 하나는 0”을 식으로 쓴 것입니다. 등식 제약 h = 0 은 항상 h = 0 이므로 ②와 ④가 자동으로 성립하고, 승수 λ 는 부호 제한(③)이 없습니다.

‘쌍대 가능성’이라는 이름

세 번째 줄에 붙은 ‘쌍대’라는 이름이 왜 거기 있는지는 아직 설명하지 못합니다. 지금은 “λ ≥ 0 을 부르는 이름”으로만 알아 두세요. 4장에서 다룸

제약이 둘일 때 — 어느 것이 활성인지 따져 보기

④가 하는 일은 “어느 제약이 활성인가”를 경우의 수로 바꿔 주는 것입니다. 제약이 둘인 작은 문제로 확인합니다.

min   ½(w₁² + w₂²)    s.t.   g₁ = w₁ − 1 ≥ 0,   g₂ = w₂ + 1 ≥ 0

L = ½(w₁²+w₂²) − λ₁(w₁−1) − λ₂(w₂+1) 이므로 ①은 w₁ = λ₁, w₂ = λ₂ 입니다. 각 제약이 활성(g = 0)이거나 비활성(λ = 0)인 경우가 2 × 2 = 4 가지입니다.

g₁g₂풀면점검판정
활성 w₁=1활성 w₂=−1λ₁ = 1, λ₂ = w₂ = −1③ 위반 (λ₂ < 0)탈락
활성 w₁=1비활성 λ₂=0w₂ = λ₂ = 0, λ₁ = 1② g₂ = 0+1 = 1 ≥ 0 ✓, ③ ✓통과
비활성 λ₁=0활성 w₂=−1w₁ = λ₁ = 0, λ₂ = −1② g₁ = −1 < 0 위반탈락
비활성 λ₁=0비활성 λ₂=0w = (0, 0)② g₁ = −1 < 0 위반탈락

답은 w = (1, 0), λ = (1, 0), J = ½ 입니다. 제약 1 은 활성이라 답을 밀어 올리고, 제약 2 는 여유가 1 이나 있어 λ₂ = 0 으로 답에 아무 영향도 못 줍니다. 제약 2 를 아예 지워도 답이 같습니다. 제약이 수백 개여도 답을 결정하는 것은 활성 제약뿐이라는 것이 부등식 제약 최적화의 핵심 모양입니다.

한계 — KKT 가 답을 보장하는 조건

일반적인 문제에서 KKT 는 “답이라면 반드시 만족하는” 필요조건이고(제약에 약간의 조건이 필요합니다), 만족하는 점이 곧 최솟값인지는 보장하지 않습니다(화면 3 의 w₁w₂ 처럼). 다만 이 교재의 문제처럼 목적함수가 그릇 모양이고 제약이 직선(평면)이면, KKT 를 만족하는 점이 곧 최솟값입니다(증명은 생략합니다). 그래서 4장에서 KKT 로 푸는 일이 정당합니다.

SVM 에 맞춰 보기 — 모양만 확인하기

2장의 문제에서 목적함수는 J = ½‖w‖², 제약은 점마다 g(i)(w, b) = y(i)(w·x(i)+b) − 1 ≥ 0 입니다. 방금 풀어 본 문제들과 똑같은 모양입니다. 2장 화면 5 의 답에서 세 점의 g 값은 0, 0.5, 0 이었으니, 상보 여유성 ④는 “제약 2 의 승수는 0 이어야 한다”고 예고합니다. 위의 제약 2(여유 1, λ₂ = 0)와 같은 상황입니다. SVM 의 라그랑지안을 직접 세우고 승수를 구하는 일, 그리고 승수가 0 이 아닌 점에 이름을 붙이는 일은 4장에서 다룸

3장 · 화면 6

3장 마무리

핵심 요약

  1. 편미분 ∂J/∂w₁ 은 다른 변수를 얼려 두고 한 변수만 움직일 때의 기울기이고, 모으면 기울기 벡터 ∇J 입니다. 제약이 없으면 그릇 모양 함수의 바닥은 ∇J = 0 입니다.
  2. 등식 제약 h = 0 아래의 최소점은 등고선과 제약선이 접하는 곳이고, 거기서 ∇J = λ∇h 입니다. 라그랑지안 L = J − λh 의 편미분을 모두 0 으로 놓아 푸는 것이 라그랑주 승수법입니다.
  3. 부등식 제약 g ≥ 0 은 답에서 활성(g = 0)이거나 비활성(g > 0, 이때 λ = 0)이고, 부등식의 승수는 λ ≥ 0 입니다.
  4. KKT 조건 네 줄: ① 정상성 ∇wL = 0, ② 원문제 가능성 g ≥ 0, ③ 쌍대 가능성 λ ≥ 0, ④ 상보 여유성 λ·g = 0. 이 교재의 문제(그릇 모양 + 직선 제약)에서는 이 네 줄을 만족하는 점이 곧 답입니다.

E(w₁, w₂) = w₁² + 3w₂² 일 때, 점 (2, 1) 에서 ∂E/∂w₂ 는 얼마일까요?

  1. 4
  2. 2
  3. 6

같은 점에서 ∇E = (4, 6) 이므로 가장 빨리 오르는 방향은 w₂ 쪽으로 더 기울어 있습니다. 등고선 E = 상수 는 원이 아니라 가로로 긴 타원이고, 기울기는 여전히 그 타원에 수직입니다. 원이 아닌 등고선에서도 “접점에서 기울기가 평행”이 그대로 성립합니다.

부등식 제약 g(w) ≥ 0 이 최적해에서 비활성(g > 0)이라면, 그 제약의 승수 λ 에 대해 맞는 말은 무엇일까요?

  1. λ = 0 이다
  2. λ > 0 이다. 제약은 늘 답을 밀기 때문이다
  3. λ 는 아무 값이나 가능하다

이 성질 덕분에 제약이 수백 개여도 답을 정하는 데는 활성인 소수만 관여합니다. 한편 반대 방향은 성립하지 않습니다. 활성(g = 0)인데도 λ = 0 인 경우가 가능합니다. 예를 들어 w ≥ 0 아래서 ½w² 를 최소화하면 답 w = 0 은 경계에 닿아 있지만 ∇J = w = 0 이라 λ = 0 입니다.

min ½(w₁² + w₂²) s.t. w₁ + w₂ − 4 ≥ 0 의 답에서 승수 λ 는 얼마일까요?

  1. 0
  2. 2
  3. 4

제약을 w₁ + w₂ ≥ c 로 두면 최솟값은 c²/4 이고 그 기울기 c/2 가 λ 입니다. c = 4 에서 2, 화면 3 의 c = 1 에서 ½ 로 모두 맞습니다. 제약을 한 단위 조일 때 최솟값이 얼마나 늘어나는지가 λ 라는 해석을 확인한 셈입니다.

직접 해보기

목적함수 J = ½(w₁² + w₂²) 에 제약 w₁ + 2w₂ = 5(등식)를 붙입니다.

  1. 라그랑지안 L = J − λ(w₁ + 2w₂ − 5) 를 쓰고 편미분 세 개를 0 으로 놓아 w 와 λ 를 구하세요.
  2. 제약을 부등식 w₁ + 2w₂ − 5 ≥ 0 으로 바꾸면 답이 같은지, 활성·비활성 두 경우를 나누어 확인하세요.
  3. 제약을 w₁ + 2w₂ + 5 ≥ 0 으로 바꾸면 답이 어떻게 되는지 구하세요. 어느 제약이 활성입니까?
  4. 2번의 답에서 KKT 네 줄이 모두 성립함을 확인하세요.
모범답안 — 그리고 흔한 실수가 왜 부족한지

1. ∂L/∂w₁ = w₁ − λ = 0, ∂L/∂w₂ = w₂ − 2λ = 0, ∂L/∂λ = −(w₁ + 2w₂ − 5) = 0. 앞의 둘에서 w₁ = λ, w₂ = 2λ 이고 셋째에 넣으면 λ + 4λ = 5, λ = 1 입니다. 따라서 w = (1, 2), J = ½(1 + 4) = 2.5 입니다. 검산: 1 + 2·2 = 5 ✓, ∇J = (1, 2) = 1·(1, 2) = λ∇h ✓.

2. 비활성(λ = 0)이라 가정하면 w = (0, 0) 인데 g = −5 < 0 이라 탈락합니다. 활성(g = 0)이라 가정하면 1번과 같은 w = (1, 2), λ = 1 ≥ 0 으로 통과하므로 답이 같습니다.

3. 비활성이라 가정하면 w = (0, 0), g = 5 ≥ 0 으로 통과하고 J = 0 입니다. 활성이라 가정하면 w₁ = λ, w₂ = 2λ, 5λ = −5 에서 λ = −1 < 0 이라 탈락합니다. 답은 w = (0, 0) 이고 이 제약은 비활성(λ = 0)입니다.

4. w = (1, 2), λ = 1: ① ∇J = (1, 2) = 1·∇g = 1·(1, 2) ✓, ② g = 1 + 4 − 5 = 0 ≥ 0 ✓, ③ λ = 1 ≥ 0 ✓, ④ λ·g = 1·0 = 0 ✓.

덧붙임 — 제약을 w₁ + 2w₂ = c 로 두고 풀면 w = (c/5, 2c/5), 최솟값 J = c²/10 이고 c = 5 에서 기울기 c/5 = 1 이 λ 와 같습니다.

흔한 실수 1 — 부등식 문제를 풀 때 활성이라고만 가정하고 λ 의 부호를 확인하지 않기. 3번에서 활성으로만 풀면 w = (−1, −2) 가 나오지만 λ = −1 이라 답이 아닙니다(실제 J = 2.5 로 원점의 0 보다 큽니다).

흔한 실수 2 — 라그랑지안에서 λ 로 편미분하는 것을 빼먹기. 그러면 제약식이 식에서 빠져 w₁ = λ, w₂ = 2λ 만 남고 미지수를 정할 수 없습니다.

이 교재가 가는 길 — 4장은 이 장의 방법 그대로 SVM 의 제약(점마다 하나) 전체에 승수를 하나씩 달아 쌍대문제를 유도합니다.
