실전: scikit-learn 과 SVM 의 자리

7장까지 SVM 을 밑바닥부터 만들었습니다. 실제로 쓸 때는 그것을 직접 짜지 않고 scikit-learn 의 SVC 를 부릅니다. 이 장은 교재의 마지막 장이고 일을 셋 합니다. (1) SVC 의 사용법과 속성이 우리 코드의 무엇에 해당하는지 정리합니다. 7장 화면 5 에서 미뤄 둔 “사용법”이 이 화면입니다. (2) \(C\) 와 \(\gamma \) 를 데이터로 고르는 방법을 봅니다. (3) SVM 을 언제 쓰고 언제 쓰지 말아야 하는지를 정직하게 따진 뒤 교재 전체를 되짚습니다.

이 장의 실행 환경

이 장의 코드는 Python 3.12, scikit-learn 1.9.1, NumPy 1.26.4 에서 실행해 출력을 붙인 것입니다. 난수가 들어가는 곳은 모두 seed(random_state)를 고정했습니다. 버전이 다르면 기본값이나 출력의 끝자리가 달라질 수 있습니다. 코드 블록을 위에서 아래로 이어 붙이면 그대로 돌아가고, 외부에서 내려받는 데이터는 없습니다. 이 장은 7장의 svm.py 를 부르지 않고 SVC 만 씁니다. 설치되어 있지 않다면 pip install numpy scikit-learn 으로 설치합니다.

SVC 를 한 번 써 보기

6장의 원형 12 점에 SVC 를 돌립니다. 7장에서 SVM(C=1, kernel="rbf", gamma=1) 으로 푼 것과 같은 문제입니다. 멈춤 기준 tol 도 7장과 같은 1e-10 으로 맞춥니다(SVC 의 기본은 1e-3 이라 끝자리가 달라지는 것을 7장 화면 5 에서 보았습니다).

# 8장 · 코드 1import numpy as np
import sklearn
from sklearn.svm import SVC

inner = [[0, 0], [0.9, 0.3], [0.5, -0.8], [-0.6, -0.6], [-1, 0.4], [-0.3, 1]]
outer = [[2.2, 0.4], [-2.2, -0.4], [1.2, 2.2], [-1, 2.3], [-0.8, -2.2], [1.6, -1.8]]
X12 = np.array(inner + outer)
y12 = np.array([1] * 6 + [-1] * 6)

np.set_printoptions(precision=5, suppress=True)
print(sklearn.__version__, np.__version__)
clf = SVC(C=1, kernel="rbf", gamma=1, tol=1e-10).fit(X12, y12)
print(clf.support_ + 1, clf.n_support_)
print(clf.dual_coef_)
print(clf.intercept_, clf.support_vectors_.shape)
alpha = np.zeros(12)
alpha[clf.support_] = clf.dual_coef_[0] * y12[clf.support_]
print(alpha)

  5. 13행 support_ 는 서포트 벡터의 번호(0 부터)이고, 보기 좋게 + 1 을 했습니다. n_support_ 는 클래스별 서포트 벡터 수입니다.

  7. 16~18행 dual_coef_ 에 \(y\) 를 다시 곱하면(y² = 1) \(\alpha \) 만 남습니다. 12 점 크기의 배열에서 서포트 벡터 자리에만 채워 넣어 7장에서 본 \(\alpha \) 와 견줍니다.

SVC 는 클래스를 작은 값부터(classes_ 가 [-1, 1]) 정렬해 나열하기 때문입니다. n_support_ = [6, 5] 도 같은 순서입니다(−1 클래스 6 개, +1 클래스 5 개). dual_coef_ 는 앞 여섯 개가 음수인데, \(\alpha \ge 0\) 에 \(y = -1\) 이 곱해졌기 때문입니다. 마지막 줄에서 \(\alpha \) 를 복원하면 7장 화면 5 에서 우리 SVM 이 낸 12 개 값과 같은 숫자(0, 1, 0.9394, 0.85546, …)이고, b = −0.36583 도 같습니다.

속성 대응표 — 7장 비교의 정식 정리

7장에서 “SVC 는 dual_coef_, support_, intercept_ 로 알려 준다”고만 했습니다. 이제 우리 코드의 이름과 나란히 놓습니다. 두 클래스(이진) 분류일 때의 대응입니다.

SVC 의 이름우리 SVM(7장)설명
\(C\), kernel, gamma같은 이름5장 · 6장의 \(C\), 커널, \(\gamma \). 기본값은 C=1.0, kernel="rbf", gamma="scale"(아래)
tol같은 이름멈춤 허용 오차. SVC 의 기본은 1e-3, 우리는 1e-10
support_support_서포트 벡터 번호(0 부터). 다만 SVC 는 클래스 순서대로 나열한다
support_vectors_X_[support_]서포트 벡터의 좌표(\(\alpha = 0\) 인 점은 보관하지 않는다)
dual_coef_(alpha_ * y_)[support_]\(\alpha ^{(i)}y^{(i)}\). 모양은 (1, 서포트 벡터 수). 부호가 레이블을 알려 준다
intercept_b_\(b\). 길이 1 의 배열
decision_function(X)decision_function(X)\(f(x) = \sum \alpha ^{(i)}y^{(i)}K(x^{(i)}, x) + b\). predict 는 이 값의 부호
coef_(alpha_ * y_) @ X_\(w = \sum \alpha ^{(i)}y^{(i)}x^{(i)}\). 선형 커널에서만 있다(다른 커널에서 부르면 오류)
n_support_(없음)클래스별 서포트 벡터 수

정리하면 SVC 가 학습 뒤에 들고 있는 것은 서포트 벡터와 그 \(\alpha \cdot y\) 와 \(b\) 뿐입니다. 4장에서 \(w\) 가 서포트 벡터로만 만들어진다고 했고, 6장에서 예측식에 서포트 벡터만 들어간다고 했던 것의 그대로입니다. 이 속성만으로 예측식을 다시 만들어 봅니다.

# 8장 · 코드 2q = np.array([[0.5, 0.5]])
sv, coef, b = clf.support_vectors_, clf.dual_coef_[0], clf.intercept_[0]
k = np.exp(-1 * ((sv - q) ** 2).sum(1))
print(round(coef @ k + b, 5), clf.decision_function(q).round(5))

# 출력1.08688 [1.08688]
  1. 1~2행 새 점 \(q\) 하나와, SVC 의 속성 세 개를 짧은 이름에 담습니다. dual_coef_[0] 은 1 × 11 표의 첫(유일한) 행입니다.
  2. 3행 서포트 벡터 11 개와 \(q\) 사이의 RBF 값 \(K(x^{(i)}, q) = \exp (-\gamma \lVert x^{(i)} - q\rVert ^{2})\) 입니다. 앞의 −1 * 이 \(-\gamma \)(\(\gamma = 1\))이고, sv - q 는 7장 화면 3 의 브로드캐스팅으로 11 × 2 표에서 \(q\) 를 뺍니다.
  3. 4행 coef @ k 가 \(\sum \alpha ^{(i)}y^{(i)}K\) 이고 \(b\) 를 더하면 6장의 예측식입니다. SVC 가 직접 계산한 decision_function 과 같은 값(1.08688)입니다. f(q) > 0 이므로 \(q\) 는 +1(안쪽)로 분류됩니다.

선형 커널에서는 \(w\) 를 직접 꺼낼 수 있습니다. 4장의 점 3개로 확인합니다.

서포트 벡터 3번과 1번, \(\alpha \cdot y = (-\tfrac14 , +\tfrac14 )\), \(b = -2\), \(w = (\tfrac12 , \tfrac12 )\). 4장 손계산의 답이 그대로 나옵니다(레이블 −1 인 3번이 앞에 오는 것도 위와 같은 이유입니다). 커널이 RBF 이면 \(w\) 가 무한 차원 공간에 있어서 꺼낼 수 없습니다. 그래서 coef_ 가 선형 커널에서만 있습니다.

gamma 의 기본값 "scale"

SVC 의 gamma 기본값은 숫자가 아니라 문자열 "scale" 이고, scikit-learn 문서에 따르면 1 / (특성 수 × X.var()) 입니다. 여기서 X.var() 는 학습 데이터 행렬 전체 칸들의 분산 하나입니다(특성마다 따로가 아닙니다). 이 사실이 바로 아래에서 중요해집니다.

스케일링은 필수

RBF 커널은 점 사이의 거리 \(\lVert x - z\rVert ^{2}\) 로 값을 정하고, 마진도 2장에서 거리로 정의했습니다. 그래서 특성 하나의 단위가 다른 특성보다 훨씬 크면, 그 특성이 거리를 독차지합니다. 작은 예로 확인합니다. 두 특성이 모두 클래스 정보를 갖고 있는데, 하나는 −3~3 쯤의 작은 단위이고 하나는 1000 배 큰 단위(예: 단위를 바꿔 쓴 길이)인 합성 데이터입니다.

# 8장 · 코드 4from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(0)
y = np.where(np.arange(200) % 2 == 0, 1, -1)
x1 = y * 1.0 + rng.normal(0, 0.8, 200)           # 단위가 작은 특성
x2 = 1000 * (0.3 * y + rng.normal(0, 1, 200))    # 단위가 1000 배 큰 특성
X = np.column_stack([x1, x2])
Xtr, ytr, Xte, yte = X[:100], y[:100], X[100:], y[100:]

print((Xtr[0] - Xtr[1]) ** 2)
print(f"{1 / (2 * Xtr.var()):.2e}")

# 출력[     4.86762 302370.92911]
8.22e-07
  1. 4행 default_rng(0) 은 seed 를 0 으로 고정한 난수 발생기라 누가 돌려도 같은 데이터가 나옵니다.
  2. 5행 레이블이 +1, −1 로 번갈아 나오는 길이 200 의 배열입니다. 앞 100 점과 뒤 100 점이 모두 균형 잡힙니다.
  3. 6~7행 x1 은 클래스마다 중심이 ±1 이고 퍼짐 0.8 입니다. x2 는 중심이 ±300 이고 퍼짐 1000 이라 클래스 차이가 있지만 약합니다. 두 특성 다 정보가 있고 단위만 다릅니다.
  4. 8~9행 두 특성을 열로 붙여 200 × 2 표로 만들고, 앞 100 점으로 학습하고 뒤 100 점(시험용, 학습에 쓰지 않은 점)으로 점수를 매깁니다.
  5. 11행 학습 점 두 개(0 번, 1 번)의 특성별 제곱 차이입니다. \(\lVert x - z\rVert ^{2}\) 는 이 둘의 합이고, 작은 단위 특성 몫은 4.9, 큰 단위 특성 몫은 302,371 입니다. 거리 제곱의 99.99% 이상이 x2 에서 옵니다.
  6. 12행 위 gamma="scale" 공식을 손으로 계산한 값입니다(특성 수 2). 약 8.2 × 10⁻⁷ 로, 행렬 전체의 분산이 x2 때문에 큰 만큼 아주 작은 \(\gamma \) 가 됩니다.

이 \(\gamma \) 로 지수 \(\gamma \lVert x - z\rVert ^{2}\) 를 계산하면, 11행의 두 점에서는 x2 몫이 8.2 × 10⁻⁷ × 302,371 ≈ 0.25 이고 x1 몫은 8.2 × 10⁻⁷ × 4.9 ≈ 4 × 10⁻⁶ 입니다. x1 이 커널 값에 미치는 영향이 사실상 0 입니다. 세 가지 설정으로 학습해 비교합니다.

# 8장 · 코드 5models = {"그대로": SVC(), "gamma=1": SVC(gamma=1),
          "스케일러+SVC": make_pipeline(StandardScaler(), SVC())}
for name, m in models.items():
    m.fit(Xtr, ytr)
    print(name, m.score(Xtr, ytr), m.score(Xte, yte))

# 출력그대로 0.59 0.61
gamma=1 1.0 0.51
스케일러+SVC 0.91 0.89

score 는 맞힌 비율(정확도)이고, 각 줄은 이름 · 학습 점수 · 시험 점수 입니다. 같은 데이터에서 실패가 두 가지, 서로 다른 이유로 일어났습니다.

  • 그대로(0.59 / 0.61) — \(\gamma \approx 8 \times 10^{-7}\) 이 되어 x1 이 보이지 않습니다. x2 만으로 가르는데 x2 의 클래스 차이는 약해서 점수가 낮습니다.
  • gamma=1(1.0 / 0.51) — 거리 제곱이 수십만이라 \(\exp (-\text{수십만})\) 은 사실상 0 입니다. 학습 점끼리 서로 닮은 정도가 0 이라 점마다 따로 놀며 학습 점수는 1.0 이지만 새 점은 찍는 수준(0.51)입니다. 학습 점을 외운 과적합입니다.
  • 스케일러+SVC(0.91 / 0.89) — 두 특성의 단위를 맞춘 뒤에는 기본 설정 그대로 두 특성이 함께 쓰입니다.

고친 방법이 표준화(StandardScaler)입니다. 특성마다 \((\text{값} - \text{평균}) \div \text{표준편차}\) 로 바꿔 평균 0, 표준편차 1 로 맞춥니다. 모든 특성이 같은 퍼짐을 가지므로 거리에 비슷하게 기여하고, gamma="scale" 도 1 / (2 × 1) = 0.5 가 되어 제 역할을 합니다. 평균과 표준편차는 학습 데이터에서만 구하고, 시험 점에는 그 값을 그대로 적용해야 합니다.

이 순서를 틀리지 않게 묶어 주는 것이 파이프라인(make_pipeline)입니다. 위 코드의 make_pipeline(StandardScaler(), SVC()) 에서 fit 은 학습 데이터로 스케일러를 맞추고 변환한 뒤 SVC 를 학습하고, score·predict 는 시험 점을 같은 스케일러로 변환해서 넘깁니다. 편의 때문만이 아니라 누수를 막는 데 쓰입니다. 누수는 시험 점(나중의 검증 점)의 정보가 학습 쪽으로 새어 들어가는 것입니다. 전체 데이터로 평균을 구한 뒤 나누면 시험 점이 이미 평균에 반영됩니다. 파이프라인은 화면 2 의 교차검증에서도 폴드마다 스케일러를 학습 폴드로만 다시 맞춥니다.

스케일링을 잊으면 조용히 틀린다

위 SVC() 는 오류도 경고도 없이 0.61 을 냈습니다. 특성의 단위가 다르면 SVM(과 거리·마진에 기대는 방법)은 스케일링부터입니다. 반대로 트리 계열(결정 트리 · 부스팅)은 특성마다 값의 순서만 쓰기 때문에 단위에 덜 민감하다고 알려져 있습니다. 스케일링이 필수인 것은 SVM 의 한계이기도 합니다(화면 3).

8장 · 화면 2

\(C\) 와 \(\gamma \) 를 데이터로 고르기

5장에서 \(C\) 는 “데이터로 고른다”고만 했고 6장의 \(\gamma \) 도 마찬가지였습니다. 이제 어떤 점수로 고르는지를 정해야 합니다.

  • 학습 점수로? 안 됩니다. 화면 1 의 gamma=1 처럼 학습 점을 외우면 학습 점수는 1.0 까지 오릅니다. 외우는 쪽으로 갈수록 좋아 보입니다.
  • 시험 점수로? 시험용 점은 “새 점”을 흉내 내는 점이라 최종 평가에 한 번만 써야 합니다. 시험 점수를 보고 \(C\) 를 고르면 시험 문제를 보고 공부한 셈이라 그 점수가 낙관적이 됩니다.
  • 그러면? 학습 데이터를 다시 쪼개 한쪽을 ‘가짜 시험’(검증용)으로 쓰는 방법이 교차검증입니다.

교차검증 — 학습 데이터를 돌려 가며 시험으로 쓴다

학습 데이터를 \(k\) 조각(폴드)으로 나눕니다. 한 조각을 검증용으로 빼고 나머지로 학습해 빠진 조각으로 점수를 매기고, 빠지는 조각을 바꿔 가며 \(k\) 번 되풀이해 \(k\) 개 점수의 평균을 냅니다. 모든 점이 한 번씩 검증에 쓰이고, 한 번 나눈 결과의 운에 덜 기댑니다. 아래는 k = 5 입니다.

데이터는 6장의 원형 구조에 잡음이 낀 합성 데이터로 바꿉니다(make_circles: 안쪽 원과 바깥 원). 점 200 개를 학습 140 + 시험 60 으로 나누고, 화면 1 의 파이프라인(스케일러 + 기본 설정 SVC)을 학습 140 점에서 교차검증해 봅니다.

# 8장 · 코드 6from sklearn.datasets import make_circles
from sklearn.model_selection import cross_val_score, GridSearchCV, train_test_split

X, y = make_circles(n_samples=200, noise=0.2, factor=0.4, random_state=0)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0)
pipe = make_pipeline(StandardScaler(), SVC())
scores = cross_val_score(pipe, Xtr, ytr, cv=5)
print(len(Xtr), len(Xte))
print(scores.round(3), scores.mean().round(3))

# 출력140 60
[0.893 0.964 0.821 0.821 0.929] 0.886
  1. 4행 noise=0.2 는 점의 흩어짐, factor=0.4 는 안쪽 원 반지름이 바깥 원의 0.4 배라는 뜻입니다.
  2. 5행 train_test_split 은 점을 무작위로 섞어 70% 는 학습, 30% 는 시험으로 나눕니다. random_state 로 같은 분할이 나오게 합니다. 시험용은 이 뒤로 최종 평가 때까지 열어 보지 않습니다.
  3. 7행 cv=5 가 5 겹 교차검증이고, 분류 문제에서는 폴드마다 클래스 비율이 비슷하도록 나눕니다. 폴드마다 파이프라인 전체(스케일러 + SVC)를 처음부터 학습합니다. 돌려주는 값은 폴드 다섯 개의 점수입니다.
  4. 9행 다섯 점수가 0.821 에서 0.964 까지 흔들립니다. 폴드 하나(28 점)만 믿으면 이만큼 운이 개입한다는 뜻이고, 그래서 평균 0.886 을 이 설정의 점수로 삼습니다.

격자 탐색 — \(C\) 와 \(\gamma \) 를 로그 스케일로

\(C\) 와 \(\gamma \) 는 “몇 배”로 효과가 달라지는 값이라서, 후보를 1, 2, 3, 4… 처럼 같은 간격이 아니라 0.01, 0.1, 1, 10, 100 처럼 10 배씩 늘어놓습니다(로그 스케일). \(C\) 를 1 에서 2 로 바꾸는 것보다 1 에서 10 으로 바꾸는 것이 모양을 훨씬 크게 바꿉니다. 두 값의 후보를 격자로 늘어놓고 칸마다 교차검증 점수를 구해 가장 높은 칸을 고르는 것이 격자 탐색(GridSearchCV)입니다.

# 8장 · 코드 7grid = {"svc__C": [0.01, 0.1, 1, 10, 100], "svc__gamma": [0.01, 0.1, 1, 10, 100]}
gs = GridSearchCV(pipe, grid, cv=5, return_train_score=True).fit(Xtr, ytr)
print(gs.best_params_, round(gs.best_score_, 3), round(gs.score(Xte, yte), 3))

# 출력{'svc__C': 10, 'svc__gamma': 0.1} 0.907 0.917
  1. 1행 파이프라인 안의 단계 이름(make_pipeline 이 svc 로 붙여 줌) 뒤에 밑줄 두 개와 파라미터 이름을 붙여 svc__C, svc__gamma 로 씁니다. 5 × 5 = 25 칸입니다.
  2. 2행 칸마다 5 겹 교차검증이므로 25 × 5 = 125 번 학습하고, 가장 좋은 칸으로 학습 140 점 전체를 한 번 더 학습해 둡니다(refit 기본값). return_train_score=True 는 폴드마다 학습 점수도 남기게 합니다(아래에서 씁니다).
  3. 3행 best_params_ 는 가장 좋은 칸, best_score_ 는 그 칸의 교차검증 점수(0.907)입니다. gs.score 는 다시 학습된 최종 모델로 처음으로 시험용 60 점을 채점한 값(0.917)입니다.

결과 표 읽기 — 과소적합과 과적합

칸 25 개의 점수를 표로 꺼냅니다. cv_results_ 에서 꺼낸 값을 5 × 5 로 모양을 바꾸면, 행은 \(C\)(위에서 아래로 0.01 → 100), 열은 \(\gamma \)(왼쪽에서 오른쪽으로 0.01 → 100) 입니다(\(C\) 가 느리게, \(\gamma \) 가 빠르게 바뀌는 순서로 쌓이기 때문입니다).

  • 한 칸의 우세는 약한 주장입니다. 0.91, 0.89, 0.90 처럼 비슷한 칸이 여럿이고, 폴드 하나의 점수가 0.82~0.96 으로 흔들렸습니다(코드 6). 그리고 화면 1 의 기본 설정(C = 1, γ = "scale")의 교차검증 점수가 0.886 이니, 격자로 얻은 이득은 이 데이터에서 2%p 남짓입니다. 격자의 가치는 최고점을 올리는 것보다 0.51 같은 낭떠러지를 피하는 것에 있습니다.
  • 최고 점수는 약간 낙관적입니다. 격자 점수를 보고 고른 값이라 그 점수는 선택에 쓰인 데이터로 잰 것입니다. 시험 점수 0.917 이 교차검증 0.907 보다 높은 것도 60 점짜리 시험이라 한 점이 약 1.7%p 이기 때문에 우연일 수 있습니다. “일반화가 더 잘 된다”는 증거는 아닙니다.
  • 가장 좋은 칸이 격자 가장자리에 있으면 그 너머에 더 좋은 값이 있을 수 있으니 범위를 넓혀 다시 돌립니다. 이 표의 최고 칸은 가운데 근처라 괜찮습니다.

두 개를 넘는 클래스 — SVC 는 일대일

SVM 은 원래 두 클래스를 가르는 방법입니다. 클래스가 \(k\) 개일 때 SVC 는 일대일(OvO) 로, 클래스 두 개씩 짝지어 \(k(k-1)/2\) 개의 이진 SVM 을 학습하고 투표로 정합니다. 반대로 클래스마다 “이 클래스 대 나머지 전부”를 가르는 \(k\) 개를 만드는 방식이 일대다(OvR) 입니다. 일대일은 분류기 수가 늘지만 각 분류기는 두 클래스의 점만 쓰므로 하나하나는 작은 문제입니다.

# 8장 · 코드 9from sklearn.datasets import make_blobs

Xb, yb = make_blobs(n_samples=120, centers=4, random_state=0)
for shape in ("ovo", "ovr"):
    d = SVC(decision_function_shape=shape).fit(Xb, yb).decision_function(Xb[:1])
    print(shape, d.shape)

# 출력ovo (1, 6)
ovr (1, 4)

4 클래스이므로 일대일 점수는 \(4 \times 3 / 2 = 6\) 열, 일대다 모양은 4 열입니다. 여기서 흔한 오해 하나. decision_function_shape="ovr" 는 일대다로 학습한다는 뜻이 아닙니다. SVC 는 항상 일대일로 학습하고, "ovr" 는 그 결과를 다른 분류기와 같은 (점 수, 클래스 수) 모양으로 모아 보여 주는 설정일 뿐입니다. 진짜 일대다로 학습하려면 OneVsRestClassifier(SVC()) 로 감싸고(4 클래스에서 SVC 가 4 개 만들어집니다), 선형 SVM 인 LinearSVC 는 기본이 일대다입니다.

한 줄: 값을 맞히는 SVM, SVR

값(숫자)을 맞히는 회귀에도 같은 생각이 쓰입니다. SVR 은 예측이 정답에서 \(\varepsilon \) 이내면 벌점이 0 이고, 벗어난 만큼만 벌점을 줍니다. 5장의 힌지 손실이 “마진 밖이면 0”이던 것을 “\(\varepsilon \)-띠 안이면 0”으로 바꾼 꼴입니다. 쓰는 법은 SVC 와 같고 \(C\), kernel, gamma 에 epsilon 이 더해집니다. 이 교재는 여기까지만 합니다.

SVM 을 쓸 때와 쓰지 말아야 할 때

여기부터는 도구의 성능이 아니라 판단의 이야기입니다. 아래 “잘 맞는다”는 말은 경험적으로 알려진 경향이고, 어느 데이터에서든 성립하는 법칙이 아닙니다. 결정은 데이터마다 교차검증으로 확인해야 합니다.

잘 맞는 경우

상황왜 SVM 이 후보가 되는가
점이 수백~수만 개 정도(중소 규모)쌍대문제와 커널 행렬이 감당되는 크기에서는 단단한 기준선이 됩니다. 점 수에 대한 계산량은 아래에서 따로 따집니다.
특성이 많은 고차원(점 수보다 많아도)마진을 크게 하는 것이 규제 역할을 해서 과적합을 억누른다고 알려져 있습니다. 문서 분류처럼 특성이 수만 개인 데이터에서 선형 SVM 이 단단한 기준선으로 쓰입니다.
클래스 사이에 빈틈이 있을 때마진 직관(2장)이 그대로 맞습니다. 서포트 벡터가 소수라 모델이 가볍고 예측식이 간결합니다(4장 · 6장).

조심해야 하는 경우

대용량 — 점 수가 커지면

7장 화면 5 에서 보았듯 그램 행렬은 \(n \times n\) 입니다(n = 10,000 이면 약 0.8 GB). scikit-learn 의 SVC 문서는 학습 시간이 점 수에 대해 적어도 제곱으로 늘고, 수만 개를 넘으면 현실적이지 않을 수 있다고 안내합니다. 학습 뒤에도 새 점 하나를 분류할 때 서포트 벡터 수만큼 커널을 계산해야 합니다(6장). 점이 많을 때의 선택지는 문서도 같이 안내합니다.

  • LinearSVC — 선형 SVM 전용 구현(liblinear)입니다. 점 수가 많을 때 SVC(kernel="linear") 보다 잘 확장되도록 만들어졌고, 다중 클래스는 일대다입니다. 손실의 기본값이 힌지의 제곱(squared_hinge)이라 SVC 와 정확히 같은 모델은 아닙니다.
  • SGDClassifier — 확률적 경사하강으로 학습하는 선형 모델로, 기본 손실이 힌지(loss="hinge")입니다. 점을 조금씩 읽으며 학습하는 방식이라 대용량에 맞습니다.
  • 커널이 꼭 필요하면 — 문서는 Nystroem 같은 커널 근사 변환을 거친 뒤 위 선형 모델을 쓰는 방법을 안내합니다. 이 교재는 소개만 합니다.

확률이 필요할 때 — SVM 의 출력은 확률이 아니다

decision_function 의 값 f(x) 는 경계 쪽으로 얼마나 깊이 들어갔는지를 재는 점수입니다. 3.1 과 1.97 은 모두 +1 쪽이라는 것 말고는 “확률 몇 %”가 아닙니다. 확률이 필요하면 점수를 확률로 바꾸는 확률 보정 단계가 따로 있어야 합니다. 옛 방식은 SVC(probability=True) 였고 내부에서 5 겹 교차검증으로 보정을 학습하기 때문에 fit 이 느려집니다. 이 환경(scikit-learn 1.9.1)에서는 이 옵션이 폐기 예고되어 쓰면 경고가 뜨고, 경고는 CalibratedClassifierCV(SVC(), ensemble=False) 를 대신 쓰라고 안내합니다. 새 방식으로 확인합니다.

# 8장 · 코드 10from sklearn.calibration import CalibratedClassifierCV

X, y = make_circles(n_samples=300, noise=0.2, factor=0.4, random_state=0)
svc = SVC().fit(X, y)
cal = CalibratedClassifierCV(SVC(), ensemble=False, cv=5).fit(X, y)
print(svc.decision_function(X[:4]).round(2))
print(cal.predict_proba(X[:4]).round(2))
print((cal.predict(X) != svc.predict(X)).sum())

# 출력[ 3.1   1.97 -2.19  2.82]
[[0.   1.  ]
 [0.01 0.99]
 [0.99 0.01]
 [0.   1.  ]]
2
  1. 3~4행 6장 구조의 합성 데이터 300 점을 만들고 기본 SVC 를 학습합니다.
  2. 5행 CalibratedClassifierCV 는 모델의 점수를 확률로 바꾸는 포장지입니다. 기본 방법(method="sigmoid")은 Platt 가 제안한 방법으로, 점수에 로지스틱 회귀를 맞춥니다. cv=5 로 교차검증 예측을 만들어 그 점수와 정답의 관계를 보정하는 데 쓰고, ensemble=False 이므로 예측에 쓰는 SVC 는 전체 데이터로 학습한 하나입니다. 학습 비용은 SVC 를 한 번이 아니라 여러 번 학습하는 만큼 늘어납니다.
  3. 6행 앞 네 점의 점수입니다. 3.1, 1.97, −2.19, 2.82 로 값 자체는 확률이 아닙니다.
  4. 7행 같은 네 점의 확률(열은 클래스 0, 1 의 순서)입니다. 점수 3.1 은 확률 약 1.00, 1.97 은 0.99 로 바뀌었습니다. 점수가 클수록 확률이 큰 단조로운 대응입니다.
  5. 8행 보정된 모델의 predict(확률 기준)와 원래 SVC 의 predict(점수의 부호 기준)가 300 점 중 2 점에서 갈렸습니다. 문서도 옛 probability=True 항목에 predict_proba 가 predict 와 어긋날 수 있다고 적고 있습니다. 확인한 것은 갈린다는 사실뿐이고, 판정이 확률과 부호 중 무엇을 따르느냐에 따라 경계 근처에서 갈릴 수 있습니다.

그 밖의 한계

  • 하이퍼파라미터와 커널 선택에 민감합니다. 화면 2 의 표에서 같은 모델이 0.51 에서 0.91 까지 움직였습니다. 격자 탐색은 이 비용을 치르는 일입니다.
  • 스케일링이 필수입니다. 화면 1 의 예에서 아무 경고 없이 0.61 이었습니다.
  • 숫자 입력만 받습니다. 범주형 특성은 숫자로 바꿔야 하고, 결측치(NaN)는 SVC 가 직접 받지 못합니다(넣으면 오류가 납니다). 채우는 단계를 파이프라인 앞에 두어야 합니다.
  • 커널 모델은 해석이 어렵습니다. 선형 커널이면 coef_ 의 \(w\) 로 특성의 영향을 볼 수 있지만, RBF 에서는 서포트 벡터와 \(\alpha \) 만 남습니다.

딥러닝 · 그래디언트 부스팅과 비교하면 — “요즘은 왜 SVM 인가?”

이 질문에는 정직한 반대 의견이 있습니다. 먼저 반대편의 말을 그대로 적습니다.

데이터요즘의 일반적 선택SVM 의 위치
표 형태(행은 사례, 열은 특성)트리 기반 그래디언트 부스팅이 강한 첫 선택으로 널리 쓰입니다. 표 데이터에서 트리 기반 모델이 딥러닝보다 여전히 낫다는 비교 연구도 있습니다(Grinsztajn · Oyallon · Varoquaux 2022, 『Why do tree-based models still outperform deep learning on typical tabular data?』).비교 후보 중 하나입니다. 특성 스케일링과 하이퍼파라미터 탐색이 필요한 반면, 부스팅은 단위에 덜 민감합니다.
이미지 · 음성 · 텍스트 같은 비정형신경망(딥러닝)이 주류입니다. 데이터에서 특징 표현 자체를 학습하기 때문입니다.SVM 은 특징(또는 커널)을 사람이 정해 줘야 합니다. 대용량이면 계산도 버겁습니다.
점이 적고(수백~수천) 특성이 많은 데이터딥러닝은 데이터가 적으면 학습이 어렵다고 알려져 있습니다.마진 최대화가 규제 역할을 해서 여전히 경쟁력이 있다고 알려져 있습니다.

그러면 SVM 을 왜 배웠나요?

정직한 답은 둘입니다. (1) 지금도 맞는 자리가 있습니다. 위 표의 셋째 줄처럼 점이 적고 특성이 많은 데이터가 그렇고, 선형 SVM 은 대용량 희소 데이터에서도 기준선으로 쓰입니다. 다만 “SVM 이 늘 최선”이라고는 말할 수 없고, 데이터마다 후보를 교차검증으로 비교하는 것이 답입니다.

(2) 이 교재에서 배운 도구가 SVM 밖에서도 쓰입니다. 제약 있는 최적화를 라그랑주 승수와 KKT 로 푸는 법(3장)은 최적화 전반에, 원문제를 쌍대문제로 바꿔 보는 눈(4장)은 다른 최적화 문제에, 데이터를 내적으로만 만나게 해서 커널로 갈아 끼우는 생각(6장)은 커널 릿지 회귀나 가우시안 프로세스 같은 다른 커널 방법에, 마진을 손실 함수로 옮긴 힌지 손실(5장)은 다른 모델의 손실 설계에 다시 나타납니다. 도구 하나를 쓰는 법이 아니라 그 도구가 왜 그런 식인지를 배운 것이 이 교재의 몫이었습니다.

쓰기 전 점검표

  • 점이 몇 개인가? 수만 개를 넘으면 LinearSVC·SGDClassifier, 아니면 부스팅 등 다른 후보부터.
  • 특성 단위가 제각각인가? 파이프라인에 스케일러를 넣었는가?
  • 확률이 필요한가? 필요하면 CalibratedClassifierCV, 아니면 점수로 충분한가?
  • \(C\) 와 \(\gamma \) 를 로그 격자 + 교차검증으로 골랐고, 시험 점수는 마지막에 한 번만 봤는가?

8장 · 화면 4

8장 마무리 — 그리고 교재 전체 되짚기

핵심 요약

  1. SVC 는 7장의 SVM 과 같은 문제를 푼다. 학습 뒤에는 support_, dual_coef_(= \(\alpha \cdot y\)), intercept_(= \(b\)) 만 들고 있고, 같은 데이터에서 같은 \(\alpha \), \(b\) 가 나온다(선형 커널에서만 coef_ = \(w\)).
  2. 스케일링은 필수. 단위가 큰 특성이 거리를 독차지하고 gamma="scale" 은 특성별 보정이 아니다. Pipeline(StandardScaler, SVC) 로 묶으면 누수 없이 해결된다.
  3. \(C\) 와 \(\gamma \) 는 로그 격자 + 교차검증(GridSearchCV)으로 고른다. 작은 쪽은 과소적합(0.51), 큰 쪽은 과적합(학습 1.00, 교차검증 0.81~0.83)이고, 시험 점수는 마지막에 한 번만 본다.
  4. SVC 는 일대일로 학습하고, 확률은 기본으로 주지 않는다(CalibratedClassifierCV). 점이 많으면 학습이 점 수의 제곱 이상으로 늘어 LinearSVC·SGDClassifier 가 대안이다. 표 데이터는 부스팅, 비정형은 딥러닝이 대세이고, SVM 의 몫은 중소 규모·고차원과 배운 도구가 다른 곳에서도 쓰인다는 데 있다.

교재 전체 총정리 — 한 장 한 줄

장핵심 한 줄
1장 점들을 가르는 직선분류는 \(w\cdot x+b\) 의 부호이고, 가르는 직선은 무수히 많아서 “어느 직선이 최선인가”가 남는다.
2장 마진과 하드 마진가장 가까운 점까지 거리가 가장 큰 직선: min ½‖w‖² s.t. y(w·x+b) ≥ 1, 마진은 \(2/\lVert w\rVert \).
3장 제약 있는 최적화라그랑지안 \(L = J - \lambda g\) 와 KKT 네 줄. 제약이 활성이면 g = 0, 비활성이면 \(\lambda = 0\).
4장 쌍대문제\(w\), \(b\) 를 지우면 max Σα − ½ΣΣαα yy (x·x), \(\sum \alpha y = 0\), \(\alpha \ge 0\). \(\alpha > 0\) 인 점이 서포트 벡터이고, 점 3개의 답은 \(\alpha = (\tfrac14 , 0, \tfrac14 )\).
5장 소프트 마진슬랙 \(\xi \) 로 침범을 허용하고 \(C\sum \xi \) 로 벌점. 쌍대에서는 \(0 \le \alpha \le C\) 만 달라진다(힌지 손실).
6장 커널 트릭쌍대와 예측식에 내적만 있으니 \(K(x,z) = \varphi (x)\cdot \varphi (z)\) 로 갈아 끼운다. RBF 는 무한 차원이고 \(\gamma \) 는 영향 범위를 정한다.
7장 밑바닥부터 구현SMO: \(\sum \alpha y = 0\) 때문에 \(\alpha \) 를 두 개씩 움직이고, 2차함수의 꼭짓점을 구해 [L, H] 로 자른다. 약 70 줄로 SVC 와 같은 답.
8장 실전스케일링 + 로그 격자 교차검증, 확률 · 대용량 · 비교의 정직한 한계.

한 문장으로 줄이면 이렇습니다. 안전한 직선(마진)을 제약 있는 최적화로 쓰고(2~3장), 쌍대로 바꾸면 내적만 남아(4장) 현실의 이상치(5장)와 곡선 경계(6장)까지 같은 틀로 풀리며, 그 문제는 두 변수씩 푸는 반복으로 풀린다(7장). 실제로 쓸 때는 스케일링과 하이퍼파라미터 탐색이 일의 절반입니다(8장).

한 특성의 단위가 다른 특성보다 1000 배 큰 데이터에 RBF 커널 SVC 를 아무 처리 없이 쓰면 어떤 일이 생기고, 어떻게 고칩니까?

  1. 큰 단위 특성이 거리를 거의 독차지해 작은 단위 특성이 사실상 무시됩니다. 표준화를 파이프라인 첫 단계에 넣어 고칩니다.
  2. SVM 은 마진을 최대화하므로 단위와 무관하게 같은 경계를 찾습니다. 스케일링은 속도만 높입니다.
  3. gamma 의 기본값 ‘scale’ 이 특성마다 분산을 따로 보정해 주므로 아무것도 안 해도 같은 결과가 나옵니다.

한 가지 더. 결정 트리나 부스팅은 특성마다 값의 순서(어디서 자를지)만 쓰므로 특성 하나에 단조로운 변환을 해도 영향이 작다고 알려져 있습니다. SVM 이 스케일링에 민감한 것은 “거리로 닮음을 재는 방법”의 공통된 약점입니다.

화면 2 의 5 × 5 표에서 학습 점수가 가장 높은 칸으로 \(C\) 와 \(\gamma \) 를 고르면 어떻게 될까요?

  1. C = 10, γ = 0.1 칸을 고르게 되어 문제가 없다.
  2. C = 0.01 인 첫 행을 고르게 되어 가장 단순해서 안전하다.
  3. 학습 점수가 1.00 인 오른쪽 아래의 칸을 고르게 되고, 그 칸의 교차검증 점수는 0.81~0.83 으로 최고점 0.91 보다 낮다.

표에서 한 가지 더 읽을 수 있습니다. 같은 γ = 0.01 열에서 \(C\) 를 1 → 10 → 100 으로 키우면 교차검증이 0.51 → 0.66 → 0.89 로 올라갑니다. 완만한 경계(작은 \(\gamma \))는 더 큰 \(C\) 로 보완해야 하므로, 한 값만 따로 정하는 것이 아니라 격자로 함께 훑어야 합니다.

점이 수백만 개인 분류 문제입니다. 이 장의 내용에 비추어 가장 알맞은 첫 선택은 무엇일까요?

  1. RBF 커널 SVC. 가장 정확한 분류기이니 시간이 걸려도 쓴다.
  2. 교차검증으로 점을 5 조각으로 나눠 학습하므로 점이 많아도 SVC 가 금방 끝난다.
  3. 선형 SVM(LinearSVC, SGDClassifier)처럼 대용량에 맞는 방법으로 시작하고, 커널이 필요하면 근사를 쓴다.

점 수가 많다는 것은 장점이기도 합니다. 점이 충분하면 복잡한 모델(부스팅, 신경망)도 과적합 없이 학습할 수 있어서 선택지가 넓어집니다. 커널 SVM 은 점이 적당히 적을 때 가장 매력적이라는 것이 이 장의 결론입니다.

1. 데이터를 다시 만들어 x2 를 1000 으로 나눕니다. 코드 블록 4 와 같은 난수를 쓰므로 같은 데이터입니다.

# 8장 · 과제 1rng = np.random.default_rng(0)

x1 = y * 1.0 + rng.normal(0, 0.8, 200)
x2 = 1000 * (0.3 * y + rng.normal(0, 1, 200))
X = np.column_stack([x1, x2]) / [1, 1000]
m = SVC().fit(X[:100], y[:100])
print(m.score(X[:100], y[:100]), m.score(X[100:], y[100:]))

# 출력0.89 0.9

시험 점수가 0.90 으로 파이프라인의 0.89 와 거의 같습니다. 두 방법 모두 두 특성의 퍼짐을 비슷하게 만들기 때문입니다(나눈 뒤 표준편차가 약 1.2 와 1.1). 그래도 StandardScaler 를 쓰는 이유는 (a) 특성이 수십 개이거나 단위를 모를 때 손으로 맞출 수 없고, (b) 파이프라인 안에서 평균과 표준편차를 학습 데이터로만 구하므로 교차검증에서도 누수가 없기 때문입니다. 1000 으로 나누는 방식은 상수 하나를 사람이 정한 것이라 데이터가 바뀌면 다시 정해야 합니다.

2. 아래 코드를 코드 1 뒤에 이어 붙여 실행합니다(X12, y12 사용).

# 8장 · 과제 2for g in (0.01, 1, 100):
    m = SVC(C=1, gamma=g).fit(X12, y12)
    at_C = (np.abs(m.dual_coef_) > 1 - 1e-6).sum()
    print(g, m.n_support_.sum(), m.score(X12, y12), at_C)

# 출력0.01 12 0.75 12
1 11 1.0 1
100 12 1.0 12

각 줄은 γ · 서포트 벡터 수 · 학습 정확도 · \(\alpha = C\) 인 점 수입니다. γ = 0.01 은 12 점이 모두 서포트 벡터이고 모두 \(\alpha = C\) 이며 정확도 0.75(3 점 틀림)입니다. 경계가 너무 완만해 안쪽과 바깥을 가르지 못한 과소적합입니다. \(\gamma = 1\)(6장 · 7장의 값)은 서포트 벡터 11 개 중 한 점만 \(\alpha = C\) 이고 정확도 1.0 입니다. \(\gamma = 100\) 은 다시 12 점 모두 서포트 벡터이며 모두 \(\alpha = C\) 이고 정확도는 1.0 입니다. 영향 범위가 아주 좁아 점마다 따로 노는(커널 행렬이 단위행렬에 가까운) 상태입니다.

왜 학습 정확도로 고르면 안 되는가 — \(\gamma = 1\) 과 \(\gamma = 100\) 의 학습 정확도가 같아서 구분할 수 없고, 화면 2 의 표에서는 학습 점수가 1.00 인 칸의 교차검증 점수가 0.81~0.83 으로 최고 0.91 보다 낮았습니다. 12 점으로는 따로 둔 점이 없어 \(\gamma = 100\) 이 과적합이라고 단정할 수는 없지만, 학습 정확도만으로는 판단할 근거가 없다는 것은 분명합니다.

흔한 실수 1 — 스케일러를 전체 데이터로 맞춘 뒤 나누는 것(누수). 흔한 실수 2 — \(\alpha = C\) 인 점을 \(\alpha = 0\) 과 같은 ‘쓸모없는 점’으로 보는 것. 5장에서 보았듯 \(\alpha = C\) 는 마진을 침범했거나 틀린 점으로, 모델에 가장 크게 기여합니다. 이 교재가 가는 길 — 직접 만들어 본 SVM 이 SVC 와 같은 답을 낸 것을 확인했으니, 이제 SVC 의 속성을 읽을 수 있고, 모르는 설정을 만나도 쌍대 · 마진 · 커널의 말로 해석할 수 있을 것입니다.
