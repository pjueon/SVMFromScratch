# 밑바닥부터 시작하는 SVM — 마진·쌍대문제·커널 트릭을 손으로 풀어 보는 서포트 벡터 머신

SVM(서포트 벡터 머신)을 예전에 간단히 배웠지만 쌍대문제와 커널 트릭은 제대로 짚어 보지 못한 독자를 위한 학습 교재입니다.
공식을 외우는 것이 아니라 "식이 왜 그렇게 나오는가"를 이해하는 것이 목표입니다. 직선 하나로 점을 가르는 데서 출발해 마진, 라그랑주·KKT, 쌍대문제 유도, 소프트 마진, 커널 트릭을 차례로 쌓고,
마지막에는 NumPy로 SMO를 직접 구현해 scikit-learn과 같은 답이 나오는지 확인합니다.
2차원 점 세 개 `(3,3)+, (4,3)+, (1,1)−`로 시작하는 하나의 예제가 장마다 이상치와 원형 데이터를 만나며 자라는 구조입니다.
장 하나는 HTML 파일 하나이고, 장 안은 화면 단위로 넘겨 읽습니다. 코드는 Python(NumPy, scikit-learn)입니다.

## 대상 독자

- 벡터와 내적은 알지만 편미분과 Σ 같은 수학 표기는 가물가물한 사람(필요한 만큼 교재 안에서 다시 설명합니다)
- SVM의 마진, 서포트 벡터라는 말을 들어 본 적은 있지만 쌍대문제와 커널 트릭을 "왜"까지 이해하지 못한 사람
- SVM을 쓸지 말지 스스로 판단할 수 있는 감각을 원하는 사람

## 시작하기

`docs/index.html` 파일을 브라우저로 열어서 읽으면 됩니다. 서버나 설치는 필요 없고 `file://`로 동작합니다.
화면은 방향키(← →)나 아래쪽 버튼으로 넘기고, 읽은 위치는 그 브라우저에 저장됩니다.
본문에 "화면 N" 참조가 나오면 누르면 그 화면으로 이동하고, 아래쪽에 돌아가기 버튼이 나옵니다.

## 한 예제가 자라는 길

점 3개 손계산(2장 검증, 4장 쌍대 풀이 `α=(¼,0,¼)`, `w=(½,½)`, `b=−2`) → 이상치 한 점이 끼면 하드 마진이 무너진다(5장, 소프트 마진) → 원형으로 둘러싼 데이터는 직선으로 못 가른다(6장, 커널) → 같은 값을 NumPy 코드로 재현하고 scikit-learn과 비교(7·8장).

## 직접 돌려 보기

교재에는 실행 파일을 따로 넣지 않았습니다. 7·8장의 코드를 직접 돌려 보려면 Python에 `numpy`와 `scikit-learn`을 설치한 뒤, 각 장의 코드 블록을 화면 순서대로 이어 붙여 실행하면 됩니다.
본문의 출력은 그렇게 코드를 추출해 실제로 실행한 결과를 적은 것이고, 사용한 scikit-learn 버전(1.9.1)은 8장 본문에 밝혀 두었습니다. 버전이 다르면 일부 출력이나 경고가 달라질 수 있습니다.
7장의 SMO 구현은 학습용이며, 대규모 데이터에는 scikit-learn(`SVC`)을 쓰라고 안내합니다.

## 제작 방식과 검증

이 교재는 `textbook-html` 플러그인으로 만들었습니다. 장마다 집필 에이전트가 쓰고, 독립된 리뷰 에이전트가 검수한 뒤 통과한 장만 커밋했습니다.
검수에서는 모든 수식과 손계산을 독립적으로 다시 계산하고, 위젯의 풀이 코드는 독립 기준 풀이와 대조했으며, 7·8장의 코드는 추출해서 실제로 실행해 출력을 비교했습니다.
헤드리스 브라우저로 런타임 점검(`authoring/_smoke.html`), 장별 가로 넘침·화면 수·용어 툴팁 점검을 했고, 마지막에 8개 장 전체의 상호 참조·표기·수치 일관성을 한 번 더 점검했습니다.
작업 방식은 `authoring/02-작업방식.md`, 장 사이 약속과 용어는 `authoring/03-진행-장부.md`에 정리되어 있습니다.
