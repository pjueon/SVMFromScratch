# 밑바닥부터 시작하는 SVM — 마진, 쌍대문제, 커널 트릭을 직접 유도하며 배우는 서포트 벡터 머신

SVM(서포트 벡터 머신)을 처음 배우는 독자를 위한 학습 교재입니다.
공식을 외우는 것이 아니라 "식이 왜 그렇게 나오는가"를 이해하는 것이 목표입니다. 직선 하나로 점을 분류하는 데서 출발해 마진, 라그랑주·KKT, 쌍대문제 유도, 소프트 마진, 커널 트릭을 차례로 쌓고,
마지막에는 NumPy로 SMO를 직접 구현해 scikit-learn과 같은 답이 나오는지 확인합니다.
2차원 점 세 개 `(3,3)+, (4,3)+, (1,1)−`로 시작하는 하나의 예제를 장마다 이어 씁니다. 중간에 이상치와 원형 데이터를 추가하면서 새로운 문제를 하나씩 다룹니다.
장 하나는 HTML 파일 하나이고, 장 안은 페이지 단위로 넘겨 읽습니다. 코드는 Python(NumPy, scikit-learn)입니다.

## 대상 독자

- 벡터와 내적은 알지만 편미분과 Σ 같은 수학 표기는 기억이 잘 나지 않는 사람(필요한 만큼 교재 안에서 다시 설명합니다)
- SVM을 처음 배우며, 쌍대문제와 커널 트릭까지 "왜"를 이해하고 싶은 사람
- SVM을 쓸지 말지 스스로 판단할 수 있는 감각을 원하는 사람

## 관통 예제의 흐름

- 2~4장: 점 3개를 손으로 계산합니다. 2장에서 답을 검증하고, 4장에서 쌍대문제를 풀어 `α=(¼,0,¼)`, `w=(½,½)`, `b=−2`를 구합니다.
- 5장: 이상치 한 점을 추가하면 하드 마진을 쓸 수 없습니다. 이 문제를 소프트 마진으로 해결합니다.
- 6장: 원형으로 둘러싼 데이터는 직선으로 분류할 수 없습니다. 이 문제를 커널로 해결합니다.
- 7·8장: 같은 값을 NumPy 코드로 재현하고 scikit-learn과 비교합니다.

## 직접 돌려 보기

교재에는 실행 파일을 따로 넣지 않았습니다. 7·8장의 코드를 직접 돌려 보려면 Python에 `numpy`와 `scikit-learn`을 설치한 뒤, 각 장의 코드 블록을 페이지 순서대로 이어 붙여 실행하면 됩니다.
본문의 출력은 그렇게 코드를 추출해 실제로 실행한 결과를 적은 것이고, 사용한 scikit-learn 버전(1.9.1)은 8장 본문에 밝혀 두었습니다. 버전이 다르면 일부 출력이나 경고가 달라질 수 있습니다.
7장의 SMO 구현은 학습용이며, 대규모 데이터에는 scikit-learn(`SVC`)을 쓰라고 안내합니다.

## 제작 방식과 검증

이 교재는 `textbook-html` 플러그인으로 만들었습니다. 장마다 집필 에이전트가 쓰고, 독립된 리뷰 에이전트가 검수한 뒤 통과한 장만 커밋했습니다.
검수에서는 모든 수식과 손계산을 독립적으로 다시 계산하고, 위젯의 풀이 코드는 독립 기준 풀이와 대조했으며, 7·8장의 코드는 추출해서 실제로 실행해 출력을 비교했습니다.
헤드리스 브라우저로 런타임 점검(`authoring/_smoke.html`), 장별 가로 넘침·페이지 수·용어 툴팁 점검을 했고, 마지막에 8개 장 전체의 상호 참조·표기·수치 일관성을 한 번 더 점검했습니다.
작업 방식은 `authoring/02-작업방식.md`, 장 사이 약속과 용어는 `authoring/03-진행-장부.md`에 정리되어 있습니다.
