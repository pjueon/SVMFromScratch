# SVM(서포트 벡터 머신) 학습 교재 제작 기획서

## 1. 목적과 대상 독자
- 목적: SVM 을 "공식 암기"가 아니라 **왜 그런 식이 나오는지** 이해하게 만든다. SVM 을 처음 배우는 독자에게
  **마진**부터 **쌍대문제(dual problem)**, **커널 트릭** 까지 처음부터 차근차근 풀어, 마지막에 NumPy 로 직접 구현하고
  scikit-learn 으로 쓸 수 있게 한다. 블로그 글 모음이 아니라 한 권의 책. 문체는 '밑바닥부터 시작하는 딥러닝' 처럼
  친절하고 대화하듯, 한국어 존댓말.
- 독자가 **전제하지 않아도 되는 것**(= 교재가 설명해야 하는 것): 편미분, 기울기(gradient), 제약 있는 최적화,
  라그랑주 승수법, KKT 조건, 쌍대성, 특징 공간(feature space), 커널 함수, 힌지 손실, 정규화 개념,
  행렬의 전치·곱셈 표기, Σ 기호 읽는 법.
- 독자가 **전제해도 되는 것**: 벡터와 내적의 기본 개념, 직선의 방정식, 파이썬 기본 문법(변수·반복문·함수),
  "머신러닝에서 분류란 무엇인가" 정도의 감. SVM 은 처음 배우는 것으로 본다.
- 독자 수학 수준: **벡터·내적은 알고 편미분은 기억이 흐릿함.** → 1장에서 내적을, 3장에서 편미분을 복습한다.

## 2. 학습 목표
다 읽은 뒤 독자는:
1. 데이터를 분류하는 초평면과 마진을 식으로 쓰고, "마진 최대화"가 왜 `||w||` 최소화가 되는지 설명할 수 있다.
2. 라그랑주 승수법과 KKT 조건으로 제약 있는 최적화 문제를 손으로 풀 수 있다.
3. SVM 의 원문제에서 **쌍대문제를 직접 유도**하고, 서포트 벡터가 왜 소수의 점인지 설명할 수 있다.
4. 소프트 마진의 `C` 가 무엇을 조절하는지, 힌지 손실과 어떻게 연결되는지 말할 수 있다.
5. **커널 트릭**이 왜 "고차원으로 보내지 않고도 고차원 내적을 계산"하게 해 주는지 설명하고, RBF 의 `γ` 를 조절할 수 있다.
6. NumPy 만으로 (간이) SMO 기반 SVM 을 구현하고, scikit-learn 결과와 비교할 수 있다.
7. SVM 을 쓰지 않을 때(대용량, 확률 출력 필요, 특성 스케일 방치 등)를 판단할 수 있다.

## 3. 기준 예제 — 2차원 점 데이터
- 설정: **2차원 평면 위의 점들.** 장마다 점을 늘리고 모양을 바꾼다. 점 3개(손계산) → 점 구름(선형 분리) →
  이상치 한 점 → 원형으로 둘러싼 데이터(비선형).
- 고른 이유: (1) 평면이라 마진·초평면·서포트 벡터를 **눈으로** 볼 수 있다. (2) 점 3개면 쌍대문제를 손으로 끝까지 푼다.
  (3) 선형 → 이상치 → 비선형으로 SVM 의 세 가지 핵심 문제가 자연스럽게 순서대로 드러난다.
- **손계산 기준 데이터(고정):**
  `x₁=(3,3), y₁=+1` / `x₂=(4,3), y₂=+1` / `x₃=(1,1), y₃=−1`
  정답: `w=(1/2, 1/2)`, `b=−2`, `α=(1/4, 0, 1/4)`, 마진 폭 `2/||w|| = 2√2`. x₂ 는 서포트 벡터가 아니다(α₂=0).
  이 한 세트를 2·3·4·7장에서 반복해 쓴다. (정답은 집필 시 반드시 재검산)
- 용어표:

| 낱말 | 뜻 | 무엇과 다른가 |
|---|---|---|
| 초평면(결정경계) | `w·x+b=0` 인 점들의 집합 (2차원에선 직선) | 마진 경계선(`=±1`)과 다름 |
| 마진 | 경계에서 가장 가까운 점까지 거리의 2배, `2/||w||` | 함수 마진(`y(w·x+b)`)과 다름 — 기하 마진 |
| 서포트 벡터 | 마진 경계 위에 놓여 경계의 위치를 정하는 점 (`α>0`) | 그냥 가까운 점이 아님. 쌍대에서 α≠0 인 점 |
| 원문제(primal) | `w, b` 를 변수로 하는 최적화 | 쌍대문제는 α 가 변수 |
| 쌍대문제(dual) | α(라그랑주 승수)를 변수로 하는 최적화 | 같은 답을 구하는 다른 방법 |
| 슬랙 변수 ξ | 마진을 침범한 정도 | 오차 자체가 아니라 "허용량" |
| 커널 | `K(x,z)=φ(x)·φ(z)` 인 함수 | φ 를 실제로 계산하지 않음 |

- 교재 중반에 들어오는 **새 요구사항:**
  - 5장: 깨끗하던 데이터에 **이상치 한 점**이 추가된다 → 하드 마진을 쓸 수 없다.
  - 6장: 점들이 **원형으로 안팎에 놓여** 직선으로 절대 분류할 수 없다 → 커널이 필요해진다.
- 의도적으로 미룰 것과 갚는 곳:
  - 쌍대문제의 "왜 내적만 등장하는가" → 4장에서 `.later` 로 남기고 **6장 커널 트릭에서 갚는다.**
  - 라그랑주/KKT 의 "부등식 제약" → 3장에서 처음 보고 4장에서 본격 사용.
  - SMO 의 정당성 증명 → 7장에서 직관만, 증명은 생략(원전 표기).
  - Mercer 정리 → 6장에서 "조건이 있다"만 말하고 증명 생략.

- **표기 규약(1장에서 확정, 전 장 공통):** `i`번째 점은 위첨자 괄호 `x⁽ⁱ⁾`, `y⁽ⁱ⁾`, `α⁽ⁱ⁾`(HTML `<sup>(i)</sup>`),
  좌표는 아래첨자 `x₁, x₂`. 따라서 손계산 기준 데이터는 `x⁽¹⁾=(3,3), x⁽²⁾=(4,3), x⁽³⁾=(1,1)` 이고,
  쌍대문제는 `Σ α⁽ⁱ⁾y⁽ⁱ⁾x⁽ⁱ⁾` 로 쓴다(위 표의 `x₁,x₂,x₃`·`αᵢ` 표기는 이 규약으로 읽는다).

## 4. 형태 — 결정 사항
- 장 = HTML 파일 1개(`ch01.html`…`ch08.html`), 장 안은 페이지(`section.screen`).
- `file://` 로 열린다. fetch / module / CDN / 외부 폰트 금지. 수식은 **LaTeX 로 쓰고 `\( … \)`(인라인), `\[ … \]`(별행)로 감싼다.**
  렌더러는 `docs/assets/katex/` 에 함께 들어 있는 KaTeX 로, CDN 없이 오프라인으로 동작한다(math.js 가 book.js 직전에 실행).
  코드 식별자(`SVC`, `np.dot` 등)는 수식이 아니라 `<code>` 로 둔다. 복잡한 식은 SVG 를 쓴다.
- 넣을 인터랙티브 위젯(전부 인라인 SVG + 자체 JS):
  1. **초평면 돌려보기** (1·2장): 기울기·절편 슬라이더, 점들의 부호가 바뀌는 것 확인
  2. **마진 시각화** (2장): 직선을 움직이며 마진 폭과 `||w||` 관계 확인
  3. **서포트 벡터 끌어보기** (4장): 점을 옮겼을 때 서포트 벡터가 아닌 점은 해가 안 변함을 확인
  4. **C 슬라이더** (5장): 이상치가 있을 때 C 에 따른 경계·마진 변화
  5. **커널 변환 (2D→3D)** (6장): 원형 데이터를 `z=x²+y²` 축을 더해 올리면 평면으로 분류되는 모습
  6. **RBF γ 슬라이더** (6장): γ 에 따라 결정경계가 뭉툭↔뾰족해지는 모습
- **넣지 않을 것:** 브라우저 내 파이썬 실행(Pyodide), 3D 라이브러리(3D 는 SVG 로 투영해서 표현), 실시간 SVM 학습 위젯
  (학습은 7장 NumPy 코드로 보여주고, 위젯은 미리 계산한 결과를 쓴다. 단 4·5·6장 위젯은 SMO 를 수십 줄 JS 로
  내장해 즉석 학습시켜도 된다 — 자체 완결이므로 외부 의존이 아니다. 구현이 과하면 사전 계산 테이블로 대체).

## 5. 서술 방침
- **개념 → 이름 순서.** "점들을 분류하는 직선이 무수히 많다 → 어느 직선이 좋을까?"에서 시작해 마진이라는 이름을 나중에.
- 1장을 ‘직선을 아무거나 그어도 되나?’라는 **문제**로 시작한다(퍼셉트론처럼 아무 직선이나 나오는 문제).
- 수식은 나올 때마다 **기호 하나하나 뜻을 적고**, 점 3개 예제 숫자로 대입해 본다.
- 편미분은 3장에서 "한 변수만 움직이고 나머지는 고정"이라는 직관부터 복습한다.
- 쌍대문제 유도는 **한 줄씩** 쓰고, 각 줄 옆에 "왜 이렇게 되는지"를 단다. 건너뛰지 않는다.
- 코드 해설: 20줄 넘으면 `ol.notes`, 구조(알고리즘 흐름)를 코드보다 먼저.
- 한계·반례를 숨기지 않는다: 하드 마진은 이상치에 약함, 커널 SVM 은 대용량에 느림, 확률 출력은 기본 제공 안 됨,
  특성 스케일링 필수, 딥러닝/트리 계열이 더 나은 경우.
- 원전 표기: Vapnik, Cortes & Vapnik(1995), Boser·Guyon·Vapnik(1992, 커널), Platt(1998, SMO),
  Bishop *PRML* 7장, 이호준/Li Hang *통계학습방법* 7장 등으로 다음 책을 가리킨다.
- 반대 의견도 쓴다: "요즘은 딥러닝/그래디언트 부스팅이 대세인데 SVM 을 왜 배우나?" → 8장에서 답한다.
