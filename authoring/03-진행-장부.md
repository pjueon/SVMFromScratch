# 진행 장부

서브에이전트 간 인계 기록. 갚은 약속은 줄을 지우고, 장 집필 후 집필자가 갱신한다.

## 미결 약속

| 약속 | 한 장 | 갚을 장 |
|---|---|---|
| 정답 직선 `x₁+x₂−4=0`(=`½x₁+½x₂−2=0`)이 가장 먼 직선임을 식으로 확인, 왜 ½ 꼴인가 | 1장 화면 4 | 2장 |
| 점과 직선 사이 거리 공식, "값 2·3은 거리가 아니다"의 해명 | 1장 화면 3 | 2장 |
| `y(w·x+b)>0` 한 줄이 제약 조건의 씨앗 | 1장 화면 3 | 2장 |
| x⁽²⁾가 직선 결정에 필요 없는 이유 | 1장 화면 4 | 4장 |
| 이상치 → 소프트 마진 | 1장 화면 4 | 5장 |
| 원형 데이터 → 커널 | 1장 화면 4 | 6장 |
| 1장 화면 1 기호 상자의 "3~4장에서 손으로 SVM 의 답을 구하고"는 실제로 **4장**(3장은 라그랑주·KKT) — 1장 표현 수정 필요 | 1장 화면 1 | 수정 모드로 정정 |

## 용어·기호

| 용어/기호 | 정의한 장·화면 | 한 줄 뜻 |
|---|---|---|
| 분류, 레이블 y(±1), 특성, 학습 데이터 | 1장 화면 1 | 점(특성)에 붙은 정답표 |
| `x⁽ⁱ⁾`(i번째 점), `x₁,x₂`(좌표) | 1장 화면 1 | 표기 규약(00-기획.md) |
| 관통 예제 | 1장 화면 1 | `x⁽¹⁾=(3,3)+1, x⁽²⁾=(4,3)+1, x⁽³⁾=(1,1)−1`, 새 점 `q=(2,3)` |
| `w`, `b`, `w·x+b=0`, 결정경계, 초평면 | 1장 화면 2 | 직선의 방정식을 벡터로 쓴 것 |
| 내적, 노름 `‖w‖`, 법선 벡터 | 1장 화면 3 | `w` 는 직선에 수직 |
| `f(x)=w·x+b`, `sign` | 1장 화면 3 | 부호로 분류, 0이면 직선 위 |
| 퍼셉트론 | 1장 화면 4(툴팁) | 아무 직선이나 찾는 옛 방법 |

## 장별 기록

### 1장 — 점들을 가르는 직선 (02cd09f)
- 화면: 1 문제 상황 / 2 직선을 `w·x+b` 로 / 3 내적과 부호(초평면 위젯) / 4 아무 직선이나? / 5 요약·퀴즈·과제
- 뒷장이 알아야 할 것: 가르는 직선 4개(가·나·다·라)로 판정이 갈린다는 예, 위젯 SVG 좌표계(x₁,x₂ 0~6).
- 커리큘럼과 달라진 점: 없음.
