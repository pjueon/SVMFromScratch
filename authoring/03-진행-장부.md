## 장별 기록

### 1장 — 점들을 가르는 직선 (02cd09f)
- 화면: 1 문제 상황 / 2 직선을 `w·x+b` 로 / 3 내적과 부호(초평면 위젯) / 4 아무 직선이나? / 5 요약·퀴즈·과제
- 뒷장이 알아야 할 것: 가르는 직선 4개(가·나·다·라)로 판정이 갈린다는 예, 위젯 SVG 좌표계(x₁,x₂ 0~6).
- 커리큘럼과 달라진 점: 없음.

### 2장 — 마진과 하드 마진 SVM (커밋 해시는 git log 참조)
- 화면: 1 가장 안전한 직선(띠·마진 직관) / 2 점과 직선 사이 거리 / 3 스케일 고정과 마진 폭(마진 위젯) / 4 최적화 문제로 쓰기 / 5 점 3개로 정답 검증 / 6 요약·퀴즈·과제
- 갚은 약속: 정답 직선 검증(½ 꼴 이유, 화면 5 에서 제약 1·3 을 더해 `½‖w‖²≥¼` 증명 — 이 예제에 한정된 요령임을 명시), 거리 공식·값≠거리, `y(w·x+b)>0` → `≥1` 제약의 씨앗.
- 뒷장이 알아야 할 것: 제약 3개는 `3w₁+3w₂+b≥1`, `4w₁+3w₂+b≥1`, `−w₁−w₂−b≥1`. 정답에서 함수 마진 1, 1.5, 1(x⁽²⁾는 여유 1.5), `‖w‖=1/√2`, `½‖w‖²=¼`, 마진 `2√2`. 1장 네 직선의 정규화 값 `½‖w‖²`: 가 4, 나 ¼, 다 4, 라 2. 위젯 id 접두어 `m-`, 좌표계는 1장과 같음. 3장 몫: "w=0 이 제약 없는 최솟값이지만 가능해가 아님 → 제약 있는 최적화는 어떻게 푸나"(화면 4 끝에 `.later` 로 표시).
- 4장 몫 유지: x⁽²⁾가 필요 없는 이유, "서포트 벡터" 이름(2장은 '딱 닿음/여유 있음'으로만 기술, 서포트 벡터 용어는 정의하지 않음).
- 커리큘럼과 달라진 점: 없음(화면 6).

### 3장 — 제약 있는 최적화 기초 (커밋 해시 미정)
- 화면: 1 편미분과 기울기 복습 / 2 등고선과 제약선이 접하는 곳(접점 위젯, id 접두어 `t-`) / 3 라그랑주 승수법 / 4 부등식 제약: 활성과 비활성 / 5 KKT 조건 네 줄 / 6 요약·퀴즈·과제
- 갚은 약속: 2장 "w=0 은 가능해가 아님 → 제약 있는 최적화는 어떻게 푸나", 2장 "작게 하고 싶은 욕심과 제약의 균형".
- 뒷장이 알아야 할 것: 규약 `min J s.t. g≥0`, `L=J−λg`, `λ≥0`, `λg=0`(4장 SVM 에서 `g⁽ⁱ⁾=y⁽ⁱ⁾(w·x⁽ⁱ⁾+b)−1`, λ→α). 손계산 예: `min ½(w₁²+w₂²) s.t. w₁+w₂=1` → w=(½,½), λ=½, J=¼(2장 화면 5 의 ¼ 와 일치). 부등식 A(`w₁+w₂−1≥0`) 활성 λ=½, B(`w₁+w₂+1≥0`) 비활성 λ=0. 1변수 `½w² s.t. w≥1` → w=1, λ=1. 두 제약 예 `g₁=w₁−1, g₂=w₂+1` → w=(1,0), λ=(1,0). 화면 5 끝에서 "제약 2 의 승수는 0 이어야 한다"고 예고만 함(값 α=(¼,0,¼) 는 미언급, 서포트 벡터 용어 미사용). KKT 는 그릇 모양+직선 제약이면 충분조건(증명 생략)이라고 명시.
- 커리큘럼과 달라진 점: 없음(화면 6). 퀴즈 정답 위치 3/1/2.

### 4장 — 쌍대문제 유도 (커밋 해시 미정)
- 화면: 1 전체 흐름(블록도) / 2 SVM 의 라그랑지안(Σ 읽는 법) / 3 w,b 로 편미분 / 4 대입해서 w,b 지우기(ΣΣ 격자, 줄별 검산) / 5 쌍대문제 완성('쌍대'의 뜻, 약·강쌍대성) / 6 서포트 벡터(위젯) / 7 점 3개 손계산 / 8 요약·퀴즈·과제
- 갚은 약속: 라그랑지안 세우기, w·x 편미분(화면 3), '쌍대' 이름, 서포트 벡터 이름, x⁽²⁾ 불필요(화면 6), λ→α.
- 새 약속: 쌍대에 내적만 남음 → 6장(`.later` 는 화면 5, 화면 7 끝에는 `.later` 없이 본문 언급). 5장은 기존 약속(못 가르는 배치)만 언급.
- 뒷장이 알아야 할 것: 손계산 값 α=(¼,0,¼), w=(½,½), b=−2, D=¼. 그램 값 18,21,6,25,7,2(레이블 곱 후 18,21,−6,25,−7,2). 제약 α⁽¹⁾+α⁽²⁾−α⁽³⁾=0, 두 변수식 `D=2a₁+2a₂−4a₁²−10a₁a₂−6.5a₂²`(후보 (3/2,−1) 탈락, (0,2/13) 탈락, (¼,0) 통과). 예측식 w·q+b=Σα⁽ⁱ⁾y⁽ⁱ⁾(x⁽ⁱ⁾·q)+b 를 화면 6 끝에서 보임(q=(2,3) → ½). 위젯은 하드 마진 브루트포스 JS(2~3 점 조합), 점 ≤6, 0.25 격자. 과제 예: (2,0)+1,(0,0)−1 → α=(½,½), w=(1,0), b=−1. 5장 예고용: 쌍대문제 한 줄(0≤α≤C)만 바뀐다.
- 커리큘럼과 달라진 점: 없음(화면 8). 퀴즈 정답 위치 2/3/1.
- 주의: 4장은 7장 예고를 쓰지 않았다.

### 5장 — 소프트 마진 (커밋 해시 미정)
- 화면: 1 이상치가 끼면(정적 SVG 두 패널) / 2 슬랙 변수 ξ / 3 C 의 의미와 위젯(id 접두어 `c-`) / 4 쌍대문제와 힌지 손실 / 5 요약·퀴즈·과제
- 갚은 약속: 이상치 → 소프트 마진(1장 화면 4), 못 가르는 데이터에서 가능해 없음(2장 화면 4·4장 화면 6).
- 새 약속: 없음. 6장 `.later` 는 화면 3 한계 상자에서 "원형 데이터는 C 로 안 고쳐짐" 하나(커리큘럼의 '넘기는 것').
- 뒷장이 알아야 할 것: 이상치 `x⁽⁴⁾`: 강한 (0.5,0.5)+ (가능해 없음), 약한 (1.5,1.5)+ (하드 마진 `w=(2,2), b=−5`, 마진 √2/2, 이상치 없을 때의 ¼). 위젯용 도우미 점 `x⁽⁵⁾=(3,4.5)+, x⁽⁶⁾=(0,1.5)−, x⁽⁷⁾=(1.5,0)−` (세 점 답 `w=(½,½), b=−2` 유지, 3점+강한 이상치는 모든 C 에서 w=0 이라 도입). 4점(세 점+약한 이상치) 손풀이: `C≤4` 에서 `α=(0,0,C,C)`, `w=(C/2,C/2)`, 목적값 `2C−C²/4`, `C≥4` 하드 마진. 하드 마진 α 최댓값 ≤ C 이면 소프트=하드(깨끗한 3점은 C≥¼). b 는 0<α<C 점에서, 없으면 구간(4점 C=1: [−2,−½]). 위젯은 쌍대 SMO(좌표상승) 자체 구현 `solveSoft(P,C)`, b 는 자유 SV 평균, 없으면 KKT 구간 가운데. 내적 `x·x` 가 쌍대에 그대로 있음은 표에서 한 줄만(6장 예고 새로 안 씀).
- 커리큘럼과 달라진 점: 없음(화면 5). 퀴즈 정답 위치 1/3/2.

### 6장 — 커널 트릭 (커밋 해시 미정)
- 화면: 1 새 요구사항(원형 12점, 정적 SVG, 섞기 논법·Σξ≥2, 직선 최선 3점 오분류) / 2 차원을 올리면 갈린다(2D→3D 위젯, id 접두어 `l-`) / 3 특징 맵 φ 와 비용(C(p+d,d) 표) / 4 쌍대에 내적만 남았다→커널 함수 K·그램 행렬(`.later` 갚음) / 5 손으로 확인 `(x·z)²`, 이름 "커널 트릭" / 6 대표 커널·RBF·무한 차원·γ·C 위젯(canvas, id 접두어 `k-`) / 7 Mercer 조건·예측식·한계 / 8 요약·퀴즈(정답 2/1/3)·과제(XOR)
- 갚은 약속: 원형 데이터(1장 화면 4, 5장 화면 3), 쌍대에 내적만 남음(4장 화면 5).
- 새 약속: 커널 쌍대문제 풀이 → 7장(커리큘럼 '넘기는 것', 화면 4 `.later`). 그 밖의 새 약속 없음(확률 출력·스케일링은 화면 7 에서 "한계"로만 언급, 장 번호 안 씀).
- 뒷장이 알아야 할 것: 7장이 구현할 식 — `max Σα−½ΣΣα⁽ⁱ⁾α⁽ʲ⁾y⁽ⁱ⁾y⁽ʲ⁾K_ij s.t. 0≤α≤C, Σαy=0`, 예측 `f(x)=Σα y K(x⁽ⁱ⁾,x)+b`, `b` 는 0<α<C 점들의 `y−Σα y K` 평균(없으면 구간). 커널 시그니처 `K(x,z)`, 그램 `K[i][j]`. 이 장 데이터(원형 12점, 원점 중심): 안쪽 +1 (0,0),(0.9,0.3),(0.5,−0.8),(−0.6,−0.6),(−1,0.4),(−0.3,1); 바깥 −1 (2.2,0.4),(−2.2,−0.4),(1.2,2.2),(−1,2.3),(−0.8,−2.2),(1.6,−1.8). 수평 분리 평면 1.16<c<5. 위젯의 `solveKernel(P,C,kern)`/`decision` 는 5장 `solveSoft` 의 커널판(최대 위반 쌍 좌표상승, tol 1e-10). 검증 값: RBF γ=1,C=1 → D=4.53924, b=−0.36583. XOR 손계산 `K=(x·z+1)²`: 그램 대각 9·나머지 1, α=⅛ 넷, D=¼, f=x₁x₂, b=0. 직선 최선 오분류 3점(LP 전수 확인).
- 커리큘럼과 달라진 점: 없음(화면 8). 7장은 SMO 를 6장에서 설명하지 않았음.

### 7장 — 밑바닥부터 구현 (NumPy, SMO) (커밋 해시 미정)
- 화면: 1 전체 구조(블록도·함수 표) / 2 두 개씩 움직이는 이유(제약·[L,H] 그림·한 변수 2차함수 유도 ①~⑦·점 3개 첫 갱신) / 3 커널 행렬과 헬퍼(NumPy 맛보기, 커널, violating_pair·clip_range, bias) / 4 SMO 본체(`smo`, 12점 한 단계씩 위젯 id 접두어 `s-`) / 5 클래스 `SVM`·3점·12점·sklearn 비교·b 구간·한계 / 6 요약·퀴즈(정답 3/2/1)·과제((2,3) 쌍 먼저 고르기)
- 갚은 약속: 6장 화면 4 "커널 쌍대문제를 컴퓨터가 푸는 방법". 새 약속: 8장 `SVC` 사용법(화면 5 `.later` 하나).
- 뒷장이 알아야 할 것(코드 파일 `svm.py` = 블록 이어 붙임, numpy 기반, sklearn 은 `from sklearn.svm import SVC` 로 비교에만 사용):
  - `linear_kernel(X, Z)`, `rbf_kernel(X, Z, gamma=1.0)` → n×m 표
  - `violating_pair(E, y, a, C) -> (i, j)`, `clip_range(ai, aj, yi, yj, C) -> (L, H)`, `bias(E, y, a, C, eps=1e-8) -> b`
  - `smo(K, y, C, tol=1e-10, max_iter=100000) -> (alpha, n_iter)` (E 를 매번 `K @ (a*y) - y` 로 재계산, 최대 위반 쌍 좌표상승)
  - `class SVM(C=1.0, kernel="rbf", gamma=1.0, tol=1e-10, max_iter=100000)`; `fit(X, y) -> self`, `decision_function(X)`, `predict(X)`(f≥0 → +1); 속성 `X_, y_, alpha_, b_, support_`(0 기반), `n_iter_`, `dual_`. kernel 은 "linear"/"rbf" 만.
  - 결과 수치: 점 3개 `SVM(C=10,"linear")` → α=(¼,0,¼), b=−2, n_iter=1, w=(½,½), D=¼, f(2,3)=½. 원형 12점 `SVM(C=1,"rbf",gamma=1)` → D=4.53924, b=−0.36583, SV=2~12번(x⁽¹⁾ 만 α=0, x⁽²⁾ α=1=C), n_iter=67(환경에 따라 달라질 수 있음; JS 위젯은 59). α=[0,1,0.9394,0.85546,0.77722,0.91462,0.81696,0.79481,0.66439,0.75392,0.71675,0.73986].
  - sklearn 비교(SVC rbf γ=1 C=1): 기본 tol=1e-3 에서 α 최대차 3.7e-4·b 차 1.3e-5, tol=1e-10 에서 1.2e-8·2.2e-9, SV 집합 같음. 3점 `SVC(linear, C=10)`: support_+1=[3 1], dual_coef_=[[-0.25 0.25]], intercept_=[-2]. 5장 4점(C=1, linear): α=(0,0,1,1), b 구간 [−2,−½], 우리·SVC 모두 −1.25(중점 규칙이 우연히 같다고 서술).
  - 한계로 쓴 것: O(n²) 메모리(1만→0.8GB), 반복마다 O(n²), 단순한 쌍 선택(LIBSVM 은 2차 정보, Fan·Chen·Lin 2005), tol·수치, 두 레이블 가정, 증명 생략. 8장은 이 중 확률 출력·스케일링 등을 새로 다룰 수 있음(7장은 언급 안 함).
- 커리큘럼과 달라진 점: 없음(화면 6). 코드 검증: 블록 추출 실행 출력 일치(numpy/sklearn 버전은 보고 참조).
