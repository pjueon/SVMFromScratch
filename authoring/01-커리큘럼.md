# SVM 교재 커리큘럼

총 8장 · 48화면 · 화면당 약 10분 → 약 8시간. 마지막 화면은 항상 요약·퀴즈·과제.
허리 장(핵심): 2장, 4장, 6장.

### 1장 — 점들을 분류하는 직선 (분류와 선형 분류기)
- **화면 5 · 약 50분**
- 다룰 것:
  1. 문제 상황: 파란 점과 빨간 점, 새 점은 어느 쪽? (분류 문제)
  2. 직선으로 가르기 — 직선의 방정식을 `w·x+b=0` 로 다시 쓰기
  3. 내적 복습: 내적이 "방향이 얼마나 같은가"를 재는 도구, `w` 가 직선의 법선 벡터인 이유 (위젯: 초평면 돌려보기)
  4. 아무 직선이나 그어도 될까? 가르는 직선이 무수히 많다는 아픔, 그리고 "더 나은 직선"의 직관 맛보기
  5. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 직선(초평면)이 무엇이고 점이 어느 쪽인지 어떻게 숫자로 알까?
- 받는 것: 없음 / 넘기는 것: `w·x+b` 의 부호로 분류한다는 틀, "어느 직선이 최선인가"라는 질문

### 2장 — 마진과 하드 마진 SVM
- **화면 6 · 약 60분**
- 다룰 것:
  1. 가장 안전한 직선 = 양쪽 점에서 가장 멀리 떨어진 직선 (마진의 직관)
  2. 점과 직선 사이 거리 공식 유도 (`|w·x+b| / ||w||`)
  3. 스케일 자유도 고정: `y(w·x+b) ≥ 1` 로 정규화하면 마진 = `2/||w||` (위젯: 마진 시각화)
  4. 최적화 문제로 쓰기: `min ½||w||²  s.t.  yᵢ(w·xᵢ+b) ≥ 1` — 왜 ½ 와 제곱을 붙이는가
  5. 점 3개 예제에 대입해 정답(`w=(½,½), b=−2`)을 검증 (손으로 풀기는 4장에서)
  6. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: "좋은 직선"을 어떻게 수식 하나로 쓸까?
- 받는 것: 1장의 초평면 / 넘기는 것: **제약이 있는 최적화 문제** → 어떻게 푸나? (→ 3장)

### 3장 — 제약 있는 최적화 기초 (라그랑주·KKT)
- **화면 6 · 약 60분**
- 다룰 것:
  1. 제약 없는 최적화 복습: 기울기가 0 인 곳, **편미분 복습** ("한 변수만 움직이기")
  2. 등식 제약이 붙으면: 등고선과 제약선이 "접하는 점" 직관
  3. 라그랑주 승수법: 라그랑지안 만들고 편미분 = 0 (손계산 예제 하나 끝까지)
  4. 부등식 제약으로 확장: 제약이 "활성/비활성"일 때 — λ>0 이면 경계 위, λ=0 이면 제약이 무관
  5. KKT 조건 네 줄 읽기 (정상성·원문제 가능성·쌍대 가능성·상보 여유성)
  6. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 부등식 제약이 있는 최적화를 어떻게 푸나, 그리고 "서포트 벡터"의 정체는 어디서 나오나?
- 받는 것: 2장의 제약 최적화 문제 / 넘기는 것: 라그랑지안, KKT, 상보 여유성 (`λ·g=0`)

### 4장 — 쌍대문제 유도
- **화면 8 · 약 80분**
- 다룰 것:
  1. 큰 그림: 원문제(w, b)에서 쌍대문제(α)로 가는 길 — 전체 흐름 먼저
  2. SVM 의 라그랑지안 세우기 (`αᵢ ≥ 0`, 기호 하나하나 해설)
  3. `w`, `b` 로 편미분해 0 으로 놓기 → `w=Σαᵢyᵢxᵢ`, `Σαᵢyᵢ=0`
  4. 대입해서 `w`, `b` 를 지우기 — 한 줄씩 (유도 핵심)
  5. 쌍대문제 완성: `max Σαᵢ − ½ΣΣ αᵢαⱼyᵢyⱼ(xᵢ·xⱼ)` 과 `.later` — "내적만 남았다!"
  6. 서포트 벡터의 정체: 상보 여유성에서 `α>0 ⇒ 마진 경계 위` (위젯: 점 끌어보기)
  7. **점 3개 손계산**: 쌍대문제를 직접 풀어 `α=(¼,0,¼)`, `w`, `b` 복원
  8. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 왜 굳이 쌍대로 푸는가? 서포트 벡터는 왜 소수인가?
- 받는 것: 3장의 라그랑주·KKT / 넘기는 것: **쌍대문제에 내적(xᵢ·xⱼ)만 있다**는 사실 → 6장에서 갚는다

### 5장 — 소프트 마진
- **화면 5 · 약 50분**
- 다룰 것:
  1. 새 요구사항: 이상치 한 점이 끼면 하드 마진은 해가 없거나 이상한 선이 된다
  2. 슬랙 변수 ξ — "조금은 침범해도 봐주자", 목적함수 `½||w||² + CΣξᵢ`
  3. `C` 의 의미와 위젯: 큰 C = 엄격, 작은 C = 관대 (위젯: C 슬라이더)
  4. 쌍대문제는 어떻게 바뀌나 (`0 ≤ αᵢ ≤ C` 한 줄 차이) + 힌지 손실로 다시 보기
  5. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 현실의 지저분한 데이터에는 어떻게 쓰나?
- 받는 것: 4장의 쌍대문제 / 넘기는 것: "그래도 직선으로는 못 가르는 데이터"가 있다는 문제

### 6장 — 커널 트릭
- **화면 8 · 약 80분**
- 다룰 것:
  1. 새 요구사항: 원형으로 둘러싼 데이터는 직선으로 못 가른다
  2. 아이디어: 차원을 올리면 갈린다 (`z=x²+y²`) (위젯: 2D→3D)
  3. 특징 맵 φ — 직접 계산하면 비싸다: 다항식 차수를 올릴 때 차원이 폭발하는 이야기
  4. **`.later` 갚기**: 쌍대문제엔 내적만 있다 → `φ(x)·φ(z)` 만 빠르게 계산하면 된다 → 커널 함수 `K(x,z)`
  5. 손으로 확인: 2차 다항 커널 `(x·z)²` 가 `φ(x)·φ(z)` 와 같음을 전개로 증명
  6. 대표 커널: 선형·다항·RBF(가우시안), RBF 가 "무한 차원"이라는 말의 뜻, γ 의 의미 (위젯: γ 슬라이더)
  7. 커널을 써도 되는 조건(Mercer, 직관만)과 커널 SVM 의 예측식 `f(x)=ΣαᵢyᵢK(xᵢ,x)+b`, 한계(대용량·과적합)
  8. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 직선으로 못 가르는 데이터를 어떻게 SVM 으로 가르나, 그리고 왜 계산이 싸지나?
- 받는 것: 4장의 "내적만 남는다", 5장의 소프트 마진 / 넘기는 것: 커널 쌍대문제 → 7장에서 구현

### 7장 — 밑바닥부터 구현 (NumPy, SMO)
- **화면 6 · 약 60분**
- 다룰 것:
  1. 전체 구조: 풀어야 할 문제(커널 소프트 마진 쌍대) 와 SMO 의 아이디어("두 개씩 골라 푼다")
  2. 왜 α 를 한 개가 아니라 두 개씩 움직여야 하나 (`Σαᵢyᵢ=0` 제약)
  3. 커널 행렬과 헬퍼 함수 (코드, `ol.notes`)
  4. SMO 본체 (간이 버전) 코드와 행별 해설
  5. 점 3개 예제·원형 데이터에 돌려보고 sklearn 결과와 비교, 구현의 한계
  6. 요약 · 퀴즈 · 과제
- 이 장이 답하는 질문: 쌍대문제를 컴퓨터가 어떻게 푸나?
- 받는 것: 6장 커널 쌍대문제 / 넘기는 것: `SVM` 클래스 → 8장에서 sklearn 과 비교
